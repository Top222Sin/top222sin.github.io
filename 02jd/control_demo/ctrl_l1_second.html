L1.1 二阶系统时域分析：ζ、ωn 与超调

一句话：一切二阶系统的动态品质由 ζ(阻尼比) 和 ωn(自然频率) 两个数字决定——超调只看 ζ，速度只看 ζ·ωn；这是”自动控制原理”课程第一根支柱。

三个公式（背下来）

推导链：这三个公式从哪来

标准二阶系统（单位负反馈 + 开环 ωn²/(s(s+2ζωn))）：

欠阻尼阶跃响应：y(t) = 1 − e^(−ζωn·t)/√(1−ζ²) · sin(ωd·t + φ)，其中 φ = acos(ζ)。

  • 超调 Mp：对 y(t) 求导令 y’=0 → 峰值出现在 t = π/ωd（第一个极值点）→ 代入得 **Mp = e^(−ζπ/√(1−ζ²))**。只看 ζ，与 ωn 无关。
  • **峰值时间 tp = π/ωd = π/(ωn√(1−ζ²))**：与 ωn 成反比（ωn 大 → 快）。
  • 调节时间 ts：包络线 e^(−ζωn·t) 衰减到 ±2% 带内 → ts ≈ 4/(ζ·ωn)（工程近似；单指数包络严格为 3.91/(ζωn)，但标准二阶响应还受 1/√(1−ζ²) 因子与穿越振荡影响，不普遍精确等于 3.91）。ζωn 是”实际快慢”的度量，工程上叫衰减率。

demo 验证

ζ ∈ {0.1, 0.3, 0.5, 0.707} 四组阶跃仿真，超调量与理论公式逐点对拍（差 <3e-5）。
ζ=0.707 是工程黄金值（Mp≈4.3%、频带最平）。

ζ 的五个区间（变体与边界）

ζ 类型 响应特征 工程判语
ζ=0 无阻尼 等幅振荡 不具备渐近稳定，持续振荡（扰动下风险高）
0<ζ<0.4 欠阻尼 超调 >25%、振荡多次 太抖（机械冲击）
0.4~0.8 欠阻尼 超调 1.5%~25%（ζ=0.707 时 4.3%） 常态目标区（0.707 黄金值）
ζ=1 临界阻尼 无超调、最快不振荡 指标设计的”最速单调”
ζ>1 过阻尼 慢、无振荡 太肉（如大阻尼机械臂）

ωn 与执行器：Mp 只由 ζ 定，但”快”（tp、ts）由 ζ·ωn 定。想同时快且稳只能提高 ωn → 更大的执行器功率（带宽=花钱），这是控制与机械/电气的第一笔交易。

你会看到什么

PX4 工程落点（真实源码）

  • src/modules/mc_att_control/AttitudeControl/AttitudeControl.hpp：setRefModelFrequency(float omega_n)——PX4 姿态参考模型用二阶参考模型做指令平滑（ωn 可调），近似欠阻尼二阶响应；姿态环期望响应与本文 ζ/ωn 语言同源（注：需结合 mc_att_control_main.cpp 的参考模型传播实现确认具体参数，ωn≈60 rad/s、ζ≈1 为常见出厂值，随版本变化）。
  • src/modules/mc_pos_control/PositionControl/PositionControl.cpp 的 _velocityControl()（L143）：速度环 P 增益 ≈ 2ζωn、I 增益 ≈ ωn²（把速度对象近似为 v̇=a 的 PI 闭环 s²+Kp·s+Ki 与 s²+2ζωn·s+ωn² 对比）——飞控速度环增益参数（MPC_VEL_*）本质上就是把 ζ/ωn 直觉翻译成增益。注意：实际速度环还含加速度限幅、前馈、积分限幅，不能简单等价标准二阶。
  • PX4 增益压缩 src/lib/rate_control/gain_compression.cpp：大机动时压缩增益防振荡，是非线性增益调度/饱和约束的工程例子（不等于保持 ζ 不变，属类比）。

自检

  • ζ→1 时 Mp→0，但 ts 变长吗？（用 ts≈4/(ζωn) 验证：ζ=1 时 ts=4/ωn，比 ζ=0.707 的 5.66/ωn 快）
  • 思考：为什么位置伺服的电流环带宽要远高于速度环？（套娃的 ts）
  • 已知 Mp≤5% 求 ζ 下限（解 Mp=e^(−ζπ/√(1−ζ²))=0.05 → ζ≈0.69）——会解这个，整定指标翻译无障碍。
