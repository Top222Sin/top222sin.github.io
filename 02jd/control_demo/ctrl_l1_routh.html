L1.2 劳斯判据：不解特征方程判稳定

一句话：劳斯表第一列的符号变化次数 = 右半平面极点数——不用求根就能判稳，5 阶以上手算特征根不现实时的救命稻草。

规则

系数 [aₙ,…,a₀] 排前两行，逐行交叉消元：

第一列全正 → 稳定；变号次数 → RHP 极点数。（前提：首一多项式、系数无缺失）

推导直觉：劳斯表在算什么

劳斯判据的数学本质：对特征多项式做连续分式展开（欧几里得辗转相除），其第一列系数符号变化与多项式的 Routh-Hurwitz 行列式判定等价。一个可靠的理解路径是：

不要用”镜像多项式（系数倒序）”来理解——系数倒序是根的倒数变换，不是虚轴镜像；虚轴镜像涉及 D(−s)。正确记忆：劳斯表 = 奇偶部连续分式展开的符号账本，第一列变号次数 = 右半平面极点个数（无虚轴根、无退化时）。

特殊情况处理（变体）

情况 现象 处理 意义
首列为 0 第一列出现 0 用 ε→0 替代后继续 多项式在虚轴附近/临界（需后续判断）
整行全零 某行全 0 用上一行系数求导作辅助多项式替换，继续 存在关于原点对称的根（±jω 或 ±σ），需由辅助多项式继续求根判断：±jω 是临界，±σ 明确含 RHP 根=不稳定

工程含义：出现整行全零说明存在对称根结构——可能是临界（±jω 等幅振荡）也可能是不稳定（±σ 发散），必须用辅助多项式继续求根确认。这在整定时常出现在”K 调到边界值”附近，值得警惕。

demo 验证

三个三次多项式，劳斯判据 vs 牛顿法+综合除法求出的实际右根数：

多项式 劳斯 数值
s³+2s²+3s+4 0 0（稳定）✅
s³+s²+2s+8 2 2 ✅
s³+6s²+11s+6 0 0（稳定）✅

工业场景

  • 参数扫描：K 从 0 涨到多少系统失稳？把 K 写进系数，劳斯表第一列找变号（得 K 的稳定区间，比根轨迹快）
  • 整定验收：PID 参数代入闭环特征方程，劳斯一票否决
  • 与 Bode 裕度的分工：劳斯给”绝对稳定域”（参数边界，快、解析）；Bode 给”裕度”（离边界多远，可测）。工厂里参数验收两件事都做：劳斯过 K 上限 → Bode 过 PM/GM 下限。

工程坑（真实）

  1. 系数缺失 ≠ 稳定：s³+2s²+3（缺 s 项，即 s³+2s²+0s+3）——劳斯表第一列 1,2,−3/2,3 有两次变号 → 2 个右半平面根，不稳定。”缺项”在工程中常是低通滤波器的 s² 项在离散化时被舍掉，需警惕。
  2. 多项式数值病态：高次（n≥6）系数差几个数量级时，浮点劳斯表可能误判——工程上先归一化系数并配合数值求根复核（归一化只能改善尺度，不能消除高阶病态）。
  3. 时滞系统不适用：含 e^(−Ls) 的特征方程是超越方程，劳斯表无法直接处理（需要 Pade 近似或上 Bode/Nyquist）。

自检

  • 特殊情况：整行全零（对称根）→ 用上一行求导系数替换后继续（.md 讨论）
  • 把 s³+6s²+11s+6+K 的 K 稳定上限找出来（答案：−6<K<60，若约定 K≥0 则 0≤K<60）
  • 推广：用劳斯判定”PID 增益 Kp 上限”——把 Kp 代入闭环特征方程再扫第一列，这是参数整定前必做的”安全边界”检查。
