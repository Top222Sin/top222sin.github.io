L4：反馈线性化 / 反步（非线性对象的确定性镇定）⭐

一句话：反馈线性化用控制量精确抵消非线性，把对象变成已知线性系统；反步对严格反馈链递归设计虚拟控制，给出可构造的李雅普诺夫稳定证明。 本篇补齐经典/现代控制”只能处理线性对象”的盲区（倒立摆、飞行器、机器人臂的确定性镇定）。

工程坑（实现时注意）

  1. FBL 依赖精确模型：u = v − ƒ(x) 必须准确知道 ƒ。模型误差会直接变成未抵消项——这是 FBL 对建模误差敏感的根本原因（SMC 则宽容得多）。
  2. 相对阶 ≤ 状态维数：FBL 能精确线性化的前提是相对阶 ρ ≤ n；ρ < n 时零动态需另作稳定性分析（内动态/最小相位）。
  3. 反步的 α̇1 不能漏：Step2 的 u 必须包含虚拟控制 α1 对时间的导数（沿真实状态轨迹），漏掉会使 z2 的动力学算错、稳定性证明崩塌。
  4. 欧拉积分误差会污染李雅普诺夫恒等式：ṀV2 与 −c1x1²−c2z2² 的残差（本例 1.25e-2）来自 dt=0.001 有限差分，非算法错误——减小 dt 可进一步压低。

自检（综合练习）

  • 把 Part A 的被控对象换成 ẍ = sin(x1) + u（非多项式非线性），重跑 FBL：只要 u = v − sin(x1)，跟踪误差仍满足同一线性 ODE——体会”精确抵消与 ƒ 形式无关”。
  • 故意在 FBL 里用 u = v − 0.9·x1²（模型误差 10%）：跟踪误差不再归零，量化 FBL 对建模精度的敏感度。
  • 进阶：把反步推广到三阶严格反馈系统（再加一个 ẋ3 = ... + u 的方程），体会递归虚拟控制的”逐级回退”结构。

结语

至此 control_demo 在 L3 工业篇补上 L3 反馈线性化/反步：从”线性对象最优/极点配置”（L2）走到”非线性对象确定性镇定”（FBL 精确线性化 + 反步可构造稳定证明），与 L3 SMC 的非线性抗扰路线互补，并接 Jacobian_demo 的李导数、pid_demo 的执行层，构成完整的非线性控制拼图。
