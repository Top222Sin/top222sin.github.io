L4：H∞ / μ 综合（鲁棒控制两条主线）⭐

一句话：H∞ 范数量化”最坏情况增益”，小增益定理给出稳定充分条件；混合灵敏度把它写成加权峰值的设计目标；μ-综合再用分块结构把鲁棒界收紧，比 H∞ 范数更少保守。 本篇补上 classic/modern 控制里”面对模型不确定性与外界扰动”的工业刚需（飞机/卫星/硬碟音圈电机/过程工业）。

为什么需要 H∞ / μ（与 L2.5/L2.6 的关系）

L2.5 的 LQR/LQG 假设模型精确已知——但真实对象总有未建模动态、参数漂移。鲁棒控制回答：”在多大不确定性下，闭环仍稳定/达标？”

两条主线：

Part A：H∞ 范数 + 小增益定理

广义对象 M(s) = 1/(s²+0.2s+1)（SISO，代表”从扰动到性能”的传递）。其 H∞ 范数是频域峰值：

小增益定理：若 ‖M‖∞·‖Δ‖∞ < 1（M 与 Δ 均稳定），则反馈互联 (I−MΔ)⁻¹M 必稳定。demo 取 Δ=δ（常增益 |δ|<1/γ），验证闭环 H∞ 范数 ≤ ‖M‖∞/(1−|δ|‖M‖∞)——本例 δ=0.1 时实测 5.30 < 界 10.10。这是充分（非必要）条件：保守，但给出了可计算的稳定保证。

Part B1：混合灵敏度

单回路 P=1/(s+1), K=2，灵敏度 S=(1+PK)⁻¹、互补 T=PK·S。设计目标写成加权峰值：

demo 取 W1=10/(s+1)（低频大）、W2=0.5s/(s+10)（高频大），实测 ‖W1·S‖∞=3.33<4、‖W2·T‖∞=0.077<1——说明该回路在两端都满足指标。这就是 H∞ 控制的”标准形式”：把工程诉求翻译成一个 ‖·‖∞ 约束。

Part B2：结构化奇异值 μ（μ-综合核心）

H∞ 范数把不确定性当任意有界扰动（无结构），往往过保守。工业不确定性常是分块结构的（如多个独立通道、实部约束）。定义 Δ=diag(δ1,δ2)（δi 为复标量，块结构），结构化奇异值

  • 下界 μ̲ = max_{|δ|=1} ρ(M·diag(δ1,δ2))（相位网格搜索，可行下界）
  • 上界 μ̄ = inf_{d>0} σ̄(diag(d,1)·M·diag(1/d,1))（D-缩放，可行上界）
  • 必有 μ̲ ≤ μ ≤ μ̄ ≤ ‖M‖2：μ < ‖M‖2 正是 μ-综合”比 H∞ 范数更少保守”的数学表述。

与兄弟仓库的分工（避免重复）

仓库/篇章 关系
本库 L2.5 LQR / L2.6 LQG H∞ 是”在不确定性下”的 LQR 推广；确定性 LQR 是 H∞ 在无不确定性极限（γ→∞）
本库 L4.1 MPC MPC 处理约束最优，H∞ 处理不确定性最优；二者都源自 Riccati/凸优化家族
pid_demo 工业落地时 H∞/μ 给出鲁棒控制器，再由 PID 电流环执行（与 L3.4 同链路）
Jacobian_demo μ 的 D/G-缩放、灵敏度分析需要雅可比/最优化（接 Jacobian L3 系列）

工程坑（实现时注意）

  1. H∞ 范数的”峰值”不在 ω=0 也不在 ∞：阻尼小（此处 0.2）时共振峰接近自然频率（ω=1），必须频域扫描或解 d|M|/dω=0 找峰值，不能凭直觉取端点。
  2. 小增益定理是充分条件：实测闭环范数常远小于界（本例 5.30 vs 10.10），别把它当成”精确等于”——它给出的是安全保证，不是紧界。
  3. μ 的上下界要同时算：只用 D-缩放上界会偏保守；相位网格下界 + D-缩放上界夹出 μ，二者越接近越可信（本例恰好重合）。
  4. 块结构决定 μ 与 ‖·‖∞ 的差距：全结构（单块）= H∞ 范数；分块越多、结构越细，μ 越紧。选错结构会得到错误（过松或过紧）的鲁棒界。

自检（综合练习）

  • 改 M(s)=1/(s²+2ζs+1) 的 ζ（如 0.05→0.5），观察 ‖M‖∞ 峰值如何从尖锐变平缓——体会”阻尼越小越需要鲁棒设计”。
  • 对 Part B2 的 M 手动验证 μ̄ ≤ ‖M‖2：取 d=1（无缩放）即 σ̄(M)=‖M‖2，缩放只会更小。
  • 进阶：把混合灵敏度权重 W1/W2 的拐点频率对调，看 ‖W1·S‖∞ 与 ‖W2·T‖∞ 如何此消彼长（性能/鲁棒权衡）。

结语

至此 control_demo 在 L1→L2→L3→L4 基础上补上 L2 H∞/μ 综合：从”精确模型下最优”（LQR/LQG）走到”不确定性下仍稳”（H∞/小增益），再到”利用结构收紧鲁棒界”（μ）。它与 L2.5/L2.6 同根、与 L4.1(MPC) 同族、与 pid_demo 同落地链路，构成一张从经典到鲁棒的控制网络。
