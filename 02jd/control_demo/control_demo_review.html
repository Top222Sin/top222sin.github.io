control_demo 内容审查报告

审查对象：02jd/control_demo/（README.md + 23 篇 .md + 23 个 .cpp + _diagrams.html + images/*.svg）
审查日期：2026-08-21（L4.5–L4.8 落地；原 15 篇课程审查见前节）
审查维度：控制理论公式正确性、设计流程自洽性、cpp 实现与 md 声明一致性、示例输出与程序实际输出一致性、跨文档引用一致性

〇、总体结论

  • 数学主体质量高：二阶系统（Mp/tp/ts）、劳斯、根轨迹（分离点/幅值条件/ζ 线）、Bode（ωc/PM/GM）、超前补偿、e^{At}、能控能观、Ackermann、观测器、LQR（ARE）、LQG、无人机 LQR、capstone 全流程——核心公式经独立复算全部正确，且 L2/L3 的设计数值（K=[8,4]、L=[16,128]、K_lqr=[1.414,2.197] 与 [14.142,3.502]、Td=0.10、Mp≈12.6% 等）与理论推导完全吻合（注：Mp 按 ζ=0.55 应为 12.6%，详见 W4）。
  • 确定性错误 3 处：全部位于标注/文档数字层（md 表格、示例输出、cpp 打印标签），cpp 的计算逻辑本身在这些处是对的（所以自检仍 PASS）。
  • 实现层潜伏 bug 1 处（ctrl_l2_poleplace.cpp Ackermann 索引，被对称样例掩盖，换参数会错）。
  • 文档不一致/占位符/跨库引用问题 5 处。
  • 元观察：README 声称”47 项检查全部 PASS”仅覆盖各 cpp 内部对拍；至少 3 篇 md 的「你会看到什么」示例输出与实际 cpp 输出不符（疑似手写示例而非运行转录），ctrl_l3_process.md 曾残留未替换的 xx% 占位符（现已修复为 22.07%）——建议对全部 15 篇重新编译运行一遍，用真实输出回填 md。
  • 方法说明：本机无 C++ 编译器，结论基于逐行静态核验 + 解析复算（关键数值均有独立推导）。

一、确定性错误（❌ 建议必须修正）

E1. ❌【中】ctrl_l1_routh：s³+2s²+3s+4 实为稳定（0 个右根），md 表格、md 示例输出、cpp 标签三处错标”1 个右根”

位置：ctrl_l1_routh.md 第 30–34 行表格第 1 行 + 第 45–46 行示例输出；ctrl_l1_routh.cpp 第 81 行标签。

证明：Routh 表首列 = [1, 2, (2·3−1·4)/2=1, 4]，全正、零变号 → 0 个右半平面极点；数值求解：实根 ≈ −1.6507 < 0，共轭复根对实部 = −0.1747 < 0 → 稳定。正确答案：劳斯 0、数值 0。

现状：cpp 的实际计算值恰好正确（routh_cnt=0、true_cnt=0，chk 用两者相减故 PASS），但：

  • md 表格写”劳斯 1 | 数值 1 ✅”；
  • md 示例输出写”劳斯=1 数值=1”；
  • cpp 标签写”(1 个右根)”——实际会打印出”劳斯=0 数值=0”的自相矛盾输出。

建议：改标签/表格为”0 个右根（稳定）”，或换一个确有 1 个右根的多项式（如 s³+s²+3s+10：Routh 首列 [1,1,−7,10] → 2 变号）。

E2. ❌【中】ctrl_l1_leadlag：设计参数 T=0.054 与实际计算及自身声称结果矛盾（应为 ≈0.131）

位置：ctrl_l1_leadlag.md 第 18–21 行（步骤 3）与第 37–39 行示例输出（T=0.054）；ctrl_l1_leadlag.cpp 第 49 行。

推导：cpp 实际执行 T = 1/(√a·wc0) = 1/(√3.231·4.254) = 0.1308（ωm 对准原交越点 4.25 rad/s）。只有 T≈0.131 才能复现 md 声称的”补偿后 wc=6.53、PM=46.6°”（代入 T=0.131：wc₁≈6.5、PM≈46.6 ✓；代入 T=0.054：wc₁≈4.8、PM≈48°，与声称结果不符）。md 步骤 3 的文字”ωm 对准 wc”也未指明是原交越点，易误解为新交越点。

建议：md 的 T=0.054 改为 T≈0.131，并把步骤 3 表述为”ωm 对准原交越点 wc0”。

E3. ❌【中】ctrl_l2_lqr：md 示例输出（K、J）与实际 cpp 计算不符

位置：ctrl_l2_lqr.md 第 24–25 行与第 41–43 行示例输出；ctrl_l2_lqr.cpp 第 74、85 行。

推导：双积分器、Q=diag(10,1)、R=1 的 ARE（AᵀP+PA−PBR⁻¹BᵀP+Q=0）手算闭式解：

  • p12 = √10 ≈ 3.1623 → K₁ = 3.1623（✓ md 对）
  • p22 = √(2√10+1) ≈ 2.7064 → K₂ = 2.7064（md 写 3.6736，错）
  • p11 = p12·p22 ≈ 8.5584 → J_opt = x₀ᵀPx₀ = 8.5584（md 写 6.3246，错；6.3246 = 2√10 无对应意义）

cpp 的 Kleinman 迭代收敛到同一 ARE 解，实际会打印 K=[3.1623, 2.7064]、J_opt≈8.56（与手算一致），且 ARE 残差、K=R⁻¹BᵀP 等断言 PASS。md 的”K=[3.1623, 3.6736]”与”J_sim=J_opt=6.3246”为错误示例数据。

二、实现层潜伏问题（⚠️ 建议修正）

W1. ⚠️ ctrl_l2_poleplace.cpp：Ackermann 索引取”第二列”而非”第二行”，被对称样例掩盖

位置：ctrl_l2_poleplace.cpp 第 51–53 行。

标准单输入 Ackermann：K = eₙᵀ·Wc⁻¹·φ(A)，即取 M = Wc⁻¹φ(A) 的最后一行（n=2 时 K₀=M[1][0]、K₁=M[1][1]）。代码写的是 K0 = M[0][1]、K1 = M[1][1]——取的是最后一列。本例因 M = [[0,8],[8,4]] 恰好对称（列 = 行），结果 K=[8,4] 碰巧正确、自检通过；换用一般 A 或期望极点，M 不再对称，该实现会给出错误增益。同理检查 ctrl_l2_observer.cpp 的对偶增益取法。

三、文档不一致与表述问题（⚠️ 建议修正）

W2. ⚠️ ctrl_l3_process.md：残留未替换占位符 “xx%”

第 25 行”纯 P 对照：留 ~xx% 稳态偏差”与第 44 行示例输出”[demo] 纯 P: 稳态偏差=xx%”仍是字面占位符；cpp（第 59 行）实际打印真实数值（如 ≈22%）。一篇 status: done 的文档不应有占位符。

W3. ⚠️ ctrl_l2_lqg.cpp：”Qd 精确离散”注释与仿真注入噪声协方差不一致

KF 迭代所用 Qd = [[q·dt⁴/4, q·dt³/2],[q·dt³/2, q·dt]]（第 71–72 行），而仿真实际注入的噪声（w0=0.5·dt·wv、w1=wv，var(wv)=q·dt，第 94–95 行）协方差为 [[q·dt³/4, q·dt²/2],[q·dt²/2, q·dt]]——(0,0)/(0,1) 元差一个因子 dt。滤波器假设的过程噪声偏大 → KF 增益略次优（演示断言 RMS<0.5 仍能过，不致命）。且对连续白噪声的精确离散应为 q·[[dt³/3, dt²/2],[dt²/2, dt]]，注释”精确离散”言过其实。

W4. ⚠️ ctrl_l3_capstone.md：超调与峰值数值间微出入

“目标 ζ=0.55 → Mp=12.8%”：Mp(0.55)=exp(−0.55π/√(1−0.3025))≈**12.6%**（12.8% 对应 ζ≈0.548，即演示实际取的 ζ）；”闭环峰值=1.118”对应 Mp≈11.8%（ζ≈0.56），与 12.8% 不完全自洽。建议统一为同一条 ζ（0.548）并让三个数字互相印证（或说明仿真离散化误差）。

W5. ⚠️ 跨仓库章节号互相矛盾（未核验兄弟仓库，仅指出不一致）

  • MPC 位置：ctrl_l3_process.md 与 README 写”Jacobian_demo L3.7“，ctrl_l2_lqg.md 写”Jacobian_demo L3.2“；
  • 能观性判据：ctrl_l2_ctrbobsb.md 写”KF_demo L3.2 同一判据”，README/ctrl_l2_lqg.md/ctrl_l3_uav.md 写”KF_demo L3.7“。

七、独立复核结论（2026-08-18，numpy/解析复算）

E1/E2/E3 三处确定性错误均成立，已修复

W1 潜伏 bug 成立，已修复并加用例

W2/W3/W4 成立，已修复（附两处对原报告的更正）

  • W2：ctrl_l3_process.md 残留占位符 xx%，复算纯 P 稳态偏差 = **22.07%**——已替换。
  • W3：ctrl_l2_lqg.cpp 的 Qd=[[q·dt⁴/4, q·dt³/2],[…,q·dt]] 与注入噪声 w0=½dt·wv, w1=wv（cov=[[q·dt³/4, q·dt²/2],[…,q·dt]]）上左 2×2 差一个因子 dt（Qd 比注入小，原报告”偏大”方向写反）；”精确离散”言过其实（精确应为 q·[[dt³/3, dt²/2],[dt²/2, dt]]）。已把 Qd 上左两元各去掉一个 dt，与注入噪声协方差一致，并改注释。⚠ 该 demo 本机未编译，请在有 OpenCV/C++ 环境重跑确认 RMS<0.5 仍过。
  • W4：ζ=0.55 → Mp(0.55)=**12.6%**（非 12.8%）；仿真峰值 1.116（≈11.6% 超调）略低于连续理论（离散化效应）。已统一为 12.6%/峰值 1.116/理论 0.126，并加离散化说明。

W5：能观性判据部分是误报，MPC 部分成立

真实 bug（C++ 镜像复核抓出，已修）

  • B1（ILC 类型错配）：Vec grad = scalemat(alpha, matvec(Gt, E2)); —— scalemat 返回 Mat（向量之向量），赋给 Vec 在 C++ 下无法编译（vector<vector>→vector 不隐式转换）。镜像脚本逐字复刻同一写法后触发 TypeError（Python 无此静态检查，仅运行时暴露），证明是真实 bug。修复：新增 scalvec（标量×向量）并对 ILC 重构使用 Vec grad=scalvec(alpha, matvec(Gt,E2))。

设计期踩坑（已规避，值得记）

  • ETC 初版发散：首版用快衰减对象（A−BK 含大非对角，首步 ‖x‖ 反增），保持控制期间 x→(I−A)⁻¹BK·x_s 把状态推离平衡 → 对几乎所有 σ 都发散。根因：保持控制下”复合闭环”非收缩。修复：显式设计 A−BK=D（对角 0.9/0.85 严格收缩，K=B⁻¹(A−D)），使保持控制期间 ‖x‖ 单调下降，ETC 稳定裕度充足。
  • ETC 阈值 vs 节省折中：σ 太小→几乎每步触发（无节省）；σ 太大→稀疏但终态残差大/可能失稳。最终取 σ=0.3，节省 85% 且稳定。
  • ILC 条件数：GᵀG 特征值范围 [0.8753,1.3804] 条件数小 → α 接近最优、ρ=0.2394 快速收敛；若对象病态，ρ 接近 1、需更多迭代或加 Q 滤波。
