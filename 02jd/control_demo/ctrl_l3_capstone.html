L3.4 capstone：位置伺服系统设计全流程 ⭐⭐

一句话：建模 → 指标 → 设计 → 验收，L1~L3 全部知识装配成一台”能出厂”的位置伺服——每个数字都有出处，每一步都可对拍。

四步流程（demo 完整走通）

① 系统辨识：给速度环 1V 阶跃，采 ω(0.1s)/ω(1.0s) 两点 → 二分法解 K_p/(s+a)：K_p=3.00, a=3.00（误差 <0.5%）✅

② 指标→频域：位置环需 Kv=10。位置对象 P(s)=K_p/(s(s+a))，速度误差系数 Kv=lim s·P(s)=K_p/a=1，不达标 → 位置控制器取 K_c=Kv·a/K_p=10 → 位置环总增益 K_ℓ=K_p·K_c=30。开环 L(s)=30/(s(s+3))：扫描得 wc=5.08、PM=30.5° < 45°（欠阻尼，需补） ✅

③ 设计（测速反馈补阻尼）：控制律 u = K_c·(r−x) − K_c·T_d·ω（阻尼项系数 = K_c·T_d），闭环特征 s²+(a+K_c·T_d)s+K_c，目标 ζ=0.55 →
T_d=(2ζ·√K_c − a)/K_c = (2·0.55·√30 − 3)/30 = 0.101 ✅（与 demo 输出一致）

④ 验收：闭环阶跃仿真 vs 二阶理论 Mp(ζ=0.55)≈12.6%：仿真峰值 1.116（≈11.6% 超调，本例中离散化使其略低于连续理论；该方向/幅度依赖具体采样周期与离散方法，非普遍规律）、稳态收敛 ✅

四步推导：每个公式从哪来

① 辨识原理：一阶惯性 G(s)=K_p/(s+a) 阶跃响应 ω(t)=K_p·(1−e^(−at))/a。两点采样得两个方程解两个未知数（K_p,a）：

② Kv 与增益分层：位置对象 P(s)=K_p/(s(s+a)) 含积分 → 速度误差系数 Kv=lim_{s→0} s·P(s)=K_p/a。指标 Kv=10 时需位置控制器 K_c 提升总增益 K_ℓ=K_p·K_c=Kv·a。Kv 定义：单位斜坡位置指令（常值速度输入）的稳态误差 e_ss=1/Kv，Kv 越大稳态速度跟踪误差越小。

③ 测速反馈的等效：内环测速反馈 u=K_c·(r−x)−K_c·T_d·ω（阻尼项系数 K_c·T_d）把速度阻尼直接注入：

为什么用测速反馈而非超前网络：测速反馈在内环注入阻尼——执行器饱和与噪声先被内环处理，外环设计时内环近似”已知的快速环节”。超前网络在外环只提相位，噪声放大发生在整个外环路径。这是”阻尼要放在最内环”的工程思路（L3.1 带宽分级同源；注：饱和/噪声并不会被自动”消化”，需内环配合限幅与滤波）。

为什么用测速反馈而非超前网络

工业伺服标配测速发电机/编码器微分——等效 PD/超前但：

  • 测速反馈在内环，饱和与噪声在内环集中处理（配合限幅/滤波，非自动消除）
  • 与电流环套娃结构天然匹配（L3.1 的带宽分级）

验收的”离散化偏差”（工程细节）

④ 中仿真峰值 1.116 vs 连续理论 1.126——差 1% 来自离散化（半隐式欧拉 + 采样周期的相位滞后）。**工程验收标准不是”完全等于理论”，而是”偏差在容差内且方向可解释”**——这正是 L1.1 对拍 tol 的设计哲学：知道理论值的适用边界。

自检（综合练习）

  • 指标改 Mp<5% + ts<0.5s：重走 ②③④（T_d 和 K_c 都要动）
  • 用 L2.3 极点配置替代 ③：期望极点从 ζ/ωn 反推，殊途同归。
  • 挑战：把 ③ 换成 L2.5 LQR（Q=diag(10,1),R=1）重设计，对比 T_d 法与 LQR 法得到的闭环极点（两者趋势接近，但数值是否一致需实际求解验证，测速反馈 ≈ 速度加权 LQR 的直觉类比）。
