L1.3 根轨迹：增益与极点的几何

一句话：增益 K 从 0→∞ 时闭环极点在 s 平面画出的轨迹——设计师直接在图上”读出”满足阻尼要求的 K，这是经典控制最优雅的工具。

两个条件

根轨迹上的点 s 满足 1+K·G(s)=0：

推导直觉：为什么是这两个条件

闭环特征方程 1+K·G(s)=0 → K·G(s) = −1 = 1∠180°(2k+1)（模 1、幅角 180° 奇数倍）。

  • 等式左边是复数 K·G(s)，其幅角 = ∠K + ∠G(s) = ∠G(s)（K 为正实数）。
  • 幅角必须等于 180° 的奇数倍 → 相角条件。这决定 s 点”能不能成为闭环极点”（几何形状）。
  • 模长必须等于 1 → |K|·|G(s)| = 1 → 幅值条件。这决定”在该点需要多大 K”（数值）。

所以：先画轨迹形状（相角条件，纯几何），再标 K（幅值条件，纯数值）——两个条件的分离是根轨迹优雅的原因。

根轨迹基本法则（快速手绘）

这 5 条法则足够你 30 秒手绘任意系统的根轨迹草图——笔试手撕和工程初判都靠它。

demo 验证（G0 = 1/(s(s+2)), 开环 L(s)=K·G0(s)）

记号约定：特征方程写 1+K·G0(s)=0 时，G0 是不含可调增益的对象；开环传递函数 L(s)=K·G0(s)。下文”G=K/(s(s+2))”即 L(s)。

  1. 分离点：K<1 两实根、K>1 共轭复根 → 分离点在 K=1, s=−1 ✅
  2. 幅值条件：K(s) = −(s²+2s) = |s|·|s+2|（逐点对拍 1e-16）✅
  3. 阻尼线设计：ζ=0.707 线 s=−a±ja 与轨迹交点 → s=−1±j, K=2 ✅

工业直觉

  • 每条轨迹”终点”是开环零点或无穷远——零点把极点”吸”过去（这就是超前补偿的原理，见 L1.5）
  • 任何时刻闭环 ζ 直接从图上量（cos β = ζ，β 是极点与负实轴的夹角）
  • K 的物理含义：K 是开环增益，调它 = 调执行器/放大器增益。根轨迹回答”我这个增益能放到多大、极点到哪”——出厂前增益标定的理论基础。

根轨迹 vs 其他设计工具（决策表）

工具 输入 输出 强项 弱点
根轨迹 G(s) K 全域极点 直观、看阻尼 只对单参数增益
劳斯判据 特征方程系数 稳定边界 解析、参数扫描快 不给动态品质
Bode G(jω) 裕度/带宽 可实测、抗噪直观 需要频率响应数据
极点配置 期望极点 反馈增益 任意放极点 需能控、指标联系弱

何时用根轨迹：参数整定阶段（K 是主旋钮）、教学直觉、加零点/极点前的”草图预判”。

你会看到什么

工程坑（真实）

  • 分离点方程仅给候选点：Σ1/(s−pi)=Σ1/(s−zi) 是 dK/ds=0 的驻点条件，解还必须位于根轨迹实轴区段且对应 K≥0 才是有效分离/汇合点。
  • K<0（正反馈）轨迹不同：K 为负时相角条件变 ∠G0(s)=0°（mod 360°），轨迹形状完全不同——正反馈/负反馈切换必须重画轨迹，别在一种图上读另一种的增益。
  • 数字工具陷阱：用 MATLAB/root locus 函数时默认开环单位反馈——你把带 H(s) 反馈的对象直接传进去，画出来的轨迹就是错的（少画了 H 的零极点）。
  • 离散系统：z 平面根轨迹”右半平面”变成”单位圆外”，法则不变但判稳条件变——从 s 换 z 别忘。

自检

  • 想要 ts 更短，K=2 还能满足吗？沿轨迹向左上走需要什么（加零点=超前补偿）？
  • 与 L2.3 极点配置对比：根轨迹只能沿轨迹放极点，极点配置任意放。
  • 手绘 G=K/(s(s+4)) 的根轨迹：分离点在哪？（答案 s=−2，K=4）
