control_demo — 自动控制 + 现代控制 精讲（23 篇 · 纯 C++17）

学习链第七篇：neon_demo(ARM) → cuda_demo(GPU) → cali_demo(标定) → pid_demo(控制工程) → Jacobian_demo(雅可比) → KF_demo(状态估计) → control_demo(控制理论双课)
约定与兄弟仓库一致：纯 C++17 标准库，每个 demo 自带合成数据 + 真值对拍 + PASS/FAIL，file(GLOB ctrl_*.cpp) 一次构建全部。

验证状态（重要）

  • 本机无 C++ 编译器。全部 23 个 demo 的数学正确性经受管 Python 3.13.12 镜像逐一核验（96 项检查全部 PASS：经典 15 + 现代/工业 32 + L4 MPC 6 + L4 H∞/SMC/FBL 22 + L4 MIMO/ILC/FTC/ETC 21）：
    • 超调公式 vs 仿真 ~3e-5（4 组 ζ）；劳斯 vs 数值求根（3 例全对）
    • 根轨迹分离点/幅值条件/ζ 线交点（1e-16 级）；PM=54.9°/GM=21.7dB 与闭环阶跃互证
    • 超前设计 PM 25.2°→46.6°；e^At 旋转/双积分器 1e-16、ZOH vs RK4 3e-13
    • Ackermann 特征多项式 1e-12；观测器+分离原理收敛 7e-7
    • ARE 残差 1e-15 + 代价=x₀ᵀPx₀ 证书；LQG 闭环 RMS=0.27
    • 电机 PI 抗扰/过程水箱/无人机 LQR/capstone 辨识(K=3.004,a=3.004)
    • L4 MPC：离散 DARE→P，无约束 MPC 首步增益与离散 LQR 完全一致（误差 1.3e-15）、ARE 残差 7.1e-15；无约束/有约束(u_max=0.6)滚动时域均收敛到目标 1.0，且约束版 |u|≤0.6 全程满足
    • L4.2 H∞：广义对象 ‖M‖∞=5.02519@ω=0.9899，小增益界 δ=0.10 闭环实测 5.3000<界 10.1013；混合灵敏度 ‖W1·S‖∞=3.3333<4、‖W2·T‖∞=0.0769<1；结构化奇异值 μ̄=μ̲=1.3302≤‖M‖₂=1.3643（D-缩放上界与相位网格下界夹逼一致）
    • L4.3 SMC：到达条件 s₀·ṡ₀=−3.000<0，终态 x₁=−0.00092、末半程 max|s|=0.0354；边界层 φ=0.1 抖振 RMS 0.2731 vs 纯符号 1.0006（抑振 3.7×）；常值扰动 d=0.5 下匹配不变性 末半程 max|x₁|=0.01715 vs 无积分 PD 0.05560
    • L4.4 FBL：输入-状态线性化后跟踪误差 |e|=0.00089、精确线性化残差 4.4e-16（vs 朴素 PD 忽略 x₁² 的 |e|=0.54318）；反步递归 ṀV₂ 全程 <0（max ṀV₂=−0.0000）、李雅普诺夫恒等式残差 1.25e-2（欧拉 O(dt)）
    • L4.5 MIMO 解耦：2×2 对象 DC 增益 K=[[1,0.5],[0.3,1/3]]，预补偿器 D=K⁻¹ 使 D·K=I（残差 1.57e-16）；无解耦交叉响应 y₂=0.300，解耦后 y₂=0、交叉耦合比下降 >100×；数值仿真稳态 [1.0,0.0]
    • L4.6 ILC：FIR 对象 GᵀG 特征值 [0.8753,1.3804]，α=0.8689、收敛因子 ρ=0.2394<1；迭代误差单调下降，‖E⁴⁰‖=2.77e-27、复现参考误差 9.44e-3（5/5 PASS）
    • L4.7 FTC：部分失效 Λ⁻¹ 预补偿使 A−BK 残差 5.55e-17（健康极点），FTC 稳态误差≈0 vs 名义 0.4225；完全卡死靠冗余重分配恢复输出 1.000 vs 名义 1.333（6/6 PASS）
    • L4.8 ETC：闭环设计成严格收缩 A−BK=D=diag(0.9,0.85)（残差 6.94e-18）；σ=0.3、N=400 下事件 61/401 节省 85%，终态 ‖x‖=4.43e-10 稳定（4/4 PASS）
  • 验证中抓到并修复的真实 bug（写进对应 .md 的踩坑注记）：
    ① 频响函数形参 jw 传 float → 全实数运算、相位恒 0（GM 永远 None）
    ② 相位扫描未解缠绕 → −180° 交越漏判
    ③ 闭环特征方程忘加反馈项 K（阶跃峰值 1.62 假象）
    ④ Bd 级数漏 k! 分母（k=2 项差 2 倍，靠 A⁻¹(Ad−I)B 交叉对拍抓出）
    ⑤ 观测器漏控制输入 u → 误差发散 1e+32
    ⑥ LQG 对象漏 Bd·u → 变开环随机游走（先验证无噪声版的方法论）

与兄弟仓库的关系（组合应用场景）

兄弟仓库 关系 组合应用场景
pid_demo 本仓库 L1 是 pid_demo 的理论地基；pid_demo 是 L1.5/L3.1 的工程深化（整定/抗饱和/串级/PX4架构） 伺服系统：control_demo L3.4 设计 → pid_demo L2.1 串级+抗饱和落地
KF_demo L2.4 观测器 = KF 的确定性特例；L2.6 LQG 直接组合两库（KF 出估计、LQR 出控制） 完整飞控：KF_demo L3.7(ES-EKF+闸门) + 本库 L3.3(姿态 LQR) = PX4 内核
Jacobian_demo 非线性对象的线性化(θ̈=(l/Jx)u 前的建模)；L3.2 给出 MPC 灵敏度 S（非线性 MPC/iLQR-DDP 的微分层） 机械臂/约束控制：Jacobian_demo L3.9(计算力矩) + 本库 L2.5(LQR)/L4.1(MPC 约束最优) 调增益
cali_demo 标定决定传感器精度 → 反馈质量（标定误差 = 等效观测噪声 R 变大） 视觉伺服：cali(内外参) → Jacobian(图像雅可比) → KF(估计) → 本库(控制)
neon/cuda_demo 控制周期 μs 级时，Ad/Bd/K 的矩阵运算需要 SIMD/GPU 加速 高带宽 MPC：1kHz 以上模型预测控制在线求解（control_demo L4.1 的 QP 反复求解走 SIMD/GPU）
