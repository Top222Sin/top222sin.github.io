L3.3 工业用例③：无人机姿态 LQR + 积分增强 ⭐

一句话：无人机滚转环是天然的(≈)线性对象 θ̈=(l/Jx)u，LQR 三行代码出增益；常值风扰靠 ∫θ 增广顶掉——PX4 姿态环的生产级同款思想。

模型与设计

demo：l=0.25, Jx=0.02（输入映射 12.5），Q=diag(20,1), R=0.1 →
K=[14.14, 3.50], Ki=2.0（Kleinman，同 L2.5）。

为什么滚转环是”天然线性”的（模型推导）

小角度下刚体欧拉方程退化为解耦的三个单轴方程：

这就是为什么飞控内环（角速率环）用线性 PID/LQR 就够了——非线性交给外环（姿态→角速率映射用四元数，见 Jacobian_demo/quaternion 系）和增益调度处理。**控制架构的本质是”把非线性推到带宽低的外环”**。

demo 验证

  • 初值 θ=0.3 rad + 常值扰动 0.5 rad/s²：8s 后 |θ|<0.003、|ω|<4e-4 ✅
  • 无积分时同样的扰动会留稳态角偏差（L2.6 阶跃扰动的对偶场景）

积分增强的数学：状态增广

把 ∫θ 当作额外状态，增广状态空间：

本文 demo 的实际做法：二阶 LQR 求 [Kθ=14.14, Kω=3.50]（Q=diag(20,1), R=0.1），再手工叠加 Ki=2.0（按扰动大小与允许稳态偏差经验选取）。严格的三阶增广 LQR 会因 Q_aug 的选取给出不同增益，两者是不同设计——本 demo 采用”LQR 主体 + 手工积分增强”的工程常用组合（PX4 亦然：姿态 P 外环 + 角速率 PID 的 I 是独立整定的）。

为什么增广后能消稳态误差：常值扰动 d 下，若稳态 θ≠0，则 ∫θ 会不断增长（状态方程 d/dt[∫θ]=θ≠0）——但若控制保证状态收敛到 0（无饱和时），唯一稳态是 θ=0。积分增强 = 把”消除稳态误差”变成”系统状态必须归零”的约束（注意：饱和时积分可能 windup，需抗饱和处理，不自动保证）。

为什么积分增强是标配

LQR 假设模型精确；真实世界有：重心偏移（等效常值力矩）、电机推力标定误差、
阵风平均值。∫θ 一项顶掉全部常值来源——代价是相位滞后，Ki 不能贪大。

你会看到什么

自检

  • Ki=0 重跑：稳态角偏差 = d/(K_θ·l/Jx) ≈ 0.5/177 ≈ 0.0028 rad——LQR 硬扛的部分
  • 推力映射 l/Jx 标错 20%：LQR 仍稳（60° PM 的鲁棒性红利）。
  • 思考：增广 ∫θ 后 LQR 的 Q 该怎么给？（∫θ 的 Q 对应”稳态误差的容忍度”，给太小 = 没积分效果，给太大 = 相位滞后严重振荡）
