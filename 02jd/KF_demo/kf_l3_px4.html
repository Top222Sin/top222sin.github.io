L3.7 扩展：EKF 在 PX4 中的应用（误差状态 + NIS 闸门）⭐

一句话：PX4 的 EKF2 是生产级误差状态 KF：IMU 高频积分标称轨迹、24 维误差状态低频修正、每个传感器一条独立 fuse 分支、更新前先过 NIS 闸门（创新马氏距离超限直接拒收）——本篇用 2D mini 版复刻这套架构，并演示野值拒收的威力。

一、PX4 EKF2 架构速览

本 demo 的 2D 平面化：δx=[δp(2), δv(2), δb_acc(2)]（6 维），IMU 100Hz + GPS 5Hz。

EKF2 的”误差状态”为什么是 24 维（结构记忆）

洞察：维数来自”要估什么”——飞控要估的不只是位姿，还有所有会污染 IMU 的误差源（零偏、磁偏、风）——每加一类误差源 = 加一组状态（L3.2 的增广思想）。这也是”状态设计”的工程艺术：够用即可，多了收敛慢，少了不诚实。磁场相关量（地磁场+机体系磁场）是独立的磁场状态，不是简单的”磁力计零偏三组”。

二、NIS 闸门（L2.4 的实战化）

NIS = νᵀS⁻¹ν ~ χ²(m)。NIS > gate ⇒ 该观测与滤波器当前信念严重不符——要么传感器坏了，要么模型失配 → 拒收本次更新。

PX4 的 GPS 闸门默认 5σ（χ²(2) 下 ≈ 25，比教科书 99% 卡方闸门 9.21 宽容——宁可多放行也不轻易断 GPS）。开发轶事：本 demo 先用 9.21，误伤 3 个正常观测；改 25 后恰好只拦野值——闸门宽度本身就是调参对象。

精确性说明：PX4 参数以”若干倍标准差”表达（test ratio 与创新方差开方比较），与”χ²(2) 卡方上分位”是两种不同的数学对象——25 是”5σ 平方”量级的工程经验值，不是 χ²(2) 的精确 5σ 分位（χ²(2) 无此概念）。本文用 25 作闸门是教学简化，真实 PX4 各观测类型/分量的 gate 逻辑更细（按版本源码核对）。

闸门宽度为什么是调参对象（5σ vs 9.21）

工程结论：闸门是”误伤率 vs 漏网率”的旋钮——传感器可靠性低（GPS 易中断）→ 放宽；传感器稳定（视觉）→ 收紧。每条传感器分支可以有自己的闸门宽度（PX4 正是这样）。

三、demo 验证（gated vs ungated 同噪声对拍）

注入 2 个 GPS 野值（+25 m, −20 m）：

指标 有闸门 无闸门
RMSE 0.80 m 2.15 m
野值拦截 2/2 ✅ 0（直接打飞）
正常观测误伤 0 —
接受观测平均 NIS 2.90 ≈ 自由度 2 ✅ —

无闸门版本被野值拉偏后需要几十步才缓过来——实际飞控里一次打飞可能就是炸机。

为什么野值能”打飞”滤波器（机制）

关键：野值的危害不只是”当时偏一下”——它同时压小了 P（过信），让后续修正变慢（L1.5/L2.4 的机制叠加）。所以”拒绝野值”的收益是长期性的，不只是一拍的事。

四、PX4 的其他工程细节（md 延伸阅读）

  • 时间戳与延迟融合：各传感器到数据带时间戳，EKF2 回滚/延迟补偿到 IMU 时刻
  • 双 EKF 冗余：跑两个实例互相监控（创新一致性），一个跑飞切另一个
  • 协方差有限化：长时间无更新时对 P 设上限，防止数值发散
  • fault recovery：连续拒收 + 创新超限 → 声光告警 + 降级模式（如仅姿态）

延迟融合的时间对齐（为什么重要）

工程级细节：延迟补偿是”生产级 KF 与教科书 KF”的分水岭之一——demo 的”数据到即更新”在真实系统里会因为时序错位引入系统性偏差（这也是 NEES 在真机常超标的隐藏原因之一）。

七、工程落点（真实项目）

  • PX4 EKF2（src/modules/ekf2）：上面架构速览的完整实现——本 demo 是它的 2D 切片，但 NIS 闸门/误差状态/多分支 fuse 全部同构。
  • robot_localization：diagnostics 的创新监控、传感器权重调节 = 简化版闸门。
  • 自动驾驶组合导航：GNSS 异常（多径、欺骗）用创新检验 + 鲁棒核——与 NIS 闸门同一思想。
  • 8 UR5e 仿真项目 飞控调试：EKF2 的 EKF2_GPS_CHECK、EKF2_REQ_* 参数就是闸门阈值的工程化（出厂前按”误伤 vs 漏网”标定）。

八、自检

  • 把闸门改成 9.21：正常观测开始被误伤（总拒收 >2）——体会闸门宽度的权衡。
  • 把野值幅度从 25 降到 8：闸门拦不住它（NIS < 25）→ 小野值需要 R 调大或鲁棒核。
  • 挑战：把 NIS 闸门换成”鲁棒核”（Huber：NIS 超阈值后按 √(NIS)/NIS 降权而非全拒）——比较两者在”中度野值”下的表现差异。
