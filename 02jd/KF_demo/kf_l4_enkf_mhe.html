L4（工业扩展）· 集合卡尔曼 EnKF + 移动 horizon 估计 MHE ⭐

本文件是 kf_l4_enkf_mhe.cpp 的配套讲解。图示：images/fig19_enkf_mhe.svg（四联图），浏览器完整预览 kf_l4_enkf_mhe_diagrams.html。
一句话：EnKF 是「蒙特卡洛版的 KF」、MHE 是「滤波的对偶——把估计写成滑动窗上的批量最小二乘优化」。两者都建立在 L1–L3 的单步 KF/最小二乘之上，是工业界（油气/气象/过程工业/机器人）天天在用的估计器。

0. 这一站解决什么

前面 18 篇把单步卡尔曼滤波讲透了：预测（卷积/方差相加）→ 更新（乘积/精度相加），增益 K 由 Q/R 比值决定。但有两个工业级现实没覆盖：

  • 状态维数千万级（油藏模拟、全球气象）时，显式维护协方差矩阵 P 的 O(n²) 存储 + O(n³) 求逆根本扛不住。→ EnKF：用 m 个随机样本的集合代替 P 的传播，只存集合、不存协方差。
  • 估计要带约束、要抑制野值、要”用到未来一段量测”（过程工业与 MPC 成对出现）。→ MHE：把估计写成一个滑动窗上的批量最小二乘问题，天然支持约束。

与兄弟仓库的呼应：MHE 的”约束批量优化”思想与 ctrl_l4_mpc（control，L4 滚动时域每步求解同一 QP）、ls_l4_lasso（LS，L4 可重放近端梯度迭代）同构——都是「把反复求解的同一结构固化」。

1. 原理

1.1 EnKF（随机集合卡尔曼滤波，perturbed-observation 变体）

核心：用集合 {xⁱ} 取代协方差 P。

为什么有效：扰动观测让每个样本带着不同的量测噪声，集合的散度自然复现了”更新步注入的量测不确定性”。当 m→∞，EnKF 均值/协方差严格收敛到精确 KF（本 demo m=200 已足够，末窗偏差见 §3）。

1.2 MHE（移动 horizon 估计，全状态观测 H=I）

可观测性结论（关键设计点）：若 H=[1,0]（仅位置观测）且 dt=0.1，速度分量几乎不可观测 → 滑窗会把速度”过拟合”到量测噪声，估计发散。本 demo 取 H=I（全状态观测），速度可观测，问题良态。权重上 Q⁻¹=50 ≫ R⁻¹=5，表示”信任动力学传播、用量测做校正”。

高斯-牛顿法方程装配（本 demo 的最关键一步）：把代价对状态向量 x 求导，残差 r 的雅可比：

  • 动力学残差 r = x_{s+1} − F·x_s → 雅可比 J = [ −F | +I ]（对 x_s 为 −F、对 x_{s+1} 为 +I）
  • 量测残差 r = z_s − x_s → 雅可比 J = −I（H=I）
  • 先验残差 r = x_0 − μ₀ → 雅可比 J = −I

1.3 箱约束 MHE（投影梯度 + 回溯）

当需要约束（如 x_0 ≥ 0）时，x* = H⁻¹g 可能落在可行域外。本 demo 用投影梯度法：

4. 工程要点（闭坑）

  1. EnKF 必须用 perturbed-observation（或等效的随机扰动）：若所有样本喂同一 z，集合不会感知量测不确定性，更新步方差被系统性低估——这是 EnKF 上手最常见的错误。
  2. MHE 的可观测性先于一切：H 选错（如仅位置观测 + 小 dt）会让速度不可观测、滑窗过拟合量测噪声而发散。先确认全状态（或充分）可观测再上 MHE。
  3. 法方程用高斯-牛顿装配而非手工展开：手工 index 极易在 cross-term 上算错系数（本 demo 真实踩坑，Atb 偏差 11.15）。统一写 H=ΣJᵀWJ, g=ΣJᵀWz，正确性由”残差代价在 x* 处确实最小”兜底。
  4. **箱约束凸问题要”目标不增”**：投影梯度 + 回溯保证单调下降 ⇒ 收敛到全局最优，绝不发散；初值务必先投影到可行域。

6. 下一步 & 兄弟仓库互引

  • KF 内部：接 L1–L3 的单步 KF / 最小二乘 / NEES 闸门；EnKF 是 KF 的蒙特卡洛推广、MHE 是滤波的批量优化对偶——两者把”单步递推”升级为”集合/窗口”视角。
  • 跨 demo：与 ctrl_l4_mpc（control，L4 滚动时域 QP）、ls_l4_lasso（LS，L4 可重放近端梯度迭代）同构——都是”反复求解同一结构”；可观测性判据承接 L3.2（状态增广与可观测性 rank）。
  • 纵深（P1）：因子图批优化（iSAM2/GTSAM，SLAM 主流）、鲁棒/自适应 KF（Huber/Student-t，把 LS 的鲁棒代价搬进 KF）、多目标跟踪 JPDA/GM-PHD + OOSM 时间偏移。
