L4.4（多目标）· 多目标跟踪（JPDA / GM-PHD）+ OOSM 时间偏移 ⭐

本文件是 kf_l4_multitarget.cpp 的配套讲解。图示：images/fig22_multitarget.svg（三联图），浏览器完整预览 kf_l4_multitarget_diagrams.html。
一句话：单目标 KF（L1/L2）只解决「一个目标 + 干净量测」；真实战场是「多个目标 + 杂波 + 量测迟到」——三件套：JPDA 做软关联、GM-PHD 做免关联基数估计、OOSM 把迟到量测无缝并入。 这是雷达/多目标跟踪（MTT）的工业主流方法论，承接 L2.4（NEES/NIS 闸门）、L3.4（多传感器融合）。

验证：受管 Python 3.13.12 先行对拍 → 转写 C++17，15 项检查全部 PASS。

0. 这一站解决什么

前 21 篇把单目标卡尔曼滤波讲透了。但工业多目标跟踪（雷达、ADS-B、多相机）的真实形态是：

  • 谁是谁？ 量测里混着多个目标的回波 + 杂波，必须做数据关联（哪条量测属于哪个目标）。
  • 几个目标？ 目标会出生、存活、死亡，目标数本身是随时间变化的随机变量（基数 cardinality）。
  • 量测迟到？ 分布式传感器/网络传输会让某些量测乱序到达（Out-Of-Sequence Measurement, OOSM），直接丢弃浪费信息、硬插会破坏滤波器一致性。

本篇三件套各攻一点，且都不依赖显式「硬」关联假设：

子主题 解决 核心思想
JPDA 软关联（谁是谁，含歧义） 枚举联合关联事件 → 边缘概率 β_ij 软分配，新息取凸组合
GM-PHD 基数估计（几个目标） 加权高斯分量 Σw 直接给目标数，免去逐对关联
OOSM 乱序量测（迟到怎么用） 迟到量测经「从 m-1 重滤波」≡ 全量测正序重滤波（OOSM 定理）

与兄弟仓库呼应：Jacobian_demo（雅可比）是 PHD 滤波量测更新线性化基础；pid_demo 的时序一致性思想同构于 OOSM 的「时间戳对齐」；L2.2 信息滤波的「更新=加法」正是 PHD 高斯分量更新的代数内核。

1. 原理

1.1 JPDA：联合概率数据关联（软关联）

传统「最近邻 / 硬关联」在歧义量测（一条量测同时落在两个目标门内）时会错配。JPDA 不硬判决，而是给每个「目标↔量测」配对一个概率：

  1. 门控（Gate）：用 χ² 门限（$\chi^2_{2,0.99}=9.21$ for 2D）剔除明显是杂波的量测。落在门内的量测才进入关联候选。
  2. 枚举联合关联事件：每个目标至多分一个量测（一条量测至多给一个目标）。事件 $E$ 的似然：
    $$\mathcal L(E)=\prod_{i:\text{命中}} P_D P_G,\mathcal N(z;x_i^-,S_i);\cdot\prod_{i:\text{漏检}}(1-P_D P_G);\cdot\prod_{j:\text{未分配}}\frac{\lambda_c}{1-P_D P_G}$$
    其中 $\lambda_c$ 是杂波空间密度、$P_D$ 检测概率、$S_i=H P^- H^\top+R$ 新息协方差。
  3. 边缘关联概率 $\beta_{ij}=P(\text{目标}i\leftrightarrow\text{量测}j)=\sum_{E\ni i\leftrightarrow j}\mathcal L(E)/\sum_E\mathcal L(E)$。
  4. 组合新息是候选新息的凸组合：$\bar\nu_i=\sum_j\beta_{ij}(z_j-x_i^-)$，再像普通 KF 一样更新。

demo A 部分：双目标 $x_1=[2,0],x_2=[-2,0]$，量测 m1 近 t1、m2 近 t2、m3 远处杂波、m4 两目标中点（歧义）。结果 $\beta_{1m4}=\beta_{2m4}=0.1037$（对称软分配）、m3 关联概率严格为 0、组合新息模长 0.0894 不超过任一单量测新息（凸组合性质）。

1.2 OOSM：乱序量测处理（迟到量测怎么用）

量测 $z[m]$ 在时刻 $N$ 才迟到到达（本应在 $m<N$ 时刻并入）。朴素做法：要么丢弃（损失信息），要么硬插到当前（破坏一致性）。

OOSM 定理（正确性判据）：在正确时刻并入迟到量测 $z[m]$ 的最优估计，严格等价于「从 $m-1$ 时刻的状态起、把 $z[m],z[m+1],\dots,z[N]$ 正序重滤波一遍」的结果——即重滤波（refilter）。

  • 实现「从 $m-1$ 重滤波」：取前向滤波器在 $m-1$ 时刻的后验 $x(m-1|m-1)$（它已正确处理 $z[0..m-1]$，与正序重滤波一致），再正序滤波 $z[m..N]$。
  • 该结果 ≡ refilter(全量测正序)，对噪声实现数值恒等（demo 验证偏差 0），而永久丢弃方案 ≠ 它（后验不确定度更大）。

⚠️ 踩坑（关键，已修复）：初版把 OOSM 理解成「逆时间平滑(RTS)回滚到 $m$ 再并入 $z[m]$ 后直接当结果」。对常量目标（$Q=0$）这碰巧对，但对随机游走（$Q>0$）会错——因为此后 $z[m+1..N]$ 在重滤波里是作为更新改变均值的，而「平滑后直接前推」没有重新并入这些量测，二者偏离可达 0.5+。正确做法是从 $m-1$ 起重新正序滤波（等价于重滤波）。这也是为什么 OOSM 的「正确性」必须用「≡ 重滤波」来判定，而不是「更接近当前真值」——对 1~2 步滞后、量测冗余的吸收，OOSM 未必在单一实现上比丢弃更接近真值，但它在数学上等价于把量测用在正确时刻。

1.3 GM-PHD：概率假设密度（免关联基数估计）

传统多目标滤波要在「关联」上花大量算力。PHD 滤波直接在强度（intensity / first moment）层面操作：用一组加权高斯分量 $w_k\mathcal N(\cdot;m_k,P_k)$ 表示多目标后验，目标个数直接由 $\hat N=\sum w_k$ 估计——不做逐对关联。

单分量更新（量测 $z$ 到来时）：

  • 漏检分量：权重乘 $(1-P_D)$。
  • 每量测更新分量：权重 $\propto \dfrac{P_D,w_k}{\lambda_c+\sum_l P_D w_l,\mathcal N(z;m_l,P_l+R)}\cdot\mathcal N(z;m_k,P_k+R)$。
  • 预测：存活分量 $\times P_S$ + 出生分量。
  • 剪枝：权重 $<w_{\min}$（本 demo $10^{-3}$）的分量丢弃。

demo C 部分：目标在 $k=10$ 出生、$k=40$ 死亡。出生前 $\hat N=0.0000$、存活期 $\hat N=0.9823\approx1$、死亡后 $\hat N=0.0000$，完整复现「出生→存活→死亡」的基数演化。

2. 与单目标 KF 的关系（承上启下）

  • JPDA = 单步 KF 更新的「关联泛化」：把新息从「单条量测」换成「按 β_ij 加权的凸组合」。关联概率的分母正是 L2.4 的 NIS/χ² 闸门在「事件」层面的推广。
  • GM-PHD = 信息滤波（L2.2）在多模态/多目标强度上的延伸：每个高斯分量独立做「预测+更新」，更新=精度相加那一套完全一致。
  • OOSM = RTS 平滑（L2.3）「时间一致性」思想的工程化：迟到量测要当作「本来就该在那个时刻出现」来处理，结果和重滤波不可区分。

4. 工程要点 & 踩坑

  1. JPDA 事件枚举随目标/量测数组合爆炸：实际系统用 Murty 算法取 top-K 事件近似，而非全枚举（demo 仅 2 目标 4 量测，全枚举 8 个事件可行）。
  2. OOSM 的「正确性」判据是 ≡ 重滤波，不是「更接近真值」：对短滞后、量测冗余的场景，迟到量测信息已被后续量测吸收，OOSM 在单一噪声实现上未必比「丢弃」更接近当前真态——但它在数学上等价于把量测用在正确时刻（demo 用 abs(oosm-ref)<1e-9 判定，对噪声实现鲁棒）。
  3. GM-PHD 剪枝阈值：$w_{\min}$ 太大会丢弱目标、太小会分量爆炸；工程上配「合并（merge）+ 剪枝」双保险。
  4. JPDA 组合新息的凸组合性质是数值稳定的天然保证：更新不会因某条歧义量测而剧烈跳变。
