L4.2（图优化）· 因子图批优化（iSAM2/GTSAM 视角）⭐

本文件是 kf_l4_factor.cpp 的配套讲解。图示：images/fig20_factor.svg（四联图），浏览器完整预览 kf_l4_factor_diagrams.html。
一句话：因子图批优化 = 把 RTS 平滑 / 信息滤波写成「图」——变量是位姿、因子是约束，MAP 解就是平滑解；加一条 loop-closure 因子就能把漂走的轨迹拉回。 这是 SLAM / 多传感器融合的工业主流方法论，承接 L2.2 信息滤波 / L2.3 RTS 平滑。

0. 这一站解决什么

前面 19 篇把单步卡尔曼滤波（含 RTS 离线平滑、信息滤波）讲透了。但工业 SLAM 的真实形态是图优化：机器人一边走一边用里程计/量测建图，偶尔认出「我回到之前来过的地方」→ 加一条回环（loop-closure）因子把整张图拉直。

  • 为什么不直接用 RTS？RTS 是链式平滑：只能往回修正一条链。一旦有闭环（终点连回起点），链结构就不够用了——需要稀疏图 + 批（或增量）优化。
  • 核心结论：因子图的 MAP（最大后验）解，在线性高斯下数学上 == RTS 平滑的解（图视角 vs 链式视角）。所以本篇是 L2.3 的「图升级版」，不是新算法。

与兄弟仓库呼应：BA / 手眼标定（cali_demo）本质是因子图；ls_l4_lasso 的「把反复求解的同一结构固化」思想同构；Jacobian_demo 的 SE(3) 雅可比是因子图残差的线性化基础。

1. 原理

1.1 因子图 = 信息矩阵视角

变量：2D 位姿 $p_i\ (i=0..N)$，维数 $2(N+1)$。三类因子（线性化后都是线性的）：

把所有因子的残差平方和（加权信息矩阵 $\Lambda$）相加，对状态求导，组装**法方程 $Hx = g$**：

  • $H = \sum J^\top \Lambda J$（信息矩阵 = 所有因子雅可比的加权和）
  • $g = \sum J^\top \Lambda z$

因为因子只连相邻位姿（between）或单点位姿（prior/unary），所以 $H$ 是块三对角 + 闭环长边——这正是「可增量求解」的稀疏结构（与 L2.2 信息滤波呼应：信息矩阵天然稀疏）。Hx=g 的解 $x^*$ 就是 MAP 估计。

1.2 因子图 MAP == RTS 平滑（图 vs 链）

随机游走链：$x_k = x_{k-1} + w_k$（$w\sim N(0,Q)$），量测 $z_k = x_k + v_k$（$v\sim N(0,R)$）。

  • 因子图：prior(0) + between(过程噪声 $Q^{-1}$) + unary(量测 $R^{-1}$)。
  • RTS：前向 KF + 后向平滑。

两者都是「在 $Q^{-1}, R^{-1}$ 加权下最小化残差平方和」——同一优化问题的两种写法，解必须一致（本 demo A 部分验证偏差 $1.1\times10^{-15}$）。

⚠️ 踩坑（已修复，最关键）：RTS 后向修正必须用预测值 $x_{k+1}^- = F\cdot x_k^+$（随机游走 $F=I$ 故为 $x_f[k]$），不是滤波值 $x_f[k+1]$。若误用滤波值，整条链会被 prior 锚定偏移（隔离测试曾出现 $k=0$ 处偏差 0.37）。本 demo 用 xpred_next = xf[k] 修正。

1.3 SLAM 闭环：里程计链 + loop-closure 因子

真值沿圆走一圈回到起点（$x_M^* = x_0^*$）。里程计带噪声 → 死推算终点漂离起点；loop-closure 因子断言 $x_M \approx x_0$（重回起点路标），把它拉回，并重新分配整条链的误差。

  • 仅里程计（determined 系统）== 死推算递推（强先验锁死起点时两者逐位一致，偏差 $5.8\times10^{-15}$）。
  • 加闭环后：终点误差 $\approx 0$，整链 RMSE 显著下降。

1.4 iSAM2 一致性（KKT 不动点）

iSAM2 的卖点是「增量更新 == 全量批解」。无论用增量还是批式求解器，最终都收敛到同一个 MAP——即总代价梯度 $\nabla J = 0$ 的不动点（KKT 一阶最优性）。本 demo 在闭环解处算梯度范数 $2.83\times10^{-13} \approx 0$，证明解是最优不动点；闭环因子是活跃约束（解相对里程计解变更 2.803，说明它确实把漂走终点拉回了）。

4. 工程要点（闭坑）

  1. RTS 后向必须用预测值：x_{k+1}^- = F x_k^+，不是滤波值 x_f[k+1]——这是教科书最易错处，错用会让整链被 prior 偏移。
  2. 因子图与 RTS 是同一优化问题的两种写法：线性高斯下 MAP≡平滑。先吃透 L2.3 RTS，再来看因子图就是「把链式推广成图」，概念零新增。
  3. 稀疏性是增量求解的根本：因子只连相邻/单位姿，信息矩阵块三对角+闭环长边 → 变量边缘化 / Schur 补可加速（GTSAM/iSAM2 的底层）。不要手搓稠密求解大图。
  4. 闭环是「活跃约束」才有效：若闭环因子信息太弱（权重远低于里程计），它拉不动轨迹；本 demo 闭环 $\sigma=0.08$ 远强于里程计 $\sigma=0.18$，故能主导。
