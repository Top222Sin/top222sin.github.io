KF_demo — 卡尔曼滤波精讲（22 篇 · 纯 C++17）

学习链第五篇：neon_demo(ARM) → cuda_demo(GPU) → cali_demo(标定) → pid_demo(控制) → Jacobian_demo(雅可比) → KF_demo(状态估计)
约定与兄弟仓库一致：纯 C++17 标准库（无 Eigen/OpenCV），每个 demo 自带合成数据 + 真值对拍 + PASS/FAIL，file(GLOB kf_*.cpp) 一次构建全部。
正篇 L1×5 + L2×6 + L3×4 = 15 篇；扩展篇 L3.5-L3.7（EKF-SLAM / MSCKF / PX4 应用）；工业扩展 L4.1-L4.4（EnKF+MHE / 因子图批优化 / 鲁棒自适应 KF / 多目标跟踪）。

统一主线

卡尔曼滤波 = 高斯贝叶斯的递推实现：

  • K 由 Q/R 比值决定：信模型还是信观测（L1.3/L1.5）
  • 体检：NEES/NIS 检验滤波器”诚不诚实”（L2.4）
  • 非线性：EKF 用雅可比（衔接 Jacobian_demo）、UKF 用采样（L2.5/L2.6）
  • 工程化：误差状态导航、可观测性、粒子滤波、多传感器融合（L3.x）

验证状态（重要）

  • 本机无 C++ 编译器（g++/cl/clang/MSVC 均不可用）。全部 22 个 demo 的数学正确性，已通过受管 Python 3.13.12 镜像实现逐一核验（90 项检查全部 PASS：正篇 41 + 扩展 11 + L4.1 EnKF+MHE 8 + L4.3 鲁棒/自适应 KF 7 + L4.2 因子图批优化 8 + L4.4 多目标跟踪 15）：
    • 1D KF vs 批量贝叶斯 ~1e-16；高斯积/卷积 ~1e-16；K∞ 边界 ~1e-9
    • CV-KF RMSE 对拍；DARE 收敛 + 稳态=全KF（6.8e-5）；IF≡KF ~1e-15
    • RTS 平滑改善 50%；NEES/NIS 400 次 MC（匹配 1.01 / 过信 40.3）
    • EKF 雅可比 vs FD ~1e-10；UKF 线性≡KF ~1e-11 + 极坐标矩转换完胜 EKF
    • ES-EKF RMSE 0.12 vs DR 4.9、零偏收敛 0.008；可观测性 rank 判据
    • PF 单峰≈KF / 多峰 PF 0.39 vs KF 1.09；融合 NEES=3.69≈4 一致
    • 扩展篇：EKF-SLAM H vs FD 1e-10 + 回环后路标误差 <0.22 m；
      MSCKF A·Hf=0（      1e-16）+ A·r 对 δf 一阶不变（~1e-12）+ 位姿修正收敛；
      PX4 闸门拦全野值、RMSE 0.80 vs 无闸门 2.15、接受 NIS≈2.9
    • L4.1：EnKF 均值/协方差与精确 KF 对拍（末窗偏差 0.27 / 0.03）、集合协方差估计器一致（0.32）；MHE 法方程残差 2.3e-14、单窗口恢复 0.44、滑动窗不发散（最大 0.68）、箱约束可行且激活（x_0 −0.154→0.000）—— 8 项全 PASS
    • 鲁棒/自适应 KF（L4.3）：±18 野值下标准 KF 整链 RMSE 1.96、Huber 0.60、Student-t 0.56（均 < 0.6×）；野值步 Huber 权重 0.0858（被降权）；Sage-Husa 跟踪时变噪声（R 末段 2.33→5.25）、自适应后 NIS 1.03 —— 7 项全 PASS
    • 因子图批优化（L4.2）：MAP≡RTS 平滑偏差 1.1e-15、信息矩阵稀疏占比 0.109；SLAM 闭环终点误差 0.080、整链 RMSE 0.37<0.59、闭环解梯度 2.8e-13≈0、闭环是活跃约束（解变更 2.803）—— 8 项全 PASS
    • 多目标跟踪（L4.4）：JPDA 软关联 β_1m4=β_2m4=0.1037（对称）、组合新息凸组合；OOSM ≡ 重滤波（1.38555≡1.38555，数值恒等）且 ≠ 丢弃、常量目标后验不确定度 P_oosm 0.0474<P_disc 0.0498；GM-PHD 基数 出生前 0.0000 / 存活 0.9823 / 死亡后 0.0000—— 15 项全 PASS
  • 因此 C++ 源码在具备编译器的环境下应当全部 PASS。
  • 开发中抓到并修复的真实 bug（写进对应 .md 的”踩坑”注记）：
    ① Joseph 形式漏 +KRKᵀ（P 缩小 20 倍，靠 IF 交叉对拍暴露）
    ② DARE 迭代同 bug；③ UKF 更新复用旧 sigma 点丢 Q 贡献（靠”线性≡KF”不变量暴露）
    ④ 精确离散 Q 的 dt⁴/4 vs 教材 dt³/3 模型失配（靠 NEES 闸门暴露）
    ⑤ 方位角残差未缠绕、路标贴脸 1/r² 病态（capstone）
    ⑥ SLAM 路标按观测顺序入状态时，状态索引必须用”槽位”而非路标编号（对拍越界暴露）
    ⑦ NIS 闸门 9.21（99% 卡方）会误伤正常观测——PX4 实际用 5σ（≈25），闸门宽度本身是调参对象

目录结构

与兄弟仓库的关系

  • Jacobian_demo：EKF 的 F=∂f/∂x、H=∂h/∂x 正是雅可比矩阵——L2.5/L3.4 直接消费其结论（极坐标观测 H 同型于其 L4.2）
  • pid_demo：KF 估计 + PID 控制 = LQG 经典组合；误差状态思想同源
  • cali_demo：BA/手眼标定的核心迭代 = 信息滤波器视角的最小二乘（L2.2）
