L2.5 非线性（一）：扩展卡尔曼滤波 EKF

一句话：EKF = 在当前估计点把 f/h 一阶泰勒展开，把 F=∂f/∂x、H=∂h/∂x 当作线性 KF 用——简单、快，但线性化点离真值远时会发散（雅可比推导见 Jacobian_demo L1，此处直接消费）。

一、两个替换

雅可比在”当前估计点”取值——估计偏了线性化就歪，歪了估计更偏（正反馈 → 发散风险）。

EKF 为什么是”扩展”而不是”新滤波”（推导直觉）

非线性系统 xₖ₊₁ = f(xₖ) + w, zₖ = h(xₖ) + v。在估计点 x̂ 做一阶泰勒展开（Jacobian_demo L1.1 的局部线性化）：

核心洞察：EKF 不是新算法，是”每步重新线性化的 KF“。误差系统的线性化让 KF 的五公式照常工作——代价是线性化误差（截断的高阶项），这就是它发散风险的来源。

二、demo 验证

  1. 极坐标观测 H vs 有限差分（~1e-10）：h=[r,θ]=[(x²+y²)^½, atan2(y,x)] 的雅可比

    H = [[x/r, y/r], [−y/r², x/r²]]

    与 Jacobian_demo L3.8 的路标观测同型——非线性滤波的骨架就是观测雅可比。

  2. 单摆 F vs 有限差分（~1e-11）：f=[θ+dt·ω, ω−dt·sinθ]，F=[[1,dt],[−dt·cosθ,1]]。

  3. 单摆 EKF 滤波 RMSE=0.027 < 观测 RMSE=0.137：强非线性动力学下 EKF 仍稳。

极坐标 H 的推导（为什么是 1/r 和 −1/r²）

与 Jacobian_demo L2.6 的重投影雅可比、L3.8 的路标观测完全同型——极坐标观测是雷达/地标/视觉重投影的共同骨架。注意方位行 [−y/r², x/r²] 的范数：‖·‖ = √(x²+y²)/r² = r/r² = **O(1/r)**（不是 O(1/r²)）——r→0 时确实奇异（r=0 处 bearing 无定义），但发散量级是 1/r（L3.4 的”路标贴脸”雷区仍适用）。

三、EKF 的三种死法（工程避险清单）

死法 场景 解药
线性化失准 初始误差大 / 强非线性 UKF（L2.6）、迭代 EKF
协方差塌缩 Q/R 低估、重复使用相关观测、数值更新破坏半正定 加 Q 下限、Joseph 形式、创新检验（注：长期无更新通常使 P 增大而非塌缩）
雅可比写错 手推符号错（本仓库踩过 3 次） 永远用有限差分对拍（本 demo 的做法）

说明：EKF 的 P⁻ = FPFᵀ + Q 适用于加性过程噪声且噪声直接进状态（G=I）的简化模型；一般模型 xₖ₊₁=f(xₖ,wₖ) 需用 G=∂f/∂w 映射：P⁻ = FPFᵀ + GQGᵀ。

线性化失准的定量直觉（什么时候 EKF 危险）

工程信号：EKF 发散前 NEES 会先爆表（L2.4 的闸门是预警）——一致性监控是 EKF 的安全气囊。

六、工程落点（真实项目）

  • PX4 EKF2：误差状态 EKF（L3.1/L3.7）——IMU 传播 + GPS/磁力计/气压计观测，每个观测 H 都是极坐标/线性混合雅可比。
  • robot_localization：EKF 节点处理非线性观测（如激光测距）时用雅可比 H。
  • OpenCV：cv::KalmanFilter 是线性 KF，非线性系统自己扩展（相机标定的迭代优化 = 高斯牛顿的雅可比，同源）。
  • 组合导航（GNSS/INS）：松耦合/紧耦合全是 EKF 家族——伪距/载波相位的 H 是卫星几何雅可比。

七、自检

  • 把观测噪声 r 调大 10 倍再跑单摆——估计会滞后但仍收敛；思考为什么非线性”等效变弱”了。
  • 把初值 θ₀=0 改成 θ₀=π（倒立点），观察收敛变慢。
  • 挑战：为什么”误差状态 EKF”（L3.1）比”全量 EKF”更抗线性化失准？（误差 δx 始终小 → 线性化永远在甜点区）
