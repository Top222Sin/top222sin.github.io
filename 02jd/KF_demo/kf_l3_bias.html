L3.2 状态增广：传感器零偏估计与可观测性

一句话：增广进状态 ≠ 估得出来——系统能否观测由 rank(O)=n 决定（O=[H; HF; HF²; …]）；不可观测的方向上 P 永不收敛，滤波器输出的是”自欺欺人的确定性”。

一、可观测性判据

线性时不变系统 (F, H) 完全可观测 ⇔ 可观测性矩阵满秩：

O = [H; HF; HF²; …; HFⁿ⁻¹]，rank(O) = n

直观：H 一次观测只能”看”部分状态；HF 是”一步预测后再看”；乘积 HFᵏ 把动力学的耦合逐步展开——只要 n 次不同时刻的观测线性无关，状态就唯一确定。

可观测性矩阵的推导（为什么是 H, HF, HF²…）

核心洞察：可观测性 = “时间上的观测序列能否反解初始状态”。单次观测 H 只看到部分维度，但动力学耦合 F 让观测”随时间泄漏”出其他状态的信息（L1.4 的”位置观测恢复速度”就是这个泄漏）。这也是为什么”可观测性”是时域概念——需要多时刻的观测。

二、demo 验证 ①：零偏可观测

增广 x=[p, v, b]（L3.1 的模型），只测位置 H=[1,0,0]：

零偏 b 通过位置的 dt² 累积效应泄漏进观测——这就是 L3.1 里 b̂ 能收敛的代数原因。但注意收敛慢（增益小），工程上需要激励（加减速/转向）加速。

为什么第三行是 −2dt²（泄漏的累积）

洞察：**可观测性靠”动力学随时间展开”**——零偏若恒定，位置误差按 t² 增长，多次观测就能拟合出这条抛物线，从而反解 b。这也解释了”可观测但收敛慢”：b 的增益来自 dt² 的小泄漏，需要足够长的观测窗口（L3.1 的几分钟才估准）。

三、demo 验证 ②：反例

4D 状态 [px, py, vx, vy]（标准二维匀速模型 F=[[1,0,dt,0],[0,1,0,dt],[0,0,1,0],[0,0,0,1]]），只测 vx（H=[0,0,1,0]）→ rank=1 < 4：

  • 可观测的只有 vx；px、py、vy 全部不可观测（HF^k 恒为 [0,0,1,0]，位置与 vy 从不进入观测）——P 中对应块无法被观测约束
  • 经典实例：匀速直行时航向不可观测（雷达导引、单目视觉尺度的病根）

不可观测的工程表现（为什么危险）

工程铁律：增广状态前先算 rank(O)（L1.4 教训的推广）；不可观测方向要删状态、加传感器、或加激励——让滤波器去估一个不可观测量，是”用复杂掩盖无知”。注意 rank 阈值要尺度归一化（SVD 相对阈值 σ_i/σ_max > ε，如 1e-6~1e-8），固定绝对阈值随状态单位漂移。

四、工程清单

  1. 增广新状态前先算 rank(O)（数值方法：行消元，阈值 1e-8）
  2. 不可观测时：加激励（机动）/加传感器（双天线航向）/删状态（别自欺）
  3. 可观测 ≠ 快收敛：条件数大 → 收敛慢 → 需要丰富激励

可观测性 vs 收敛速度（工程两问）

决策流程：① rank 满了吗？不满 → 改传感器/状态。② 满了，条件数多大？太大 → 加激励或接受慢收敛。**”能估”和”估得快”是两个问题**——面试答”可观测性”时主动说这一句，是加分项。

七、工程落点（真实项目）

  • PX4 EKF2 的零偏估计：陀螺/加计零偏在状态里（L3.1）——可观测性分析决定”什么时候能动 b”（静止时陀螺零偏可观测、加计零偏与重力耦合需特定姿态）。
  • 单目 VIO 的尺度：单目视觉观测对”尺度”不可观（深度×尺度歧义）——所以 VIO 需要初始化（IMU 重力对齐）或外部先验。
  • 雷达导引：匀速直行目标只有距离观测 → 横向速度不可观 → 必须加机动（这正是”目标跟踪要机动”的原因）。
  • MSCKF（L3.6）：为什么克隆位姿？——为了给特征观测提供”多个视角”（视角多 = 可观测性好）。

八、自检

  • 把 H 改成 [0,1,0]（只测速度），rank 变 2——位置可积出来吗？（差一个常数，不可观测！）
  • 思考：为什么”位置观测 + 常值零偏”可观测，而”位置观测 + 随机游走零偏”只是渐近可观测？
  • 挑战：把 demo 的 3D 模型（只测 vx 的反例）改成”测 vx + vy”，rank 变多少？（2——位置仍不可观，差平移常数）
