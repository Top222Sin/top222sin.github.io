L3.6 扩展：MSCKF 多状态约束滤波（VIO 核心）⭐

一句话：MSCKF 把”滑窗内的历史位姿”克隆进状态、特征点不进状态——特征误差 δf 用残差堆叠后的左零空间投影 A（A·Hf=0）精确消掉，一条特征只产生一个纯位姿约束；状态维数只随窗口（~20 姿势）而非特征数（成千上万）增长，这就是 AR 眼镜/无人机视觉惯性里程计能实时跑的根本原因。

一、与 EKF-SLAM 的对比

EKF-SLAM MSCKF
状态 机器人 + 所有路标 IMU 误差状态 + 滑窗位姿克隆
特征点 在状态里 不在（只做粗略三角化）
状态维数 3+2M（M=特征数） 15+6K（K=窗口位姿数，~20）
计算量 随特征数平方增长 与特征数解耦

为什么”特征不进状态”是革命（对比动机）

核心思想：特征的位置是”nuisance parameter”（多余参数）——估它不如消掉它。MSCKF 用零空间投影把特征误差 δf 从观测方程里代数消去，剩下纯位姿约束，再用 KF 更新。这是”图优化边缘化”思想的滤波版。

二、零空间投影：三行代数

一个特征被 K 个位姿观测 → 堆叠残差：

r = Hx·δx + Hf·δf + n （Hf 是 K×2）

特征位置不准怎么办？找一个 A 满足 A·Hf = 0（Hf 列空间的左零空间，K−2 维）：

A·r = (A·Hx)·δx + A·n ← δf 彻底消失，只剩位姿约束！

然后就是普通的 KF 更新（用 A·Hx 当雅可比、A·r 当残差）。

零空间投影的推导（为什么能消 δf）

数学直觉：K 次观测给了 K 维信息，其中 2 维”被特征位置消耗”，剩下的 K−2 维是纯位姿信息——A 就是”提取这 K−2 维”的投影。特征估不准没关系，因为 A 只保留位姿方向的信息（与 Jacobian_demo 的”可观测性”一脉相承：观测的信息结构决定能估什么）。

⚠️ 维数限定：K−2 是本 demo 的 2D 单标量特征 miniature（Hf 是 K×2、rank=2）下的结论。真实 MSCKF 是 3D 特征、每帧 2 个像素残差：Hf 为 2K×3（rank=3），左零空间维数 = 2K−3——公式随观测模型变，别把 K−2 当通用结论。

三、demo 验证（2D bearing-only miniature，K=5 位姿窗）

  1. A·Hf = 0：Gram-Schmidt 求正交补基，正交性 ~1e-16 ✅
  2. 不变量：特征估计 f̂ 扰动 1e-5 → A·r 变化 ~1e-12（原始残差 r 变化 ~1e-3）——投影后的约束对特征估计一阶不敏感 ✅
  3. 位姿修正：窗口位姿误差 0.107 → 0.098（观测几何弱时改善有限，但约束正确且不依赖特征精度）✅

不变量的工程意义（为什么这测试重要）

验证方法：扰动 f̂ 看 A·r 是否几乎不变——这是 MSCKF 实现正确性的黄金测试（本 demo 的不变量检查）。真实 MSCKF 同样用这个性质容忍”特征只粗三角化”。

四、真实 MSCKF 还有什么（本 demo 简化掉的）

  • 3D + 相机投影模型（针孔 + 畸变），每个特征 2K×3 的 Hf
  • 零空间用 QR 分解求（数值更稳），也可用右零空间/舒尔补等价做法
  • 窗口滑出时边缘化（marginalization）老位姿，保留其信息
  • 特征三角化的粗估从两帧五点法/多帧初始化
  • 代表实现：Mourikis & Roumeliotis 2007（火星探测起家）、OpenVINS、MSCKF_VIO、VINS-Mono（与其同族的优化法）

MSCKF vs 滑窗优化（VINS-Mono）的关系

工程选型：手机 AR（Apple ARKit 早期用 MSCKF 风格）、无人机（PX4 的 vision 融合）用滤波法保实时；桌面级 SLAM 用优化法保精度。

五、代码走读（kf_l3_msckf.cpp）

  • build()：残差 + Hx/Hf 雅可比；Gram-Schmidt 正交补 → A；A·Hf=0 与 A·r 不变量两道检查；标准 KF 更新。

六、你会看到什么

七、工程落点（真实项目）

  • OpenVINS（宾大）：开源 MSCKF 完整实现（3D、QR 零空间、边缘化）——工业/学术 VIO 标配参考。
  • MSCKF_VIO（Kumar 实验室）：经典开源实现。
  • PX4 视觉定位融合：EKF2 融合外部 vision 位姿——若用 VIO 前端（如 OpenVINS）就是 MSCKF 链路。
  • 火星车/无人机：Mourikis 的原始动机是计算受限平台——MSCKF 是”滤波法 VIO”的工业标准。

八、自检

  • 把特征粗估误差从 0.18 调到 2.0：A·r 几乎不变（不变量的意义），但原始 r 完全不可用。
  • 把 K 从 5 减到 3：A 退化成 1×3，约束变弱——窗口太短的代价。
  • 挑战：为什么零空间维数是 K−2（不是 K）？（2 维被特征位置消耗——每多一个位姿观测多 1 维位姿信息）
