KF_demo 内容审查报告

审查对象：02jd/KF_demo/（README.md + OUTLINE.md + 18 篇课程 .md + 18 个 .cpp + _diagrams.html + images/ 18 张 SVG）
审查日期：2026-08-18
审查维度：卡尔曼滤波公式正确性（五公式/信息形式/RTS/DARE/EKF/UKF/ES-EKF/MSCKF）、数值声明、文档与程序一致性、文件完整性

〇、总体结论

  • 整体质量高：18 篇（L1×5 + L2×6 + L3×7）三件套齐全（20 md = README + OUTLINE + 18 篇，18 cpp，18 张图，无缺件）。本报告逐篇通读了全部 18 篇 md 并复算了核心公式，绝大多数内容正确且理论深度出色：
    • 五公式、高斯积/卷积、信息形式（预测难更新易）、RTS 三公式、DARE/Joseph、NEES/NIS 与卡方、EKF（极坐标 H、单摆 F）、UKF sigma 点、ES-EKF 误差动力学、可观测性、SIR 粒子滤波、EKF-SLAM 分块 H、MSCKF 左零空间、PX4 NIS 闸门——公式与标准文献全部一致。
    • 特别亮点：L1.4 明确区分”逐拍独立加速度采样的精确离散 Q（dt⁴/4·dt³/2·dt²）”与”教材/ Van Loan 连续模型的 Q（dt³/3·dt²/2·dt²）”——这是多数教材都含糊的点，处理正确。
  • 确定性错误 2 处（均在 md 文档层，cpp 实现正确）：① L1.1 的 K 轨迹示例输出与程序不符；② L1.3 的 r 扫描表 4/5 行数值错误。
  • 轻微问题 2 处。
  • 方法说明：本机无 C++ 编译器，结论基于逐篇公式复算 + cpp 关键实现核对（含稳态方程的闭式解验证）。

一、确定性错误（❌ 建议修正）

E1. ❌ kf_l1_1dkf.md —— K 收敛轨迹示例输出与程序实际计算不符（且与文中 q/r 矛盾）

位置：kf_l1_1dkf.md 第 39 行（”增益 K 从初值快速收敛到稳态 K∞≈0.27”）与第 53 行示例输出（”K0=0.800 K1=0.364 … K_inf=0.27”）。

推导：文中的随机游走参数为 q=0.05、r=0.25、初值 P₀=1.0（kf_l1_1dkf.cpp 第 60–61、81 行同）。一维稳态增益满足 K∞²·r = q·(1−K∞) → K∞ = (−q+√(q²+4qr))/(2r) = 0.3583。逐步轨迹（cpp 实际计算）：K0 = 1.05/1.30 = 0.808、K1 = 0.2519/0.5019 = 0.502。

现状：md 写 K0=0.800、K1=0.364、K∞=0.27——其中 K∞=0.27 对应的是 q=0.025（代入 q=0.025/r=0.25 得 0.2702），与文中 q=0.05 矛盾；K0/K1 也与 cpp 输出（0.808/0.502）不符。

影响：照抄 K 轨迹的学习者会得到错误的收敛数值；建议以 cpp 实际输出（K0=0.808、K1=0.502、K∞≈0.358）回填 md。

E2. ❌ kf_l1_gain.md —— r 扫描表 4/5 行数值错误

位置：kf_l1_gain.md 第 37–44 行（”demo 的 r 扫描表”）。

推导：固定 q=0.1（cpp 第 20 行），K∞ = (−q+√(q²+4qr))/(2r)（由 K²r=q(1−K) 闭式解）：

r 正确 K∞ md 表格 判定
0.01 0.9161 0.9189 ❌
0.1 0.6180 0.6146 ❌
1.0 0.2702 0.2702 ✅
10 0.0951 0.0685 ❌
100 0.0311 0.0095 ❌

证据：kf_l1_gain.cpp 第 57–67 行按同一迭代（q=0.1）计算，实际输出即 0.9161/0.6180/0.2702/0.0951/0.0311。md 的 0.0685 恰为 q=0.05、r=10 的解（0.0683）——表格疑似混用了不同 q。

建议：按 cpp 实际输出修正扫描表（或统一注明 q 值）。

二、轻微问题（⚠️ 建议修正）

W1. ⚠️ kf_l3_bias.md —— 可观测性矩阵 O 第三行第三列量纲笔误

第 30 行显示 [ 1 2dt −2dt+dt³/2·...]。按 L3.1 的 F（[[1,dt,−dt²/2],[0,1,−dt],[0,0,1]]），HF² 第三列 = −2dt²（计算：−dt²/2 − dt·dt − dt²/2 = −2dt²，无 dt 线性项、无 dt³ 项）。md 的 “−2dt” 量纲错误（应为 dt² 量级）。cpp（dt=0.1）输出第三行第三列 −0.02 = −2·0.01 佐证正确值。

W2. ⚠️ README.md —— 第 132 行笔误 “H=∂h/∂h”

应为 H=∂h/∂x（与同句 F=∂f/∂x 对齐；该行是介绍与 Jacobian_demo 的衔接）。

W3. 📋 覆盖性说明（非错误）

README 声称”52 项检查全部 PASS”（正篇 41 + 扩展 11）只证明各 cpp 内部对拍通过；但 md 的「你会看到什么」存在与程序实际输出不符的示例（E1/E2），说明示例段落未经运行转录（与 control_demo、Jacobian_demo 同模式）。其余运行数字（RMSE、NEES 1.011/40.3、RTS 改善 50%、PF 0.39/1.09、PX4 0.80/2.15、SLAM 路标误差 0.180/0.144/0.219 等）本环境无法复核，建议在有 g++ 的环境统一回填。
