L1.3 增益 K 的物理意义：边界行为与稳态

一句话：K ∈ (0,1) 是”信观测还是信模型”的旋钮——r→0 时 K→1（全信观测），r→∞ 时 K→0（全信模型）；稳态 K∞ 由 Riccati 方程唯一决定，与初值无关。

一、K 是什么

一维下 K = p⁻/(p⁻+r)：先验方差占创新方差的比例。直观读法：

  • K=0.8：修正量的 80% 来自观测（观测很准/模型很烂）
  • K=0.1：只修 10%（观测很烂/模型很准）

极端边界（demo 验证到 1e-9 精度）：

场景 K 行为
r→0（观测无噪声） →1 x 完全跳到观测值 z
r→∞（观测全是噪声） →0 完全忽略观测，纯预测

K 的推导直觉（为什么是 p⁻/(p⁻+r)）

另一种等价读法（精度视角）：K = 观测精度 / (先验精度 + 观测精度) = (1/r)/(1/p⁻ + 1/r)。增益 = 观测信息的相对权重——与 L1.2 的”精度加权平均”完全一致。

二、稳态：Riccati 方程

迭代 p ← (1−K)(p+q)，K=(p+q)/(p+q+r) 收敛到唯一不动点 p∞（demo 中 2000 次迭代内收敛，K_k 单调收敛到 K∞，差 < 1e-12）。

关键结论：K∞ 与初始 p₀ 无关——滤波器”忘记”初值。这就是工程上敢用固定增益（≈Wiener 滤波器）的理由，L2.1 展开。

稳态 Riccati 不动点的解析解（一维）

设稳态后验方差 p∞，预测方差 m = p∞+q，增益 K∞ = m/(m+r)。稳态条件：更新后回到 p∞：

验证：q=0.1, r=1 → p∞ = (−0.1+√0.41)/2 = 0.270156，m = 0.370156，K∞ = 0.370156/1.370156 = 0.270156（r=1 时数值上恰有 p∞=K∞；一般 r≠1 时两者不等）。demo 输出 0.270297 是迭代 2000 步的浮点收敛值，与解析值差 ~5e-5（收敛判据精度内）——这是面试高频手算题：记住 p∞² + q·p∞ − r·q = 0 和 K∞ = (p∞+q)/(p∞+q+r)。

三、demo 的 r 扫描表

q 固定时 K∞ 随 r 单调下降——调 R 就是在调”滤波器带宽”。

为什么 K∞ 随 q 上升（模型可信度的另一面）

q 大 = 模型噪声大 = 模型不可信 → 相对更信观测 → K 上升。K 是一个比值旋钮，q/r 一起决定它——调参时”调 Q 或调 R”是同一根旋钮的两个把手（L1.5 展开）。

六、工程落点（真实项目）

  • 固定增益滤波器（稳态 KF）：嵌入式里预计算 K∞ 写死，省掉每拍矩阵运算——L2.1 专讲。手机 IMU 姿态、简单温控都是这种。
  • 调 R 的工程直觉：GPS 精度标称 2m → R≈4；视觉定位噪声更大 → R 更大。传感器融合的”信任度”就是 R⁻¹。
  • 自适应增益：GPS 卫星数变化 → R 实时变化 → K 自适应（L2.1 的”时变 R 场景”）。这也是为什么”固定 K”在真机不总是够用。

七、自检

  • 把 q 改大，观察 K∞ 上升（模型更不可信 → 更依赖观测）。
  • 思考：为什么 K_k 会收敛而不会振荡？（Riccati 是压缩映射）
  • 手算：q=0.05, r=0.25 的稳态 p∞ 与 K∞（p∞²+0.05p∞−0.0125=0 → p∞≈0.08956，K∞=(0.13956)/(0.38956)≈0.35826——demo 的 K_inf=0.3583 即此）
