L1.2 贝叶斯视角：高斯的乘积（更新）与卷积（预测）

一句话：预测 = 两个独立高斯相加 → 卷积（方差相加）；更新 = 先验 × 似然 → 乘积（精度相加）。KF 五公式不过是这两条高斯代数的矩阵版。

一、更新 = 高斯乘积

先验 N(μ₁, σ₁²) × 似然 N(μ₂, σ₂²) 的归一化乘积仍是高斯：

μ = (μ₁σ₂² + μ₂σ₁²)/(σ₁²+σ₂²)，σ² = σ₁²σ₂²/(σ₁²+σ₂²)

把 K = σ₁²/(σ₁²+σ₂²) 代入，正好得到 KF 更新：

μ = μ₁ + K(μ₂−μ₁)，σ² = (1−K)σ₁²

demo 验证两组公式逐位一致（差 < 1e-16）。直觉：均值按精度加权平均，方差一定变小——这就是”融合让信息变多”。

乘积公式推导（为什么是这种形式）

两个高斯相乘：N(μ₁,σ₁²)·N(μ₂,σ₂²) ∝ exp(−½[(x−μ₁)²/σ₁² + (x−μ₂)²/σ₂²])。指数里的二次项：

洞察：精度（1/σ²）相加，均值按精度加权——“谁准听谁的”。这就是贝叶斯更新的本质：后验精度 = 先验精度 + 似然精度（L1.1 的 Ω 视角在矩阵版的推广）。

二、预测 = 卷积（方差相加）

x_next = x + w（w 为过程噪声）时，独立随机变量相加 → 方差相加：

Var(x+w) = Var(x) + Var(w)（对应 p⁻ = p + q）

demo 用 2 万样本蒙特卡洛验证经验方差 ≈ σ₁² + 0.3（差 < 0.01）。预测永远不会让不确定性变小——没有新信息。

卷积为什么是”方差相加”（直觉+推导）

两个独立随机变量和的方差：

核心对比（背下来）：

  • 乘积（更新）：精度相加 → 信息变多 → 方差变小
  • 卷积（预测）：方差相加 → 噪声叠加 → 方差变大
  • 一个”融合知识”，一个”走过时间”——方向相反，这是 KF 全部行为的根源。

三、信息形式（information form）

把协方差倒过来定义信息矩阵 Ω = P⁻¹，更新公式惊人地简单：

Ω = Ω⁻ + HᵀR⁻¹H（精度相加！），ξ = ξ⁻ + HᵀR⁻¹z

demo 验证 Ω = 1/σ² 与乘积公式一致。这是 L2.2 信息滤波器的伏笔——SLAM 里更新只做加法的秘密就在这。

六、工程落点（真实项目）

  • 信息形式在 SLAM：路标长时间无观测时，KF 的 P 中对应块”不动”但要维护；信息滤波器里它只是”没被加过”——更新 = 累加稀疏块，这就是 g2o/因子图的增量性质（L2.2 展开）。
  • 概率机器人学（Probabilistic Robotics, Thrun）：全书 KF 部分就是这个”贝叶斯滤波 + 高斯假设”的框架，belief 就是高斯（μ, Σ）。
  • 传感器融合的”信任度”语言：产品经理说的”这个传感器准”在数学上就是 R⁻¹（信息量）；多传感器融合 = 信息相加。

七、自检

  • 改变 σ₁²/σ₂² 比值，观察 K 如何在 (0,1) 间滑动——谁精度高信谁。
  • 思考：为什么”乘积”使方差变小而”卷积”使方差变大？（提示：一个是融合信息，一个是叠加噪声）
  • 挑战：三个高斯相乘，μ 和 σ² 的通式？（精度相加 + 按精度加权平均——递归两次乘积即可，KF 多传感器更新就是这样）
