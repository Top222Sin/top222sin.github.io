L2.4 一致性检验：NEES / NIS 与卡方 ⭐

一句话：**RMSE 只告诉你”准不准”，NEES/NIS 告诉你滤波器”诚不诚实”**——它自报的 P 与实际误差是否匹配。NEES~χ²(n) 均值应为 n；持续偏大 = 过信（Q 太小），持续偏小 = 欠信。这是调参从”玄学”变”科学”的关键一步。

一、两个统计量

NIS 是工程利器：现场没有真值，但每次更新都能算创新马氏距离——它跑飞了说明模型失配（传感器故障、Q/R 错了）。

NEES 的统计推导（为什么均值是 n）

若滤波器”诚实”（P 真实反映误差分布），则误差 e = x_true − x̂ ~ N(0, P)：

核心洞察：NEES/NIS 是”滤波器假设（高斯+正确 P）”的拟合优度检验——χ² 分布是它的零假设。NEES 持续 > n：P 虚小（过信）；持续 < n：P 虚大（欠信）。**”诚实”不是形容词，是可用统计检验的数学性质**。

二、demo 验证（400 次蒙特卡洛）

配置 NEES NIS 判决
模型匹配 1.011 0.993 ✅ 诚实（期望 1）
Q 故意调小 200× 40.3 — ❌ 过信红灯爆表

NEES=40 意味着实际误差是滤波器自报的 √40 ≈ 6.3 倍——它对自己的 P 严重说谎（Q 太小 → P 缩得太快）。

为什么 Q 小 200 倍 NEES 爆到 40（机制）

这是过信的典型签名：NEES 爆表 + RMSE 变差。反过来欠信（Q 大）NEES 掉到 0.0x——误差小但 P 虚大，滤波器”过度谦虚”。

三、判读表（NEES 与 NIS 分开看）

NEES（状态维数 n）：

症状 病因 药方
NEES 持续 > n 过信：Q 偏小 / R 偏大 / 模型漏项 调大 Q、加状态（如零偏 L3.2）
持续 < n 欠信：Q 偏大 / R 偏小 调小 Q（白丢精度）
围绕 n 波动 一致 ✅ 收工

NIS（观测维数 m）：E[NIS]=m，且对 R 的诊断方向与直觉相反——R 假设过小 → S 过小 → NIS 偏大；R 假设过大 → NIS 偏小。NIS 偏大也可能是模型漏项/野值（不只是 R 的问题），需结合创新均值/自相关综合判断。

六、工程落点（真实项目）

  • PX4 EKF2：创新一致性（NIS）监控是标配——GPS 数据进来先过闸门再 fuse（L3.7 专讲），连续拒收触发故障降级。
  • robot_localization：diagnostics 输出创新统计，超界告警。
  • VINS/视觉 SLAM：视觉残差加鲁棒核（Huber/CAUCHY）本质就是”NIS 超界降权”的连续化版本。
  • 出厂标定：任何”我调好了 Q/R”的宣称，最后一步都该过 NEES 验收——这是滤波器交付的”体检报告”。

七、自检

  • 反向实验：把 Q 调大 100×（欠信），看 NEES 掉到 ~0.0x。
  • 单步 NIS 闸门：统计匹配模型下 NIS>3.84 的比例，应约 5%。
  • 挑战：为什么 NEES 用”误差的二次型”而不是 RMSE？（RMSE 只有标量聚合、无分布信息；二次型把”误差大小”和”自报方差”一起检验——诚实性必须两者匹配）
