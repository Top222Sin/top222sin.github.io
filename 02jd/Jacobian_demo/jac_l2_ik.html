L2.3 逆运动学：伪逆与阻尼最小二乘（DLS）

一句话：给定末端目标 x_des，逆解就是不断”把 Cartesian 误差 e = x_des − x(q) 反推成关节增量”。DLS：q̇ = Jᵀ(JJᵀ+λ²I)⁻¹ e，对奇异稳健；配合回溯线搜索保证误差单调下降。

一、从速度级到迭代

我们知道 ẋ = J·q̇。反过来，想把末端挪向 x_des，就令期望末端速度 ẋ_des = e = x_des − x(q)，解得关节速度：

q̇ = Jᵀ (J·Jᵀ + λ²I)⁻¹ e （DLS；λ=0 退化为普通伪逆）

每个控制周期 q ← q + μ·q̇，μ 是步长。迭代几步，末端就被”牵引”到目标。

推导链：为什么伪逆解是最小范数解

欠定/超定问题 J·q̇ = e（关节数 ≠ 任务维数）的最小二乘解：

几何直觉：q̇ 分解为”驱动末端误差的分量”+”零空间分量”（L2.4 展开）；伪逆只保留前者——用最小的关节运动换最大的末端误差消除。λ>0 的 DLS 额外惩罚关节速度范数，奇异时不再爆炸。

二、为什么需要 DLS + 线搜索

  • 普通伪逆（λ=0）在奇异处 (JJᵀ 不可逆) 会算出 Inf/NaN → 关节速度爆炸。
  • DLS（λ>0）给分母垫 λ²I，奇异附近仍有限、平滑。
  • 回溯线搜索：不是盲目用满步 μ=1，而是逐步缩短 μ（μ←μ/2），直到末端误差真正下降，避免越过奇点”反弹”。

线搜索为什么必要（数值分析）

G-N/DLS 的更新方向是”局部最优”（一阶近似下），但非线性目标在远离解时一阶近似失真——大步长可能让误差反而变大（尤其经过奇异区时）。回溯 Armijo 条件：

工程价值：保证迭代单调收敛，不会因为一步走太远而”飞掉”——这是所有牛顿类方法的标配安全网（L2.5 的 L-M 的自适应 λ 也是同一目的的不同实现）。

三、代码走读（jac_l2_ik.cpp）

  • fk / Jfk：二连杆正运动学 / 雅可比。
  • dlsStep：实现 DLS 一步。
  • 主流程：① 从一个可达目标 x_des（由某 q* 正解得到）和初值 q0 出发迭代，断言收敛误差 < 1e-2；② 近奇异(q=0,0)处验证 DLS(λ=0.1) 有限，而普通伪逆发散。

五、工程落点（真实项目）

  • 工业臂在线 IK：UR/ABB 示教器的”线性运动”每拍解一次 J⁺（DLS）——你在拖动示教时背后就是这个方程。
  • ROS MoveIt：KDL/TRAC-IK 的数值 IK 全是”雅可比伪逆 + 线搜索”的工业实现；TRAC-IK 并行跑多初值提高成功率。
  • 视觉伺服：L3.4 IBVS 的关节速度也是 DLS 反解——同一工具。
  • 与解析 IK 的取舍：UR5e 等有解析解（效率高、可重复），但解析解需要手推闭式、只适用特定构型；数值 DLS 通用、天然处理奇异——你 08robot 项目里 IK 用数值解（Jacobian 阻尼最小二乘 + 8 初值多解）正是本 demo 的工程化。

六、自检

  • 把目标设到工作空间边缘（接近奇异位形），看普通伪逆如何崩、DLS 如何稳住。
  • 把 λ 调大，体会”更稳但更慢、末端微微偏离目标”的权衡。
  • 挑战：多解问题（二连杆同一末端位置有两个解）——伪逆从初值出发会收敛到哪个解？换初值能换解吗？（能，这就是”8 初值多解”的做法）
