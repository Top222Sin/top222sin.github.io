L1.5 图像处理中的雅可比：Lucas-Kanade 光流

一句话：在光流里，雅可比就是**图像灰度对位移的敏感度 [Ix; Iy]**。LK 用一个”残差雅可比”迭代地把两帧间的像素位移估计出来。

一、问题设定

合成图像 I1(x,y) = sin(0.3x)·cos(0.2y)。第 2 帧相对第 1 帧平移了 (DX,DY)=(2,1)：

I2(x,y) = I1(x+DX, y+DY)

光流目标：从 I1、I2 反推出 (DX,DY)。

二、残差雅可比

定义一个窗口内的灰度残差 r(u,v) = I2(x,y) − I1(x+u, y+v)。它关于位移 (u,v) 的雅可比是

J = [ ∂r/∂u , ∂r/∂v ] = [ −Ix , −Iy ]

（其中 Ix,Iy 是 I1 在当前估计位移处的图像梯度，Ix=∂I1/∂x 等）。注意负号：残差是”目标减采样”，对位移求导带负号。这个 1×2 行向量就是”残差对未知量的雅可比”。

推导链：为什么残差雅可比是图像梯度（带符号）

五、你会看到什么

六、工程落点（真实项目）

  • OpenCV cv::calcOpticalFlowPyrLK：就是 LK 光流的金字塔多尺度版——先粗后细（coarse-to-fine）解决大位移问题（这个 demo 自检里的 (10,5) 大位移场景，金字塔是工业解法）。
  • 视觉 SLAM/VIO 前端（ORB-SLAM、VINS）：特征点跟踪用金字塔 LK——雅可比思想贯穿整个 VIO 前端。
  • LK 的现代变体：inverse compositional（IC-LK）把雅可比在参考帧算一次（不再每迭代重算），计算量大幅下降——是 OpenCV 内部实现的核心优化。
  • 与推理引擎的关系：光流/特征跟踪常作为 SLAM 前处理部署在端侧，若你在 ncnn/MNN 上移植，核心算子就是 Sobel 梯度 + 2×2 矩阵求逆（可查 ncnn 是否有对应实现，没有就自己写 2×2 闭式逆）。

七、自检

  • 把真实平移改成 (10,5)（大位移），看单步 LK 是否失败、迭代 LK 是否仍能收敛。
  • 把窗口改小，体会”孔径问题”（纹理不足时雅可比病态）。
  • 思考：A = Σ[Ix;Iy][Ix,Iy] 的特征值分别代表什么？（大特征值 = 纹理丰富方向，小特征值 = 弱纹理方向；两特征值都小 = 孔径问题，LK 退化——这正是 Harris 角点检测用同一个 A 的原因）
