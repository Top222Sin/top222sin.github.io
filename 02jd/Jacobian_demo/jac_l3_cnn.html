L3.6 深度学习：一维 CNN 雅可比 ∂y/∂x 的反向传播求法

一句话：把 1D CNN 拆成”卷积（稀疏线性）+ ReLU（对角门控）+ 卷积 + ReLU + 全连接”，其输入雅可比 **∂y/∂x 就等于”反向传播一个单位矩阵”**——用 backprop(identity) 即可，无需任何自动微分库。

一、为什么 CNN 的雅可比好算

一个训练好的 CNN 在固定权重下，对输入是分段线性的：

  • 卷积 = 一个稀疏的 Toeplitz/块对角线性算子（多个输入通道也要累加）；
  • ReLU = 一个对角门控矩阵 g = diag(ẏ>0)；
  • 全连接 = 稠密矩阵。

三者都是线性/对角，所以整张网络对输入的雅可比 J = ∂y/∂x 就是这些矩阵从输出往输入连乘。而”从输出往输入连乘一个矩阵”正好是反向传播（backprop）的定义——于是：

∂y/∂x = backprop(I) ，其中 I 是”把输出梯度设成 1-hot”的恒等。

推导直觉：backprop(identity) 技巧

核心洞察：反向传播本质是计算图上的雅可比-向量积的反向形式（VJP: vector-Jacobian product, vᵀJ）——注意不是 JVP（Jacobian-vector product, Jv，那是前向模式）。用 one-hot 输出梯度做 N 次反向传播（每次得一行），就得到完整的 Dout×Din 雅可比——不需要为每个输入单独算。这是”反向模式自动微分”（L3.3）的直接应用：backprop 是工具，雅可比是产物。

二、网络结构

in(1ch, L0=10) → Conv1(3ch, k=3) → ReLU → Conv2(2ch, k=3) → ReLU → FC(12→2)

雅可比 J 形状为 Dout × L0 = 2 × 10：J[i][j] = ∂y_i / ∂x_j，即”输入第 j 个采样点”对”第 i 个输出”的影响。

卷积层的雅可比为什么是稀疏的（结构分析）

valid 卷积 y[c][n] = Σ_{ci,k} W[c][ci][k]·x[ci][n+k] 是线性算子，其雅可比：

每个输出元素 (c,n) 最多有 C_in·k 个非零偏导（输入通道 × 核大小）——卷积雅可比是稀疏的块带状结构（单通道时为 Toeplitz 带状）。这意味着反传一层的复杂度约 O(N·C_in·C_out·k) 而非 O(N²·C_in·C_out)——结构稀疏性 = 计算廉价性（ncnn/MNN 的卷积算子优化正是利用这一点，im2col 把卷积转为 GEMM 复用 BLAS 优化、直接卷积/Winograd 则减少乘法）。

三、代码走读（jac_l3_cnn.cpp）

  • conv_valid：多通道 valid 卷积 y[c][n] = Σ_{ci,k} W[c][ci][k] · x[ci][n+k]。
  • forward：前向一遍得到 y。
  • jacobian_backprop：对 y_0、y_1 分别置 1，逐层把梯度传回输入，拼成 J(2×10)。
  • jacobian_fd：有限差分 ∂y/∂x 作为对拍基准。

五、工程落点（真实项目）

  • 可解释性/敏感度分析：输入扰动对输出的影响（∂y/∂x）用于特征归因（saliency map）——对抗样本、模型解释都用这个雅可比。
  • 量化感知训练（QAT）：伪量化算子的梯度（straight-through estimator）本质是”量化误差对权重的雅可比”——你部署 ncnn/MNN 的 int8 模型时，QAT 的每一轮训练都在算这类雅可比。
  • 剪枝敏感度：哪些权重删了掉点最少 = 损失对权重的雅可比大小——One-shot 剪枝的标准依据。
  • 对抗攻击（FGSM）：x + ε·sign(∇x L) 就是”损失对输入的雅可比方向”——和本 demo 的 ∂y/∂x 同一物（换损失函数）。

六、自检

  • 把输入某个 x[j] 人为抹平成常数，看 J 第 j 列是否整体变小——ReLU 门控会”关掉”某些通道的回传。
  • 思考：这个 backprop(identity) 技巧对任意”线性+ReLU”网络都成立，也是现代反向模式自动微分（PyTorch/TF）在局部等价的核心思想。
  • 挑战：如果把 ReLU 换成分段线性（如 leaky ReLU），雅可比还是对角矩阵吗？（是——激活函数永远是逐元素的，雅可比恒为对角）
