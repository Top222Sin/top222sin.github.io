L3.4 综合案例：基于图像的视觉伺服 IBVS

一句话：相机装在机械臂末端。IBVS 把图像雅可比 L（计算机视觉）与机械臂雅可比 J（机器人）串接，用 DLS 求鲁棒控制律，把图像特征收敛到目标——这是雅可比思想的集大成。

一、三条链路

世界中一个特征点 P，相机在臂末端。相机帧下 Pc = R(−φ)·(P − 末端位置)，图像特征（归一化，本例用比值特征）s = Pc.y / Pc.x。

  1. 图像雅可比（视觉）：特征速度 ṡ 与末端位姿速度的关系

    ṡ = L · ξ_e , L = [∂s/∂xe, ∂s/∂ye, ∂s/∂φ]（1×3，对末端位姿参数求导）

  2. 机械臂雅可比（机器人）：末端位姿速度与关节速度

    ξ_e = J(q) · q̇

  3. 串接：ṡ = (L·J) · q̇，即”特征对关节的雅可比”。

坐标系说明（重要）：严格 IBVS 应区分相机速度 twist ξ_c 与末端位姿速度——两者通过相机-末端外参变换 ξ_c = Ad(T_ce)·ξ_e（手眼标定 AX=XB 给的正是 T_ce）。本 demo 采用理想化假设：相机与末端同原点、同朝向（T_ce=I），故 ξ_c=ξ_e，L·J 直接成立。若相机有安装偏移，角速度还会诱导额外的相机平移速度，公式必须补 Ad(T_ce)（见 L2.6 的手眼标定关联）。

为什么”特征对关节的雅可比 = L·J”（链式法则）

核心洞察：IBVS 是”两个世界”的雅可比串接——视觉测的是”像素对相机运动”的敏感度（L），机器人算的是”末端对关节”的敏感度（J），链式法则把两者缝成一条”像素对关节”的直接映射。这正是不需要显式 3D 重建的原因：误差直接定义在图像平面，控制直接作用在关节。

二、DLS 控制律（总雅可比直接反解）

目标特征 s_des，误差 e = s − s_des。直接对总雅可比 LJ 用阻尼最小二乘（L3.2/L2.3 同款）：

q̇ = −k · (LJ)_μ⁺ · e, (LJ)_μ⁺ = (LJ)ᵀ((LJ)(LJ)ᵀ + μ²I)⁻¹

  • k 是控制增益（闭环速度），μ 是DLS 阻尼参数（奇异托底）——两者作用与量纲不同，勿混用；
  • 若需两步（先求相机速度再反解关节），那是一种任务空间分层近似：v_c* = −k·L⁺e, q̇ = J⁺v_c*，一般不等价于对 LJ 直接 DLS（J 无法实现的 v_c* 会被丢弃），故本 demo 用总雅可比直接反解，数学一致。

为什么 IBVS 要 DLS（奇异与退化的双重风险）

工程结论：IBVS 的”脆弱”不在链式法则，而在雅可比退化与特征管理。注意本例是单特征比值 s=y/x——只约束一个方向，不能唯一确定二维末端位姿（是”单特征局部伺服演示”而非完整位姿 IBVS）；标准 IBVS 用多点特征（通常含深度项 Z 需估计）才是完整方案。

三、代码走读（jac_l3_ibvs.cpp）

  • fk / Pc / sval：正运动学、相机帧、特征；Lmat：图像雅可比 (1×3)；Jmat：机械臂雅可比 (3×2)。
  • ① 验证 L 与有限差分一致（误差 3e-8）；② 验证 ∂s/∂q = L·J 与 FD 一致（2e-7）；③ 伺服循环迭代把 s 收敛到 s_des（误差 < 1e-3，约 60 步）。

四、你会看到什么

五、工程落点（真实项目）

  • 工业视觉伺服（ViSP 库）：法国 Inria 的 ViSP 就是 IBVS/PBVS 的标准实现（vpServo 类），大量工业抓取/装配应用。
  • 手术机器人：内窥镜持镜臂用 IBVS 自动跟器械——特征就是器械末端在图像里的位置。
  • 无人机视觉着陆：AprilTag 特征 → 图像雅可比 → 位置/姿态伺服（PX4 的 precision landing 是类似思想）。
  • 与 UR5e 仿真项目 手眼标定的关系：IBVS 需要”相机-末端”外参（cali_demo 的手眼标定 AX=XB 就是干这个）——标定误差直接进 L·J 的精度，标定是 IBVS 的地基。

六、自检

  • 把特征点移到视野边缘（Pc.x 接近 0 的奇异侧），看控制律是否触发奇异检测/限幅——体会”投影分母为零”的退化（注意 Pc.x<0 是相机后方非成像区，控制器拿不到真实特征，不能期待”拉回来”）。
  • 思考：若把图像雅可比 L 用错（比如漏了比值特征的链式项），控制律会怎样”拧巴”？这正是雅可比必须算对的现实后果。
  • 挑战：PBVS（位置视觉伺服）与 IBVS 的区别？（PBVS 在 3D 位姿空间做伺服误差，IBVS 在图像平面——PBVS 对相机标定敏感、IBVS 对深度估计/特征退化敏感，各有死穴）
