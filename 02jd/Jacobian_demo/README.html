Jacobian_demo —— 雅可比矩阵数学原理与跨领域应用

仿照 pid_demo / cali_demo / neon_demo 结构的教学仓库。每个主题 = 一份可运行 C++17 代码 + 一份原理说明 .md + 一份图示 _diagrams.html + 一张 **images/fig*.svg**。

雅可比矩阵 J(p)=∂f/∂p 是”一阶偏导矩阵”，也是映射 f 在 p 处的最佳线性近似。它像一根红线，串起了机器人、数值优化、计算机视觉、机器学习——本仓库按 L1（入门）/ L2（原理与算法）/ L3（架构与工程综合）/ L4（自动微分引擎） 四级，带你走完这一圈。

五、校验状态（重要说明）

  • 本机无 C++ 编译器（g++/cl/clang/MSVC 均不可用）。所有 21 个 demo 的数学正确性，已通过受管 Python 3.13.12 镜像实现逐一核验：
    • 每个 demo 的”解析雅可比 / 梯度 / 残差雅可比”都与有限差分一致（误差通常 < 1e-6）；
    • 迭代算法（IK、BA、GN、IBVS 伺服、最速下降、LM、EKF、计算力矩跟踪）均实际收敛到理论目标；
    • 扩展篇（L3.5–L3.9）的关键验证：SE(3) exp/log 互逆 1e-16、伴随同态 ~1e-16；1D-CNN 雅可比 vs 有限差分 ~1e-10；双积分器/自行车/倒立摆 A,B vs 有限差分 ~1e-111e-9，MPC 灵敏度 S 与有限差分一致；EKF 的 F/G/H vs 有限差分（1e-81e-7）且位姿误差 0.58→0.007；机械臂 J/M/G/C 与动能 Hessian、势能梯度、反对称性对拍（1e-151e-9），闭环跟踪最终误差 ~8e-5；L4 自动微分（前向对偶数 + 反向计算图 tape）的 JVP/VJP/全雅可比/标量损失梯度与有限差分对拍 ~4e-11，且前向≡反向（差 0）。
    • 因此 C++ 源码在具备编译器环境下应当全部 PASS。
  • 调试用的临时 Python 校验脚本（以 _dbg* / _validate* / _gen* 开头）已随仓库清理移除，仅保留 20 份 jac_*.cpp + 文档 + 图示。

六、学习路径建议

  1. 先读 L1.1 → L1.2：建立”雅可比=最佳线性近似、det=面积缩放、秩=维数”的直觉。
  2. 走 L1.3 → L2.1 → L2.2 → L2.3 → L2.4：把雅可比在机械臂（运动学、奇异、IK、轨迹）上用透。
  3. 并行看 L1.4 / L2.5（优化）与 L1.5 / L2.6（视觉），体会”残差雅可比”是同一套思想。
  4. 收尾 L3.1 → L3.2 → L3.3 → L3.4：SLAM 流形、运控线性化、ML 链式法则，最后用 IBVS 把视觉与机器人熔于一炉。
  5. 扩展篇（按需深入）：L3.5 SE(3) 完整位姿 → L3.6 1D-CNN 雅可比 → L3.7 多动力学模型 → L3.8 EKF 工业定位 → L3.9 机械臂计算力矩控制，覆盖李群、深度学习、物理建模与两个真实工业用例；最后用 L4 自动微分 收口——把前面所有”手推/差分的雅可比”统一成可编译进计算的自动求导引擎，并回头看清 L3.3 反向传播只是它的特例。
