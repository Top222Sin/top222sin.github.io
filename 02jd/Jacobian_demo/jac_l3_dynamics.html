L3.7 动力学：双积分器 / 自行车 / 倒立摆 的雅可比 A、B 与 MPC 灵敏度

一句话：运动控制（MPC/LQR）先把非线性系统在标称点线性化为 xₖ₊₁ ≈ A·xₖ + B·uₖ，其中 A=∂f/∂x、B=∂f/∂u 就是雅可比；本 demo 把三个经典模型（双积分器、自行车、倒立摆）的 A、B 解析求出并与有限差分对拍，再算 MPC 灵敏度 S=∂u*/∂x。

一、三个模型

模型 状态 x 控制 u 关键雅可比特征
双积分器 (p, v) (a) 线性系统：A=[[1,dt],[0,1]]、B=[dt²/2;dt] 为常数（离散后），线性化与原模型完全一致
自行车/unicycle (x, y, θ) (v, φ) A 含 −v sinθ，B 含 (v/L)sec²φ
倒立摆 cart-pole (x, vx, θ, θ̇) (F) 全非线性，含重力/耦合项（θ=0 竖直向上为不稳定平衡点）

为什么选这三个模型（递进理解线性化）

核心认知：真实的 MPC/LQR 里 A、B 几乎都不是常数——它们是状态和输入的函数，每个控制周期都要重新计算（实时线性化）。你看到”MPC 每步解 QP”背后隐含”每步先重算 A/B 雅可比”。

二、线性化与 MPC

离散动力学 xₖ₊₁ = f(xₖ, uₖ)，在 (x,u) 处一阶展开即得 A、B。一步 MPC：

u* = −(BᵀQB + ρI)⁻¹ BᵀQ (A x − x_goal)

其最优控制对状态的灵敏度：

S = ∂u*/∂x = −(BᵀQB + ρI)⁻¹ BᵀQ A （2×3）

这正是 LQR 增益的来源——状态稍变，最优控制该怎样跟着变。

倒立摆的 A 为什么”全非线性”（推导示例）

cart-pole 连续动力学（M 车质量、m 摆质量、l 摆长，θ=0 约定为摆杆竖直向上、θ=π 为下垂）：

要点：m·l·θ̇²·sinθ·cosθ 是离心耦合项（含 sinθ）——漏掉它，中心差分立刻对不上。手推非线性雅可比最容易漏”交叉项”（一个状态对另一个状态的速度耦合），逐项对拍有限差分是唯一可靠的验证方式（本 demo 的 fd_AB 就是干这个）。角度约定必须与代码统一：θ=0 竖直向上 → 小角度 θ̈≈+(g/l)θ（正反馈，不稳定平衡点）；θ=π 下垂 → 稳定平衡点。

三、代码走读（jac_l3_dynamics.cpp）

  • f_di/A_di/B_di：双积分器；f_bike/A_bike/B_bike：自行车（轴距 Lwb=1.0）；f_cart/A_cart/B_cart：倒立摆（M=1,m=0.2,l=0.5,g=9.81）。
  • fd_AB：用中心差分（O(h²)）对拍解析 A、B。
  • mpc_u / mpc_S：一步最优控制与解析灵敏度；mpc_S 与”对 x 做有限差分得到的 ∂u*/∂x”对拍。

五、工程落点（真实项目）

  • PX4 的 EKF2 状态传播：F=∂f/∂x 是 EKF2 每步的雅可比（KF_demo L3.7 详解）——IMU 驱动的状态预测 F 矩阵就是运动学/动力学雅可比。
  • 倒立摆 = 火箭/人形站立的抽象：SpaceX 着陆段、人形机器人平衡全用”线性化 + LQR/MPC”——cart-pole 是它们的教育版。
  • 自动驾驶 MPC：自行车模型是车辆控制标准模型（v·tan(δ)/L 转向），A/B 每步重算。
  • ncnn/推理部署：若在嵌入式做 MPC，A/B 重算 + QP 求解有实时预算约束——稀疏/预计算技巧（如只更新变动的行）可参考推理引擎的算子调度思想。

六、自检

  • 把自行车的 v 调到 0（原地不动），看 B 中转向项是否退化为 0——这正是”速度为 0 无法转向”的非线性体现。
  • 思考：倒立摆的 A 含 m·l·θ̇²·cosθ 项（离心耦合），漏掉它中心差分立刻对不上——雅可比必须算全。
  • 挑战：为什么倒立摆在 θ=0（竖直向上，不稳定）处 A 有不稳定极点、θ=π（下垂，稳定）处无？（势能在 θ=0 是局部极大——线性化后特征值符号由重力恢复力方向决定，这正是”反馈线性化/平衡控制”要克服的）
