L3.2 运动控制：动力学雅可比 A/B 与 MPC 灵敏度

一句话：模型预测控制（MPC/LQR）先把非线性系统沿标称轨迹线性化为 xₖ₊₁ ≈ A·xₖ + B·uₖ，其中 A=∂f/∂x、B=∂f/∂u 就是雅可比。最优控制对状态的灵敏度 S=∂u*/∂x 也由 A、B 解析给出。

一、从非线性到线性模型

在 (x,u) 处对 f 求一阶偏导，得到雅可比 A=∂f/∂x（3×3） 与 B=∂f/∂u（3×2）。MPC 后续所有的”预测 / 优化”都用这组 A、B。

二、MPC 与灵敏度

一步 MPC 求解 u* = argmin_u ‖A x + B u − x_goal‖²_Q + ρ‖u‖²（前提：A/B/Q 当步视为常量、目标是下一时刻状态、无控制约束、Q 对称、ρ>0；用绝对状态时需包含标称轨迹的仿射偏置项，或用误差变量形式），解析解：

u* = −(BᵀQB + ρI)⁻¹ BᵀQ (A x − x_goal)

其灵敏度（最优控制如何随状态变化）恰是：

S = ∂u*/∂x = −(BᵀQB + ρI)⁻¹ BᵀQ A （2×3）

形式上类似 LQR 反馈增益——但注意区分：这是一步、无约束、带正则的有限时域反馈增益；无限时域 LQR 的 Riccati 增益需要求解代数 Riccati 方程（或加终端代价/无限时域后等价）。两者数值不同（已实测验证）。

五、工程落点（真实项目）

  • PX4 位置控制：PositionControl 的位置→速度→加速度串级本质是”线性化模型 + 增益”——虽然飞控用 PID 而非在线 MPC，但增益的物理含义就是 A/B 反推的（control_demo L1.1 的 Kp≈2ζωn 映射）。
  • 自动驾驶 MPC（轨迹跟踪）：车辆动力学 A/B 每步线性化（运动学/动力学模型），QP 求解——CarMaker/ROS 的 mpc_local_planner 全是这套。
  • 四足/人形 MPC（MIT cheetah、Unitree）：全身 MPC 把浮基动力学线性化，A/B 雅可比是每步计算的骨架。
  • 模型预测控制 vs LQR 选型：约束重要（限幅/避障）→ MPC；无约束、算力紧 → LQR——但两者的”雅可比线性化”哲学相同。

六、自检

  • 把 dt 调大，看 A、B 如何偏离”连续模型的离散化”（线性化仅在标称点附近有效）。
  • 把 ρ（控制惩罚）调大，灵敏度 S 的整体幅值通常变小（越不依赖状态、控制越保守；逐元素不保证单调）。
  • 挑战：把一步 MPC 换成”两步预测”，S 还等于 −(BᵀQB+ρI)⁻¹BᵀQA 吗？（不等——多步预测的反馈增益是 Riccati 递推的结果，control_demo L2.5 的 Kleinman 迭代就是）
