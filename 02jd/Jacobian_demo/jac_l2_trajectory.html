L2.4 轨迹规划：零空间冗余分解

一句话：冗余机械臂（关节数 > 任务维数）在满足主任务的同时，还能在”零空间”里优化次要目标，且绝不干扰主任务。公式为 q̇ = J⁺·ẋ + (I − J⁺J)·ẋ_null。

一、冗余自由度意味着什么

3R 平面臂做 2D 位置任务：3 个关节、2 个任务自由度。多出来的 1 个自由度可以”随便用”——只要不破坏末端轨迹。这就引入了零空间投影：

N = I − J⁺J

（J⁺ 是 Moore-Penrose 伪逆）它把任意关节速度”去掉其中影响末端运动的分量”。N·q̇_null 所驱动的运动，末端纹丝不动，只在关节空间里”扭来扭去”。

⚠️ 严格零空间 vs 阻尼近似：N = I − J⁺J 只有用精确 Moore-Penrose 伪逆（λ=0 + 秩截断）才是严格正交投影（满足 JN=0、N²=N）。若用阻尼伪逆 J_λ⁺ = Jᵀ(JJᵀ+λ²I)⁻¹，则 J·(I−J_λ⁺J) = λ²(JJᵀ+λ²I)⁻¹J ≠ 0——零空间泄漏，次要任务会对主任务产生残余干扰（λ 越大泄漏越明显）。本 demo 用 λ=0 的精确伪逆验证严格性质；工程上若用 DLS，需接受近似或改用任务优先级方法。

推导直觉：零空间是什么

对线性映射 J: Rⁿ → Rᵐ（n>m），方程 J·q̇ = ẋ 的通解（要求任务速度可实现，即 ẋ ∈ Range(J)）：

零空间 = 所有”不影响末端速度”的关节速度构成的子空间，维数 = n − rank(J)（满行秩时 = n − m）。N = I − J⁺J 是到该子空间的正交投影。**”多余”的自由度不是浪费，是自洽的优化空间**。

二、完整控制律

q̇ = J⁺·ẋ_des + N·q̇_null

  • 第一项（精确伪逆）跟踪末端到目标；
  • 第二项在零空间内优化次要目标（如让第 3 关节逼近期望角、远离关节极限、避开障碍）。

三、代码走读（jac_l2_trajectory.cpp）

  • fk / Jfk：3R 臂正运动学 / 位置雅可比（2×3）。
  • pinvDLS：阻尼伪逆 J⁺ = Jᵀ(JJᵀ+λ²I)⁻¹（返回 3×2；λ 取很小值以近似精确伪逆，并建议同时输出 ||J·N||、||N²−N|| 验证泄漏量）。

五、工程落点（真实项目）

  • 协作臂（UR/KUKA iiwa）：冗余自由度（7 轴）的肘部姿态保持、避障就是零空间优化——你拖拽 iiwa 时它自动绕开障碍，靠的就是 N·ẋ_null。
  • MoveIt 的 KinematicsBase 冗余解 + 多目标 IK：零空间分量用于关节极限/奇异规避。
  • 人形机器人（Atlas）：腿部冗余（髋膝踝）用零空间做”重心保持/步态优化”。
  • 手术机器人：持镜臂在跟随主臂运动时，零空间用于”不碰患者”。

六、自检

  • 把次要目标换成”远离关节极限”（如 q3 朝 0 而不是 0.35），观察行为变化。
  • 思考：若去掉 N 投影，次要任务会不会”拽偏”末端轨迹？（会！直接加 ẋ_null 不投影，末端就偏了——N 是”正交化”的关键）
  • 挑战：验证零空间性质 J·N = 0 和 N² = N（幂等投影）——这是”投影”的数学身份，代码里可以加断言。
