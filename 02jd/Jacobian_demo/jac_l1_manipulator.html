L1.3 机械臂速度运动学：J(q)·q̇ = ẋ

一句话：对机械臂，关节角速度 q̇ 经过雅可比 J(q) 映射为末端 Cartesian 速度 ẋ：ẋ = J(q)·q̇。这是”雅可比在机器人里最原始的模样”。

一、从正运动学求导

二连杆平面臂（l1=l2=1）正运动学：

对时间求导（θ̇ = q̇），把含 q̇ 的因子提出来，就得到 2×2 的**机械臂雅可比 J(q)**：

直观上：J 的两列，分别是”只让关节 1 转动 / 只让关节 2 转动时末端的速度方向”。

推导链：为什么 J 的每一列是”单关节驱动的末端速度”

对位置 p(q) = FK(q) 求全微分：

核心直觉：机械臂雅可比 = 逐关节”速度贡献列”拼起来的矩阵。每个关节的速度贡献只取决于当前构型（J 是 q 的函数）——这就是为什么 J(q) 随姿态变化，机器人控制要每拍重算。

二、为什么重要

  • 给定目标末端速度 ẋ，求关节速度 q̇ → 这是速度级控制 / 逆运动学的基础。
  • J 的列向量一旦共线（平行），就出现了奇异位形：某一方向的末端速度再怎么动关节也做不出来。

奇异位形的几何（列共线 = 秩亏）

工程含义：奇异附近关节速度 q̇ = J⁻¹ẋ 会爆炸（逆的范数→∞）——这就是为什么工业控制器要 DLS 正则（L2.2/L2.3），以及轨迹规划要避开奇异区。

三、代码走读（jac_l1_manipulator.cpp）

  • fk(q)：正运动学，返回 (x,y)。
  • Jfk(q)：解析雅可比 J(q)（2×2，平面位置雅可比；注意 KDL 的 JntToJac 返回 6×N 的含角速度 twist 雅可比，这里是最简 2×2 教学版）。
  • 主流程：取 q=(0.6,1.1)、q̇=(0.4,−0.7)，分别计算
    ① matVec(Jfk(q), qd)（解析 ẋ ≈ (0.0716, 0.3688)）；
    ② 有限差分 (fk(q+h·q̇) − fk(q))/h（数值 ẋ，前向差分 O(h)）；
    二者之差 < 1e-4 即 PASS。

四、你会看到什么

五、工程落点（真实项目）

  • ROS 生态：urdf 解析 + KDL/tf2 的运动学链，kdl_kinematics 的 JntToJac 就是算这个 J(q)——MoveIt 逆运动学、速度控制全依赖它。
  • PX4/无人机：多旋翼没有”机械臂式” J，但姿态雅可比（角速度→欧拉角率的 B 矩阵，L2.1 的 det B=cosβ）是同一思想；固定翼/倾转旋翼的舵面效率矩阵就是”控制雅可比”。
  • ncnn/推理引擎（如果做机器人端部署）：机械臂雅可比每拍重算 = 实时性约束，浮点精度/查表优化可参考推理库的算子优化思路。
  • UR/ABB 工业臂：示教器上的”线性运动”模式就是实时解 q̇ = J⁻¹·ẋ_des——你拖动手柄时示教器每秒解几百次这个方程。

六、自检

  • 把 q 调到接近 (0,0)（完全伸展），看 J 的两列是否趋于平行（奇异位形的苗头）。
  • 试一个具体的 q̇，手算一下列向量的几何含义。
  • 挑战：三连杆臂（3 DOF 做 2D 任务）的 J 是 2×3——它还有”零空间”吗？（有！L2.4 的冗余分解正是靠多出的列）
