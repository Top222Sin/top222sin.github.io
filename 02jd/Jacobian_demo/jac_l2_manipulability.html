L2.2 可操作度（Manipulability）与奇异规避

一句话：可操作度 w = √det(J·Jᵀ) 量化末端”各方向灵活度”。w→0 即奇异位形（J 的列平行，维数坍缩）。阻尼最小二乘 DLS 用 λ² 给分母兜底，在奇异处仍给出有限关节速度，而普通伪逆直接发散。

一、可操作度椭球

JJᵀ 的特征值刻画末端各方向”可达速度”的大小。其行列式的平方根

w = √det(J·Jᵀ) = σ₁·σ₂

正比于”可操作度椭球”的体积（σᵢ 是 JJᵀ 特征根的平方根，即 J 的奇异值）。椭球越扁，说明某些方向越”将将能动”；椭球塌成一条线，w→0，即到达奇异。

推导直觉：为什么椭球由 JJᵀ 决定

末端速度约束 ẋ = J·q̇，关节速度有界 ‖q̇‖ ≤ 1。问：末端能到达哪些速度方向？

Yoshikawa 可操作度（1971）正是这个椭球体积——“末端在这个构型下整体有多灵活”。w 大 = 椭球胖 = 各方向都能动；w 小 = 椭球扁 = 某些方向接近不能动。

二、阻尼最小二乘（DLS）

把关节速度 ẋ（这里指末端速度指令）反解为 q̇：

q̇ = Jᵀ (J·Jᵀ + λ²I)⁻¹ ẋ

注意顺序：先 Jᵀ，再对 (JJᵀ+λ²I) 求逆（λ=0 才是普通伪逆）。λ²I 像”防滑垫”——即便 JJᵀ 接近奇异，分母也有 λ² 托底，q̇ 不会发散。

五、工程落点（真实项目）

  • 工业臂奇异规避：KUKA/ABB 控制器实时算 w（或 σ_min），进入奇异区自动降速/切换 DLS——你的 w 就是它们的 singularity index。
  • 路径规划：MoveIt/OMPL 的约束采样用可操作度做”奇异代价”（离奇异越近代价越高），轨迹优化时避开。
  • 冗余机械臂（L2.4 零空间）：可操作度梯度本身常作为次要目标——ẋ_null = k·∂w/∂q 让机械臂”自动远离奇异”。
  • 遥操作：手术机器人（达芬奇）的奇异规避 + 力反馈缩放，底层就是 w/σ_min 的实时监控。

六、自检

  • 把 q 从好构型缓缓移到 (0,0)，画一条 w 随关节角变化的曲线，看它如何跌落。
  • λ 取太大 / 太小各有什么副作用？（太大→末端响应迟钝；太小→奇异处重新发散）
  • 挑战：σ_min（最小奇异值）和 w 哪个对”奇异预警”更敏感？（σ_min 直接是最弱方向的速度能力，比体积 w 更物理直观——工业监控多用 σ_min）
