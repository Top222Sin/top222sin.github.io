L4 自动微分（Automatic Differentiation）：前向模式 + 反向模式

一句话：**自动微分 = 把”求导规则”编译进”计算过程”**。它既不是符号微分（爆炸式展开），也不是数值差分（截断/舍入误差），而是用”对偶数 / 计算图”在求值的同时机械地套用链式法则——雅可比主题在深度网络、优化器、求解器里真正的工业引擎。

一、为什么需要自动微分

前面所有 demo（L1.1 定义、L2.5 GN/LM、L3.8 EKF）要算雅可比 J=∂f/∂x，手段无非两种：

  • 手推解析式：精确但人工、易错，深层组合函数（神经网络、BA 残差链）几乎不可手推；
  • 有限差分：实现简单，但有截断误差 + 舍入误差的权衡，且 n 维要 n+1 次重算，百万参数时完全不可行。

自动微分的出发点：任何程序都是一堆基本运算（加、乘、sin、exp…）的复合，而每个基本运算的导数我们都知道。只要在”求值”时同步携带导数信息，链式法则就自动完成——这就是 AD。它有两条路线：

路线 携带信息 一次传播得到 成本
前向模式 forward / tangent 输入方向的切向量 JVP J·t ∝ 输入维数 n
反向模式 reverse / adjoint 输出方向的余切向量 VJP Jᵀ·u ∝ 输出维数 m

三、前向模式（对偶数 / dual numbers）

把每个变量从 double v 升级为 v + ε·d，其中 d 是”切向量”。核心规则是乘积的链式法则：

把切向量取成单位矩阵的两列（x 的切向量=[1,0]，y 的切向量=[0,1]），一次前向求值就同时得到 J 的两行——即 J = J·I。

  • 若切向量换成单一方向 t=[tx,ty]，则一次前向得到 J·t（JVP，雅可比-向量积）。
  • 本 demo 用 Fwd{v, vector<double> d} 实现，所有基本运算重载切向量传播。

四、反向模式（计算图 / tape）

前向模式”从输入往输出推”，反向模式相反：**先正常求值，把每个中间结果记进一张计算图（tape），再从输出往回，沿图的边反向累加”伴随量（adjoint）”**。

反向遍历一次，每个输入变量的 adj 就是 ∂(输出)/∂(输入)。

  • 对每个输出各做一次（seed 该输出=1）→ 拼出整行 → 得到全 J；
  • 若同时 seed 多个输出 u=[u0,u1]，一次反向得到 Jᵀ·u（VJP，向量-雅可比积）；
  • 若对标量损失 L=f1²+f2² 做反向（输出维数 m=1，seed=1 一次）→ 直接得到 ∇L。

选型铁律：前向模式成本 ∝ n，反向模式成本 ∝ m。训练 = “标量损失 m=1 对百万参数 n 很大” → 反向模式碾压 → 这就是 L3.3 里手推的反向传播（backprop） 的工程本质。PyTorch/TF 的 autograd 是反向模式；Ceres 的 Jet 是前向模式。

五、代码走读（jac_l4_autodiff.cpp）

  • f_eval / Lfun / jacobian_fd：有限差分雅可比与标量损失（对拍基准）。
  • Fwd + f_add/f_sub/f_mul/f_sin/f_cos/f_exp + eval_fwd：前向模式（对偶数），切向量长度自适应——{1,0}/{0,1} 得全 J，{tx}/{ty} 得 JVP。
  • Rev + tape + r_* + propagate：反向模式（计算图），reset_adj 清伴随、eval_rev 建图。
  • main：
    1. 前向模式得 Jfwd；
    2. 前向 JVP = J·t；
    3. 反向模式逐输出 seed 得 Jrev（2 次反向）；
    4. 校验 Jfwd ≡ Jrev；
    5. 反向 VJP = Jᵀ·u（1 次）；
    6. 标量损失 ∇L（反向 1 次）。
      全部与有限差分对拍，误差 < 1e-6。

七、工程落点（真实项目）

  • PyTorch / JAX autograd：反向模式 AD 的工程实现——记录前向计算图，反向 propagate 求 ∇L。本 demo 的 tape 就是它被”最小化”后的样子。
  • Ceres Solver：Jet<T,N> 是前向模式 AD，专为”残差对少量参数（如 BA 的相机/路标位姿）”设计——n 不大时前向更快，与 L2.6 重投影/BA 直接衔接。
  • **L2.5 GN/LM**：高斯-牛顿每步都要 JᵀJ 与 Jᵀr，J 用 AD 自动取得，无需手推——工业界最小二乘求解器的标准做法。
  • TensorFlow XLA / 编译器：反向模式 + 检查点（checkpointing）把”反向遍历图”转成可融合的算子序列，是训练编译优化的基础。
  • 可微物理 / 可微渲染 / 控制（L3.7 MPC 灵敏度）：把动力学/渲染写成可微程序，梯度直接喂给优化器——AD 让”端到端可微”成为现实。

八、自检

  • 把 f 改成你自己的函数（如 Rosenbrock 100(y−x²)²+(1−x)²），看 J、∇L 是否仍与有限差分一致。
  • 把输入维数升到 3（x,y,z），验证”前向模式成本 ∝ n、反向模式成本 ∝ m”——n=3,m=2 时前向 1 次、反向 2 次。
  • 挑战：为什么训练用反向而非前向？写出成本表达式（前向 O(n·cost)，反向 O(m·cost)，n≫m=1）。
  • 进阶：在 propagate 里加 OP_SQR（平方节点），即可去掉 r_mul(f1r,f1r) 的重复子图，体会”计算图复用中间节点”。

九、下一步

自动微分补全了”雅可比怎么来”这一环——此前 L3.3 ML 反向传播 手推了 2 层网络的 δ，这里是它背后通用的自动求导引擎；接下来可接：

  • L2.5 GN/LM：用 AD 取 J 跑真正的非线性最小二乘；
  • L3.7 多动力学模型：AD 求 A/B 矩阵喂给 MPC；
  • L3.8 EKF 定位：AD 求 F/G/H 雅可比，彻底告别手推。
