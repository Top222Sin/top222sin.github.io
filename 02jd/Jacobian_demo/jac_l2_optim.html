L2.5 数值优化：Gauss-Newton / Levenberg-Marquardt

一句话：非线性最小二乘 min_θ Σ rᵢ(θ)² 的核心工具（牛顿 / 高斯-牛顿 / LM）都依赖残差雅可比 J = ∂r/∂θ。G-N 近解处二次收敛；L-M 用 λI 在”最速下降”与”G-N”间自适应，远处也稳健。

一、残差雅可比

模型 y = f(θ)（如 y = a·e^{b·x}），残差 rᵢ(θ) = f(θ;xᵢ) − yᵢ。在 θ 处把残差线性化：

r(θ+Δ) ≈ r(θ) + J·Δ （Jᵢⱼ = ∂rᵢ/∂θⱼ）

从牛顿法到高斯-牛顿（推导链）

目标 E(θ) = ½Σrᵢ² = ½rᵀr。牛顿法需要 Hessian：

为什么可以丢：解附近 r→0，Σrᵢ·∇²rᵢ 项被 r 本身压小；残差近线性时 ∇²rᵢ≈0。这是 G-N 二次收敛的前提——收敛快但依赖初值（远离解时近似失效）。这也解释了为什么 G-N 和”线性回归”的闭式解长得一样——线性回归就是 J 常数的 G-N。

二、三种下降方向

  • 高斯-牛顿（G-N）： Δ = −(JᵀJ)⁻¹ Jᵀ r （无阻尼，假设残差近似线性，近解处快；严格”二次收敛”需解处残差为零 + J 满列秩 + 光滑性）
  • 莱文伯格-马夸尔特（L-M）： Δ = −(JᵀJ + λI)⁻¹ Jᵀ r （λ 大→接近最速下降，λ 小→接近 G-N）

符号约定：由 r(θ+Δ) ≈ r + J·Δ 出发，最小化 ‖r+JΔ‖² 得正规方程 (JᵀJ)Δ = −Jᵀr，所以更新方向带负号（除非实现用 θ←θ−Δ 约定）。下文 L-M 同理。

L-M 的精髓是自适应 λ：下降顺利就减小 λ 逼近 G-N；不降反升就增大 λ 退守最速下降。

L-M 自适应策略（简化启发式；工业标准是信任域）

直觉：λI 给 (JᵀJ) 的对角线”充气”——λ 大时对角占优，方向趋近 −∇E/λ（最速下降，稳健但慢）；λ 小时趋近 G-N（二次收敛但脆弱）。真实 Ceres 用信任域（按”实际下降/模型预测下降”比值 ρ 调整半径），上述 λ 调节是其简化启发式。注意 λI 对参数尺度敏感，不同量纲参数应配合缩放（或改用 λ·diag(JᵀJ)）。工程结论：LM 对”局部收敛性”非常稳健，但不保证任意初值收敛到全局最优**——多初值（multi-start）仍是标配。

三、代码走读（jac_l2_optim.cpp）

  • residuals / jacobian：残差 r 与残差雅可比 J（对 a,b：J=[e^{bx}, a·x·e^{bx}]）。
  • solve：统一实现 G-N(λ=0) 与 L-M(自适应 λ)，用代价函数决定是否接受更新。
  • 断言：① G-N 易初值 (1.5,−0.2) 收敛到真值 (2,−0.5)；② L-M 易初值收敛；③ L-M 难初值 (0.3,0.6) 也稳健收敛；④ G-N 难初值仅展示（通常发散）。

五、工程落点（真实项目）

  • Ceres Solver：Google 出品，SLAM/标定/机器人的事实标准——G-N、L-M、Dogleg 三种策略，你提供 residuals + jacobians（或自动微分），它负责 λ/信任域调度。本 demo 就是 Ceres 内部正在做的事的最小版。
  • g2o：图优化框架（位姿图 L3.1、BA L2.6）的核就是 LM——每个边提供残差+雅可比，g2o 组装稀疏系统求解。
  • **OpenCV cv::solvePnP 的迭代法 / cv::calibrateCamera**：相机标定（cali_demo）内部就是 G-N/LM——你标定出来的内参就是 LM 的收敛结果。
  • PX4 传感器标定 / EKF2 调参：非线性参数估计场景，LM 是标配工具。
  • LLM 微调/量化：低秩适配（LoRA）的目标函数训练本质也是”残差最小化 + 梯度下降”，LM 思想体现在二阶优化器（K-FAC 等）里。

六、自检

  • 给数据加噪声，看拟合参数如何在真值附近抖动（最小二乘的统计特性）。
  • 把 L-M 的初始 λ 调很大，观察它前期”像最速下降”、后期”像 G-N”的行为切换。
  • 挑战：为什么 G-N 的 (JᵀJ) 一定半正定，而牛顿的精确 Hessian 可能不定？（JᵀJ 是平方和，任何 z 有 zᵀJᵀJz=‖Jz‖²≥0——这正是 G-N 数值稳定的结构优势）
