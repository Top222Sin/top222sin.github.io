L3.3 机器学习：反向传播 = 雅可比链式法则

一句话：反向传播（backprop）就是雅可比链式法则的工程化实现。损失对各参数的梯度，等于”损失对各激活的雅可比”沿各层权重雅可比一路链式相乘。

一、一个小网络

x(2) → [W1,b1] → z1 → tanh → h(3) → [W2,b2] → y(1)，标量损失 L = ½(y − y*)²。

前向：z1 = W1·x + b1，h = tanh(z1)，y = W2·h + b2。

二、链式法则写出梯度

从输出往回链式求导（定义 z2 = W2·h + b2，y = z2）：

每一行都是一次”雅可比相乘”：∂L/∂W2 = (∂L/∂z2)(∂z2/∂W2)，依此类推。这正是 L1.1 的链式法则，只是层数更多。注意线性层 y=Wx+b 对 W 的雅可比是 xᵀ，所以参数梯度是外积 δ·xᵀ（不是内积）。

核心洞察：

  1. **反向传播 = 从输出往输入，逐层左乘”层雅可比”**——和 L1.1 的复合函数链式法则完全一样，只是从右往左算；
  2. 雅可比是稀疏的/结构的：tanh 雅可比是对角阵（逐元素激活），所以反向传播是”逐元素乘”而非全矩阵乘——这是神经网络能高效训练的结构红利；
  3. 代价函数是标量 → 梯度是”向量×向量”的内积形式（δ 是”反向传播的误差向量”）。

三、输出对输入的雅可比

整个网络把输入映到输出，其雅可比

∂y/∂x = W2 · diag(tanh’(z1)) · W1 （1×2）

即”各层雅可比的矩阵乘积”。这与反向传播共用同一套导数。

forward 模式 vs backward 模式（自动微分选型）

工程结论：神经网络训练必须用反向模式（backprop），因为”标量损失对百万参数”；如果反过来（海量输入、标量输出），前向模式更优。PyTorch/TF 的 autograd 是反向模式自动微分的工程实现——本 demo 手推的 δ1/δ2 就是它内部在做的链式乘法。

五、你会看到什么

六、工程落点（真实项目）

  • PyTorch/TensorFlow autograd：反向模式自动微分，内部就是”记录前向计算图 + 反向链式”——本 demo 是它 2 层网络的完整手推版。
  • ncnn/MNN/ONNX Runtime：推理引擎只做前向；但量化感知训练（QAT）、梯度裁剪、敏感度分析（哪些层剪了掉点）需要梯度——有些引擎支持部分反向（如 ncnn 的训练模式早期版本）。
  • LLM 微调（LoRA）：低秩适配的梯度只流过小矩阵——反向传播 + 稀疏参数更新，推理部署时把低秩合并回权重（你部署 LLM 时会遇到）。
  • 可微编程：Ceres 的自动微分（Jet 类型）是前向模式的工程实现；PyTorch 是反向模式——理解两种模式的区别是选型的基础。

七、自检

  • 把隐藏层激活从 tanh 换成 ReLU，看反向传播里 δ1 的公式如何变化（tanh’→阶跃）。
  • 加深网络到 3 层，体会”链式法则串联越多，梯度越容易消失 / 爆炸”。
  • 挑战：为什么 ReLU 能缓解梯度消失？（ReLU’=1 当 x>0——梯度不衰减；tanh’∈(0,1]——多层连乘指数衰减）
