cuda_demo —— CUDA / OpenCL 学习目录

按 01CUDA基础学习.docx 的结构逐节展开。每个知识点落成 可运行/可教材的 .cpp + 配套 .md（含内联图示），与笔记条目一一对应。
本沙箱无 GPU / 无 nvcc，CUDA 文件为教材级标准代码，需在有 CUDA Toolkit 的机器上 nvcc 编译运行；OpenCL 同理需对应 SDK。
本目录与 neon_demo/ 平级——NEON 是 ARM 后端那条线，这里开始 GPU 这条线（CUDA 主、OpenCL 对照）。

13. cuda_l2_warp_divergence.cpp（L2.2 教学内核，约 9 KB）

  • 高效 kernel 第二道分水岭：指令怎么在 SM 上排布才不空转。四个概念环环相扣——warp 是调度单位 → 分支发散让 warp 内串行 → occupancy 决定能塞多少 warp → 寄存器压力反压 occupancy。
  • 演示一 inspect_warp：把 lane / warp_in_block / global_warp 写回，CPU 校验「t%32 / t/32 / 连续」三层层次。
  • 演示二 diverge_by_lane vs coherent_by_warp：用 __ballot_sync 把分支发散”显影”成可校验数字（无需计时）——前者谓词按 lane → 每 warp popc=16（半真半假，必发散）；后者谓词按 g<n/2 对齐 warp → popc=32 或 0（不发散）。
  • 演示三 occ_free vs occ_bounded(256,4)：用 cudaOccupancyMaxActiveBlocksPerMultiprocessor 真机量化 occupancy，说明 __launch_bounds__ 压寄存器提占用率。
  • 演示四 high_pressure vs low_pressure(256,8)：同样算术，结果对拍一致；区别在寄存器用量，编译加 --ptxas-options=-v 看 registers / spilled。
  • 编译：nvcc -O3 -std=c++17 cuda_l2_warp_divergence.cpp -o warp && ./warp。
  • 对应笔记：L2 能写高效 kernel → 2、warp 概念、分支发散、occupancy、寄存器压力。

19. cuda_l2_reduction_tiling.cpp（L2.4 教学内核，约 9 KB）

  • L2 收官：第一个”真正高性能”手写 kernel，串起 L2.1(shared/bank/pad)/L2.2(occupancy)/L2.3(减 DRAM 流量)。
  • 归约：reduce_halving（交错寻址，stride=32 撞 2 路 bank conflict）+ reduce_warp_shuffle（末段 __shfl_down_sync，寄存器级无冲突）；每 block 出一 partial。
  • 矩阵乘：matmul_naive（每线程一输出，全局流量最大）+ matmul_tiled（TILE×TILE shared 分块，读 b_tile[k][tx] 2 路冲突）+ matmul_tiled_transposed（B 转置入 shared，读 b_tile[tx][k] 无冲突）；三者数值对拍一致。
  • analyze_tiling() 在 CPU 上确定性算出 S=256 时全局取数 朴素≈3.36e7 → 分块≈1.97e5，下降 ≈170×（FLOPs 不变）；run_gpu_checks() 真机对拍归约 + 三种 matmul（注释放开即跑）。
  • 编译：nvcc -O3 -std=c++17 cuda_l2_reduction_tiling.cpp -o rt && ./rt。
  • 对应笔记：L2 能写高效 kernel → 4、共享内存归约 reduction、矩阵乘分块 tiling。
