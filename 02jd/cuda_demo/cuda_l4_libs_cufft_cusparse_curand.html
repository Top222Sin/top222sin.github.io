L4（工业扩展）· cuFFT + cuSPARSE + cuRAND 库族：科学计算三大调库

本文件是 cuda_l4_libs_cufft_cusparse_curand.cpp 的配套讲解。图示：images/fig22_libs.svg（四联图），浏览器完整预览 cuda_l4_libs_cufft_cusparse_curand_diagrams.html。
一句话：L1.3 只调了 cuBLAS/cuDNN 两条「稠密线性代数 + 卷积」线；科学计算真正的主战场还在 FFT（谱/卷积）、稀疏矩阵（图/FEM/推荐）、随机（蒙特卡洛）三条线——它们分别由 cuFFT / cuSPARSE / cuRAND 收口，本篇用确定性 CPU 模型把三条线的库行为都验证一遍。

0. 这一站解决什么

L1.3（cuda_l1_blas_cudnn）把「调库」树立为第一性原理：能调库就不手写 kernel。但那一篇只覆盖了：

  • cuBLAS：稠密 GEMM / AXPY（第 45 行的 SGEMM 行主序 swap 陷阱）
  • cuDNN：卷积前向

科学计算的版图远不止于此。回想你学 CUDA 的初衷之一是「科学计算 / 信号处理 / 稀疏 / 蒙特卡洛」——这三块各自有一条专属库族：

需求 库 核心操作
谱分析 / 快速卷积 cuFFT 复迭 FFT / IFFT
稀疏矩阵（图/FEM/推荐） cuSPARSE CSR SpMV / 格式转换
随机（蒙特卡洛/初始化） cuRAND 确定性伪随机 + 分布变换

本篇把这三族落到「纯 C++ 可跑」的确定性模型里——无 GPU 也能验证「库的语义正确」，真机 API 由 #ifdef __CUDACC__ 守护。

1. 原理：三族各自的「不变量」

1.1 cuFFT —— 频域不变量

  • fft(x) 与朴素 DFT Σ x[m]·e^{-2πi·km/N} 必须逐点一致（复平面）。
  • 逆变换满足 ifft(fft(x)) == x（往返一致）。
  • 卷积定理：ifft(fft(a)·fft(b)) == direct_conv(a,b)——这是 FFT 在「快速卷积 / 相关 / 滤波」里的杀手锏，复杂度从 O(N²) 降到 O(N log N)。

1.2 cuSPARSE —— 稀疏不变量

  • 稠密矩阵 → CSR（row_ptr / col_idx / val 三件套），0 元素不存。
  • SpMV: y = A·x 在 CSR 上只遍历非零元，与稠密 matvec 数值完全一致。
  • csr2dense 往返：dense → CSR → dense 必须还原原矩阵（格式可逆）。

1.3 cuRAND —— 随机不变量

  • 确定性：同种子 → 随机流逐位一致（可复现实验）。
  • 分布正确：Box-Muller 把 U(0,1) 变换成 N(0,1)；大样本下 mean≈0, std≈1。

2. 算法步骤（host CPU 模型）

实现要点：fft_inplace 用迭代 radix-2（位反排 + 蝶形），长度取 2 的幂；CSR 三件套用 vector 顺序构造；cuRAND 用与 Python 镜像同序的 LCG（state=(state*1103515245+12345)&0x7fffffff）。

3. 与主线关系

  • L1.3（cuBLAS/cuDNN）：本篇是「调库篇」的直接延伸——从稠密线扩到谱/稀疏/随机三线。
  • L2.4 / L3.2（GEMM/TC）：cuSPARSE 的 SpMV 是 GEMM 在「极度稀疏」下的特例，也是图神经网络的底层原语。
  • L4（Hopper）：FlashAttention 里的 online softmax 分块、FFT 的长序列处理，在「大模型/科学计算」场景下汇合。
  • 跨域同构：cuRAND 的「确定性流」与 LS/KF 的「固定种子 RNG 对拍」同一套纪律；cuSPARSE 的 CSR 累加与 neon SME ZA 外积累加同构（都是「贡献累加进一个稀疏/稠密结构」）。

5. 验证（受管 Python 双复核 6/6 PASS）

# 检查 结果
1 cuFFT fft(x) == 朴素 DFT（max|Δ|） <1e-9 PASS
2 cuFFT ifft(fft(x)) == x（往返） <1e-9 PASS
3 cuFFT 卷积定理 ifft(fft(a)·fft(b)) == 直接卷积 <1e-9 PASS
4 cuSPARSE CSR SpMV == 稠密 matvec <1e-12 PASS
5 cuSPARSE csr2dense 往返 == 原稠密矩阵 <1e-12 PASS
6 cuRAND 确定性 + N(0,1) 分布(mean≈0,std≈1) PASS

数值由 host 端 double 复现；受管 Python 3.13.12 算法镜像 + C++ 控制流镜像双复核，6/6 PASS。本沙箱无 GPU/nvcc，真机 cuFFT/cuSPARSE/cuRAND API 由 __CUDACC__ 守护。

6. 自检（踩坑与纪律）

  • 不等式断言方向坑（项目级）：验证「分布落在容差内」时，err = max(0, |x| - tol)——只有真的超界才 >0 才 FAIL；初版误写 max(0, tol-|x|)，当 |x|>tol（应 FAIL）时反而被 clamp 成 0 误判 PASS。已修。
  • cuRAND 确定性锚点：比对「重抽流」时必须取第一个 z1（首轮 z0,z1），不能直接用 z[1]——循环里 z[i]=z0 只存了 z0，z[1] 是第二轮 z0，与重抽的 z1b 不是同一量。已修。
  • FFT 用 double 模型：host 端用 double 保证与 Python 镜像逐位一致；真机 cuFFT 默认 float，量级差异在 __CUDACC__ 注释里说明，不混入确定性断言。

7. 兄弟仓库互引

  • Least_squares_method_demo：LS 的 XᵀX 与 cuSPARSE 的 CSR 累加同属「贡献累加」范式。
  • neon_demo：SME ZA 外积累加 ≡ cuSPARSE CSR 遍历累加（稀疏 vs 稠密）。
  • KF_demo：KF 因子图固定种子 RNG 与 cuRAND 确定性纪律同构。
