L4 跨平台 SIMD 抽象层（SSE/AVX 封装 NEON）—— 一处写多端编译

定位：本篇补全 P2 neon「跨平台 SIMD 抽象（SSE/AVX 封装）」专题，按 L4 工业扩展层落地。
与 neon_l4_cmsis_dsp（库 API 语义复刻）、neon_l4_audio_dsp（音频算法核）共组
「一处写多端编译」工程化主线；承 neon_l1_lut 的 SIMD 原理、neon_l4_sme2 的指令语义模型。
应用指向：同份 kernel 源码编译到 ARM NEON / x86 SSE / AVX / 标量回退。

一、为什么需要 SIMD 抽象层

  • 多端现实：产线里同一算法要跑在 ARM 端（手机/NPU/MCU 的 NEON）、x86 端（服务器/桌面 SSE/AVX）、以及无 SIMD 的回退（MCU 标量、单元测试）。
  • 裸写 intrinsic 的痛苦：vaddq_f32 / _mm_add_ps / _mm256_add_ps 三条指令语义完全相同，却要写三遍、维护三套、测三遍。
  • 解耦：把”向量是什么（Simd<L> 类型）”与”算什么（kernel 算法）”分开。kernel 只调统一 API，后端由条件编译选择——一处写、多端编译。

二、抽象契约

操作 语义 NEON SSE AVX
vload 对齐/非对齐载入 vld1q_f32 _mm_loadu_ps _mm256_loadu_ps
vstore 存回 vst1q_f32 _mm_storeu_ps _mm256_storeu_ps
vadd/vmul 逐元素 vaddq_f32/vmulq_f32 _mm_add_ps/_mm_mul_ps _mm256_add_ps/_mm256_mul_ps
vbroadcast 标量广播 vdupq_n_f32 _mm_set1_ps _mm256_set1_ps
vhsum 水平归约 vaddvq_f32 两次 _mm_hadd _mm256_reduce_add_ps

关键：kernel 用模板宽度 L 写一次（simd_dot<L> / simd_saxpy<L> / simd_relu<L>），把 Simd<L> 换成 float32x4_t/__m128/__m256、把 vload/vadd/... 换成 VLOAD/VADD/...，其余循环/数据布局/算法一字不改。

三、代码走读（neon_l4_simd_abstract.cpp）

  1. 标量模拟后端（始终编译）：template<int L> struct Simd + 全套 vload/vstore/vadd/vsub/vmul/vhsum/vrelu/vbroadcast，逐 lane 标量展开。本沙箱无 NEON/SSE/AVX，正走此路 = x86 标量对照。
  2. kernel：simd_dot 把向量水平和累加到 double 累加器（acc += (double)vhsum(...)），故结果与车道宽度无关；标量尾巴处理不可整除 L 的部分。
  3. 生产后端映射（文档化，SIMD_SHOW_PRODUCTION 守卫，本环境不编译）：给出 NEON/SSE/AVX 三套 Vec4/Vec8 + VLOAD/VADD/... 的逐行对应，证明”换后端 = 换几行 typedef/宏，kernel 零改动”。

四、你会看到什么（5/5 PASS，受管 Python + C++ 控制流镜像双复核）

区 检查 结果
C1 跨后端 dot<2/4/8> 三者结果一致 且 == 朴素标量（double 累加器） err=4.4e-16
C2 saxpy<4> == 朴素 y += 0.5·x err=0
C3 relu<4> == max(0,·) err=0
C4 load/store 往返精确（L=4） err=0
C5 vadd<4> 逐元素 == 标量加 err=0

洞察：C1 直接证明”一处写多端编译”的算法无关性——无论后端是 2/4/8 路还是标量，点积数学结果一致（真实 float32 SIMD 有 ~1e-6 级舍入，属已知硬件细节；模型以 double 累加器做精确演示）。C2–C5 证明抽象 API 与逐元素标量运算逐位等价。

五、互引 / 落点

  • 承接：neon_l1_lut §1 SIMD 原理 → 本篇把”原理”落成可复用的抽象；neon_l4_sme2 的指令语义模型同属”不可运行环境下的语义建模”。
  • CMSIS/音频互引：neon_l4_cmsis_dsp 与 neon_l4_audio_dsp 的 FIR/双二阶/矩阵乘，正是本抽象层要包裹的 kernel——把它们写成 Simd<L> 后端即可跨端。
  • 跨域：向量水平归约的 Σ 累加 ≡ LS 法方程 JᵀJ ≡ KF 因子图 Λ ≡ SME ZA 外积（review 跨篇同构链），同一套线性代数，换后端不改算法。
  • 真实工程：xsimd / SIMDe / std::experimental::simd / Eigen 的 Vectorized backend，均为此抽象思想的成熟实现。

参考：ARM ACLE（arm_neon.h）；Intel Intrinsics Guide（immintrin.h）；xsimd 文档。
