L4 BF16/FP16 NEON —— FMLAL / BFMMLA 与精度谱

定位：本篇是 P1 neon 矩阵线「BF16/FP16 NEON」专题，按 L4 工业扩展层落地。
与 neon_l2_int8_gemm 的 int8 量化主线、neon_l4_sme2 的 SME2 外积累加共组
推理后端「低精三档」（int8 / bf16 / fp16）。承接 neon_l3_sve_kernels 后端分层栈。

一、为什么 BF16/FP16 是「省带宽 + 保精度」的双刃

  • FP32 GEMM 的瓶颈在带宽：每元素 4 字节，128-bit 寄存器只装 4 个 float。
  • BF16（1 符号 + 8 指数 + 7 尾数，与 FP32 同指数位 → 动态范围≈FP32）把元素压到 2 字节，同样寄存器装 8 个，带宽减半，且不需重缩放。
  • FP16（1+5+10）更省（10 位尾数精度更高），但动态范围小，需 loss-scaling。
  • 新指令把它们接入 fp32 累加器：BFMMLA = bf16·bf16 → fp32（2x2 块），FMLAL = fp16 长点积累加到 fp32。累加器仍是 fp32，避免低精度累加爆炸。
  • 这就是你笔记里「训练用 bf16、推理用 fp16/int8」的硬件落点。

二、指令语义

指令 输入 输出/累加 语义
BFMMLA (vbfmmlaq_f32) 2x4 bf16 × 4x2 bf16 2x2 fp32 out[i][j] += Σ_k a[i][k]·b[k][j]（块乘，累加 fp32）
FMLAL (vfmlalq_lane_f32) fp16 向量(8) fp32 标量 acc += Σ_t a[t]·b[t]（fp16 长点积，累加 fp32）
vaddq_f16 4 路 fp16 4 路 fp16 逐元素加

累加器统一 fp32，是低精推理不爆数值的关键。BF16 同指数位免重缩放，比 FP16 更省心。

三、代码走读（neon_l4_bf16.cpp）

本文件给三层，结构与 neon_l2_int8_gemm 同构：

  1. 可移植转换 + 指令语义模型（始终编译）：f32_to_bf16/bf16_to_f32/f32_to_fp16/fp16_to_f32（RNE 舍入）；
    bfmmlaq_model / fmlal_dot_model / vaddq_f16_model 精确复刻指令语义，x86 上也能对拍。
  2. 全 GEMM 低精路径：gemm_bf16_model / gemm_fp16_model（先转低精再标量累加回 fp32），对照 fp32 参考 gemm_fp32_ref。
  3. ARM 真 intrinsic（__ARM_FEATURE_BF16/__ARM_FEATURE_FP16 守卫）：vbfmmlaq_s32 等，x86 跳过、ARM 真跑。

四、你会看到什么（18 项对拍，受管 Python 镜像复核）

受管 Python 3.13.12 镜像 C++ 控制流（float32 语义 + 忠实 MT19937 复刻），18 项检查全 PASS（精度谱具体数值随 RNG 映射而变，但序 fp16≤bf16≤int8 始终不变）：

区 检查 结果
A 转换 bf16 RNE（1.0/0.5 精确、1.0625=1/16 精确、3.14159 误差 9.65e-4<0.01） PASS
A 转换 fp16（0.1=0x2E66、2.0=0x4000、65504 最大正规数、1e30 溢出→Inf 0x7C00） PASS
B BFMMLA 模型 == 标量 2x4×4x2→2x2 fp32 GEMM err=0
C FMLAL fp16 长点积(8) 累加 fp32 == 标量 err=0
D vaddq_f16 4 路 == 标量 err=0
E bf16/fp16 全 GEMM 相对 fp32 参考误差有限且有损；模型确定性逐位一致 PASS
F 精度谱 **fp16 误差(3.88e-4) ≤ bf16 误差(3.81e-3)**（精度谱有序） PASS
F bf16 路径确为有损（与 fp32 有差） PASS
F 三种低精误差均有限且 <1.0（int8=7.11e-3） PASS

洞察：精度谱有序 fp16 ≤ bf16 ≤ int8——fp16 的 10 位尾数精度最高、bf16 次之（7 位）、int8 最粗。但 bf16 凭「同指数位免重缩放 + 动态范围≈fp32」在训练/大模型推理更受青睐，fp16 凭精度在小模型推理占优，int8 凭带宽在量化推理最省。

五、互引 / 落点

  • 承接：neon_l2_int8_gemm 的 int8 量化主线 → 本篇补 bf16/fp16 两档，共组低精三档。
  • SME2 互引：neon_l4_sme2 的 bmopa（bf16 外积累加进 fp32 ZA）正是本篇 BFMMLA 的「外积版」——同 bf16 输入、同 fp32 累加，只换分解方式。
  • 真实后端：NCNN gemm_int8.h 在 I8MM 之上可切 bf16/fp16 路径；MNN KleidiAI kai ukernel 的 bf16 档。
  • 跨域：与 [[cuda_demo]] 的 FP8/TMA 在「低精推理后端」上汇合（review §三 HPC 算子前沿）。

参考：ARM A64 指令集手册 BF16/FP16 章；NCNN gemm_int8.h；MNN KleidiAI ukernel 文档。
