L2.5 等式约束最小二乘（KKT）

一句话：KKT 一行拼出来——min ‖Ax−b‖² s.t. Cx=d 的解是增广 KKT 方程 [[AᵀA, Cᵀ];[C, 0]][x;λ]=[Aᵀb; d]，约束被精确满足，代价 SSE ≥ 自由解。

一、约束最小二乘与 KKT

带等式约束的 LS：

min ‖Ax − b‖² s.t. Cx = d

构造拉格朗日函数 L = ½‖Ax−b‖² + λᵀ(Cx−d)，对 x 和 λ 求驻点：

∂L/∂x = Aᵀ(Ax−b) + Cᵀλ = 0
∂L/∂λ = Cx − d = 0

拼成KKT 方程（对称不定）：

[AᵀA Cᵀ; C 0] [x; λ] = [Aᵀb; d]

一次线性求解同时得到 x 和拉格朗日乘子 λ。λ 的物理含义是”约束张力”——约束被违背时有多大的恢复力。

二、约束解的性质

  • 约束精确满足：Cx = d 到机器精度（该组数据测试容差 ~1e-10；实际受条件数/尺度影响）。
  • SSE 关系：SSE_free ≤ SSE_constrained——约束缩小可行域，最优代价不会更低。自由解的最优 SSE 是约束解 SSE 的下界（约束解 ≥ 自由解）。
  • 变体：软约束 = 加权惩罚（岭回归，L1.3，是 Tikhonov 的特例）；不等式约束 = QP（Lasso/MPC，Lasso 是 L1 惩罚常转化为 QP）。

KKT 方程的推导（为什么拼成增广矩阵）

核心洞察：KKT 是”原问题最优性条件”的直接拼装——x 行是”梯度为零”（无约束部分的驻点条件 + 约束的拉格朗日项），λ 行是”约束可行”（原始可行性）。为什么矩阵不定：左上 AᵀA 半正定（A 满列秩时才正定）、右下 0 块使整体既非正定也非负定 → 不能 Cholesky，必须带主元的 LDLᵀ 或 QR（这就是数值库对 KKT 系统特殊处理的原因）。KKT 矩阵非奇异还需约束资格条件（如 C 满行秩、d∈range(C)）。λ 的”约束张力”解读：λ 大 = 该约束”拉”参数很用力（违反约束的代价高；注意 λ 依赖约束的单位/缩放，跨约束不可直接比较）。

三、demo 设定

直线 y = ax + b，n=30 点，真值 a=3, b=1，σ=0.3。约束 a = 2.5（模拟”已知增益比”的标定先验）。比较自由解与约束解。

四、代码走读（ls_l2_constraint.cpp）

  • 第 39–45 行：生成数据，算自由 OLS 解 a_free, b_free（2×2 法方程）。
  • 第 46–50 行：KKT 方程——3×3 矩阵 [[Sxx, Sx, 1]; [Sx, Sn, 0]; [1, 0, 0]]（第 47 行），右端 [Sxy; Sy; 2.5]（第 48 行），约束 a=2.5 塞进第三行。inv3 求 3×3 逆（第 20–27 行），matvec 解出 [a, b, λ]（第 49 行）。
  • 第 51 行：chk 约束精确满足 |a_c − 2.5| < 1e-10。
  • 第 52–54 行：chk 约束解 SSE ≥ 自由解（可行域缩小的代价）。
  • 第 55–58 行：打印自由解/约束解的 a、SSE、λ，结论说明变体。

五、你会看到什么

自由解 a≈3.0（数据真值附近），约束解 a=2.5000（被精确钉住，误差 ~1e-16）。约束解的 SSE 略高于自由解（约束让拟合线偏离数据最优方向）。λ 的符号/大小反映约束”拉”参数的力度。噪声随机，SSE 和 λ 每次略异。

六、自检

  • 把约束改成 a = 3.0（恰好等于数据真值），看约束解 SSE 是否≈自由解（约束刚好不 binding）。
  • 思考：为什么 KKT 矩阵是不定的（既非正定也非负定）？不能直接用 Cholesky，需 LDLᵀ 或 QR。
  • 把约束换成 a + b = 4（线性组合约束），改写 C 和 d，验证 KKT 仍一行可解。

七、下一步
