L3.2 工业用例：GPS 伪距定位

一句话：到第 k 颗卫星的伪距 ρₖ = ‖x − sₖ‖ + δt·c + ε——四颗以上卫星就把 [x, y, z, δt·c] 四个未知量耦合在一个非线性 LS 里，高斯-牛顿在当前点线性化，迭代两三步收敛。钟差和位置同时被解出来，这是定位算法的核心机制。

一、伪距方程与线性化

第 k 颗卫星位置 sₖ ∈ ℝ³，接收机位置 x ∈ ℝ³，接收机钟差等效距离 b = δt·c。伪距观测：

ρₖ = ‖x − sₖ‖ + b + εₖ （k = 1..M, M ≥ 4）

未知量 p = [x, y, z, b]ᵀ ∈ ℝ⁴。残差：

rₖ(p) = ρₖ − (‖x − sₖ‖ + b)

在当前估计 pₖ 处对 pₖ + Δ 一阶展开（L1.5 的 GN 模式）：

r(pₖ + Δ) ≈ r + J·Δ， J = ∂r/∂p

雅可比的几何含义：‖x − sₖ‖ 对 x 的导数是从卫星指向接收机的单位向量：

Jₖ = [ (x − sₖ)/dₖ , 1 ]ᵀ，dₖ = ‖x − sₖ‖

即 J 是 M×4 的几何矩阵，前三列是 M 条视线方向，第四列全 1（钟差对各观测等量贡献）。

GN 更新（解一个 4×4 法方程）：

JᵀJ · Δ = Jᵀr， p ← p + Δ

⚠ 符号坑（重要，开发踩过）：若残差定义 r = z − h(p)（观测减模型），则 r(p+Δ) ≈ r − J·Δ（J=∂h/∂p 是模型雅可比），最小化 ‖r − JΔ‖² 得 JᵀJΔ = Jᵀr——更新方向 +Δ 正确。若写成 r = h(p) − z 则残差雅可比为 −J，正规方程是 −JᵀJΔ = −Jᵀr（同样得 JᵀJΔ=Jᵀr）。关键是 J 定义统一：本文 J 是观测模型 h 的雅可比（非残差雅可比），残差展开带负号。cpp 注释 L7 强调的正是这个约定。

二、工程背景：为什么是 LS，为什么是 GN

  • GPS 每秒输出一次定位结果，本质是每秒一次的非线性最小二乘。
  • 至少 4 颗卫星：3 个空间分量 + 1 个钟差分量。多了更好——冗余抗噪，且能算 GDOP。
  • GDOP = √tr((JᵀJ)⁻¹)：几何矩阵病态度。卫星分布越”张开”，JᵀJ 越良态，同噪声下定位越准——这是选星算法的依据。
  • KF_demo 的松组合 = 这个 LS 拿到位置后，再喂给卡尔曼滤波器做时间平滑。

GDOP 的推导（为什么”几何张开”能提升精度）

核心洞察：GDOP 是”卫星几何 → 定位误差放大因子“的定量——同一套 LS 算法，几何好（星张开）和几何差（星聚拢）的精度可以差一个数量级。选星（从 N 颗里挑 GDOP 最小的 4 颗）、城市峡谷定位差、GPS 欺骗检测（GDOP 异常）全是这一条公式的工程应用。与 L1.3 病态/岭回归的关系：JᵀJ 病态 = 几何差，GDOP 就是几何病态度在定位场景的名字。工程上 GPS 用加权形式 (JᵀWJ)⁻¹（卫星仰角加权）并需处理电离层/对流层/多路径延迟——本 demo 是理想化最小情形。

三、demo 设定

  • 5 颗卫星坐标见 cpp L28–30，距离量级 ~10⁴ km；接收机真值 pos_true = (100, -200, 50) m（地心附近）。
  • 钟差等效距离 b_true_m = 0.001·c·1e-6 = 0.3 m（cpp L33）。
  • 伪距噪声 σ = 3.0 m（L40：gauss()*3.0）。
  • 起点 x = {0,0,0,0} —— 纯地心，离真值约 224 m，GN 必须能拉回来。
  • 收敛判据：max|Δ| < 1e-8 或 30 步上限。

五、你会看到什么

定位误差典型值 ~4 m：噪声 σ=3 m × √(GDOP 因子 ~2)。GN 3 步内收敛——线性化点离真值不远时二次收敛很快。换种子或卫星几何时数值略异，但都远低于 15 m 的容限。

六、自检

  • 把卫星全挪到同一象限（如都 >0），看 JᵀJ 病态度上升、定位误差变大——这就是”几何不好”的量化。
  • 思考：为什么 J[k][3] = 1.0 这列不能缺？（少这列等于假设钟差已知，4 个方程 3 个未知量，会被噪声放大。）
  • 把起点从地心挪到真值附近（如 x = {100, -200, 50, 0}），看 GN 是否一步收敛（线性化点足够准时一步即可达 tol）。
