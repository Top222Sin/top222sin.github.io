L4.9 PCA / 低秩（作为 LS）

前几篇把 LS 当”拟合一条曲线/一个模型”。PCA 揭示一个更深的视角：LS 本身就是降维与低秩逼近的引擎——把数据投影到使其重构误差最小的方向，等价于在协方差阵上做特征分解。本项目用 Jacobi 旋转做对称特征分解，并以 Eckart-Young 定理自证”PCA = 最佳低秩逼近”。

〇、动机：为什么 PCA 是”作为 LS”

问题 LS 视角
数据有冗余维度 找最小二乘意义下”最能代表数据”的低维子空间
去噪 / 压缩 截断小特征值 = 丢掉对重构误差贡献最小的成分
可视化（高维→2D） 投影到 top-2 主方向，使投影后方差最大（信息损失最小）

PCA 的目标 min ‖X − X_k‖²_ F 在 X_k 为秩 k 时，最优解就是取协方差 C = XᵀX 的 top-k 特征向量——这是一串最小二乘问题（每步投影到当前最优方向，即幂迭代 / Rayleigh 商）。

一、原理

中心化数据 Xc（列均值归零），协方差 C = Xcᵀ Xc /(n−1)（d×d 对称半正定）。

  • 主方向：第 1 主方向 v1 = argmax_{‖v‖=1} ‖Xc v‖² = argmax vᵀ C v（Rayleigh 商），即 C 的最大特征向量。
  • Eckart-Young：最佳秩-k 逼近 X_k = Xc·V_k·V_kᵀ，其中 V_k 为 top-k 特征向量；重构误差 即被丢掉的特征值之和——丢谁、丢多少，由 LS 残差精确量化。
  • 方差解释比：Σ_{i≤k} λ_i / Σ_i λ_i，衡量前 k 主成分保留了多少信息。

二、算法：Jacobi 特征分解（对称阵）

反复做 2×2 Givens 旋转消去最大非对角元，直到对角占优：

旋转同时更新 C 与特征向量矩阵 V。收敛后特征值降序排列。纯 C++17 可写、确定、数值稳定（比幂迭代更适合”取 top-k 全部特征向量”）。

“PCA 作为 LS”的三重体现：

  1. 主方向 = 最大方差 = Rayleigh 商最大 → 一个 LS 投影问题；
  2. 低秩重建 = 最小化重构误差 → 一个 LS 近似问题；
  3. 幂迭代求解主方向 = 反复做 v ← C v / ‖C v‖（迭代 LS 投影）。

  • 同构家族（写在 MEMORY 的”贡献累加”范式）：PCA 的协方差 C=XᵀX 是 GN 中 JᵀJ 的特例——GN 的 Hₖₖ = Σ JᵀJ 逐项累加 ≡ PCA 的 XᵀX 累加 ≡ SME 的 ZA 外积累加 ≡ KF 因子图信息矩阵累加，四者同构（见 [L4.10 Schur 补 BA](/02jd/Least_squares_method_demo/ls_l4_schur_ba.html) 的块累加同构）。

  • matmul/matvec/transpose/dot/normv：小矩阵库。
  • ortho_columns：Gram-Schmidt，生成确定性正交基（真值信号子空间）。
  • jacobi_eig：对称阵 Jacobi 旋转，返回降序特征值 + 特征向量（列）。
  • rnd()：LCG（seed=20260820），与受管 Python 验证逐位同序。

六、自检 / 易错点

  • 中心化忘了：PCA 必须减去列均值，否则第一主成分会被”整体偏移”带偏（变成拟合均值而非方差方向）。
  • Jacobi 的 θ 符号：t = sign(θ)/(|θ|+√(θ²+1))，写错符号会让旋转方向反掉、收敛变慢甚至不收敛。
  • 特征向量列序：排序后务必同步重排 V 的列，否则”top-k”取到的是错误方向（见 [[ls_l2_qr|L1.4]] 的”列对应”坑）。
