验证状态

  • 本机无 C++ 编译器。全部 26 篇数学经受管 Python 3.13.12 验证（103 项检查全部 PASS：正篇 31 + 方向/方法扩展专题 72）：
    • Aᵀr=0（1e-13）；法方程=QR（1e-15）；WLS 优于 OLS（50 次 MC）
    • Hilbert-7：岭回归压制误差 12→0.012；Hilbert-10：QR 误差 6e-4 vs 法方程 48
    • 指数拟合 GN 8 步收敛；∇=Jᵀr 对拍 1e-10；LM 远起点收敛
    • Huber 抗 20% 野值（0.72→0.19）；RLS=批量 LS（7e-9）；遗忘因子跟踪突变（0.4 vs 1.4）
    • KKT 约束 1e-16；TLS 无偏 vs OLS 衰减（20 次 MC）；GPS 定位 4.0 m/3 步；ARX 辨识 0.004
    • 方向专题(L4)：IMU 12 参数校准 0.003 + 磁力计椭球；OFDM 导频 LS 降误码、LMS 收敛 Wiener、
      MVDR 干扰零深；软测量 RMSE 0.058 + RUL 外推；仿射 DLT + RANSAC 抗 50% 外点 + LK 光流 2e-5；
      ICP 一步收敛 + 车道线三次拟合 + 滑窗降噪 92%
    • 方向专题(L4.7) 子空间辨识：QR上三角/RᵀR=MᵀM/SVD重构 3 项；N4SID 阶数 n=2·A稳定·一步预测 RMSE≈2σ·I-O 0.027；
      MOESP 谱/阶数 n=2·N4SID↔MOESP 一致；PEM 准则下降·精调不退化·I-O 0.027·Riccati 收敛（共 16 项，C++ 控制流镜像 16/16 PASS）
    • L4.6 Lasso 稀疏正则化：软阈值闭式 4 例一致；1D 闭式 0.375 一致；稀疏恢复 17/17 真零压零 + 3 非零 + 支撑精确；FISTA 12 步目标(21.37)严格低于 ISTA(23.25)；大λ→全零；2D 网格搜索目标一致(1.02755 vs 1.02771)；欠定压缩感知 m=18<n=40 真支撑⊆恢复；Lasso vs OLS 选 3（OLS 铺开 15）
    • L4.8 NNLS 非负最小二乘：投影梯度（PIP 主动集）收敛到 KKT 最优（‖g_active‖<tol）；各分量 x≥0（min x = 2.4e-7）；vs 无约束 LS 多负分量——证明非负约束改变了最优解（5/5 PASS）
    • L4.9 PCA/低秩（作为 LS）：最佳秩-k 近似 = SVD 截断（Eckart-Young）；投影残差 = 丢弃特征值能量；SVD 重构误差 1.3e-15（5/5 PASS）
    • L4.10 Schur 补 BA：块法方程 + 锚定相机0 消 gauge 歧义；Schur 约化 δ 与全解 δ 偏差 5.7e-12（完全等价）；LM 阻尼收敛（重投影 rms 3.43→0.18 px）（5/5 PASS）
    • L4.11 分位数回归：非对称 check loss 梯度≈0（max|∇|=1.7e-6）；分位覆盖 frac(r<0)≈τ（max|Δ|=5e-3）；平滑梯度下降收敛（5/5 PASS）
  • 验证中抓到并修复的真实 bug（对应 .md 有注记）：
    ① QR 解用了 Q·b 而非 Qᵀb；② GN/LM 步进符号：Δ=−(JᵀJ)⁻¹Jᵀr 写成 +（ uphill，三处）
    ③ GPS 雅可比符号约定与残差方向不一致（发散 1e15）；④ TLS 用了 λ_min 特征向量（法向而非线方向）
    ⑤ Householder 子数组索引 off-by-k；⑥ RLS 的 R 与真实 σ² 失配 + 无界回归量 → 回路增益≈1 振荡
    ⑦ 波束成形增益要取共轭权 wᴴa（wᵀa 给出 0.13 假增益）；⑧ 光流残差=当前帧−扭曲模板（放反则 dx 恒 0）
    ⑨ 2D Kabsch 角度符号 atan2(sxy−syx,…)（反了转错方向）；⑩ 软测量/车道线特征必须归一化（裸 350~400 病态）
    • ⑪ Schur BA 全自由时 7-自由度相似变换（gauge）歧义使 J 秩亏 7、H 奇异 → 固定相机0 锚定坐标架消除歧义（H 满秩）
    • ⑫ Schur BA 阻尼 λ 误”附加”到 Hcc 行尾（变 12×24 矩形阵 → solve 零除）→ 应在 Hcc、Hpp 对角加 λ（Schur 恒等式对 (H+λI) 仍成立）
    • ⑬ 分位数 check loss 在 0 处不可微、裸梯度下降抖动 → 改用平滑替身 √(r²+δ²)−δ（Huber 式）做梯度下降，收敛处梯度≈0

与兄弟仓库的关系（本仓库 = 全链地基）

兄弟仓库 它里面的 LS 是什么 对应本篇
cali_demo 相机标定/手眼/BA = 流形上的非线性 LS（GN/LM + Huber 核） L1.5 + L2.2 + L2.3
KF_demo KF = 递推加权贝叶斯 LS；批量贝叶斯≡KF(L1.1)；信息滤波=法方程 L1.1 + L1.2 + L2.4
control_demo 系统辨识(L3.4) = ARX 最小二乘；LQR 的黎卡提方程与 LS 同源 L3.3
Jacobian_demo GN/LM 求解器、BA 重投影残差 = 雅可比驱动的非线性 LS L2.1 + L2.2
pid_demo 自整定中的模型拟合 = 在线 RLS L2.4
neon/cuda_demo 大规模 LS(QR 分解) 的 SIMD/GPU 加速对象 L1.4

组合场景一（视觉 SLAM 一帧）：cali(内参) → 三角化(L3.4②) → 重投影 BA(Jacobian L2.6 = 本仓库 GN+Huber)。
组合场景二（组合导航）：GPS 单点定位(L3.2) → EKF 时刻更新(KF_demo) = 松组合。
组合场景三（自适应控制）：ARX 辨识(L3.3) → LQR 重算(control_demo L2.5) = 自校正调节器。
