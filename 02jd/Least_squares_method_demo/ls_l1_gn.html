L1.5 非线性最小二乘：高斯-牛顿（GN）

一句话：非线性问题在当前点”假装线性”，解一个线性 LS，重复到收敛——Δ = −(JᵀJ)⁻¹Jᵀr（注意负号！）。这就是 Ceres / g2o 的内核。

一、非线性 LS

模型 y = f(x, p)，p 是参数。残差 rᵢ = yᵢ − f(xᵢ, p)，目标 min ½‖r(p)‖²。在当前 pₖ 线性化：

r(pₖ + Δ) ≈ r + J Δ，J = ∂r/∂p（雅可比）

求最优 Δ 使 ‖r + JΔ‖² 最小 → 又是一个线性 LS（L1.1 的形式）：

J Δ = −r ⇒ Δ = −(JᵀJ)⁻¹Jᵀr ← 负号！

⚠ 写成 +Jᵀr 就是在爬坡（梯度上升）。p ← p + Δ，重复直到 ‖Δ‖ 很小。

二、与梯度下降的关系

  • 梯度下降：Δ = −α Jᵀr（一阶，慢但远点稳）
  • 高斯-牛顿：Δ = −(JᵀJ)⁻¹Jᵀr（二阶近似，近点快、远点可能发散）
  • LM（L2.2）：Δ = −(JᵀJ + λI)⁻¹Jᵀr（两者折中，Ceres 默认）

GN 的 JᵀJ 是 ½‖r‖² 的 Hessian 近似——丢掉了 Σ rᵢ ∇²rᵢ 项（小残差时合理）。

GN 步长的推导（为什么是 −(JᵀJ)⁻¹Jᵀr）

核心洞察：GN 每步 = 在当前点解一个线性 LS（L1.1 的法方程，只是把 A 换成 J、b 换成 −r）——这就是”非线性问题局部线性化”的迭代实现。负号来自 Δ = −(JᵀJ)⁻¹Jᵀr（不是 +）：写成 +Jᵀr 就是沿梯度上升（爬坡）。收敛性：在解处残差为零、J 满列秩、初值足够近的条件下 GN 二次收敛；一般情况下（非零残差）收敛是线性/超线性——“近收敛点快”是普遍观察，严格二次收敛需条件。工程实现用 QR/Cholesky 解正规方程而非显式求逆（JᵀJ 会平方条件数）。

三、demo：指数拟合

模型 y = a·e^{bx}，真值 (a, b) = (2.5, −0.8)，30 个点，噪声 σ=0.05。残差 r = y_obs − a·e^{bx}，雅可比：

∂r/∂a = −e^{bx}， ∂r/∂b = −a·x·e^{bx}

初值 (1.5, −0.5)，2×2 法方程手写，迭代到 |Δ| < 1e-12。

四、代码走读（ls_l1_gn.cpp）

  • resid(p0,p1)：第 33–36 行，r = y − a·e^{bx}。
  • ① 解析雅可比 vs FD：第 48 行 Jan = −e 或 −a·x·e，与中心差分对拍（tol 1e-6）。
  • ② GN 迭代：第 58–71 行，手写 2×2 JᵀJ 与 Jᵀr，d0 = −(H11·g0 − H01·g1)/det（负号在），更新 a += d0。

五、你会看到什么

无噪声版 numpy 复算 6 步即收敛到精确真值；有噪声 8 步量级。

六、自检

  • 把初值拉远（如 a=0.1, b=0.1），看 GN 是否还能收敛（可能发散 → 引出 LM 的动机）。
  • 思考：为什么 JᵀJ 是 Hessian 近似？被丢的 Σrᵢ∇²rᵢ 项在大残差时为何不能忽略？
  • 把残差改成 r = a·e^{bx} − y（符号反），验证雅可比符号随之反、GN 步方向仍正确（负号保证下降）。

七、下一步

进入 L2.1 残差雅可比与 Hessian——把 GN 的”一阶/二阶”摆清楚：∇=Jᵀr、H≈JᵀJ。

兄弟仓库联系
