L4.8 非负最小二乘（NNLS）

前 21 篇把 LS 讲透了，但默认解可以是任意实数。现实里很多量不能为负：化学浓度、资产权重、像素发射率、NMF 的基系数……一旦无约束 LS 解出负值，结果就物理不可解释。NNLS 就是把 LS 加上 x ≥ 0 这个最简单的约束——它仍是凸二次规划，本项目用投影梯度下降（PGD）求解，并用 KKT 条件自证正确性（不依赖外部求解器）。

〇、为什么需要 NNLS（动机）

场景 为什么 x 必须 ≥ 0
光谱/色谱定量 组分浓度、吸光度非负
投资组合（Long-only） 权重非负，不能做空
非负矩阵分解 NMF 基图像与系数图均为非负
图像/辐射亮度 像素发射率、深度非负
贝叶斯后验的矩 某些物理量的期望非负

无约束 LS 在这些场景会解出负分量（图右红柱），NNLS 把解投影回可行域（绿柱），得到物理可解释的结果。注意：NNLS 不是”把 LS 解里负的截断成 0”——截断法（clamp）一般不是约束最优，本项目第 5 项检查证明 NNLS 目标值可严格优于朴素截断。

一、原理：NNLS = 带约束的 LS

NNLS 在其上加非负约束：

KKT 条件（最优性判据，本项目用它做验证）：

  • 梯度 ∇f = Aᵀ(Ax − b) ≜ −s（s = Aᵀ(b − Ax)）。
  • 互补松弛：对第 j 个分量，
    • 若 x_j > 0（被动/自由）：s_j = 0（停在内部，梯度为零）；
    • 若 x_j = 0（活动/在边界）：s_j ≤ 0（再往 +x 方向走会增大目标，故不能动）。
  • 即：活动分量梯度 ≤ 0，被动分量梯度 ≈ 0。这恰是”投影到 x≥0 锥”的几何意义。

二、算法：投影梯度下降（PGD）

f 是二次凸函数，黑塞 ∇²f = AᵀA 半正定、Lipschitz 光滑常数 L = 2·λ_max(AᵀA)。梯度步：

max(0,·) 即把结果投影回非负象限。步长 α = 1/L 保证单调收敛到全局最优（凸问题无局部极小）。

λ_max(AᵀA) 用幂迭代求（仅矩阵-向量乘，无需特征值全套），确定性初值 v = 1/√n。

为什么不用活动集/法方程？ 活动集（Lawson–Hanson）需要在子问题上解法方程，对病态 A 数值不稳；PGD 只做矩阵-向量乘，绝对稳定，且收敛点天然满足 KKT——非常适合”无编译器、靠镜像兜底”的纯 C++17 复现。

与仓库主线的关系（”LS 即地基”再印证）

NNLS 是 L1.1 法方程 / L1.3 岭回归 的直接推广：

  • 无约束 LS（L1.1）= 投影到全空间；
  • 岭回归（L1.3）= 加 ℓ₂ 球约束的 LS；
  • NNLS = 加 ℓ∞ 盒约束（x≥0）的 LS。
    三者同属”约束二次规划”，区别只在可行域形状。NNLS 还可看作 L2.5 等式约束 KKT 的”不等式版”——KKT 从等式乘子变成互补松弛。

三、代码走读（ls_l4_nnls.cpp）

  • matmul / matvec / transpose / solve：小矩阵库（solve 用高斯消元+部分主元，仅给无约束 LS 基线用）。
  • rnd()：LCG（seed=20260820），与受管 Python 验证逐位同序，保证对拍一致。
  • lambda_max_ATA：幂迭代 80 步求 λ_max(AᵀA)。
  • nnls_pgd：20000 步 PGD，x ← max(0, x − α·2Aᵀ(Ax−b))。
  • main：合成 A(12×7)、x_true（5 正 + 2 零）、b = A·x_true + 1e-3 噪声；跑 NNLS 与无约束 LS；断言 5 条。

四、验证表（受管 Python + C++ 控制流镜像，均 5/5 PASS）

# 检查 判据 结果
① 可行性 min(x_est) ≥ −1e-9 0.0 ✅
② 恢复误差 ‖x_est−x_true‖/(‖x_true‖+1) < 1e-2 1.0e-4 ✅
③ KKT 互补松弛 活动 s_j≤0、被动 s_j≈0，maxviol < 1e-5 8.6e-16 ✅
④ 残差不劣于 LS f_nnls ≥ f_ls − 1e-8 +9.1e-7 ✅
⑤ 优于朴素截断 f_nnls ≤ f_clamped + 1e-7（单侧上界） −2.4e-6 ✅

第 ③ 项用 KKT 自证最优（无需外部 solver）；第 ⑤ 项证明 NNLS 真优于”截断 LS”——这正是 NNLS 的工程价值。

五、自检 / 易错点

  • PGD 步长：必须用 α = 1/(2λ_max)，而不是 1/λ_max——后者对应光滑常数定义不同，会发散或慢。
  • KKT 符号：s = Aᵀ(b−Ax) = −∇f。活动分量要求 s_j ≤ 0（即 ∇f_j ≥ 0，不能再下降），初写常把符号写反（误写成要求 s_j ≥ 0）——本项目 ③ 用 worst = max(active s_j) 直接检验，避免方向坑。
  • 不等式断言方向（踩过的内存坑）：第 ⑤ 项”NNLS 不差于截断”是单侧上界 f_nnls − f_clamped ≤ 1e-7，用 max(0, diff − 1e-7) 当 err，而非 abs(diff)——否则 NNLS 严格更优（diff 为负）会被误判 FAIL。
