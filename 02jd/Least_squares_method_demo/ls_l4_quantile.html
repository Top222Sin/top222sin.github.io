L4.11 分位数回归（作为 LS）

普通最小二乘（OLS）估计的是条件均值——它最小化对称的 Σ(y−Xβ)²。但很多场景我们关心的是条件分位数：比如风险价值 VaR（τ=0.05 分位）、收入分布的不平等、需求预测的上/下界、稳健回归（抗厚尾）。分位数回归就是把”平方损失”换成非对称的 check / pinball 损失 ρ_τ(r)=r·(τ−1_{r<0})——正残差权重 τ、负残差权重 τ−1。它与 OLS 同属一个优化骨架（都是 min_β Σ 损失），只是损失函数从对称 L2 换成非对称 Lτ，因而用 IRLS 重加权 / 平滑梯度下降这类 LS 式迭代求解。这正是”分位数回归（作为 LS）”的含义。

〇、动机：均值之外，我们需要分位

场景 关心的分位 为什么
金融 VaR / CVaR τ=0.01~0.05 尾部风险，而非平均收益
需求/负荷预测上下界 τ=0.1 / 0.9 给出预测区间而非单点
收入不平等 τ=0.1 / 0.9 底部 vs 顶部差异
厚尾/异方差鲁棒回归 τ=0.5（中位数） LAD 抗离群，比 L2 稳健
生存/排队分析 任意 τ 条件分位函数刻画全部分布

OLS 给一条线；分位数回归给一束线（τ 从 0.1 到 0.9 扇出），共同描绘 y|x 的条件分布。

一、原理：check loss = 非对称 LS

1.1 两个损失

  • OLS：L₂(β) = Σ (yᵢ − xᵢᵀβ)² —— 对称，最优解是条件均值 E[y|x]。
  • 分位数回归：L_τ(β) = Σ ρ_τ(rᵢ)，rᵢ = yᵢ − xᵢᵀβ，
    ρ_τ(r) = r·(τ − 1_{r<0}) = { τ·r (r≥0) ; (τ−1)·r (r<0) }。
    它是分段线性的”V”形：右支斜率 τ、左支斜率 τ−1（图右蓝 V）。τ=0.5 时退化为 0.5|r|（LAD，中位数回归）。
  • 关键性质（分位覆盖）：最优 β̂_τ 满足 P(y ≤ xᵀβ̂_τ) = τ，即约 τ 比例的残差为负。本项目验证 ①。

1.2 与 LS 的同构

把 check loss 看作”加权 / 非对称的最小二乘“：残差为正时惩罚权重 τ、为负时 τ−1。求 min_β Σ ρ_τ(rᵢ) 与 OLS 用完全相同的迭代骨架：

  • IRLS（迭代重加权最小二乘）：按当前残差符号设权重 wᵢ = τ（正）/ (1−τ)（负），解加权 LS β ← argmin Σ wᵢ rᵢ²，迭代。每步都是我们熟悉的（加权）法方程。
  • 平滑梯度下降：用平滑 check loss（把 V 的折点磨圆）ρ_τ^δ(r) = (τ−0.5)r + ½(√(r²+δ²)−δ)，梯度 ∂/∂β = −Σ xᵢ[(τ−0.5)+½·r/√(r²+δ²)]，下降即可（本项目采用，确定性可复现）。
    两者都”逐残差加权累加进一个 LS 式目标”——与 L4.9 的 JᵀJ ≡ XᵀX、L4.10 的 Σ JᵢᵀJᵢ、SME ZA、KF 因子图信息矩阵同属”逐项累加“范式。

三、与主线/兄弟仓库的关系

  • L1.1 / L1.2（法方程、WLS）：IRLS 的每步就是加权法方程 XᵀW X β = XᵀW y，与 L1.2 的 WLS 完全一致。
  • L2.3（Huber / M-估计 / IRLS）：Huber 也是”把平方损失磨圆做鲁棒 LS”，与这里的平滑 check loss 同一思路——鲁棒/分位估计 = 换损失的 LS。
  • L4.9 / L4.10（累加同构）：check loss 的梯度/信息仍来自”逐样本累加”，与 XᵀX、Σ JᵢᵀJᵢ 同构。

六、自检（易错点）

  1. check loss 不可微于 0：直接用子梯度下降易振荡。修复：用平滑 check loss（磨圆折点）做光滑梯度下降，δ 小（0.02）偏差可忽略。
  2. IRLS 权重 ≠ 真分位：朴素”按符号设 w=τ/(1−τ)“的加权 LS 收敛到的是 expectile 而非分位。本项目用平滑 check loss 梯度下降直最小化分位损失，规避此坑（.md 亦点明 IRLS 是 LS 式近似）。
  3. 不等式方向（第 ④ 项）：”β̂ 的 check loss 应 ≤ OLS 的”用单侧上界 err=max(0, CL̂−CL_ols)，避免把”OLS 更差”误判 PASS（详见项目记忆”不等式断言 chk 方向坑”）。
  4. 覆盖率的抽样/平滑偏差：N=200、δ=0.02 下 |frac−τ| 仅 5e-3，远优于容差 0.085。
  5. 异方差才看得到扇形：若噪声同方差，Q_τ(x) 只平移不明显扇出；本项目用 σ(x)=0.4+0.3|x| 制造异方差，使 τ=0.9 与 τ=0.1 预测差达 1.34。
