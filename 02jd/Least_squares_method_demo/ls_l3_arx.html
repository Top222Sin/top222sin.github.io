L3.3 工业用例：ARX 系统辨识

一句话：**线性系统 y(k) = Σaᵢy(k−i) + Σbᵢu(k−i) + e**——把过去输入输出堆成回归矩阵 Φ，参数 θ 就是一次普通 LS 的解 (ΦᵀΦ)⁻¹ΦᵀY。前提是输入”持续激励”，否则 ΦᵀΦ 病态、参数不可辨识。

一、ARX 模型与 LS 辨识

单输入单输出（SISO）线性系统：

y(k) = a₁·y(k−1) + a₂·y(k−2) + … + aₙₐ·y(k−nₐ) + b₀·u(k) + b₁·u(k−1) + … + bₙ_b·u(k−n_b) + e(k)

写成向量形式 y(k) = φ(k)ᵀ·θ + e(k)，其中回归量 φ(k) = [y(k−1), ..., y(k−nₐ), u(k−n_b), ..., u(k)]、参数 θ = [a₁, ..., aₙₐ, b₀, ..., bₙ_b]ᵀ。堆叠 N 次观测：

Y = Φ·θ + E （Y ∈ ℝᵏ, Φ ∈ ℝ^{k×ⁿ}, θ ∈ ℝⁿ）

θ 的 LS 解（L1.1）：

θ̂ = (ΦᵀΦ)⁻¹·ΦᵀY

demo 用最朴素一阶 y(k) = a·y(k−1) + b·u(k−1) + e，于是 φ(k) = [y(k−1), u(k−1)]，2×2 法方程闭式解：

行列式 det = Σy²·Σu² − (Σyu)²，闭式解：

â = (Σu²·ΣyY − Σyu·ΣuY) / det， b̂ = (Σy²·ΣuY − Σyu·ΣyY) / det

二、工程背景：辨识 vs 拟合

  • 拟合（L1.1 标定）：已知模型结构、反演参数；传感器是静态关系 y = ax + b。
  • 辨识（本篇）：从输入输出时间序列同时反解模型结构与参数——动态系统的等价”标定”。
  • control_demo 的”阶跃两点法”（一阶系统 K、T）是 ARX 的时域特例；ARX 更普适：高阶、多输入、零飘项 c 都能塞进 φ。
  • 模型阶数（nₐ, n_b）靠 AIC / BIC / 残差白性检验选——不在本篇范围，但思路：阶数加到残差不再变白为止。

三、持续激励：不可省的前提

ΦᵀΦ 病态的几何含义：回归量 φ(k) 在 N 步里都”挤在一个方向”。若输入 u 是常数（如恒压 1.0），系统稳定后 y 也恒定，φ = [c₁, c₂] 全共线 → det → 0 → 参数不可辨识。

持续激励（PE）：输入谱必须覆盖模型阶数对应的频率。

工程上常用方波、PRBS、扫频正弦。demo 用 ±1.0 方波（cpp L33）——直流 + 丰富谐波，最简单也最有效。

持续激励的谱解释（为什么”频率覆盖”必要）

工程洞察：PE 条件的本质 = L1.1 的”x 要有散布”在时序系统里的推广——参数可辨识性由”激励的能量分布”决定，不是”数据量”。30 秒的常值输入永远辨识不出动态参数，1 秒的方波就够——激励设计是辨识实验的核心（control_demo 的阶跃响应辨识就是最简 PE）。

四、demo 设定

  • 真值 a = -0.8, b = 0.5；N = 200 步；噪声 σ = 0.02。
  • 输入 u(k) = ±1.0 方波（周期 40 步），L33 (k/20) % 2 == 0 ? 1 : -1。
  • 从 k > 1 开始采样 φ（首两步无历史值）。
  • 检查：① 参数辨识误差 < 0.02；② 最大残差与噪声同级（< 0.08，约 4σ）。

六、你会看到什么

参数估计误差典型值 ~4e-3（噪声 σ=0.02 的 1/5 量级，N=200 步平均）。残差最大值 ~0.06 ≈ 3σ——3σ 内的极值在 N=200 上是预期的。换种子时数值略异但都满足容限。

七、自检

  • 把输入从方波改成常数 u(k) = 1.0，看 det = Σy²·Σu² − (Σyu)² 是否趋向 0、参数估计发散（验证持续激励的必要性）。
  • 思考：为什么 ARX 把输出 y 也当回归量而不只是 u？（自回归 a·y(k−1) 表达系统的”自由响应”——只有 u 不够，否则只能辨识 b 不能辨识 a。）
  • 把模型阶数提到 2（y(k) = a₁y(k−1) + a₂y(k−2) + b₁u(k−1) + b₂u(k−2) + e），法方程变 4×4，看 LS 是否仍能解（验证向高阶扩展的便利性）。
