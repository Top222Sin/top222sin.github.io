L4.4 视觉：仿射 DLT + RANSAC + 光流

一句话：图像配准与光流——DLT 把对应点对写成线性 LS、RANSAC 用最小点集抗外点、Lucas-Kanade 光流是窗口内 GN 最小化光度误差，三者都是 LS 在像素域的不同包装。

一、仿射变换 DLT

2D 仿射变换 6 参数 [a, b; c, d] + [e, f]：

x’ = a·x + b·y + e
y’ = c·x + d·y + f

每对对应点贡献 2 行约束。把 6 个未知排成向量 p = [a, b, c, d, e, f]ᵀ，单点的两条设计矩阵行：

row_xp = [x, y, 0, 0, 1, 0]， row_yp = [0, 0, x, y, 0, 1]

n 个点叠成 2n×6 的设计矩阵，法方程 AᵀA·p = Aᵀ·b（6×6 高斯消元一步解）。DLT 名字来自 Direct Linear Transform——把几何变换参数线性化进 LS。

二、RANSAC：抗外点的 LS

外点（误匹配）会让普通 LS 偏离。RANSAC 三步：

  1. 随机抽最小点集（仿射 = 3 对不共线点）拟合模型；
  2. 用全部数据评估模型，统计内点（残差 < 阈）；
  3. 重复 N 次，保留内点最多的模型。

理论上 50% 外点率下，60 次抽样命中纯内点集的概率 > 99%。3 个内点拟合的仿射矩阵误差几乎为零（cpp 第 91 行 rerr < 0.05）。

三、Lucas-Kanade 1D 光流

亮度恒定假设：I(x, t+dt) = I(x−dx, t)。一维位移 dx 使”扭曲模板”匹配当前帧：

残差 r(x) = I_current(x) − I_warped(x, dx) = I(x, dx_true) − I(x, dx)

最小化 Σ r²，GN 迭代（∂r/∂dx = −∂I/∂x ≡ Ix）：

δdx = Σ Ix·r / Σ Ix²， dx ← dx + δdx

⚠ 开发踩过的坑：残差方向是 当前帧 − 扭曲模板（cpp 第 102 行 r=I(x,dx_true)-I(x,dx)），别放反——放反就变成在原始模板空间优化，方向相反。

四、代码走读（ls_l4_vision.cpp）

  • **solve6**（第 18–27 行）：6×6 高斯消元 + 回代，DLT 的法方程求解器。
  • 真值：At[6]={1.1, 0.1, 0.2, 0.9, 5.0, -3.0}（第 35 行）。
  • DLT（30 点带噪）（第 37–54 行）
    • 30 个随机点 (x,y)∈[0,10]²，应用 At 后加噪声 σ=0.03（第 39–42 行）。
    • 设计矩阵：{x,y,0,0,1,0} 给 xp、{0,0,x,y,0,1} 给 yp（第 43–44 行）。
    • 法方程 A6[a][b2] += rows[i][a]*rows[i][b2]; b6[a] += rows[i][a]*ys[i]（第 47–48 行）。
    • solve6 解出 6 参数，误差 max|a−At| < 0.02（第 52–53 行）。
  • RANSAC（30 点 50% 外点）（第 56–92 行）
    • 30 个对应点，每个 50% 概率被打成外点（加 ±5 随机扰动，第 62 行）。
    • 60 次抽样，每次 3 个不同点拟合仿射矩阵（第 66–79 行）。
    • 残差阈值 ex²+ey²<0.01（第 84 行），保留 best_in 最大的模型。
    • 检查 rerr < 0.05 且 best_in ≥ 11（第 90–91 行）。
  • 1D LK 光流（第 94–109 行）
    • 真值位移 dx_true=0.7（第 95 行），灰度函数 I(x,dx)=sin(1.5(x−dx))+0.3cos(3.0(x−dx))（第 96 行）。
    • 21 像素窗口，GN 迭代 20 次（第 98–107 行）。
    • **残差 r = I(x,dx_true) − I(x,dx)**（第 102 行，注意方向）。
    • 梯度 Ix = −1.5cos(1.5(x−dx)) − 0.9sin(3.0(x−dx))（第 103 行，注意 dI/ddx 是负的）。
    • 更新 dx += Σ Ix·r / Σ Ix²（第 106 行），收敛到 |dx−0.7| < 0.02（第 108 行）。

五、你会看到什么

噪声由随机数生成，每次运行具体数值略有差异；RANSAC 内点数会随机略异（10~14 之间），但模型误差始终极小（纯内点拟合的代数必然），光流 GN 收敛值始终 < 1e-3。

六、自检

  • 把 DLT 改成单应（8 参数透视变换），设计矩阵行怎么写？需要多少个对应点？（提示：每点 2 行 9 未知，去掉一个齐次自由度 → 4 点）。
  • RANSAC 的 60 次抽样，外点率从 50% 涨到 80% 还够吗？计算需要的最小抽样次数（公式 log(1−p)/log(1−wⁿ)）。
  • 思考：光流为什么用 GN 而不是直接闭式解？（亮度方程非线性，线性化后逐步修正；窗口内多余约束使残差最小化，是 LS 不是解方程）。
