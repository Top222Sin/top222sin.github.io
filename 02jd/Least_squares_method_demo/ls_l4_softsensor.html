L4.3 软测量与预测性维护

一句话：工业大数据两件套——软测量用多元 LS 替代昂贵仪表，预测性维护用趋势拟合外推 RUL；两件套的共同地基是”特征归一化 + 线性 LS”。

一、软测量的多元线性回归

化工/炼厂里”产品质量”往往要实验室离线化验（几小时一个样），但温度 T、压力 P、流量 F 是实时可测的。把产品质量 y 建成辅助变量的线性模型：

y = β₀ + β₁·T̂ + β₂·P̂ + β₃·F̂ + ε， T̂=(T−350)/50、P̂=(P−1)/2、F̂=(F−10)/20

把 n 条历史样本叠成 X ∈ ℝ^{n×4}（含常数项）、y ∈ ℝⁿ，法方程一步解：

β = (XᵀX)⁻¹Xᵀy

⚠ 开发踩过的坑：温度裸值 350~400 会让 XᵀX 病态（行列式爆炸、κ 恶化），必须先归一化到 [0,1] 区间——这是 L1.3 病态 / L1.4 QR 动机在工程里的现身。

二、预测性维护：趋势拟合 + 外推

机械部件的振动 RMS、轴承磨损量随时间退化，常见二次型：

v(t) = c₀ + c₁·û + c₂·û² + ε， û = (t−t_mid)/t_mid

3 参数 LS 拟合后，外推到阈值 th 的时间点：

t_RUL = min{t > t_now : v(t) ≥ th} − t_now

⚠ 坑：阈值必须设在观测区间之外——否则 t_RUL < 0（已经过阈），拟合外推无意义（RUL 定义为未来剩余寿命）。cpp 第 85 行 while(...) t+=0.5 即线性搜索外推——**注意循环内必须每次重新计算归一化时间 û(t)**，否则 û 固定、循环只是走到上限，不是真外推。

⚠ 根转换（重要）：若拟合用的是归一化时间 û=(t−t_mid)/t_mid，二次方程 c₀+c₁û+c₂û²=th 求出的根是 û*，物理时间必须转换回 t* = t_mid·(1+û*)——不能直接把根当物理时间。demo 的 t*=(−c₁+√(c₁²−4c₀c₂))/(2c₂) 是 û 空间的根，转换后才是 RUL 真值（示例：v(t)=1+0.02t+1e-5t² 在 th=15 的正根约 t≈549h；demo 的 ~1010h 是从 t_now 起算的剩余寿命，两者定义不同需分清）。

三、demo 设定

  • 软测量（cpp 第 36–64 行）：真值 β={0.5, 2.0, −1.5, 0.8}，80 样本训练、30 样本验证，加噪 σ=0.05。预期 β_err < 0.05、预测 RMSE < 0.1。
  • 预测性维护（cpp 第 66–90 行）：50 个时序点 v(t)=0.02t+1+1e-5t²+噪声，阈值 th=15，归一化时间 û=(t−245)/245。预期 RUL_err < 50h。

四、代码走读（ls_l4_softsensor.cpp）

  • **solve4**（第 19–28 行）：4×4 高斯消元 + 回代，封装 LS 法方程求解器。
  • 软测量（第 36–64 行）
    • 真值 bt[4]（第 37 行），特征归一化 (t-350)/50, (p-1)/2, (f-10)/20（第 42 行）—— 这是抗病态的关键。
    • 法方程 XtA[a][b] += X[i][a]*X[i][b]; Xty[a] += X[i][a]*y[i]（第 47–48 行）。
    • solve4 解出 β（第 50 行），误差 max|β−bt|（第 52 行），tol 0.05。
    • 验证：30 个新样本预测 RMSE（第 54–63 行），tol 0.1。
  • 预测性维护（第 66–90 行）
    • 退化数据 ts, vs（第 70–71 行），归一化时间 (ts[i]-245)/245（第 74 行）。
    • 3 参数 Vandermonde 法方程 r[3]={1,u,u*u}（第 75 行），累加 + 消元（第 76–82 行）。
    • 外推 RUL：while(c0+c1*û+c2*û²<th && t<2000) t+=0.5（第 85 行）。
    • 真值 RUL 用二次方程求根公式（第 87–88 行）：t* = (−c₁+√(c₁²−4c₀c₂)) / (2c₂)。

五、你会看到什么

噪声由随机数生成，每次运行具体数值略有差异；RUL 外推因二次项放大噪声，预测误差随机略异（但始终 < 50h 容差），β 始终 < 0.05。

六、自检

  • 把特征归一化去掉（直接用裸 350~400 的温度），看 XᵀA 行列式变成什么量级？β 误差恶化多少？
  • 阈值 th 改到 5（小于观测区间内的最大值），看 RUL 预测是否变成负数？为什么”外推”前提是阈值在区间外？
  • 思考：如果退化曲线是指数 v = e^{αt}，怎么把它线性化（提示：log v = αt）再做 LS？
