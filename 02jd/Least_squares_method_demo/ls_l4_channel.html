L4.2 通信：信道估计 + LMS + 波束成形

一句话：三个同源镜头——OFDM 导频 LS 是频域一次性解、LMS 是 LS 的随机梯度在线版、MVDR 是带方向约束的加权 LS（等价 Wiener 滤波）。

一、OFDM 导频 LS 信道估计

OFDM 把宽带信道切成 N 个正交子载波，每子载波 Y[k] = H[k]·X[k] + W[k]。导频位置 k ∈ 𝒫 已知 X[k]，直接除：

Ĥ[k_p] = Y[k_p] / X[k_p]， k_p ∈ 𝒫

这是 LS 在频域的退化（每个导频一个一元方程）。非导频位置线性插值：

Ĥ[k] = (1−t)·Ĥ[k_p] + t·Ĥ[k_{p+1}]， t = (k−k_p)/(k_{p+1}−k_p)

8 个导频覆盖 64 子载波（cpp 第 37 行 pilot[i]=i*(N/Np)），等距插值（第 41–45 行）。

二、LMS：LS 的随机梯度在线版

Wiener 解 w* = R⁻¹p（R 自相关、p 互相关）是离线 LS 的总体最优。LMS 用瞬时梯度代替期望梯度：

迭代：w_{n+1} = w_n + μ·e_n·u_n， e_n = d_n − w_nᵀu_n

μ 步长小 → 收敛慢但稳；大 → 快但抖。2000 步后 w 收敛到 Wiener 解附近（误差 < 0.08）。这是把 min E[‖d−wᵀu‖²] 拆成”每来一个样本就梯度降一步”的在线 LS。

三、MVDR 波束成形

M 元阵列，期望方向 a(θ₀)、干扰方向 a(θ₁)。MVDR 在”期望方向增益恒为 1”约束下最小化输出功率：

min wᴴRw s.t. wᴴa₀ = 1

Lagrange 展开，闭式解：

w = R⁻¹a₀ / (a₀ᴴR⁻¹a₀)

验证时阵列增益 = wᴴa（注意是共轭转置，cpp 第 95 行 conj(wv[i])*a0[i]）：期望向 g₀ ≈ 1、干扰向 g₁ ≈ 0（零深）。

⚠ 开发踩过的坑：增益要取 wᴴa 不是 wᵀa，复信号必须共轭。

四、代码走读（ls_l4_channel.cpp）

  • OFDM LS 估计（第 27–53 行）
    • 3 径信道 h = {1.0, 0.5·e^{j0.3}, 0.2·e^{-j1.1}}（第 29 行），H(k) 由 3 径 DFT 算（第 30 行）。
    • BPSK 调制 X[k] = ±1（第 32 行），噪声 σ=√(0.5/20)（第 33 行）。
    • 8 导频位置等距（第 36–37 行），LS 除法 Hp[i]=Y[pilot[i]]/X[pilot[i]]（第 39 行）。
    • 线性插值填满 64 子载波（第 41–45 行），最后一段延拓。
    • 误码对比：Y[k]/Hest[k] 判决 vs 直接 Y[k] 判决（第 47–51 行）。
  • LMS（第 55–66 行）
    • 真值 wt={0.8,−0.4,0.2}，μ=0.05（第 56 行）。
    • 2000 步迭代 w[i] += μ·e·u[i]（第 57–63 行）。
    • 误差 max|w−wt| < 0.08（第 64–65 行）。
  • MVDR（第 68–99 行）
    • 4 元均匀线阵，d=0.5λ（第 69 行），期望 30°、干扰 −20°（第 72 行）。
    • 协方差 R += x·xᴴ 累加 2000 样本再平均（第 74–80 行）。
    • 复矩阵高斯消元解 R·Ra = a₀，得 Ra = R⁻¹a₀（第 82–90 行）。
    • den = a₀ᴴ·Ra（第 91 行），w = Ra/den（第 93 行）。
    • 增益 g₀ = wᴴa₀ ≈ 1，g₁ = wᴴa₁ ≈ 0（第 94–96 行），tol 1e-3 / 0.15。

五、你会看到什么

噪声由随机数生成，每次运行具体数值略有差异；LMS 收敛值、误码数会随机略异，但增益约束 g₀=1 由 w=R⁻¹a/(aᴴR⁻¹a) 代数保证（代数恒等），干扰零深始终 < 0.15。

六、自检

  • 把 OFDM 导频数从 8 降到 4，误码会变差多少？为什么”奈奎斯特采样”在频域同样适用（导频间距 ≤ 相干带宽）。
  • LMS 步长 μ 调到 0.5 会发生什么？（发散 / 抖动 / 收敛过冲）。
  • MVDR 的 R 如果是单位阵（无干扰），w 退化成什么？提示：R⁻¹=I ⇒ w = a/(aᴴa)，即常规延时叠加波束形成。
