L1.2 加权最小二乘（WLS）与高斯-马尔可夫定理

一句话：数据精度不一时，按 1/σ² 加权让准的数据多说话——这就是 WLS；高斯-马尔可夫定理保证它是线性无偏估计中方差最小的（BLUE）。

一、为什么需要加权

L1.1 的 OLS 假设各观测等方差、不相关（同 σ²）。若各点噪声方差不同（异方差 σᵢ），等权 OLS 不再最优——噪声大的点应少信、噪声小的点应多信。WLS 取权重 wᵢ = 1/σᵢ²：

min Σᵢ wᵢ (aᵢᵀx − bᵢ)² = min ‖W^{1/2}(Ax − b)‖²

其中 W = diag(1/σᵢ²) = R⁻¹（R 是观测噪声协方差）。加权后的法方程：

AᵀWA x = AᵀW b

二、高斯-马尔可夫定理

若噪声零均值、不相关、方差 σᵢ²，则：

  • OLS 在等方差时是 BLUE（Best Linear Unbiased Estimator，线性无偏最小方差）；
  • 异方差时 WLS 才是 BLUE——OLS 此时仍然无偏（在 E[ε|A]=0 或零均值条件下），但方差不是最小（不再 BLUE），标准误估计也需修正。

⚠ 统计纠错：异方差不破坏 OLS 的无偏性——无偏只需要零均值条件，与方差结构无关。异方差影响的是效率（方差非最小）和标准误估计。所以准确说法是”OLS 仍无偏但非 BLUE”，不是”OLS 有偏”。

参数协方差（”理论精度”）：

Cov(x̂) = (AᵀR⁻¹A)⁻¹ = (AᵀWA)⁻¹ （W = R⁻¹ = diag(1/σᵢ²)，已含绝对方差）

若把权重写成”相对权重” W = R₀⁻¹（R = σ²R₀），则协方差为 σ²(AᵀWA)⁻¹——两种写法必须区分。本 demo 的 w = 1/σ(x)² 是绝对权重，理论 std 直接取 √((AᵀWA)⁻¹[0][0])，不再额外乘 σ。

demo 打印 std(a_wls) = √((AᵀWA)⁻¹[0][0])，与蒙特卡洛 50 次的样本散布对照。

高斯-马尔可夫定理的推导骨架（为什么 W 能保 BLUE）

核心洞察：BLUE 不是”猜的”——是”无偏约束下的最小方差”这一优化问题的解析解，而解恰好是 WLS（权重 = 噪声协方差逆）。W=R⁻¹ 不是习惯，是信息论最优：噪声小的观测（R 小）信息量大（R⁻¹ 大），权重自动放大。这就是”加权 = 信息滤波”（KF 视角）的统计源头。注意：BLUE 只依赖一、二阶矩条件，不需要高斯分布假设（高斯分布是 ML 的假设，BLUE 更弱）。若误差相关（R 非对角），应使用 GLS（广义最小二乘）而非 WLS。

三、直线拟合的加权法方程

直线 y = ax + b，权重 wᵢ = 1/σᵢ²。记 Sw = Σwᵢ, Swx = Σwᵢxᵢ, Swxx = Σwᵢxᵢ², Swxy = Σwᵢxᵢyᵢ, Swy = Σwᵢyᵢ：

det = Sw·Swxx − Swx²，a = (Sw·Swxy − Swx·Swy)/det。

四、代码走读（ls_l1_wls.cpp）

  • 异方差模型：σ(x) = 0.1 + 0.02x（x 越大噪声越大），w = 1/σ²（第 32 行）。
  • ① 预累加 Sw/Swx/Swxx（与数据无关，只依赖权函数）。
  • ② 蒙特卡洛 50 次：每次重新生成噪声数据，分别用 WLS 与 OLS 解 a，统计平均 |Δa|。
  • ③ 打印理论 std(a_wls) = √(Swxx/det)，对照实测散布。

五、你会看到什么

WLS 与 OLS 的差距随异方差程度增大；σ 恒定时两者重合（退化为 L1.1）。

六、自检

  • 把 σ 改成常数（等方差），验证 WLS 解与 OLS 逐位一致。
  • 思考：为什么 W = R⁻¹？KF 的 R⁻¹、BA 的信息矩阵 Ω = HᵀR⁻¹H 都是这一族——加权 LS = 信息滤波器视角。
  • 把某个点的 σ 调极小（近乎无噪），看它是否”独裁”整个拟合（权重趋于无穷）。
