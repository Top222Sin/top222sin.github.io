L3.1 工业用例：传感器线性标定

一句话：传感器输出 y 与被测量 x 的线性关系 y = ax + b 出厂都是未知的——用一组已知点采样，LS 反演出 (a, b)，之后才能用 x̂ = (y − b)/a 把读数还原成物理量。这是整个学习链里最小、最常见、也最不能省的”标定 Hello World”。

一、问题与法方程

传感器输入输出建模为线性：

y = a·x + b + ε，ε ~ N(0, σ²)

取 n 个已知标定点 (xᵢ, yᵢ)，A = [xᵢ, 1]（n×2），b = [yᵢ]。LS 解满足法方程（L1.1）：

行列式 det = n·Σxᵢ² − (Σxᵢ)²，闭式解：

â = (n·Σxᵢyᵢ − Σxᵢ·Σyᵢ) / det， b̂ = (Σxᵢ²·Σyᵢ − Σxᵢ·Σxᵢyᵢ) / det

得到 (â, b̂) 后，反演公式把后续读数 y 还原成物理量：

x̂ = (y − b̂) / â

未标定（拍脑袋给增益 a=0.02）的反演 x̃ = y/0.02 把零飘 b 和增益误差全压进结果——本篇 demo 量化这一差距。

⚠ 噪声模型注记：本 demo 的”线性标定 + LS 反演”假设x 精确、只有 y 有噪（OLS 场景）。若标定基准 x 本身有测量噪声（如恒温槽温度不准），斜率会被系统性衰减（回归稀释）——那是 TLS 的场景（L2.6）。传感器标定通常 x 是”已知标准”（可认为精确），OLS 够用；若标准不可靠则上 TLS。

二、工程背景：为什么标定绕不开

  • ADC、热电偶、压力计、电子秤、霍尔电流计……输出经放大/ADC 后都带零飘 b 与刻度系数 a，且随温度、老化、批次漂移。
  • 工厂出货前用一组已知激励（恒温槽/标准砝码/基准电压）扫一遍，LS 算出 (a, b) 写进 EEPROM。
  • 非线性强的（相机、IMU）走 cali_demo 的 BA；线性范围里，这一篇就够了。
  • 多次重复标定取平均：噪声是零均值，N 次平均把 σ 压成 σ/√N——这是 demo 里”16 次平均”的动机。

三、demo 设定

  • 真值 a_true = 0.0185、b_true = -0.42（量纲：ADC/°C）；7 个标定温度 T = {0, 10, 25, 40, 60, 80, 100}°C；读数噪声 σ = 0.02。
  • 16 次独立标定取平均（每次重置随机种子 → 16 组独立噪声实现），看参数偏差是否 < 8e-3。
  • 反演测试：30 个随机温度 T ∈ [0, 100]，比较标定反演 T_cal = (adc − b̂)/â 与未标定 T_naive = adc/0.02 的 RMSE。

四、代码走读（ls_l3_calib.cpp）

  • L13–18：urand/gauss——LCG + Box-Muller，固定种子可复现。
  • L28–29：真值与标定点表 Ts[7]。
  • L30–42：16 次标定循环——每次 set_seed(1200+m)（L33）重置噪声；内层 7 点累加 Sx/Sy/Sxx/Sxy（L34–37），L39 算 det，L40–41 套闭式解并累加到 pa/pb。
  • L43：pa/=M; pb/=M; —— 平均 16 次估计，σ/√16 把噪声方差压到 1/16。
  • L45：chk 标定参数偏差 < 8e-3。
  • L46–60：反演 RMSE 对比——L47 切到独立种子 set_seed(777)（不与标定样本同分布）；L50–52 生成随机温度的 ADC 读数，并算 T_cal vs T_naive；L53 用 adc/0.02 模拟”拍脑袋增益”。
  • L60：检查 T_cal 的 RMSE 比 T_naive 至少小 10 倍（写法 err<0.1·RMSE_naive ? 0 : 1）。
  • L61–62：[结论] 强调”多点+LS 抗噪”是所有出厂标定的公共内核。

五、你会看到什么

噪声由 LCG 生成、种子固定 → 同机可复现；跨机或换编译器浮点顺序略异。16 次平均把单次参数偏差 ~2e-2 压到 ~5e-3（≈ 2e-2/√16）。反演 RMSE：标定 ~1°C 来自噪声 σ/â ≈ 0.02/0.0185；未标定 ~25°C 因为增益偏差 ~10% × 满量程 100°C。

六、自检

  • 把标定次数从 16 降到 1，看参数偏差是否回到 ~2e-2（验证 σ/√N 规律）。
  • 思考：为什么 7 个标定点要尽量均匀铺满量程而不是扎堆在一端？（AᵀA 的 det = n·Σx² − (Σx)² 在共线/聚簇时趋向 0 → 岭回归/条件数问题的雏形，见 L1.3/L1.4。）
  • 把 T_naive = adc/0.02 改成 adc/0.0185（增益对了零飘没补），看 RMSE 还剩多少——量化”零飘 b”独立于”增益 a”的影响。
