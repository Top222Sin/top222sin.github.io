L1.1 线性最小二乘：法方程与几何

一句话：最小二乘 = 把 b 正交投影到 A 的列空间——残差最短必垂直于列空间，”垂直”的代数写法就是法方程 AᵀAx = Aᵀb。

一、问题与法方程

给定超定方程 Ax ≈ b（A∈ℝ^{m×n}, m>n），一般无精确解。最小二乘找 x̂ 使残差 r = b − Ax 的 2-范数最小：

min ‖r‖² = min ‖b − Ax‖²

对 x 求梯度令其为零：

∇ₓ ½‖b − Ax‖² = −Aᵀ(b − Ax) = −Aᵀr = 0 ⇒ AᵀAx = Aᵀb

这就是法方程（normal equation）。它的几何来源：最优解让残差 r = b − Ax̂ 垂直于 A 的列空间——Aᵀr = 0 即”残差与 A 的每一列正交”。

法方程的推导链（为什么梯度是 −Aᵀr）

核心洞察：法方程不是”硬凑的算法”，是”残差最短”这一几何目标的一阶必要条件——Aᵀr=0 是说”残差和列空间正交”，正交即最短（勾股定理）。这也是为什么 LS 的解是线性闭式的（不用迭代）：二次型的最小值点由梯度为零直接给出。

二、几何解释：正交投影

把 A 的列空间记作 col(A)。LS 解 Ax̂ 是 b 在 col(A) 上的正交投影：

  • b = Ax̂ + r，其中 Ax̂ ∈ col(A)、r ⊥ col(A)
  • 投影矩阵 P = A(AᵀA)⁻¹Aᵀ，Ax̂ = Pb
  • 残差 r = (I−P)b，‖r‖ 是 b 到 col(A) 的最短距离

“LS 是正交投影”这一句话是后续 WLS / 岭 / QR / TLS 全部变体的公共地基。

投影矩阵的性质（为什么 P 是”投影”）

工程直觉：P 是”把任意向量拍扁到 A 列空间”的算子——一次投影就是”数据 → 模型空间”的最优映射。Ax̂ = Pb 说明 LS 解本质是数据在模型空间的正投影，与具体坐标无关（几何不变量）。这就是为什么换基/加权/正则化都只是”换投影的方向”，内核不变。

三、直线拟合：2×2 法方程手写

直线 y = ax + b 拟合 n 个点 (xᵢ, yᵢ)：A = [xᵢ, 1]（n×2），b = [yᵢ]。法方程 2×2：

行列式 det = n·Σxᵢ² − (Σxᵢ)²，闭式解：

a = (n·Σxᵢyᵢ − Σxᵢ·Σyᵢ) / det， b = (Σxᵢ²·Σyᵢ − Σxᵢ·Σxᵢyᵢ) / det

为什么 det = n·Σx² − (Σx)² 会退化（为 L1.3 埋伏笔）

工程洞察：拟合的稳定性由x 的散布（方差）决定，不是点数——10 个分散的点比 100 个挤在一起的点估计更准。这直接引出 L1.3 岭回归（det 病态时加 λI）和 L1.4 QR（不平方条件数）。标定/实验设计”布点要铺满量程”的数学原因就在这里。

四、代码走读（ls_l1_normal.cpp）

  • gauss()：确定性 LCG + Box-Muller，可复现。
  • 主流程：n=40 个点，真值 y = 2x + 1，噪声 σ=0.3。
  • ① 累加 Sx/Sy/Sxx/Sxy，套上面的 2×2 闭式解（第 50–52 行）。
  • ② 验证残差正交 Aᵀr = 0（第 54–59 行：Σxᵢrᵢ ≈ 0、Σrᵢ ≈ 0，tol 1e-10）。
  • ③ 参数接近真值（|a−2|, |b−1| < 0.15）。

五、你会看到什么

噪声由随机数生成，每次运行具体数值略有差异；但 Aᵀr 始终 < 1e-10（法方程的代数必然），参数始终在真值附近。

六、工程落点（真实项目）

  • Eigen A.colPivHouseholderQr().solve(b) / A.bdcSvd().solve(b)：生产代码从不显式构造 (AᵀA)⁻¹——法方程只出现在推导和 2×2 手算里，实际求解用 QR/SVD（L1.4 的条件数灾难是原因）。
  • **OpenCV cv::solve(A, b, x, DECOMP_SVD)**：标定/拟合的通用解（cali_demo 内部大量使用）。
  • **numpy np.linalg.lstsq**：默认 SVD 求解——“最小二乘”一词在库里的默认实现就是投影。
  • 统计软件 R/SPSS 的 lm()：输出里 t-value/p-value 全来自 Cov(x̂) = σ²(AᵀA)⁻¹（法方程的统计角色——本篇只讲几何，WLS 篇讲协方差）。
  • 与 08robot：UR5e 的关节角→笛卡尔映射的线性化拟合、相机标定的 DLT 初值，全是法方程的直接应用。

七、自检

  • 把噪声 σ 调大 10 倍，看拟合参数是否仍在真值附近（无偏性）、但波动变大。
  • 思考：为什么 m = n（恰定）时法方程退化为 AᵀAx = Aᵀb ⇒ x = A⁻¹b（无残差）？投影变成恒等。
  • 把 A 的两列改成线性相关（共线），法方程 AᵀA 奇异 → 无唯一解（对应 L1.3 病态、L1.4 QR 的动机）。
