L1.3 岭回归与正则化

一句话：AᵀA 病态时，加一个 λI 救场——(AᵀA+λI)x = Aᵀb。代价是引入一点偏差，换来数值稳定性；三种视角（条件数 / 贝叶斯先验 / L2 正则）是同一件事的三个名字。

一、病态的危害

L1.1 的法方程 AᵀAx = Aᵀb 在 AᵀA 病态（条件数 κ(AᵀA) = κ(A)² 极大）时灾难性失稳——输入微小扰动，解剧烈跳变。经典病态矩阵 Hilbert 矩阵 Hᵢⱼ = 1/(i+j+1)：7 阶 Hilbert 条件数 ~1e8，即便无噪声，法方程解也爆炸。

二、岭回归

给 AᵀA 加一个对角扰动 λI：

(AᵀA + λI) x = Aᵀb

  • λ→0 退化为 OLS；
  • λ 适度 → 压制 AᵀA 的最小特征值方向，解稳定但轻微有偏（偏差-方差权衡）；
  • λ 过大 → 欠拟合（解趋于 0）。

三、三个视角（同一件事）

视角 解释
数值 AᵀA 的最小特征值被 λ 抬高，条件数 κ(AᵀA+λI) 下降 → 数值稳定
统计（贝叶斯） 等价于先验 x ~ N(0, σ²/λ · I)——λ 越大先验越紧（相信”参数小”）
机器学习 L2 正则 = 权重衰减：min ‖Ax−b‖² + λ‖x‖²（λ↑ 欠拟合，λ↓ 过拟合）

贝叶斯视角的推导（为什么岭 = 高斯先验）

核心洞察：三个视角是同一个二次目标的三个解释——数值（特征值抬升）、统计（先验收缩）、ML（权重衰减）。工程意义：λ 不是玄学，是”先验强度”（统计）或”正则强度”（ML）——λ 的选择 = 偏差-方差权衡。注意：经典 L-curve 是 log‖Ax−b‖ vs log‖x‖ 曲线（找拐点定 λ），不是”误差 vs λ”——后者需要真值/验证集，两者别混。实践中 λ 选择常用交叉验证/GCV 或 L-curve；固定 λ=1e-7 只对本例有效，不具一般性。这也解释了为什么”岭解是有偏的”：先验把参数往 0 拉，偏差换来方差减小。

四、demo：Hilbert-7 无噪声还原

真值 x = [1,1,…,1]，b = H·x（无噪声）。比较 LS 与岭(λ=1e-7)：

  • LS：误差 ~12（爆炸，系数范数 ~17，剧烈振荡）
  • 岭 λ=1e-7：误差 ~0.012（四个数量级改善，系数范数 ~2.6）

六、你会看到什么

这些数值经 numpy 独立复算确认（LS=11.58、岭=0.01204），非占位符。

七、自检

  • 把 λ 从 1e-7 调到 1e-3、1、100，画出”误差 vs λ”曲线，找最优 λ（L 曲线法）。
  • 思考：为什么 λ 不能太大？（偏差主导，解趋于 0 → 欠拟合）。
  • 比较 L1.4 的 QR：QR 不加正则就能稳到 6e-4（只 κ(A) 不 κ(A)²）——什么时候用岭、什么时候用 QR？

八、下一步

进入 L1.4 QR 分解与数值稳定性——不碰法方程，直接 x = R⁻¹Qᵀb，条件数只 κ(A) 不 κ(A)²。

兄弟仓库联系
