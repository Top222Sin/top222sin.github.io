L4.5 自动驾驶：ICP + 车道线 + 滑窗

一句话：三个标配镜头——ICP 用 Kabsch 一步求 R,t；车道线用归一化 Vandermonde 三次拟合；滑窗 LS 是视觉里程计的最小内核。L4 在此收官。

一、2D ICP 与 Kabsch 公式

点云配准：把 src 旋转平移到 ref，最近点对应已知时一步 LS 闭式解。去质心后求 2×2 协方差：

sxx = Σ aₓ·bₓ， sxy = Σ aₓ·b_y， syx = Σ a_y·bₓ， syy = Σ a_y·b_y

（a=src−质心_src，b=ref−质心_ref）

2D 旋转角闭式解（Kabsch 推导）：

θ = atan2(sxy − syx, sxx + syy) ← 从 a(src) 到 b(ref) 的旋转角

⚠ 方向约定（重要，开发踩过）：atan2(sxy−syx, sxx+syy) 给出 src→ref 的旋转；atan2(syx−sxy, sxx+syy) 是反向（ref→src）。数据生成必须与求解方向一致：若真值定义为 src = R·ref + t（把 ref 变到 src），那求解的应是 ref→src 的旋转（约 −θ 而非 +θ）——本 demo 的 icp_step 用 a=src、b=ref 求 src→ref，则数据生成应写 src = R⁻¹·(ref−t) 或对 +0.3 结果取逆。**凡 ICP 都要先画坐标链、统一”谁是源谁是目标”**，否则配准方向反了直接发散。

平移 t = 质心_ref − R·质心_src，整个 icp_step 函数（cpp 第 34–51 行）就是去质心 + 旋转 + 平移三步。

注意：真实 ICP 的”最近点对应”是离散匹配步骤（NN 搜索），Kabsch 是固定对应下的闭式 Procrustes 子问题——两者交替迭代才是完整 ICP。本 demo 只演示 Kabsch 子步（对应已知），与”GN 的非线性对应版”是启发性类比而非严格等价。

二、车道线三次拟合

车道线在图像平面或车体坐标下是缓变曲线，三次多项式够用：

y = c₀ + c₁·x + c₂·x² + c₃·x³

x 范围 0~80（40 个点，每点间距 2），裸 Vandermonde 让 AᵀA 病态（行 1, x, x², x³ 量级跨度 1 ~ 5×10⁵）。归一化：

û = x / 40

设计矩阵行 [1, û, û², û³]，4×4 法方程解出 a，反归一化：

c₀ = a₀， c₁ = a₁/40， c₂ = a₂/40²， c₃ = a₃/40³

（cpp 第 80 行 aa[1]/40, aa[2]/1600, aa[3]/64000）。

三、滑窗 LS 降噪

时序信号 sig[i] = 真值 + 噪声，模型假设”局部窗口内信号为常值”——窗口内 9 点均值（1D LS 闭式解）：

μ_i = (1/9) Σ_{j=i−4}^{i+4} sig[j]

降噪比 = 1 − MSE_sw / MSE_pt，cpp 第 100 行 tol e2sw < 0.6·e2pt。这是滑动窗口优化（VIO / 视觉里程计内核）的最简版本——把”窗口内残差联合 LS”的思想退化成局部常值。

四、代码走读（ls_l4_autodrive.cpp）

  • ICP（第 24–58 行）
    • 真值 θ=0.3 rad、t=(1.5, −0.8)（第 25–26 行）。
    • 60 个参考点 ref（高斯随机），src = R·ref + t + 噪声 σ=0.02（第 30–32 行）。
    • icp_step 闭包（第 34–51 行）：
      • 质心计算（第 37–38 行）；
      • 协方差 sxx/sxy/syx/syy（第 39–43 行）；
      • Kabsch 角度 theta=atan2(sxy-syx, sxx+syy)（第 44 行）；
      • 应用 R、t（第 46–50 行）。
    • 调用两次（第 52 行 icp_step(src); icp_step(src);），一步收敛 + 二步精修。
    • 最大点距残差 < 0.08（第 55–57 行）。
  • 车道线（第 60–85 行）
    • 真值 ct[4]={0, 0, 0.15, -0.008}（第 62 行），40 点 ×2 间距，噪声 σ=0.3。
    • 归一化 u=x/40（第 68 行），Vandermonde 行 r[4]={1,u,u*u,u*u*u}（第 69 行）。
    • 4×4 法方程累加 + 高斯消元（第 70–77 行）。
    • 反归一化 c_est[4]={aa[0], aa[1]/40, aa[2]/1600, aa[3]/64000}（第 80 行）。
    • 误差 max|c_est − ct| < 0.15（第 82–83 行）。
  • 滑窗 LS（第 87–101 行）
    • 100 点信号 sig[i] = 2.0 + 0.01·i + 噪声 σ=0.3（第 90 行）。
    • 单点误差 e2_pt vs 滑窗均值误差 e2_sw（第 91–98 行），窗口 9 点。
    • 检查 e2_sw < 0.6·e2_pt（第 100 行），降噪比 100·(1−e2_sw/e2_pt)（第 101 行）。

五、你会看到什么

噪声由随机数生成，每次运行具体数值略有差异；ICP 在最近点对应已知假设下一次收敛，但噪声 σ=0.02 让残差始终有 0.03 量级，滑窗降噪比 ~88%94% 之间随机略异。

六、自检

  • 把 Kabsch 公式改成 atan2(syx−sxy, sxx+syy)（方向反），看 ICP 是收敛还是发散？两次迭代后点距变大还是变小？
  • 思考：为什么 ICP 在”最近点对应已知”时一步收敛，而真实 ICP（对应未知）需要”找最近邻 + Kabsch”交替？后者是不是 GN 的对应版？
  • 把车道线 Vandermonde 不归一化（直接用 1, x, x², x³），看法方程条件数恶化多少？三次系数 c₃ 的误差膨胀多少倍？
