L3.4 capstone：LS 大一统（全链收官）⭐⭐

一句话：从静态 LS → 加权 → 岭 → 递推 → 非线性——五步走完一条主线，背后是同一套法方程 AᵀAx = Aᵀb 的变体。本篇用五个”代表镜头”实跑两个、指回三个，把 cali / KF / control / Jacobian 全部接回同一张地图，是整个仓库的收官章。

一、五镜头地图

整个学习链可以用”LS 在每一站换了什么”串起来：

镜头 公式 出场篇 新增什么
① 静态 LS x̂ = (AᵀA)⁻¹Aᵀb L1.1 投影 / 法方程
② 三角化（多视线交点） A 是视线垂直约束 cali/Jacobian BA 内核 多约束叠加
③ GN 非线性定位 Δ = −(JᵀJ)⁻¹Jᵀr KF L3.2 / L1.5 线性化 + 迭代
④ ARX 辨识 θ̂ = (ΦᵀΦ)⁻¹ΦᵀY control L3.4 时序回归量
⑤ RLS = KF(q→0) θₖ = θₖ₋₁ + K(y−ŷ) KF L1.1 递推 / 贝叶斯

本质一句话：加权 (W)、正则 (λI)、递推 (RLS)、非线性 (GN) 都是同一套法方程的不同手术——把数据投影到参数空间的几何内核没变。

二、为什么本篇是 ⭐⭐

  • 它是唯一一篇显式跨级（L1/L2/L3）的总结章：前面每篇只解决一个变体，本篇证明它们是同一棵树。
  • 后续 L4（自动驾驶融合）和兄弟仓库（cali/KF/control/Jacobian）都把这一篇当公共地基——丢掉任何一站的 LS 模块，整条链都断。
  • 实跑 ①② 让你亲手验证 capstone 不是 PPT——同样的 2×2 法方程代码同时解”直线拟合”和”三角化”两个看似无关的问题。

三、demo 设定

  • ① 直线拟合：30 点，真值 y = 0.7x + 0.3，σ = 0.1；2×2 法方程闭式解。
  • ② 三角化：两个相机中心 c1=(0,0), c2=(10,0)，真值点 p=(5,4)；两条视线方向加 σ=0.05 噪声；每条视线提供一个垂直约束 uᵀX = uᵀc，两约束堆成 2×2 系统。
  • ③④⑤ 指回 L3.2 GPS / L3.3 ARX / L2.4 RLS 的 PASS 记录——不再重复跑，引用即可。

四、代码走读（ls_l3_capstone.cpp）

  • L16–20：urand/gauss，种子 15 固定。
  • L30–42：① 直线拟合——
    • L33–37：n=30，x = i·0.1，y = 0.7x + 0.3 + gauss()*0.1，累加 Sx/Sy/Sxx/Sxy。
    • L38–39：det = n·Sxx − Sx²，闭式解 a, b（与 L1.1 公式一致）。
    • L40：chk ①直线拟合=LS，tol=0.1。
    • L41：printf ① 拟合 a, b。
  • L43–60：② 三角化——
    • L45–46：两相机中心与真值点。
    • L47–50：视线方向 d1, d2 = (pw − c) + gauss()*0.05，再 hypot 单位化（L49–50）。
    • L51–53：每条视线的垂直单位向量 u = (−d_y, d_x)；约束 uᵀX = uᵀc 堆成 A[2][2]、rhs[2]。
    • L54–56：2×2 行列式 + 闭式解 X0, X1。
    • L57：误差 err = hypot(X0−5, X1−4)。
    • L58：chk ②三角化=LS，tol=0.2。
    • L59：printf ② 三角化误差。
  • L61：chk ③GN定位 ④ARX辨识 ⑤RLS=KF (见各篇 PASS)——占位检查，err=0 + tol=0.5 必过，只是把五镜头完整性登记在测试输出里。
  • L62–64：[结论] 五步链路 + 兄弟仓库映射。

五、你会看到什么

① 拟合误差 ~3e-2：30 点噪声 σ=0.1，参数标准误约 σ/√(n·Var(x)) 量级。② 三角化误差 ~0.1 m：视线方向噪声 σ=0.05，被两个相机基线 10 m 放大成点位置噪声。噪声随机，每次略异。

六、自检

  • 把 ② 三角化的基线从 10 m 缩到 1 m（短基线），看误差是否放大多倍——这就是”短基线三角化病态”的几何来源。
  • 思考：① 用的是 Σx², Σxy，② 用的是视线垂直约束——它们怎么都是 2×2 法方程？（因为本质都是”把约束堆成 A，求 AᵀAx = Aᵀb 的投影”——投影与具体约束含义无关。）
  • 把 ③ GN / ④ ARX / ⑤ RLS 各自的 cpp 在本机跑一遍，确认三处都 PASS——capstone 是引用而非重跑，但你应该亲自验证被引用的 PASS 真的存在。

七、下一步

进入 L4.1 传感器校准：IMU 六面+磁力计椭球——从单变量线性标定走向多轴、多模态的 IMU 校准：六面加速度计 + 椭球拟合磁力计，把本篇的”LS 大一统”思想用到真实多传感器栈里。

兄弟仓库联系

cali BA = ② 三角化的多帧多视角扩展；KF = ⑤ RLS 加上过程噪声 Q>0；control 辨识 = ④ ARX 的频域与时域工程化；Jacobian 提供 ③ GN 步长与 ⑤ RLS 协方差更新的灵敏度工具。全学习链的公共地基——这就是 capstone 的意义。
