L4.7 子空间辨识：N4SID（斜投影）+ MOESP（正交投影）+ 状态空间 PEM

一句话：子空间辨识 = 用 Hankel 数据矩阵做”斜投影/正交投影”，直接从 I/O 数据里搬出状态空间模型 (A,B,C,D)，是工业系统辨识（L3.3 ARX/OE 类最小二乘辨识）的状态空间升级版——不再假设固定 ARX 结构，而是先估阶数 n、再估全状态矩阵。

一、问题定义与工业背景

L3.3 用 ARX（输入/输出回归）做辨识，本质是固定模型结构的最小二乘。L4.7 升级到状态空间辨识：

真系统（离散）： x[k+1] = A·x[k] + B·u[k]， y[k] = C·x[k] + D·u[k] + e[k]
目标：从 I/O 数据 {u[k], y[k]} 同时估出 阶数 n 与 **(A,B,C,D)**。

工业里这叫”黑箱/灰箱辨识”，是模型预测控制（MPC）、故障诊断、软测量（L4.3）的模型来源。两种主力算法：

  • N4SID（Numerical algorithms for Subspace State Space System ID）：斜投影，能直接恢复状态序列 X 并给出完整 (A,B,C,D)，是主力。
  • MOESP（Multivariable Output-Error State-sPace）：正交投影（LQ 紧致形式），擅长阶数判定，本篇用作”与 N4SID 一致确认同阶”的兄弟验证。

两者都由同一套 Hankel 数据矩阵驱动，是同一几何事实的两面——这正是本篇要讲的”跨域同构”中的”投影即子空间”。

二、Hankel 数据矩阵与”投影空间朝向”（关键坑）

把 I/O 数据排成块 Hankel 矩阵（块行 i=10 ≫ 2n，列 L=N-2i+1）：

⚠️ 工程坑（本篇第 3 次踩、必记）：投影必须在样本空间（L×d，L 为列数且 L>d）做。列空间只有 d 维（d=i·(m+l)），在信号空间（d×L）下投影会退化成单位阵，等于没投影。所有 P_Uf、Yf_perp、Wp_perp 都在转置后的样本空间构造（cpp 第 180–208 行 n4sid_oblique）。

三、N4SID（斜投影）

核心：把 Y_f 先去掉 U_f 的影响（列空间投影），再正交投到过去 [U_p;Y_p] 的剩余分量，得到

O = Γ_i · X （O 为 i·l × L，Γ_i 是扩展可观矩阵，X 是状态序列）

由 O·Oᵀ 的对称 SVD 取前 n 个左奇异向量得 Γ_i（奇异值谱直接判阶数 n）。然后：

  • C = Γ_i 的前 l 行（可观矩阵首块行就是 C）
  • A = pinv(Γ_top)·Γ_bot（移位不变性：后 l 块行 = 前 l 块行 × A）
  • 仅 B, D 由状态序列 LS 估：B = (X_next − A·X)·Uᵀ/(U·Uᵀ)，D 同理

关键设计：A、C 从 Γ_i 直接求得，保证移位不变性与可检测性；若像早期版本那样用 LS 重估 C，会破坏可检测性导致预测器发散（cpp 第 240–270 行 recover_ac/recover_bd）。

四、MOESP（正交投影 / LQ 紧致，阶数检测）

把 [U_p;Y_p;U_f;Y_f] 做 LQ 分解 W = L·Q（L 下三角 2d×2d），按标准 MOESP 分区成四个 d×d 块：

O_i = L22⁻¹ · L21 （未来块 vs 过去块；d=i·(m+l)）

O_i 的奇异值谱前 n 个主导、其余≈0 → 阶数 n。本篇用 pinv(L22)（当 L22 近奇异时自动低秩截断，比裸 inv 稳定——早期裸 inv 在部分数据量下会蹦出 1.7e4 的伪模态使阶数误判）。结果与 N4SID 判阶完全一致（cpp 第 210–238 行 moesp_lq）。

五、状态空间 PEM（预测误差方法）

以 N4SID 估计为初值 θ=vec(A,B,C,D)（9 参数），做一步预测误差最小化：

ε[k] = y[k] − Ĉ·x̂[k] − D̂·u[k]， x̂[k+1] = Â·x̂[k] + B̂·u[k] + K·ε[k]
其中稳态 Kalman 预测器增益 K 由离散代数 Riccati 方程解出：
K = P·Cᵀ·(C·P·Cᵀ+R)⁻¹， P = A·(P−K·C·P)·Aᵀ + q·I

Gauss-Newton 对 θ 精调（cpp 第 290–370 行 riccati/pred_crit + 主程序 GN 循环）。本篇实测：N4SID 一步预测 RMSE≈2σ（几乎等于新息地板），PEM 初值即已接近 GN 最优，精调不退化、与 N4SID 模型一致。

六、手写算法基础设施（纯 C++17 可移植）

本篇不依赖任何第三方库，全部手写：

  • svd_jacobi：单边 Jacobi SVD（U,S,Vt，用于 pinv 与 O·Oᵀ 特征值分解）
  • pinv：SVD 基伪逆（tol=1e-12，防奇异除零）
  • householder_qr_R：Householder QR → 上三角 R（验证 RᵀR=MᵀM）
  • matmul/transpose/ident：基础线性代数
  • riccati：离散代数 Riccati 迭代（DARE）
  • moesp_lq 的 LQ：经 QR(Mᵀ) 取 R 转置得到

七、代码走读（ls_l4_subspace_pem.cpp）

  • 工具层（第 20–145 行）：固定种子 LCG + Box-Muller（与受管 Python 验证脚本同种子，实例可复现）；svd_jacobi/pinv/householder_qr_R/is_upper_tri/eigabs2/eigM；真系统 sim_true；build_hankel。
  • n4sid_oblique（第 180–208）：样本空间斜投影 O=Γ_i·X。
  • moesp_lq（第 210–238）：标准 LQ 分区 O_i=L22⁻¹·L21，阶数检测。
  • recover_ac / recover_bd（第 240–270）：Γ_i 取前 n 左奇异向量；A=pinv(Γ_top)·Γ_bot；仅 LS 估 B,D。
  • riccati / predictor_err / sim_out（第 290–330）：稳态 Kalman 增益 + 一步预测误差 + 无噪 I/O 仿真。
  • flatten / unflatten / pred_crit（第 340–370）：参数向量化（B stride 用 mI，不是 n_est——早期误写 n_est 导致 B 串到 C 元素、PEM 爆炸）。
  • main（第 375+）：内部正确性（QR/SVD 3 项）→ N4SID（阶数/A稳定/一步预测RMSE/I-O）→ MOESP（谱/阶数/一致）→ PEM（准则下降/精调不退化/I-O/Riccati），共 16 项检查。

八、你会看到什么

本机 RNG 固定种子（与受管 Python 3.13.12 验证脚本逐位一致），上述数值为 C++ 端口的预期输出（C++ 控制流镜像脚本已 16/16 对拍通过，严格 matmul 无维度越界）。数学正确性由受管 Python 镜像逐条验证：QR 上三角/RᵀR=MᵀM/SVD重构 3 项 + N4SID 阶数·A稳定·一步预测RMSE·I-O + MOESP 谱·阶数·N4SID↔MOESP 一致 + PEM 准则下降·精调不退化·I-O一致·Riccati收敛，共 16 项 ALL CHECKS: PASS。

九、自检

  • 把 i_block 从 10 调到 6 或 14，阶数判定还准吗？为什么块行要 ≫ n？（提示：可观性需要足够”深”的 past）
  • unflatten 里 B 的 stride 为什么必须是 mI 而不是 n_est？写成 n_est 会让 PEM 的 V0 爆到多少量级？（提示：本篇早期 bug，V0 从 0.14 炸到 ~2e4）
  • 若把 recover_ac 改成”LS 重估 C”，预测器 A−KC 的特征根会怎样？为何要保可检测性？
  • MOESP 用 inv(L22) 在哪些数据量下会蹦出伪模态？pinv 如何救场？
