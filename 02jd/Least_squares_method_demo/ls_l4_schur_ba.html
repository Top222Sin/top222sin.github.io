L4.10 Schur 补 BA（矩阵块累加同构）

Bundle Adjustment（BA，光束法平差）是视觉 SLAM / SfM 的核心：在已知多相机位姿与多 3D 点的初值后，联合微调它们使所有”投影像素 vs 观测像素”的重投影残差平方和最小。它本质是一个超大规模非线性最小二乘，规模随相机数、点数线性增长。本项目用合成 BA（3 相机、8 点、固定相机 0 锚定坐标架）演示其法方程的块结构与 Schur 补边缘化 3D 点技巧，并点明其”逐项 JᵢᵀJᵢ 累加 ≡ JᵀJ“与 SME 的 ZA 外积累加、KF 因子图信息矩阵、普通 LS 的 XᵀX 是同一个数学同构（本仓库反复出现的主线）。

〇、为什么需要 Schur 补 BA（动机）

场景 BA 的角色
视觉 SLAM 一帧 三角化得到初值后，联合优化相机位姿 + 地图点（GN/LM）
SfM（运动恢复结构） 全局 BA 同时优化所有相机与外点，是精度天花板
机器人 MSCKF / VIO 滑窗 BA 边缘化旧点、保留相机状态
标定（cali_demo） 手眼 / 多相机 rig 的本质就是流形上的 BA

直接解 BA 的全量法方程 H δ = -Jᵀr 维数 = 6·N_cam + 3·N_point，当点数远大于相机数时 H 巨大且稠密。Schur 补（边缘化 3D 点）把系统**约化成只关于相机的低维系统 S δc = …**，再把点状态回代——既降维又保持等价，是 g2o / Ceres / GTSAM 的底层基石。

1.3 gauge（歧义）与锚定

BA 的代价对全局 7 自由度相似变换（3 旋转 + 3 平移 + 1 缩放）不变——所有相机和点同乘一个相似变换，重投影完全不变。这使 J 秩亏 7、H 奇异。本项目固定相机 0 的位姿（锚定坐标架）消除该歧义，使 H 满秩可逆（真实 BA 也这么做，通常再加一个参考帧/尺度约束）。

1.4 阻尼：Levenberg–Marquardt

近 gauge 方向曲率极小，H 病态，纯高斯-牛顿全步会严重过冲发散（本项目初版 δ 范数 ~14，是真实误差的 ~300 倍）。实际 BA 用 LM 阻尼：解 (H + λI) δ = −Jᵀr，λ 大时退化为梯度下降、λ 小时回到 GN，并用回溯保证每步代价下降。Schur 恒等式对阻尼系统同样成立（只需给 Hcc、Hpp 都加 λ）。

二、算法步骤

J 的解析结构（投影梯度 ∂π/∂Pc = [f/Z,0,−fX/Z²; 0,f/Z,−fY/Z²]）：

  • 对点 Xⱼ：∂r/∂X = [∂π/∂Pc]·R
  • 对平移 t_c：∂r/∂t = [∂π/∂Pc]
  • 对旋转 w_c：∂(RX)/∂w = −(RX)^×·J_r(w)（J_r 为 SO(3) 右雅可比）

三、与主线/兄弟仓库的关系

  • L1.5 / L2.2（GN/LM）：BA 就是流形上的 GN/LM；本节加的 λI 阻尼 = L2.2 的 LM。
  • L2.1（JᵀJ ≈ H）：BA 法方程的 H = JᵀJ 正是 L2.1 的 H ≈ JᵀJ。
  • L4.9（PCA/JᵀJ 累加）：H = Σ_i JᵢᵀJᵢ 与 PCA 的 C = XᵀX = Σ_k x_k x_kᵀ 同构。
  • KF_demo 因子图：批量因子图把每个残差因子累加进信息矩阵 Λ = Σ JᵢᵀΩᵢJᵢ——与本节块累加逐一对应（”因子累加进信息矩阵”）。
  • neon_demo（SME ZA）：SME 的 ZA 外积累加也是”逐外积累加进一个大矩阵”，与 Σ JᵢᵀJᵢ 同构。
  • cali_demo：相机标定 / 手眼 / 多相机 rig 的本质就是 BA。

四、代码走读（纯 C++17，无 OpenCV）

文件 ls_l4_schur_ba.cpp（配套 _diagrams.html + images/fig25_schur_ba.svg）。核心组成：

  • 线性代数：matmul / matvec / transpose / solve（高斯消元+部分主元）/ inv / cholesky。
  • SO(3)：rodrigues 旋转、jr 右雅可比、skew、matvec3。
  • gen_problem：LCG 确定性数据（与 C++ 控制流镜像逐位一致）。
  • jacobian：48×36 解析雅可比，固定相机 0 的列恒为 0（锚定）。
  • schur_solve(Hcc,Hcp,Hpc,Hpp,bc,bp,λ)：阻尼 Schur 边缘化，返回 (δc, δp, S)。
  • lm_step：LM 回溯（最多 50 次放大 λ），保证每步实际代价下降。
  • main：组装 H_acc、双路求解（Schur vs 全量）、LM 迭代 25 步、输出 5 项检查。

六、自检（易错点）

  1. gauge 未消除 → H 奇异：一开始 3 相机 8 点全自由，J 秩亏 7，全解与 Schur 全崩。修复：固定相机 0 锚定，满秩。
  2. 阻尼加错位置：初版把 λ 当”附加列”拼到 Hcc/Hpp 上（变成 12×24 / 24×48 矩形阵），inv 与 solve 全乱。修复：对对角线加 λ（Hcc[i][j] += (i==j?λ:0)）。
  3. 全步过冲：纯 GN 在病态 BA 上 δ 范数 ~14（真实误差 ~0.05），代价爆炸。修复：LM 阻尼 + λ 回溯。
  4. SO(3) 雅可比：旋转雅可比用 −(RX)^×·J_r(w)（标准右雅可比），保证局部线性化自洽，收敛到噪声地板。
  5. 不等式方向：④ 用 max(0, cost_new−cost_old) 当误差，PASS 当且仅当”确实下降”，避免把上升误判为 PASS（详见项目记忆中的”不等式断言 chk 方向坑”）。
