本仓库 Obsidian 使用指南

本仓库（8 个主题 demo：NEON / CUDA / 标定 / 控制 / 雅可比 / 卡尔曼滤波 / 最小二乘 / PID）已被改造为 Obsidian 友好结构。本文档说明如何打开、已完成的自动化改造，以及四大核心玩法。

一、三步打开仓库

  1. 安装并启动 Obsidian。
  2. 选择 「打开其他仓库 / Open another vault」 → 定位并选中本目录 **02jd**（即放有 8 个 *_demo 文件夹的那一层）。
  3. 等待左下角索引完成，文件栏即出现 8 个 demo 文件夹。**vault 根必须是 02jd**，否则跨 demo 的 [[wikilink]] 会解析偏移。

二、已自动完成的改造

改造项 说明
.obsidian/ 基础配置 默认使用 [[wikilink]]、开启「自动更新链接」、关系图谱按 demo 着色
138 篇 .md 补 frontmatter 每篇头部加入 level / topic / demo / type / status 五个字段
关键相对链接 → [[wikilink]] 篇内与跨 demo 的 .md 导航链接转为双链，解锁反向链接与图谱

注：矩阵里的 [[0,1],[-4,-0.8]] 等是数学记法，不是链接，已自动跳过；图片 ![]() 内联引用保持原样（Obsidian 原生渲染）。

三、四大核心玩法

3.1 关系图谱（Graph）

左侧或右侧面板打开 Graph。你会看到 8 个彩色簇（每个 demo 一色），簇内是 L1 → L2 → L3 的递进连线，簇间有跨 demo 引用（如 KF → Jacobian、KF → PID、CUDA → NEON）。点任意节点可聚焦其邻居。

3.2 反向链接（Backlinks）

打开某篇笔记，右侧 Backlinks 面板会自动列出「谁引用了我」。例如打开 Jacobian_demo/jac_l1_definition.md，能看到 KF_demo 里 EKF 相关篇目反向指向它。

3.3 大纲（Outline）

任意笔记内打开 Outline，每篇的”一、二、三…”标题会自动排成可点击目录，长文导航很方便。

3.4 MOC 导航

每个 demo 的 README.md 都是该模块的内容地图（MOC），篇内笔记顶部也回链了对应 README。建议从 README 进入，再顺着 [[下一篇]] 逐篇推进。

五、数学公式

文档里的公式是 Unicode 文本（如 p⁻ = F·p·Fᵀ + Q），并非 LaTeX。若要更美观的渲染：

  • 选中公式，用 $ ... $（行内）或 $$ ... $$（独立行）包裹；
  • Obsidian 内置 MathJax，保存即渲染。

六、非 Markdown 文件怎么办

.cpp / .h / .cu / .svg / .html 在 Obsidian 里是附件：

  • 在笔记里用 [[xxx.cpp]] 可直接跳转到对应源码；
  • 篇内配图已用 ![]() 内联，Obsidian 直接显示 SVG，无需再开 _diagrams.html；
  • 这些文件不参与图谱节点，但会作为链接出现在引用它们的笔记中。
