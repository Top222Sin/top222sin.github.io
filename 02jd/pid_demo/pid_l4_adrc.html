L4 ADRC 自抗扰控制（Active Disturbance Rejection Control）

PID 把”模型不准 + 外部扰动”全部丢给积分项慢慢磨；ADRC 不磨——它派一只扩张状态观测器（ESO）实时把”总扰动”测出来，然后一把抵消掉。最妙的是控制器只需知道一个 b0（控制增益），对象长啥样完全不用管。

一、为什么 PID 在大扰动下被动

二阶对象 y'' = f(y,y',u) + b0·u，真正的”麻烦”是那个 f——它把模型误差、耦合、外部扰动全打包在一起。传统 PID：

f 造成的偏差只能靠 Ki·∫e 一点点积掉。扰动一大、f 一变，积分就追得气喘吁吁。

ADRC 的觉醒：把 f 当成一个”新状态” x3 = f，用观测器把它在线估计出来，然后控制律里直接减掉它：

抵消之后闭环里 f 基本消失，对象退化成你想要的二阶理想系统。

关键结论：ADRC 的”积分”来自 ESO 对扰动的估计与抵消，所以即使对象是未知/时变的，它也能像”已知模型 + 理想 PD”一样干净地跟踪。工业上韩京清方法在电机、无人机、伺服里就靠这个抗未知扰动。

五、与 PID 家族的衔接

  • 对比 L3.2 鲁棒与抗扰：那里用 DOB（扰动观测器）+ 前馈，思路是”估计扰动→前馈补偿”；ADRC 把”模型不确定性”也包进同一个 f 里一起估，更系统化，且模型无关。
  • 对比 L1.5 抗积分饱和：ADRC 没有传统积分器，也就没有 windup 问题；若 b0 给错或 ωo 过低，仍可能发散——这是它的另一类失效模式。
  • 对比 L2.3 PX4 架构：飞控用经典 PID + 前馈，没上 ESO；但”前馈补偿扰动”的思想与 ADRC 同源。

六、工程坑（真实）

  1. b0 必须近似正确：抵消项是 (u0 − ẑ3)/b0，b0 偏差会直接放大 u。实践中 b0 取对象控制增益的数量级即可，不要求精确。
  2. ESO 带宽 ωo 不能太低：太低则 ẑ3 跟不上快变扰动（如斜坡），抵消滞后 → 性能下降；太高则对噪声敏感（观测器极点 −ωo 过激进）。
  3. 非线性对象 ≠ 无限鲁棒：ADRC 假设 f'≈0（扰动缓变）。若 f 本身剧烈跳变，ESO 有估计滞后，需配合更高 ωo 或非线性 fal 函数（本 demo 用线性 ESO 已足够演示）。
  4. 和 PID 不是替代而是升级：ADRC 本质 = “PD + 扩张扰动观测器”，可以看作是 PID 里积分项的一种”更主动”的替代品。

七、自检

  • 把 b0 从 1.0 改成 0.6（故意给错），看 ADRC 跟踪是否仍稳、误差是否变大。
  • 把 ωo 从 10 降到 3，再跑斜坡扰动，看 ẑ3 是否跟不上、max|e| 是否上升。
  • 把扰动从斜坡 d(t)=t 换成阶跃 0.5，确认 ADRC 与无积分 PD 的差距进一步拉开。
