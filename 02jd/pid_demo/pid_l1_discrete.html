L1.3 PID 离散化形式

连续 PID 是 u(t)=Kp·e + Ki∫e + Kd·de/dt，但代码里只能写差分。怎么写，有讲究。

一、位置式 vs 增量式

形式 递推式 存储 特点
位置式 uₖ = Kp·eₖ + Ki·Σeᵢdt + Kd·(eₖ−eₖ₋₁)/dt 需要积分累加器 直观；但积分项一旦饱和易 windup
增量式 Δuₖ = Kp(eₖ−eₖ₋₁)+Ki·eₖdt+Kd(eₖ−2eₖ₋₁+eₖ₋₂)/dt；uₖ = uₖ₋₁+Δuₖ 不存独立积分累加器，但需存输出 + 两拍误差历史 无独立积分器，配合输出冻结可简化抗 windup；手动/自动切换需正确初始化才无扰

本 demo 用 PD（Ki=0） 严格证明：两者逐拍输出浮点级一致——它们是同一个连续 PID 的两种写法，不是两套算法。

结论：增量式就是位置式的差分形式——只要积分初值一致、初始输出一致、离散约定相同（矩形积分端点一致）、无饱和、无滤波、增益不变，两者逐拍完全相同。工程上偏好增量式的真正原因是行为而非数学：它不单独存积分累加器，手动/自动切换时只需把 uₖ₋₁ 初始化为当前手动输出、误差历史对齐即可无扰切换（bumpless 靠正确初始化实现，非天然）；饱和时”冻结输出更新”即可简化 windup 处理。注意：增量式本质仍是输出累积（uₖ=uₖ₋₁+Δuₖ），不处理仍会 windup，只是”饱和时停止累加”的实现更直白。

注：带 I 项时两者在”积分初值”约定不同时会有头几拍偏差（标准教材称它们等价，忽略初始化）。工程上增量式更受青睐，正是因为不单独存积分器、对增益突变/手动→自动切换的初始化更直接。

二、采样周期 dt 的隐形代价

控制器每 dt 秒才看一次误差、算一次输出，中间靠零阶保持（输出不变）。dt 越大：

  • 微分项 (eₖ−eₖ₋₁)/dt 越粗糙；
  • 相位滞后越大，闭环越容易振荡。

本 demo 把 plant 用细子步积分（隔离出”控制器离散化”这一项），只让 PID 按不同 dt 采样：

dt 现象
0.01s 平滑爬升到 1.0，几乎无超调
0.10s 出现可见超调
0.30s 明显振荡、超调放大

dt 的量化代价

  • 微分项信噪比：D 项增益实际是 Kd/dt——dt 减半，噪声放大翻倍（L2.2 展开）。
  • 相位滞后：零阶保持等效延迟 dt/2，对应相位滞后 φ ≈ −ω·dt/2——闭环带宽 ωc 处损失 ωc·dt/2 弧度。dt=0.3s、ωc≈10 rad/s 时损失 1.5 rad≈86°！这就是 dt 大必振荡的根源（L2.4 的极点边界是同一件事的另一面）。

三、代码走读（pid_l1_discrete.cpp）

  • simPos / simInc：同一个 plant，分别用位置式、增量式 PID；plant 细子步积分、零阶保持。
  • ① 等价性：Ki=0 时 max|y_pos − y_inc| < 1e-9 才 PASS。
  • ② dt 敏感性：三个 dt 跑同增益，断言”小 dt 良好跟踪”且”大 dt 不更优”。

四、工程坑（真实）

  1. Kd 忘了除以 dt：离散 D 项是 Kd·(eₖ−eₖ₋₁)/dt，很多初版代码漏掉 /dt——dt=0.01 时阻尼只有设计的 1%，系统该振荡不振荡、该稳不稳。写 D 项先核对 dt。
  2. Ki 忘了乘 dt：同理 I 项是 Ki·Σe·dt，漏乘 dt 会导致积分增益虚高 100 倍，超调爆炸。
  3. 增量式饱和处理陷阱：增量式”饱和时冻结 Δu”只是让 windup 处理变简单（不更新输出/积分状态即可），不是自动免疫——若直接把 uₖ=uₖ₋₁+Δuₖ 无脑累加，饱和期间 Δu 继续累积、解除饱和瞬间输出仍会跳变。
  4. 浮点累积误差：长时间运行的位置式积分累加器会有漂移（尤其定点 MCU），增量式的输出累积同样有舍入误差，但避免了独立长积分累加器——嵌入式里两者都需要定期限幅/重置，增量式的”无独立积分器”只是少一处漂移源。

五、自检

  • 把 Ki 从 0 改成 2，再看位置式与增量式是否在头几拍出现细微偏差（体会积分初值约定；若两者初始化约定一致则无偏差）。
  • 把 plant 时间常数 plantT 改小（更快的 plant），看同样 dt=0.3 下振荡如何加剧——这就是 L2.4”离散稳定性”要讲的稳定边界。
