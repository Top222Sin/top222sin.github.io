L2.5 增益调度与自适应（Gain Scheduling）⭐

线性 PID 在”增益随工况变化”的非线性系统上，固定增益只能顾一头。解法：按工况（operating point）调度增益——这正是 PX4 按推力/空速调度姿态·速率增益的思路。

一、为什么需要增益调度

之前所有 demo 都暗含一个假设：plant 增益是常数。但现实里很多系统不满足：

  • 电机在低速/高速段推力增益不同；
  • 飞机空速变了，单位舵偏产生的角加速度变了；
  • 机械臂靠近奇异点时，单位力矩产生的关节角速度剧变。

若 plant 增益 K(op) 随工况 op 变化，固定 Kp 意味着 有效回路增益 Kp·K(op) 随 op 大幅波动——op 一端增益太小（迟钝、余差大），另一端增益太大（超调、振荡）。这正好解释 L1.4 里”增益调大就抖”。

增益调度 vs 自适应的区别（重要概念辨析）

方法 原理 特点
增益调度（GS） 预先按工况查表/插值增益 Kp(op) 离线设计、确定性、无需在线辨识——“开环补偿非线性”
自适应控制 在线辨识 plant 参数并更新增益 在线、能应对未预见的漂移——“闭环补偿不确定性”
自整定（一次） 启动时自动辨识一次（L3.1/L3.3） 出厂后固定，不跟踪工况

工程经验：能预先建模的非线性 → 增益调度（简单可靠）；不可预见的参数漂移 → 自适应（复杂，需激励持续、有发散风险）。PX4 用调度（按推力/空速查表），不用连续自适应——飞控对确定性优先于最优性。

二、demo 模型与调度律

本 demo 用一个二阶 plant，其增益随工况 op 变化：

  • 固定增益：用名义工况 op=0.5 整定的 Kp0，全工况都套同一组 Kp0/Ki/Kd。
  • 调度增益：按 Kp(op) = Kp0·K0 / K(op)（K0=K(op0)）补偿 plant 增益变化，让比例通道 Kp(op)·K(op) ≈ 常数。

调度律推导（为什么除以 K(op)）

闭环有效增益 = Kp·K(op)（控制器增益 × plant 增益）。希望比例通道对所有 op 恒定：

关键：K(op) 是”plant 增益随工况的模型”，必须离线辨识（阶跃测试各工况点）或由物理规律给出（如 √ 流量、气动系数随空速）。调度律 = 模型反函数——增益调度本质上是用 plant 模型做开环补偿。注意：Kp·K(op) 恒定只保证比例通道；完整闭环特征还含 K·Kd（阻尼）与 K·Ki（积分）项，严格保持闭环响应需三增益同比例调度（见下方”工程坑”）。本 demo 的”调节时间方差/最大超调”断言是当前参数下的验收指标，不是调度律的普遍数学推论。

三、代码走读（pid_l2_gain_sched.cpp）

  • simGS(op, Kp, Ki, Kd, dt, N)：给定工况与增益，跑出一个阶跃响应序列。
  • 指标：steadyErr（末值偏差）、overshoot（峰值超出末值）、settling（±2% 调节时间）。
  • 对拍断言：
    • 两种策略稳态误差都 < 0.05（二阶系统 I 项消余差）；
    • 调节时间方差：var(调度) < 0.5 · var(固定) —— 调度让全工况”手感”一致（当前参数下的验收指标）；
    • 最大超调：maxOv(调度) ≤ maxOv(固定) —— 调度不引入更坏表现。

四、你会看到什么

  • 左图：plant 增益 K(op) 上升（红），调度 Kp(op) 同步下降（绿），二者乘积≈常数。
  • 右图：固定增益下，超调随工况剧烈波动（红折线）；调度增益下各工况超调几乎齐平（绿线）。

五、工程坑（真实）

  1. 调度律要同比例缩放 Ki/Kd 才保闭环：只调 Kp 时 K·Kd、K·Ki 仍随工况变化（阻尼/积分作用漂移）。完整做法 Kp/Ki/Kd 同乘 K0/K(op)；工程中受滤波器/执行器/噪声限制，不可能精确保持闭环，按”主要失效模式”调度即可。
  2. 调度的”切换抖动”：工况快速穿越调度区间时增益突变 → 输出跳变。工程处理：插值（线性/样条查表）而非分段常量，或对增益做低通（注意：增益低通会给调度引入滞后——截止频率需与工况变化速度、闭环带宽共同设计）。
  3. 调度变量本身要可测且平滑：如果调度变量（空速/推力）本身噪声大，增益会抖——先滤波调度变量。
  4. 调度 + 积分的交互：工况切换时积分器状态对应旧增益，直接换增益可能跳变——切换时对积分器做 bumpless 转移（按新增益重新标定积分）。
  5. PX4 的推力调度：PX4 多旋翼控制存在按工况调度增益的实践（参数随版本变化，如 MC_ROLLRATE_K 等与推力相关的缩放，src/lib/rate_control/gain_compression.cpp 是大机动时的增益压缩实现）；固定翼则按空速调度。不同机型/版本实现不同，引用需固定版本。

六、自检

  • 把 Kof(op) 的斜率从 3 调到 8（增益变化更剧烈），看固定增益的超调波动如何更夸张、调度增益依旧齐平。
  • 把调度律改成 Kp(op)=Kp0（即”不调度”），核对两条线重合、方差判据失败——确认调度确实在起作用。
  • 把 Kp0 整体调大，看固定增益在 op 高端如何率先发散（effective gain 过大）。
