L4 模糊 PID（Fuzzy PID）

固定增益 PID 在强欠阻尼对象上容易「一脚油门踩到底」——大超调。模糊 PID 不换控制器结构，而是让 Kp/Ki/Kd 跟着误差 e 和误差变化率 ec「自动变」：大误差时降 Kp 防冲、增 Ki 消静差、按需调 Kd 加阻尼。那张 7×7 规则库，就是老师傅的整定经验。

一、为什么固定增益会「冲」

强欠阻尼对象 G(s)=1/(s²+0.4s+1)（ζ=0.2）。固定 Kp0=2.2, Ki0=1.4, Kd0=0.4 阶跃时超调高达 0.4218——一上来 Kp 太大，冲过头再拉回来。人类整定时会「误差大就保守点、快稳了再精准点」，模糊 PID 把这条直觉写成规则。

二、核心：模糊推理机

规则方向（关键）：大正误差 → 降 Kp（ΔKp<0）防超调、增 Ki**（ΔKi>0）消静差；零误差附近 → ΔKp≈0 不瞎动。规则库必须反对称，写反符号会放大**超调（本 demo 初版就栽过，见第六节）。

三、代码走读（pid_l4_fuzzy.cpp）

  • trimf(x,c,w)：三角隶属度，|x−c|/w < 1 时为 1−|x−c|/w，否则 0。
  • TAB_KP/TAB_KI/TAB_KD[7][7]：规则库，元素存「后继语言中心索引」。
  • fuzzy_out(e_norm,ec_norm,tab)：遍历命中规则、按 min 取激活强度、重心法解出连续 ΔK。
  • sim_fuzzy(use_fuzzy,...)：闭环跑固定 PID vs 模糊 PID；模糊模式实时算 ΔKp/ΔKi/ΔKd 并叠加到基准增益（带非负截断与 ±5 限幅）。

四、你会看到什么（已用受管 Python 3.13.12 验证，全部 PASS）

对象 G(s)=1/(s²+0.4s+1)，dt=0.02, T=20, r=1，基准 Kp0=2.2,Ki0=1.4,Kd0=0.4，量化 ge=gec=3，比例 kps=0.5,kis=0.15,kds=0.12：

检查 结果 含义
推理自检 ΔKp(e=3,0) −2.00 大正误差→降 Kp ✓
推理自检 ΔKp(e=−3,0) +2.00 对称 ✓
推理自检 ΔKp(0,0) 0.00 原点不动 ✓
推理自检 ΔKi(e=3,0) +2.00 大误差→增 Ki ✓
固定 PID IAE=2.8965，超调=0.4218 基准
模糊 PID IAE=2.1381，超调=0.3695 超调↓13%、IAE↓26%
模糊超调 < 固定超调 PASS 更柔
模糊 IAE < 固定 IAE PASS 质量更好
模糊稳态误差 < 0.02 PASS（1.4e-3） 仍消静差

关键结论：模糊 PID 把「大误差降 Kp、增 Ki」的经验规则化，超调 0.42→0.37、IAE 2.90→2.14，且保留积分器消静差能力——适合暖通/家电这类「允许慢但别冲」的场景。

五、与 PID 家族的衔接

  • 对比 L2.2 增益调度：增益调度也是「增益随工况变」，但靠模型/查表；模糊 PID 靠规则库，免模型、更贴近人工经验。
  • 对比 L1.3 PID 三项：控制器仍是标准三项，模糊只动增益。
  • 对比 L1.5 抗积分饱和：本 demo 对叠加后的 ki 做非负截断，已是轻量 anti-windup。

六、工程坑（真实）

  1. 规则库方向必须反对称：初版误把「大误差→增 Kp」，结果超调不降反升；改为 ΔKp(大正误差)<0 才对。
  2. 量化因子 ge/gec 要匹配论域：太小→推理迟钝（一直 ZO），太大→过度饱和乱跳。
  3. 增益非负截断：ki=Ki0+dki 可能变负，必须夹紧到 0，否则积分项变「负积分」数值崩。
  4. 模糊不万能：规则库依赖经验，强非线性/强扰动对象要更多状态量（见 L4.1 ADRC 用 ESO 主动抵消）。

七、自检

  • 把 TAB_KP 大误差行全改成「增 Kp」，重跑看超调是否飙升（反向验证规则方向）。
  • 把 ge 从 3 改到 0.5，看模糊 PID 是否退化成接近固定 PID（推理迟钝）。

八、下一步
