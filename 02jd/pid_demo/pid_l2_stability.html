L2.4 离散稳定性与频率域

“增益调大就抖”不是玄学——它有精确的边界。离散系统稳不稳，看特征根（极点）在不在单位圆内。

一、离散闭环的极点判据

对一阶 plant x' = −x + u，纯 P 控制 u = Kp·(R−x)，用前向欧拉离散：

闭环极点（特征根）就是那个系数 p_FE = 1 − dt·(1+Kp)。稳定 ⟺ |p_FE| < 1：

→ 采样越慢（dt 越大），能用的增益上限越低。这就是”dt 太大就发散”的数学来源。

推导链：从差分方程到稳定判据

  1. 闭环递推 xₖ₊₁ = a·xₖ + b（a 是极点系数）；
  2. 迭代解 xₖ = aᵏ·x₀ + b·(1−aᵏ)/(1−a)；
  3. k→∞ 收敛 ⟺ |a| < 1（指数项衰减）。

关键认知：离散系统稳定判据是极点落在复平面单位圆内（|z|<1），而连续系统是左半平面（Re(s)<0）。z=e^{s·dt} 映射把左半平面”卷”进单位圆——这就是为什么连续里”增益随便大”在离散里会越界。

二、Tustin 为什么更稳（A-稳定）

双线性变换把连续左半平面整体映射进单位圆。本 demo 推出 Tustin 闭环极点恒在单位圆内，即任意 Kp>0 都不发散——对比前向欧拉的硬边界。工程上 Tustin 是默认选择，原因就在这。

三种离散化的稳定域对比（s 平面绝对稳定域）

方法 s 平面绝对稳定域 z 平面映射边界 特性
前向欧拉 ` 1+dt·s < 1`，以 (−1/dt,0) 为圆心、半径 1/dt 的圆
后向欧拉 ` 1−dt·s > 1`，以 (1/dt,0) 为圆心的圆外
Tustin 整个左半 s 平面 虚轴→单位圆 A-stable + 频率映射可预畸变

工程含义：对 PID 控制器本身的离散化，Tustin 是首选；对 plant 仿真（ODE 积分）前向欧拉简单但小心刚性；后向欧拉绝对稳但慢。选型别混用——控制器用 Tustin、plant 仿真用细步 RK4 是常见组合。

三、频率域直觉（相位裕度）

频率域里：增益↑ → 相位裕度↓ → 离不稳定更近。极点从原点移到 −1（单位圆左边缘）时，对应等幅振荡；越过 −1 就发散。本 demo 里 p_FE→−1 正是临界振荡点，Kp = 2/dt−1 即临界增益。

z 域极点位置 ↔ 时域行为速查

注意 z<0 的”折返振荡”是离散特有——前向欧拉在 dt 偏大（dt/T>1）时可能产生负极点（z=1−dt/T<0）；后向欧拉对稳定一阶实极点 z=1/(1+dt/T)>0 恒正，不会折返。看到”每拍跳一下但整体收敛”先检查是不是前向欧拉把 dt 推过了。

四、代码走读（pid_l2_stability.cpp）

  • simFE(dt,Kp,N)：前向欧拉闭环递推，返回末值（发散→巨大）。
  • simTustin(dt,Kp,N)：Tustin 闭环闭式递推，恒收敛。
  • 对拍：① FE 小Kp 极点|p|<1 且收敛；FE 大Kp 极点|p|>1 且发散；② 同 Kp=25 下 Tustin 仍收敛；③ 更大 dt 下 Kp=50 前向欧拉也发散。

五、你会看到什么

  • 左图：单位圆内（绿/蓝点）稳定，圆外（红点）发散。
  • 右图：红色边界是 Kp = 2/dt − 1；边界下方是稳定域，dt 越大边界越低（稳定域越窄）。

六、工程坑（真实）

  1. 仿真稳定 ≠ 真机稳定：仿真里 plant 模型是”你写的”，真机有未建模高频模态（结构共振、执行器延迟）——留 30~50% 增益余量，别贴着稳定边界设计。
  2. 采样抖动：真实系统 dt 不恒定（RTOS 调度抖动），离散极点分析基于固定 dt——抖动会把”恰好稳定”的系统推到边界外。工程上按最坏 dt（最大采样间隔）算稳定边界。
  3. 量化/舍入：定点 MCU 上极点接近单位圆时，舍入误差可能把 |z|=0.99 推到 1.01——长跑后缓慢发散。检测方法：长时间跑漂移测试。
  4. 大 dt + D 项混叠：D 项差分在 dt 大时本质是高频混叠（L2.2 已述）——稳定分析若只算 P 项边界，实际 D 项会先制造噪声型振荡。

七、自检

  • 把 dt 从 0.1 调到 0.3，边界 2/dt−1 会从 ≈19 降到 ≈5.67；此时 Kp=25 远超边界 → 仍发散（且比 dt=0.1 时更猛）。核对无误：dt 越大边界越低、稳定域越窄——与”调小 dt 才更稳”的直觉一致。
  • 把 simFE 换成 Tustin，对任意 Kp 跑都收敛——体会 A-稳定性。
  • 这解释了 L1.3 里”dt 越大越振荡”：本质就是极点逼近/越过单位圆。
