L4 Smith 预估器（Smith Predictor）——大纯滞后的标配补偿

温度、流量、液位这些过程对象，信号从阀门到传感器常常要”走好几秒”（死区时间 L）。普通 PID 一看到滞后，反馈就慢半拍，增益稍大就振荡甚至发散。Smith 预估器是产线对付大纯滞后的标准解法：在反馈环里把滞后减掉、加回无滞后模型，把死区时间 L 移出反馈环。

一、问题：死区时间为什么这么难

一阶加纯滞后（FOPDT）对象：

u(t−L) 表示”现在施加的控制，要 L 秒后才体现在输出上”。对反馈控制器来说，它发出的 u 要等 L 秒才看到效果——这 L 秒的”盲期”会带来相位滞后。相位滞后越大，能保证稳定的增益上限越低 → 只能用小增益 → 响应巨慢。

核心矛盾：你想快（大增益），但滞后逼你慢（小增益）。

二、Smith 的核心技巧：从反馈里”减去滞后”

控制器本来看到的是 y(t)（带滞后）。Smith 在内部放一个对象的无滞后模型，构造一个”预测的无滞后输出”喂给控制器：

直觉：真实输出 y 比无滞后模型 ym 慢了 L，y − ym_delayed 把这段滞后”扣掉”，再加回 ym 就得到若没有滞后时本该有的输出。

于是控制器 C 作用在 yf 上，等价于面对一个没有滞后的对象。滞后 L 退化为纯粹的”传输延迟”（只让响应整体平移 L，不影响稳定性/超调）。

三、代码走读（pid_l4_smith.cpp）

  • piPlain(r,...)：普通 PI 直接作用于 u(t−L) 的真实 FOPDT 对象。
  • piSmith(r,...)：PI 作用在 yf = y − ym_delayed + ym，模型 ym 用当前 u 立即更新。
  • 两者用完全相同的增益，只差”反馈量有没有经过 Smith 预测”。

四、你会看到什么（已用受管 Python 3.13.12 验证，全部 PASS）

对象 K=1, T=2, L=4（死区时间比对象时间常数还长），PI 增益取对带滞后对象很激进的 Kp=1.6, Ki=0.8，dt=0.05, T=60s：

检查 结果 含义
普通 PI（同增益）末值 / 超调 637.1 / 63614% 死区在环内 → 直接发散失稳
Smith（同增益）末值 / 超调 1.000 / 0% 滞后移出环 → 稳且零超调
Smith 调节时间 24.55 s 收敛
Smith < 0.8×普通PI 调节时间 24.55 < 48.0 ✓ 明显更快
模型略失配 Lm=3.5（真实 4.0） 22.05 s，末值 1.00 模型不精确仍稳且快

关键结论：同样的增益，普通 PI 在带滞后对象上发散，Smith 却稳又快。这就是 Smith 存在的理由——它把”死区时间”这个稳定性的头号杀手请出了反馈环。

五、与 PID 家族的衔接

  • 对比 L1.4 整定直觉：Z-N 在带滞后对象上求出的增益被迫很小（因为滞后压低了稳定裕度）；Smith 让你能用”无滞后模型”对应的更激进增益。
  • 对比 L4 ADRC：ADRC 对付”模型不准+快变扰动”，Smith 专门对付”大纯滞后”，二者互补，都是工业伺服/过程控制的标配。
  • 对比 L4 IMC/λ 整定：IMC 也是”基于模型”的整定，且 IMC 结构里天然能嵌入 Smith 预估（IMC 处理延时对象时就是把延迟放进反馈支路）。

六、工程坑（真实）

  1. Smith 极度依赖模型精度：它内部用 ym 去”抵消”真实滞后。若模型 Lm/Tm/Km 与真实差太多，抵消就不干净，残余滞后还在环里 → 反而可能比不用 Smith 更糟。模型失配是 Smith 的头号天敌（本 demo 用 Lm=3.5 vs 真实 4.0 验证”略失配仍 OK”，但大失配会翻车）。
  2. **只补偿”纯滞后”**：若滞后是”分布式的”（如高阶对象的多阶滞后混在一起），单纯的死区时间模型不够，需要更高阶模型。
  3. 不解决执行器饱和：Smith 不改变对象的幅值限制；大设定值阶跃下饱和仍会让预估失真，需配合抗饱和。
  4. 和 PID 不是二选一：Smith 预估器里包着一个 PI（本 demo 用 PI 作内环控制器），它增强的是”反馈环对滞后的免疫”，不是替代 PID。

七、自检

  • 把模型死区 Lm 从 4.0 故意错配成 2.0（差一倍），看 Smith 是否开始振荡、甚至比普通 PI 还差。
  • 把 L 从 4.0 调到 1.0（滞后变小），看普通 PI 也能稳住——Smith 的优势在”大滞后”时才显著。
  • 把增益 Kp/Ki 调小到普通 PI 也能稳的范围，确认两种情况都收敛，但 Smith 仍更快/更平。

八、下一步

进入 L4 IMC / λ 整定：另一种”基于模型”的整定法，但这次的卖点是一个旋钮 λ 直接设定闭环带宽，比 Z-N 更可解释。
