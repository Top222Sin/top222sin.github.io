L4 IAE / ISE / ITAE / ITSE 性能指标

「稳不稳」只是及格线；整定好坏得量化。IAE / ISE 把整条误差曲线压成一个数——越小越好。ITAE / ITSE 再额外惩罚「拖尾」，更适合自动寻优。整定不再是玄学，而是一个最小化指标的数值优化问题。

一、为什么需要指标

只看「稳态误差 / 超调」太粗：同一种「稳」，整定参数差一倍，IAE 能差一倍。把整条 e(t) 曲线积分成一个标量，才能横向比较、自动寻优。

检查 结果 含义
定常误差 e=0.5 → IAE = 0.5·T（自洽 PASS） 算法对拍闭式
定常误差 e=0.5 → ISE = 0.25·T（自洽 PASS） 算法对拍闭式
激进 PID（Kp=3.0,Ki=2.0,Kd=0.2） IAE=2.3057，ISE=0.8323，ITAE=9.46，超调=0.4490 高 Kp 大超调
优调 PID（Kp=1.4,Ki=0.8,Kd=0.5） IAE=1.2586，ISE=0.5823，ITAE=2.75，超调=0.0130 缓和、收敛快
优调 IAE < 激进 IAE PASS 指标量化「更优」
优调 ISE < 激进 ISE PASS 同上
超调与 IAE 同向（激进更大） PASS 指标与直观一致
优调稳态误差 < 0.02 PASS（1.4e-4） 优调仍消静差

关键结论：优调整定的 IAE(1.26) 比激进(2.31) 低近一半、ITAE(2.75) 比激进(9.46) 低一个量级——指标把「整定质量」变成可寻优的标量。自动整定（见 L3.1 自整定）本质就是最小化 IAE/ISE。

五、与 PID 家族的衔接

  • 对比 L1.5 整定：指标就是整定的「打分函数」，ZN/试凑都是在隐式压指标。
  • 对比 L3.1 自整定 / L3.2 自整定器：自整定 = 以 IAE/ISE 为目标做参数寻优。
  • 对比 L2.4 稳定性：指标衡量「性能」，稳定性衡量「会不会散」——两者都齐才叫好整定。

六、工程坑（真实）

  1. ISE 比 IAE 更狠：平方让大误差权重更高，适合「绝不允许大偏差」的场景；IAE 更「民主」，适合一般伺服。
  2. ITAE 惩罚尾差：时间因子 t 让早期误差权重小、后期大，适合「允许短暂超调但必须快收敛」。
  3. 离散步长 h 要小：h 大则积分本身有截断误差，指标失真（本 demo h=0.02）。
  4. 指标低 ≠ 鲁棒：IAE/ISE 只测 nominal 轨迹，要叠加扰动/参数摄动才算鲁棒（见 L3.2 鲁棒与抗扰）。

七、自检

  • 把激进 Kp 从 3.0 调到 2.0，看 IAE/超调是否同步下降（指标随整定连续变化）。
  • 改对象阻尼 ζ（如 Ac 第二行 -0.8→-0.4），看指标对模型误差的敏感度。
