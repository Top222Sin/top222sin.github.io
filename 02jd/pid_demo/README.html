pid_demo —— 控制理论 / PID 学习目录

本目录是「NEON（ARM 后端）→ CUDA（GPU 后端）→ 标定（几何地基）→ PID（控制地基）」四步学习法的第四站。
与 neon_demo/、cuda_demo/、cali_demo/ 平级，沿用同一套 L1/L2/L3 三级递进 + 每个知识点落成「可运行 .cpp + 配套 .md（含内联 SVG）+ _diagrams.html 预览 + images/ 矢量图」 的约定。

当前阶段：已全数落成 ✅。 下方 24 个知识点已全部写成自包含、可编译运行的 demo：每个 .cpp 自带合成被控对象 + 真值对拍 → 打印 PASS/FAIL；配套 .md 含内联 SVG 讲解；_diagrams.html 浏览器预览；images/ 矢量图汇总。

〇、运行环境约定（重要，决定 demo 怎么写）

  • 语言/库：C++17 + 仅标准库（不依赖 OpenCV / Eigen 等）。PID 控制本质是数值仿真，用 std::vector/std::array 即可表达被控对象与控制律，比 cali_demo 更轻——你可在任意机器直接编译运行，无需安装额外依赖。
  • 无真机也能跑：每个 demo 自带 合成被控对象（plant）生成器（用已知真值参数构造一阶/二阶/多旋翼动力学 + 加可控噪声/扰动），跑完把「控制器输出 vs 真值响应 / 整定增益 vs 理论最优」做误差对拍并打印 PASS/FAIL。这复刻了 cali_demo 的「CPU 对拍」风格——不接真实电机/飞控也能验证算法正确性。
  • 构建：每个 .cpp 均可 g++ / cl 直接编译；目录根提供 CMakeLists.txt 一键构建全部。
  • 与 PX4-Autopilot 的关系：本目录以 PX4-Autopilot 的真实飞控控制代码作为工程参照底稿，把课本里的 PID 落到生产级飞控的代码形态上。重点参考文件：
    • src/modules/mc_rate_control/MulticopterRateControl.cpp + src/lib/rate_control/rate_control.hpp（角速率 PID：并行 K·(P + I/s + sD)、D 项滤波、前馈、抗饱和）
    • src/modules/mc_pos_control/PositionControl/PositionControl.cpp（位置→速度→加速度串级 + 推力饱和 + ARW 抗饱和）
    • src/modules/mc_autotune_attitude_control/mc_autotune_attitude_control.cpp（阶跃激励 + 系统辨识 + GMVC 自动整定状态机）

一、学习大纲（L1 / L2 / L3 三级）

L1 —— 入门：跑通流程、建立控制直觉

编号 知识点 目标（学完能做什么） 内容要点 计划文件 状态
L1.1 被控对象建模与离散化 会造 plant、会看响应 一阶惯性 / 二阶系统；连续→离散（前向/后向/Tustin）；采样周期 dt 与控制频率；阶跃响应指标（稳态误差、超调、调节时间）；用合成 plant + 阶跃看响应曲线 pid_l1_plant.cpp + pid_l1_plant.md ✅ 已落成
L1.2 PID 三项的物理意义 讲清 P/I/D 各自干了啥 P（比例：响应快但有余差）、I（积分：消除稳态误差、却引入超调/振荡）、D（微分：阻尼、抑制超调、放大噪声）；位置式 PID 直观实现；阶跃响应对拍真值 pid_l1_terms.cpp + pid_l1_terms.md ✅ 已落成
L1.3 PID 离散化形式 不会离散化踩坑 位置式 vs 增量式（增量式天然抗 windup）；Tustin/前向/后向差分对比；同一连续 PID 不同离散化在 dt 大时的差异 pid_l1_discrete.cpp + pid_l1_discrete.md ✅ 已落成
L1.4 整定直觉（Ziegler-Nichols / 试凑） 会手调出稳定增益 临界增益法（闭环临界振荡求 Ku/Pu）、阶跃响应法；在二阶 plant 上自动做临界振荡实验套公式得 Kp/Ki/Kd；对比试凑法 pid_l1_tuning.cpp + pid_l1_tuning.md ✅ 已落成
L1.5 抗积分饱和基础 识破 windup 积分 windup 成因（执行器饱和时积分仍在累积→解锁后大超调）；clamping / conditional integration 基础实现；对拍 windup 造成的超调 pid_l1_antiwindup.cpp + pid_l1_antiwindup.md ✅ 已落成

L1 收口自检：给定合成 plant 真值，五个 demo 各自恢复/整定，阶跃响应指标对拍全部 PASS。

L2 —— 进阶：吃透原理、工程细节与失效模式

编号 知识点 目标 内容要点 计划文件 状态
L2.1 串级 PID 与多回路 懂内/外环嵌套 外环输出是内环设定值；PX4 PositionControl::update：_positionControl(P)→_velocityControl(PID)→_accelerationControl；合成双环（位置环+速度环）对拍 pid_l2_cascade.cpp + .md ✅ 已落成
L2.2 微分噪声与 D 项滤波 抑制 D 项噪声 D 项放大测量噪声；PX4 对 D/角加速度做低通滤波 + yaw 输出 LPF；比较无滤波 vs 滤波的噪声响应；微分先行（derivative-on-measurement）避免设定值突变冲击 pid_l2_derivative_filter.cpp + .md ✅ 已落成
L2.3 多旋翼 PID 架构解析（PX4 代码走读） ⭐ 能读飞控控制代码 MulticopterRateControl + lib/rate_control/RateControl：并行 PID K·(P+I/s+sD)、增益 K 换算、前馈 FF、抗饱和（来自 control allocator 的饱和反馈）、yaw 输出 LPF；PositionControl 串级 + 推力饱和 + ARW；每个增益映射到参数 MC_ROLLRATE_P/I/D/FF/K。代码走读对照 pid_l2_px4_arch.cpp + .md ✅ 已落成
L2.4 离散稳定性与频率域 会判稳 z 域特征根、采样定理与相位滞后、相位裕度直觉；离散 PID 稳定性边界（dt 过大→发散）；量化/舍入影响 pid_l2_stability.cpp + .md ✅ 已落成
L2.5 增益调度与自适应 ⭐ 懂非线性补偿 gain scheduling（按工作点/状态插值增益，如 PX4 按 thrust/airspeed 调度）；为什么线性 PID 在非线性系统中需要调度；合成：不同工作点用不同增益 vs 固定增益的误差对比 pid_l2_gain_sched.cpp + .md ✅ 已落成

L4 —— 工业扩展：ADRC / Smith / IMC / FOPID / 模糊 / 指标 / MIMO（P1/P2 补全，按 L4 落地）

编号 知识点 目标 内容要点 计划文件 状态
L4.1 ADRC 自抗扰控制 ⭐ 模型无关强抗扰 扩张状态观测器 ESO 在线估计”总扰动” f（模型误差+外部扰动），控制律 u=(u0−ẑ₃)/b0 直接抵消；仅用 b0 即稳，对未知/时变对象鲁棒；对比无积分 PD pid_l4_adrc.cpp + .md ✅ 已落成
L4.2 Smith 预估器（大纯滞后补偿）⭐ 死区时间移出反馈环 FOPDT 对象 dy/dt=(−y+K·u(t−L))/T；反馈量 yf=y−ym_delayed+ym 抵消滞后；同样激进增益下普通 PI 发散、Smith 稳而快；模型失配鲁棒性 pid_l4_smith.cpp + .md ✅ 已落成
L4.3 IMC / λ 整定（内模控制）⭐ 一个旋钮设带宽 IMC 控制器 C=(Ts+1)/(K(λs+1))；等价 PI 增益闭式 Kc=T/(Kλ), τI=T；完美模型下闭环 Y/R=1/(λs+1)，TC=λ 可预测可设带宽；增益失配仍零稳态误差 pid_l4_imc.cpp + .md ✅ 已落成
L4.4 分数阶 PID（FOPID）⭐ 多两自由度更柔顺 Grünwald-Letnikov 离散化 Dᵃe≈h⁻ᵃΣ(−1)ʲC(α,j)e(k−j)；积分项全历史不截断（保积分器/DC）、微分项截断窗口；μ>1 多相位超前→超调↓；同 Kp/Ki/Kd 下 FOPID 超调 0.0173→0.0000 pid_l4_fopid.cpp + .md ✅ 已落成
L4.5 模糊 PID ⭐ 增益随误差自适应 e,ec∈[−3,3] 三角隶属→7×7 规则库（ΔKp/ΔKi/ΔKd）→重心法解模糊；大误差降 Kp 防超调、增 Ki 消静差；强欠阻尼对象超调 0.4218→0.3695 pid_l4_fuzzy.cpp + .md ✅ 已落成
L4.6 IAE/ISE/ITAE/ITSE 指标 ⭐ 整定质量量化 IAE=∫ e dt、ISE=∫e²dt、ITAE=∫t
L4.7 MIMO PID（2×2 解耦）⭐ 多变量回路独立整定 2×2 耦合对象 K=[[1,0.3],[0.5,1]]；静态解耦器 D=K⁻¹ 使 D·Kss=I（直流严格对角化）；各对角回路普通 PID；瞬态交叉耦合峰值 0.1479→0.0000 pid_l4_mimo.cpp + .md ✅ 已落成
L4.8 FOPID λ/μ 自动寻优 ⭐ 整定自动化 用 L4.6 的 IAE 作目标函数，对 (λ,μ) 做 7×7 网格搜索；自动找到 (1.1,1.3)，比整数 PID 降 5.2%、比手工 FOPID 降 4.1% IAE；并自动发现 μ*>1 pid_l4_fopid_autotune.cpp + .md ✅ 已落成
L4.9 MIMO 解耦 + IAE 自动整定 ⭐ 多变量自动整定 复用 L4.7 解耦器 D=K⁻¹ 把 2×2 对角化，再对每回路用 L4.6 的 IAE 做 (Kp,Ki) 7×7 网格搜索；全系统 IAE 比统一 NOM 降 63%，交叉耦合仍被压到 ≈0；并揭示「IAE 单目标在稳定对象上无内点最优」 pid_l4_mimo_autotune.cpp + .md ✅ 已落成
L4.10 MIMO 解耦 + ITAE 自动整定 ⭐ 指标即偏好 把 L4.9 的目标 IAE 换成 ITAE 同台顺序整定；最优增益整体移向更温和（回路1 Kp 2.3→1.4、回路2 Ki 1.5→1.3）；ITAE 压低 20.5%、代价 IAE 仅升 3.2%，亲手验明「选哪个指标，最优就落哪」 pid_l4_mimo_itae_autotune.cpp + .md ✅ 已落成

二、目录结构约定（落地时遵循）

每个知识点的三件套：

  • **.cpp**：自包含、注释即讲解，含「合成被控对象 + 控制器/整定 + 真值对拍 + 打印 PASS/FAIL」。可 g++ -O3 -std=c++17 xxx.cpp -o x && ./x。
  • **.md**：完整教学，含 1–4 张内联 SVG 图（方框图、阶跃响应曲线、串级结构图、抗饱和对比图等）。
  • **_diagrams.html**：浏览器直接预览该知识点全部 SVG。
