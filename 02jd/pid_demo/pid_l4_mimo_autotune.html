L4 MIMO 解耦 + IAE 自动整定（per-loop autotune）

L4.7 MIMO PID 用静态解耦器 D=K(0)⁻¹ 把 2×2 对象在直流严格对角化，再给每个对角回路一个「手工固定」的 PID（Kp=1, Ki=0.5, Kd=0.2）。一个现实问题立刻冒出来：这两个回路的增益，到底该怎么定？ 本 demo 把 L4.8 的指标驱动寻优 思想套到 MIMO 上——解耦后，每个回路独立用 L4.6 的 IAE 指标 当「打分函数」，对 (Kp,Ki) 做网格搜索自动整定。

一、为什么不能只给一个「统一整定」

L4.7 已经证明：解耦后各回路可当 SISO 独立整定。但 L4.7 给两回路同一个 Kp=1, Ki=0.5, Kd=0.2——这是「拍脑袋」的折中：回路 1 时间常数 τ1=1、回路 2 时间常数 τ2=2，动态根本不同，同一组增益不可能同时最优。

二、核心：解耦 + 每回路 IAE 网格搜索

做法（裸且有效，适合教学与初版）：

为什么解耦后才能「逐回路独立整定」？因为 D·K=I 使直流严格对角化，回路间的稳态耦合被积分器消除、瞬态耦合被压到 ≈0（见 L4.7），于是整定回路 i 时可以把其它回路近似当扰动、独立优化。

三、代码走读（pid_l4_mimo_autotune.cpp）

  • 矩阵库 / inv / sim_mimo 与 L4.7 逐字一致（2×2 递推、D=inv(Kss) 预补偿、Kd=0.2 固定）。
  • sim_mimo 返回四条全程轨迹 y1,y2,e1,e2：既要回路误差算 IAE，也要 y2/y1 算交叉耦合峰值。
  • iae(e,dt)：离散 Σ|e|·h，来自 L4.6。
  • main 里两个 7×7 双层循环分别扫回路 1 / 回路 2，用 best1/best2 与 Kp?_opt/Ki?_opt 跟踪最小值；最后用自动增益重跑全系统。
  • 检验（chk）：自动 IAE < 固定 NOM IAE（两回路 + 全系统总和）；自动增益已偏离 NOM；两回路阶跃稳态 ≈1/≈0、瞬态交叉耦合峰值 <0.03。

四、你会看到什么（受管 Python 3.13.12 验证，全部 PASS）

对象 K=[[1,0.3],[0.5,1]]，τ1=1, τ2=2，dt=0.05, T=15，Kd=0.2 固定；NOM 增益 (Kp,Ki)=(1.0,0.5)：

回路 整定 (Kp,Ki) 该回路 IAE 相对 NOM
回路1（r=[1,0]） 固定 NOM (1.0, 0.5) 1.9816 基准
回路1（r=[1,0]） IAE 自动 (2.3, 1.5) 0.6666 −66.4%
回路2（r=[0,1]） 固定 NOM (1.0, 0.5) 2.0013 基准
回路2（r=[0,1]） IAE 自动 (2.3, 1.5) 0.8084 −59.6%
检查 结果
全系统 IAE 总和（固定 3.9828 → 自动 1.4750） PASS（−63.0%）
回路1 阶跃稳态 y1_ss≈1、交叉 y2_ss≈0 PASS（0.0000）
回路2 阶跃稳态 y2_ss≈1、交叉 y1_ss≈0 PASS（0.0000）
两回路瞬态交叉耦合峰值 <0.03 PASS（0.0000，仍被解耦压住）

关键结论：解耦后每回路用 IAE 独立整定，全系统 IAE 比统一 NOM 降 **63%**；且解耦器把交叉耦合压到 ≈0，自动整定只管「把自己这条回路调快」，不会把邻居带跑。

五、洞见：IAE 单目标在稳定对象上「无内点最优」

注意自动整定落到了网格的激进端 (Kp=2.3, Ki=1.5)——这不是偶然。IAE 只惩罚「误差有多大、持续多久」，对稳定对象而言增益越大响应越快、误差累计越小，于是无约束 IAE 会一路把增益顶到搜索窗边界（本 demo 两回路的有效对象都较良性，不超调，更助长这一现象）。

这恰是 L4.8「选哪个指标，最优就落哪」的孪生教训：IAE 偏向激进增益。工程整定不能只喂 IAE，必须加约束：

或干脆换指标——L4.6 的 ITAE（Σ k·h·|e|·h）给早期误差加权，最优会落到一个更「中庸」、更工程可行的点。本仓库的 IAE/ITAE 取舍在 L4.6、L4.8 已反复印证。

六、工程坑（真实）

  1. 整定回路时要冻结邻居：扫回路 1 时回路 2 固定 NOM（r=0），否则两条回路的积分器互相激励会让 IAE 评估失真。解耦保证了「冻结邻居 ≈ 只评自己」。
  2. IAE 无内点最优：如第五节，纯 IAE 会把增益顶到窗边界；demo 的「−63%」是「窗内最优」，不是「理论最优」。要工程可行整定须加约束或换 ITAE。
  3. 网格分辨率换精度：7×7 只给 0.3/0.2 步长最优；要更精可在盆地内加密。
  4. 解耦是前提：没解耦前直接逐回路 IAE 整定会「按下葫芦浮起瓢」——L4.7 已演示无解耦时交叉耦合峰值 0.1479，整定没法稳定收敛。本 demo 的 IAE 搜索建立在 L4.7 解耦之后。
  5. 无编译器确认：本机无 C++ 编译器，demo 用受管 Python 3.13.12 做算法验证（10/10 PASS），再逐字转写 C++17，并用 C++ 控制流镜像（12/12 PASS）兜底静态类型 bug。

七、自检

  • 把网格步长改成 0.1、范围扩到 [0,3]×[0,2]，看最优 (Kp,Ki) 是否继续外推（验证「IAE 顶边界」现象）。
  • 在 sim_mimo 里把 decouple 置 false 再扫：应发现无解耦时 IAE 搜索发散/互相牵制——亲手验证「解耦是逐回路整定的前提」。
  • 把目标函数从 iae 换成 itae（给早期误差加权），重扫看最优是否移向更温和的增益。

八、与 PID 家族的衔接

  • 上游：L4.7 MIMO PID（提供解耦器 D=K⁻¹ 与 2×2 仿真框架）；L4.6 IAE/ISE（提供打分函数）；L4.8 指标驱动寻优（本 demo 的方法论母版）。
  • 下游：自动整定可接模糊/增益调度——「按工况调增益」与「指标驱动寻优」是同一目标的两套实现（见 L4.5 模糊 PID）。
  • 指标即偏好验证：把本 demo 的 IAE 目标换成 ITAE 同台对比，最优增益整体移向更温和——见 L4.10 MIMO + ITAE 自动整定。
  • 跨仓同构：control_demo 的 L4.5 MIMO 解耦 用同一 D=K(0)⁻¹ 范式，本 demo 在其基础上加了「解耦后 IAE 自动整定」一层。
