L3.2 鲁棒与抗扰（扰动前馈 / 扰动观测器 DOB）⭐

增益整得再漂亮，现实里总有没建模的扰动——风、负载变化、摩擦。本篇看 PID 之外的两把抗扰武器：扰动前馈与扰动观测器（DOB），并验证它们真能把偏差压下去。

一、为什么 PID alone 不够抗扰

PID 的积分项最终能消除常值扰动的稳态误差——但它靠”误差慢慢累积”来补偿，期间系统会大幅偏离设定值、恢复也慢。对快变/大扰动，这个瞬态不可接受。

定量的说法：积分项的”顶扰动”速度受 Ki 限制，而 Ki 又受稳定边界（L2.4）限制——**”消除扰动”和”保持稳定”争抢同一个 Ki。扰动前馈/DOB 的哲学是：别等误差长大，直接测/估扰动并反向补偿**，把 Ki 从”抗扰”的重担里解放出来。

二、两把抗扰武器

同一 plant：x' = −x + u + d（d 为未知扰动，t1 时刻阶跃注入 d0）。

策略 做法 关键
① PID 仅 u = Kp·e + Ki∫e + Kd·de 只靠积分磨回，瞬态大
② 扰动前馈（已知 d） 额外 u_ff = −d 扰动被瞬时抵消，零偏差
③ DOB 估计 d_hat = LPF(x' + x − u)，再 u_ff = −d_hat 未知扰动也能估出并抵消

DOB 的物理直觉：把”实际加速度 x'“与”模型预测的加速度 −x+u“做差，多出来的就是扰动，低通平滑后即 d_hat。

DOB 的推导链（为什么 x’+x−u 是扰动）

τ 是观测器带宽：τ 大 → d_hat 平滑但滞后大（扰动补偿不及时）；τ 小 → 快但把噪声也当扰动（输出抖）。DOB 与 KF/观测器（control_demo L2.4）同源——都是”模型 + 修正”，DOB 用低通做修正、KF 用协方差最优修正。

三、代码走读（pid_l3_robust.cpp）

  • sim(cfg, dt, N, sp, d0, t1, Umax, dHatFinal)：统一闭环仿真，按 useFF / useDOB 切换策略。
  • 指标：peakDev（t1 之后的峰值偏差）、steadyErr（末值偏差）。
  • 对拍判据（扰动真值 d0 已知）：
    • peakFF < 0.2·peakPID —— 完美前馈几乎消除瞬态；
    • peakDOB < 0.6·peakPID —— DOB 显著优于裸 PID；
    • 三者稳态误差都 < 0.02；
    • DOB 估计 |d_hat − d0| < 0.1·d0 —— 观测器收敛到真值扰动（核心真值对拍）。

五、工程坑（真实）

  1. DOB 依赖模型精度：d_hat 公式里的 “−x+u” 是模型——模型错（比如惯性 J 标错 20%），d_hat 会系统性偏置（把模型误差当扰动补偿）。先校准模型再上 DOB。
  2. DOB 与执行器饱和打架：扰动大时 u_ff 可能推 u 进饱和——DOB 估计要随饱和状态冻结（同 L1.5 的 anti-windup 思想），否则饱和期间 d_hat 继续涨、退饱和跳变。
  3. 前馈只能补”已知/可测”扰动：测噪声的”前馈”（demo 自检里）退化成开环补偿，噪声进输出——可测但不可靠的信号宁可用 DOB。
  4. 双积分/柔性系统：DOB 假设对象可逆（x’ 与 u 直接关联）；对柔性/非最小相位对象，直接反演会放大高频——需要滤波整形。

六、自检

  • 把 d0 从 0.5 调到 1.0，看 PID 仅偏差如何翻倍、DOB 依旧收敛（鲁棒）。
  • 把 DOB 的 tau 从 0.3 调到 1.0（更慢的观测器），看 d_hat 滞后变大、瞬态抑制变弱——体会观测器带宽权衡。
  • 把 useFF 改成”测量有噪声的 d”，看前馈效果退化——引出为什么需要 DOB。
