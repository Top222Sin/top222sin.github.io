L4 FOPID λ/μ 自动寻优（IAE 指标驱动）

L4.4 分数阶 PID 把 λ,μ 两个阶次自由度打开后，一个现实问题立刻冒出来：这两个旋钮到底拧到哪？ 手工逐个试值既慢又靠运气。本 demo 用 L4.6 的 IAE 指标 当「打分函数」，对 (λ,μ) 做网格搜索，让电脑自己把最优整定找出来——整定自动化的一步。

一、为什么不能再手工试值

L4.4 已经证明 μ=1.2 比 μ=1 好，但那是「先拍脑袋猜一个、再验证」。分数阶 PID 的整定空间是 5 维（Kp/Ki/Kd + λ/μ），穷举靠人试不现实。自然想法：

做法（裸且有效，适合教学与初版）：

为什么用网格而不是梯度法？分数阶闭环对 (λ,μ) 非凸、且仿真代价高，粗网格先定位盆地，后续要更精可加细或换 Nelder-Mead。教学 demo 用网格最直观。

三、代码走读（pid_l4_fopid_autotune.cpp）

  • 复用 gl_weights / tustin_ss / sim_fopid：与 L4.4 逐字一致（GL 积分全历史、微分截断 Hd=400）。
  • iae(e,dt)：离散 Σ|e|·h，来自 L4.6。
  • main 里先算两个基准：整数 PID (1,1) 与手工 FOPID (1,1.2)（L4.4 的值）；
    再双层循环扫网格、用 best_iae / lam_opt / mu_opt 跟踪最小值。
  • 检验（chk）：自动 IAE 必须 **<** 整数 IAE、且 **≤** 手工 IAE（手工点本就在网格内）；并验证自动发现了 μ*>1（证明分数阶微分真有用，而非偶然）。

四、你会看到什么（受管 Python 3.13.12 验证，全部 PASS）

对象 G(s)=1/(s²+0.5s+1)，dt=0.02, T=20, r=1，Kp=1.6, Ki=0.9, Kd=0.9：

整定 (λ,μ) IAE 相对整数 PID
整数 PID (1.0, 1.0) 1.1228 基准
手工 FOPID (1.0, 1.2) 1.1105 −1.1%
自动寻优 (1.1, 1.3) 1.0645 −5.2%
检查 结果
优化 IAE < 整数 PID IAE PASS（1.0645 < 1.1228）
优化 IAE ≤ 手工 FOPID IAE（含该网格点） PASS（1.0645 ≤ 1.1105）
自动发现 μ*>1（分数阶微分确有用） PASS（μ*=1.3）
自动发现 0.7≤λ*≤1.3 PASS（λ*=1.1）
相对整数 PID 改善 >1% PASS（−5.2%）

关键结论：自动寻优找到 (λ*,μ*)=(1.1,1.3)，比整数 PID 降 **5.2%、比手工 FOPID 降 4.1% IAE，并且自动发现了 μ*>1**——独立印证了 L4.4「分数阶微分多给相位超前」的物理直觉。整定从「人拍脑袋」变成「指标驱动」。

五、洞见：选哪个指标，决定最优在哪

把目标函数换成 ITAE（Σ k·h·|e|·h，更惩罚尾差，见 L4.6）再扫一遍，最优 (λ,μ) 会不一样——本机复算显示 ITAE 视角下自动点 ITAE≈3.00 高于整数 PID 的 2.66。

原因：μ>1 加的微分在 t=0 有个「微分冲击」，抬高了早期 |e|；IAE 不区分早晚，ITAE 却重罚后期误差。这正说明 「用哪个指标打分，最优就落在哪」——呼应 L4.6 四种指标的不同取向。工程里常把 IAE/ITAE 组合成加权和，或按「允许初期超调 vs 要求快速归位」选指标。

六、工程坑（真实）

  1. 手工点要落在网格内：否则「自动 IAE ≤ 手工 IAE」这条例证可能不成立（自动只保证不差于网格内最优点）。本 demo 把 (1.0,1.2) 显式纳入网格。
  2. 指标即偏好：IAE 最优 ≠ ITAE 最优（见第五节）。选指标前先想清楚「要压超调还是压尾差」。
  3. 网格分辨率换精度：7×7 粗网格只给 0.1 步长最优；要更精可在盆地内加密或上 Nelder-Mead，但代价是更多次仿真。
  4. 无编译器确认：本机无 C++ 编译器，demo 用受管 Python 3.13.12 做算法验证（5/5 PASS），再逐字转写 C++17，并用 C++ 控制流镜像（5/5 PASS）兜底静态类型 bug。

七、自检

  • 把网格步长改成 0.05、范围扩到 [0.5,1.5]，看最优 (λ*,μ*) 是否移动（验证盆地位置）。
  • 把目标函数从 iae 换成 itae 再扫，打印最优并对比——亲手验证「指标决定最优」。

八、与 PID 家族的衔接

  • 上游：L4.4 分数阶 PID（开 λ/μ 自由度）；L4.6 IAE/ISE（提供打分函数）。
  • 下游：自动寻优可接 L4.5 模糊 PID——模糊规则本质也是「按工况调增益」，与「指标驱动寻优」是同一目标的两套实现。
  • 多变量版：L4.7 MIMO PID 解耦后每回路 IAE 寻优，已落地为 L4.9 MIMO 解耦 + IAE 自动整定；L4.9 把目标换 ITAE 同台对比，演示「指标即偏好」——见 L4.10 MIMO + ITAE 自动整定。
