L1.1 被控对象建模与离散化

控制的本质：先认识你要控的东西（plant），再设计控制器让它听话。
这一步不建模，后面所有 PID 调参都是”盲调”。

一、连续域里的被控对象

绝大多数执行机构都能用两个”积木”拼出来：

模型 传递函数 直觉
一阶惯性 G(s) = K / (T·s + 1) 有”惯性”：输入变了，输出慢慢跟上（T 越大越慢）
二阶振荡 G(s) = K·ω² / (s² + 2ζω·s + ω²) 会”过冲+振荡”：ζ 越小越振荡，ω 越大越快

其中：

  • K 是稳态增益（最终能到多少）；
  • T 是时间常数（多快到）；
  • ζ（阻尼比）决定超调，ω（自然频率）决定快慢。

本 demo 用一阶 K=1, T=1，单位阶跃 r(t)=1 激励，看输出怎么爬到 1。

二、从连续到离散（代码里只能积分离散量）

计算机跑的是差分方程。把 s 换成离散近似，就得到三种常见方法：

方法 替换 s ≈ 特点
前向欧拉 (z−1)/(dt) 简单，但刚性系统可能发散（非 A-stable）
后向欧拉 (z−1)/(dt·z) 恒稳定（A-stable），但相位滞后
Tustin（双线性） (2/dt)·(z−1)/(z+1) 保持稳定域映射（A-stable），存在频率扭曲，可预畸变补偿

本 demo 直接用闭式差分公式（推导见 pid_l1_plant.cpp）：

  • 前向：xₖ₊₁ = xₖ + dt·(−xₖ + K)/T
  • 后向：xₖ₊₁ = (xₖ + dt·K/T) / (1 + dt/T)
  • Tustin：xₖ₊₁ = ((2T/dt − 1)·xₖ + 2K) / (2T/dt + 1)

② 后向欧拉：用下一时刻导数近似 s·x ≈ (xₖ₊₁ − xₖ)/dt 但右侧取 k+1 时刻值：

③ Tustin（双线性）：用梯形积分（面积平均）近似导数，s = (2/dt)·(z−1)/(z+1) 等价于对状态方程两边做梯形离散：

关键差异的直觉：前向欧拉”看过去”（用 k 时刻斜率），后向”看未来”（用 k+1 时刻斜率），Tustin”取平均”（梯形面积）。dt 很小时三者几乎重合；dt 大时前向可能过冲发散（斜率估计超前于实际）、后向偏保守、Tustin 最忠实地保持稳定域映射。

输入假设说明：本文所有递推式在零阶保持（每个采样区间 u 保持 uₖ）下使用，故 Tustin 式中 uₖ₊₁ = uₖ。这是离散实现的常用约定，但严格说 Tustin 的梯形积分不天然等价 ZOH——需要时按实际输入策略调整。

三、代码走读（pid_l1_plant.cpp）

  • simTrue()：用 dt/20 的超细欧拉当”真值”基准。
  • simDiscrete()：三种方法各自的闭式递推，返回 0..N 的阶跃响应。
  • 指标：steadyState()（末值）、settlingTime()（进入 ±2% 带且不再出来的时间）。
  • 对拍：|稳态 − K| < 0.02 且相对真值最大形态偏差 < 0.05 才 PASS。

前向欧拉的稳定边界（为什么 dt/T<2 才稳）

一阶递推 xₖ₊₁ = (1 − dt/T)·xₖ + (dt/T)K·uₖ 的离散极点为 z = 1 − dt/T，稳定条件 |z|<1：

这就是”dt 太大前向欧拉会发散”的精确边界——自检里 T=1、dt=1.9 时 dt/T=1.9<2，前向欧拉交替过冲但不发散（表现夸张的折返）；真正发散要到 dt>2。

四、你会看到什么

三种离散化的阶跃响应几乎重合，且（在各离散模型稳定、输入为零阶保持的条件下）都收敛到 K=1——稳态值由 plant 的 DC 增益决定。差别主要体现在”大 dt、刚性系统”时的瞬态与稳定边界，那才是选方法的分水岭（L2.4 离散稳定性会专门讲）。

五、工程坑（真实）

  1. 零阶保持（ZOH）的隐藏假设：离散化默认 u 在两个采样点间保持常量——真实系统用 PWM/DAC 输出正是这样，但若执行器有自身动态（电机电感、液压伺服），ZOH 假设就不够，需把执行器动态并进 plant 模型。
  2. Tustin 的频率扭曲：Tustin 把连续频率轴非线性压缩（预畸变），高频处闭环特性会偏离连续设计——设计截止频率时要按 ω_digital = (2/dt)·tan(ω_c·dt/2) 预畸变补偿。
  3. dt 选择的两难：dt 小 → 离散误差小但计算量/噪声敏感度上升；dt 大 → 省算力但相位滞后大。经验规则：采样率取闭环带宽的 20~50 倍（control_demo L2.1 的采样保持滞后 φ≈−ω·dt/2 是理论依据）。

六、自检

  • 把 T 改成 0.1（更快的 plant），看调节时间如何缩短。
  • 把 dt 改到 1.9（接近临界），前向欧拉会开始明显偏离真值——体会”离散化不是免费的”。
  • 想看二阶振荡？把 simDiscrete 里的递推换成二阶状态方程（本 demo 注释里给了思路）。
