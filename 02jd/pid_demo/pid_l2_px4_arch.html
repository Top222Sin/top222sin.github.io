L2.3 多旋翼 PID 架构解析（PX4 代码走读）⭐

前面学的 PID “零件”，在 PX4 飞控里是怎么拼起来的？这一篇把真实代码搬进纯 C++ 跑一遍。

一、PX4 角速率控制律（真实形态）

来自 src/lib/rate_control/rate_control.cpp（update() L71）+ mc_rate_control/MulticopterRateControl.cpp：

结构要点：

  • _gain_p/_gain_i/_gain_d/_gain_ff 是直接使用的各轴增益向量（三轴 Vector3f，hpp L127-129 可见 _gain_p/_gain_d），由参数 MC_ROLLRATE_P/I/D/FF 等直接装载——没有额外的统一缩放 K（某些 PX4 版本/派生固件有 MC_ROLLRATE_K 总增益，但非当前主线的通用事实，需按版本确认）。
  • D 项 −_gain_d.emult(angular_accel) 直接作用在角加速度（上游估计/传感器链路产生，通常由角速度微分+滤波得到）——本质是 derivative-on-measurement，且角加速度本身已带滤波（L2.2 思想）。
  • FF：前馈（MC_ROLLRATE_FF），直接把设定值”预支”进输出。
  • 抗饱和：setSaturationStatus()（hpp L78 / cpp L50）→ updateIntegral()（cpp L88）——按饱和方向门控误差的条件积分（误差若推动控制量退出饱和才继续积分，否则冻结），属 conditional integration / integrator limiting，不是标准 back-calculation（back-calculation 需 İ=Ki·e+Kaw·(u_sat−u) 回算项，RateControl 无此结构）。

二、本 demo 验证的三件事

# 验证 对应代码 结论
① 形式等价 setPidGains(K·P, K·I, K·D) Kp=K·P, Ki=K·I, Kd=K·D 时与经典 PID 逐拍一致（<1e-9）
② 前馈有效 + FF·rate_sp 有 FF 时跟踪 RMS 更小（设定值立刻补进输出）
③ 抗饱和 setSaturationStatus→冻结积分 条件积分把 windup 超调压下去

三、代码走读（pid_l2_px4_arch.cpp）

  • simPx4(cfg, tau, sp, aw)：复刻上面的并行式 + 前馈 + 条件积分，一阶角速率 plant。
  • simClassic(Kp,Ki,Kd,...)：经典位置式 PID（用来对拍 ①）。
  • ① 等价性：maxDiff(yPx4, yClassic) < 1e-9；② FF：rmsErr(FF) < rmsErr(noFF)；③ 抗饱和：oNoAW > oAW + 0.1 且 oAW < 0.4。

四、串级全景（呼应 L2.1）

PX4 完整链路比”位置→速度→角速率”多一层姿态控制：PositionControl::update() 出加速度/推力设定 → mc_att_control（姿态控制器）生成姿态/角速度设定 → mc_rate_control 收速率设定 → RateControl 出扭矩。本 demo 聚焦”位置→速度→速率”的教学抽象，省略了姿态环（control_demo L3.3 与 quaternion 文档专门讲姿态层）——不是完整 PX4 链路。

五、自检

  • 把 K 改成 2.0，看经典 PID 的 Kp/Ki/Kd 需同步 ×2 才等价——体会”并行式用 K 统一缩放”。
  • 把 FF 调到 0.3，看跟踪滞后进一步缩小（前馈越强越跟手，但别过冲）。
  • 把 cW.I 调到 4.0，看无抗饱和时 windup 如何更夸张。
