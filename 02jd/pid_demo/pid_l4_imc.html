L4 IMC / λ 整定（Internal Model Control）——一个旋钮设定闭环带宽

Ziegler-Nichols 整定靠”把系统激到临界振荡”反推增益，结果往往过冲、过激，而且你说不清到底调出了多快的响应。IMC（内模控制）换了个思路：从对象模型直接反推控制器，闭式给出一个唯一旋钮 λ——它直接等于闭环时间常数。想要多快，设 λ 就行；想要多稳，把 λ 调大。可解释、可设带宽、鲁棒性一目了然。

一、为什么 Z-N 不够”工程化”

Z-N 给的是”临界附近”的经验公式，两个问题：

  1. 要先把系统搞到临界振荡才能测 Ku/Pu——在线做有风险，离线又依赖模型。
  2. 整定结果激进（尤其 PID 型），超调大，且你无法直观说”这个增益对应多快的响应”。

IMC 直接从模型出发，把”想要多快”变成一个显式参数。

二、IMC 推导（一阶对象）

对象 Gp(s) = K / (T s + 1)。IMC 控制器 = “可逆对象” × “低通滤波器 F”：

  • 1/(λs+1) 是滤波器，λ 是唯一调参旋钮（一阶对象用一个就够了）。
  • Gp⁻¹ 把对象”抵消”掉（这就是内模控制的核心：模型匹配时，控制器与对象互逆）。

三、代码走读（pid_l4_imc.cpp）

  • imc(λ)：直接按公式给 Kc=T/(Kλ), Ki=1/(Kλ)。
  • simPI：标准 PI 闭环仿真一阶对象。
  • 验证：TC ≈ λ（测调节时间应 ≈ 3.912λ）、λ 单调可调、增益失配下仍零稳态误差且 TC 变为 λ/K_actual。

四、你会看到什么（已用受管 Python 3.13.12 验证，全部 PASS）

对象 K=1, T=2，dt=0.02, T=25s，IMC 增益 Kc=2/λ, Ki=1/λ：

λ 调节时间(仿真) 理论 3.912λ 末值(稳态误差)
1.0 3.92 s 3.91 1.0000 (≈0)
2.0 7.88 s 7.82 0.9999 (≈0)
4.0 15.70 s 15.65 0.9931 (≈0)
  • 增益公式校验：Kc=T/(Kλ), Ki=1/(Kλ) ✅ 精确成立。
  • λ↑ ⇒ 调节时间↑（3.92 → 15.70，单调），完全可预测——λ 就是带宽旋钮。
  • 鲁棒性：对象增益失配（K_actual=1.5，模型 K=1）时，闭环仍零稳态误差，有效时间常数 = λ/K_actual = 2/1.5 = 1.33s（实测调节 5.24s ≈ 3.912×1.33=5.22s）。

五、与 PID 家族的衔接

  • 对比 L1.4 整定直觉：Z-N 的 Ku/Pu 是”临界振荡反推”，IMC 的 Kc=T/(Kλ) 是”模型正推”，后者直接挂钩 λ=期望 TC。
  • 对比 L4 Smith 预估器：Smith 处理大纯滞后，IMC 处理”基于模型设定带宽”；两者都基于模型，且 IMC 结构本身就是 Smith 在延时对象上的推广框架。
  • 对比 L4 ADRC：ADRC 走”估计扰动并抵消”（模型无关），IMC 走”用精确模型反推控制器”（模型相关）——代表了鲁棒控制的两条路线。

六、工程坑（真实）

  1. λ 太小 = 激进 = 对模型误差敏感：λ 小 → Kc 大 → 闭环快，但一旦模型不准（K/T 估错），大增益会把误差放大。λ 大则保守、稳。
  2. 滤波器阶数：一阶对象用一阶滤波器 1/(λs+1) 足够；高阶/带滞后对象要给 1/(λs+1)^r（r 使控制器真分式），否则 C_imc 物理不可实现。
  3. 模型失配不致命但改变 TC：IMC 的妙处是”即使模型错，闭环仍稳定且零稳态误差”，只是 TC 变成 λ·(K_model/K_actual)——你可以靠 λ 把带宽调到安全区。
  4. 和 Smith 是亲戚：IMC 框架里把对象写成 Gm(s)·e^{−Ls}，滤波器前放一个”无滞后模型的 Smith 预估”，就是 IMC 版的 Smith 预估器。

七、自检

  • 把 λ 从 2 改成 0.5，看调节时间缩短到约 2s，但把对象 K 故意错配成 1.5，对比 λ=0.5 与 λ=4 谁更”扛造”。
  • 把对象从一阶换成带小滞后 e^{−0.3s}，用仍按一阶 IMC 整定的增益，看响应是否仍稳（验证”模型不精确仍 OK”）。
  • 把滤波器阶数意识带入：思考若对象是二阶 K/((T1s+1)(T2s+1))，C_imc 该配几阶滤波器才真分式。

八、下一步

回到 L4 ADRC 自抗扰：同样追求”强抗扰”，ADRC 走模型无关路线，IMC 走模型精确路线——对照着看，鲁棒控制的两条腿就齐了。
