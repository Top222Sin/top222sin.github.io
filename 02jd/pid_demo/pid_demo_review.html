一、确定性错误（❌ 建议修正）

E1. ❌ pid_l1_plant.md —— 离散化表”前向/后向欧拉”的 s 替换式写反

位置：pid_l1_plant.md 第 38–40 行表格。

错误内容：

方法 md 表格写的 s≈ 标准正确形式
前向欧拉 (z−1)/(dt·z) (z−1)/dt
后向欧拉 (z−1)/dt (z−1)/(dt·z)
Tustin (2/dt)(z−1)/(z+1) ✅ (2/dt)(z−1)/(z+1) ✅

证据：a) 标准定义：前向欧拉 dx/dt ≈ (x_{k+1}−x_k)/dt → s↔(z−1)/dt；后向欧拉 dx/dt ≈ (x_k−x_{k−1})/dt → s↔(z−1)/(dt·z)。b) 同一 md 自己的递推公式（第 43–45 行）与前向/后向标签一致：前向 x_{k+1}=x_k+dt·(−x_k+K)/T 是标准的 forward Euler（导数在 k 点），后向 x_{k+1}=(x_k+dt·K/T)/(1+dt/T) 是标准 backward Euler（导数在 k+1 点）——表格与递推公式自相矛盾。c) pid_l1_plant.cpp 第 32–41 行的实现也证实了正确顺序。

影响：学习者照表格记”前向=(z−1)/(dt·z)”会得到与代码、与标准定义都相反的记忆。建议对调表格两行（并相应调换”特点”列的描述归属）。

二、轻微问题（⚠️ 建议修正）

W1. ⚠️ pid_l3_autotune.md（及 pid_l3_pipeline.md 同款）—— FOPDT “解析真值”实为近似解

第 48–51 行把 ωu = π/(2L)、Ku_true = √(1+(ωu·T)²)/K、Pu_true = 4L 表述为”临界点的解析解已知“。实际上 relay 自激振荡的精确条件是 ωu·L + atan(ωu·T) = π；ωu = π/(2L) 是假设 atan(ωu·T)≈π/2（即 T 远大于 L 的”积分主导”极限）下的近似，对一般 FOPDT（T 与 L 同量级）会有偏差。demo 用 15% 容差对拍能过，说明所选 plant 落在近似适用域，但”解析解”表述易误导。Ku = 4d/(πa)（Åström-Hägglund 描述函数）本身是标准公式，无误。

建议：改述为”描述函数近似解（ωu·L+atan(ωu·T)=π 的近似）”并注明适用条件。

E1 复核（成立 ✅）

  • 标准定义核验：前向欧拉 dx/dt≈(xₖ₊₁−xₖ)/dt（导数在 k 点）→ s↔**(z−1)/dt；后向欧拉 dx/dt≈(xₖ−xₖ₋₁)/dt（导数在 k+1 点）→ s↔(z−1)/(dt·z)**。md 表格把两者对调，确属写反。
  • md 内部矛盾：第 43–44 行递推公式（前向 xₖ₊₁=xₖ+dt·(−xₖ+K)/T、后向 xₖ₊₁=(xₖ+dt·K/T)/(1+dt/T)）与 cpp 第 34/37 行实现都正确，唯独表格与二者矛盾。
  • 特点列无需动：前向”可能发散”（非 A-stable）、后向”A-stable”的描述本就正确，只需对调 s 替换式。
  • 修复：pid_l1_plant.md 表格对调 s 替换式，特点列保持。图片/HTML 经 grep 确认不含前向/后向的 s 替换式文字，无需改图。

W1 复核（成立 ✅，且比 review 描述更严重）

  • 精确条件推导：FOPDT G(s)=K·e^{-Ls}/(Ts+1) 在 relay 反馈下，描述函数法给出相位条件 arg G(jωu) = -π，即 ωu·L + atan(ωu·T) = π（精确）。ωu=π/(2L) 是假设 atan(ωu·T)→π/2（即 T≫L 积分主导极限）的近似。

  • Python 数值求根（受管 venv）量化了近似偏差：

    plant T/L ωu 精确 vs 近似 Pu 精确 vs 近似(4L) Ku 精确 vs 近似 cpp 容差

    pipeline (K=1,T=τ,L=τ) 1 20.29 vs 15.71 (−22.6%) 0.31 vs 0.40 (+29.2%) 2.26 vs 1.86 (−17.7%) 30%

  • 关键发现：两处 plant 的 T/L 均不满足 T≫L，近似偏差本身就达 12–29%，已接近或超过 cpp 对拍容差。review 说”落在近似适用域”偏乐观——实际是”近似偏差刚好被容差放过”。这意味着 cpp 把近似值当”真值”对拍，名不副实：relay 仿真用的是精确 FOPDT 模型，其估计应接近精确真值，对拍近似真值时偏差被近似误差主导，而非 relay 算法误差。

  • 修复（范围比 review 大）：

    1. pid_l3_autotune.md：改述”解析解已知”→精确相位条件 ωu·L+atan(ωu·T)=π + 近似适用域说明 + 精确数值
    2. pid_l3_autotune.cpp：注释诚实化 + 真值计算升级为二分求根（ωu·L+atan(ωu·T)=π，单调递增收敛）+ cout 文字”解析真值”→”精确真值”

8.3 可复用范式沉淀

  • GL 积分必须全历史：分数阶积分权重衰减极慢，截断即丢积分器；微分可截断（权重速衰）。
  • 耦合断言要区分稳态/瞬态：有积分器时稳态交叉耦合被本路积分消除，解耦器价值在抑制瞬态耦合——断言对象必须选对。
  • 无编译器兜底：C++ 控制流镜像（逐字复刻 cpp 逻辑的 Python 镜像）能在无 g++ 时兜底静态类型/控制流 bug（L4.4–L4.7 确认 24/24、L4.9 确认 12/12、L4.10 确认 11/11 无 B-class 错误）。
  • IAE 单目标在稳定对象上无内点最优：对良态稳定对象，增益越大响应越快、IAE 越小，纯 IAE 网格搜索会把增益顶到搜索窗激进端（L4.9 优调落在 (2.3,1.5) 窗边界）。工程整定须加超调/调节时间/|u| 约束，或换 ITAE（早期误差加权→更中庸最优）。此坑与 memory §三「不等式 chk 方向坑」、L4.8「指标决定最优」同源，属「指标即偏好」家族。
