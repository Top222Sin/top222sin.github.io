L1.5 手眼标定（眼在手上 / 眼在手外）

手眼标定是”视觉 → 动作”的桥梁：求相机系与机械臂系之间那个固定不变的刚体变换 X。

一、两种安装方式

安装 X 的含义 典型场景
眼在手上（eye-in-hand） cam2gripper（相机装在法兰上） 装配、抓取，相机随臂动
眼在手外（eye-to-hand） cam2base（相机固定看工位） 固定工位视觉、引导机器人取放

两种安装的工程取舍（面试高频）

核心差异：X 是”相机↔法兰”还是”相机↔基座”——决定了数据配对的数学方向（第三节）。

二、统一方程 AX = XB

记 A = 法兰在基座下的相对运动，B = 标定板在相机下的相对运动，X 是待求固定变换。核心方程：

  • 旋转部分：R_A · R_X = R_X · R_B（R_A 与 R_B 通过 R_X 共轭——不是普通交换；用单位四元数把”左乘/右乘”线性化为矩阵方程 SVD 解 R_X）

术语澄清：手眼标定旋转求解的常用方法——Park–Martin（旋转轴/矩阵对数 + 平移线性最小二乘）、Tsai–Lenz（两步法，轴角推导）、Daniilidis（真正的对偶四元数法）。本 demo 实现的是 Park–Martin 式单位四元数分离求解（先解旋转 qX，再线性解平移），不是对偶四元数法——文档早期误称”对偶四元数”，已修正。

本 demo 自实现 Park–Martin 式单位四元数法（注意：是单位四元数分离求解，非 Daniilidis 对偶四元数——术语见下方”旋转部分”注记）：把每对相对运动的旋转写成 S(qA)·qX = W(qB)·qX（S/W 是四元数左乘/右乘矩阵），堆叠成 (S(qA)-W(qB))·qX = 0，SVD 取最小奇异向量得 qX；再用线性系统 (R_A - I)·t_X = R_X·t_B - t_A 解平移。

AX=XB 的推导（为什么是”相对运动”方程）

核心洞察：X 是固定变换，所以在任意两个时刻之间”穿过”它应自洽——A·X=X·B 是”相对运动在 X 下可交换”的代数表达。为什么能闭式解：旋转部分 R_A·R_X=R_X·R_B 是一个”共轭”方程，用对偶四元数把”左乘/右乘”都线性化成矩阵，SVD 一步出解（L2.2 展开）。

三、关键：眼外 / 眼手的 A、B 方向恰好相反

这是新手最容易踩的坑，也是很多代码”跑出来差一个对称”的根源。

A（法兰相对运动） B（板相对运动）
眼在手上 G_i⁻¹·G_{i+1} T_i·T_{i+1}⁻¹
眼在手外 G_{i+1}·G_i⁻¹ T_{i+1}·T_i⁻¹

代码里两个分支用完全一致的 solveHandEye()，只换了相对运动的”配对方向”。

为什么方向相反（眼外推导）

记忆口诀：”眼在手上 A 用逆前（G_i⁻¹G_{i+1}），眼在手外 A 用顺后（G_{i+1}G_i⁻¹）”——A 的方向决定 B 跟着反。写代码前先画坐标链图，别硬记。

四、数据怎么采

每个采集位姿同时记录：

  • T_gripper2base：机械臂正运动学（读关节角 → FK）
  • T_target2cam：相机拍标定板 + 内参 + solvePnP

多组（≥10，姿态多样）喂给求解器。

采集质量要求（为什么 ≥10 且多样）

工程铁律：手眼标定的成败 70% 在采集——运动多样、板可见、帧干净（L2.3/L3.2 分别讲退化与坏帧处理）。

五、代码走读（cali_l1_handeye.cpp）

  • 合成真值 X，反推各 T（无需真机），分别造眼外/眼手两套数据。
  • solveHandEye() 自实现 Park–Martin；与 OpenCV calibrateHandEye(TSAI) 交叉验证（眼在手分支）。
  • 用 X_gt⁻¹·X_est 应≈单位阵，报告**旋转误差(°) + 平移误差(mm)**；均 < 阈值 → PASS。

六、工程落点（真实项目）

  • OpenCV cv::calibrateHandEye：支持 TSAI/PARK/HORAUD/ANDREFF 四种方法——本 demo 自实现 Park–Martin 与它交叉对拍。
  • easy_handeye（ROS）：工业级手眼标定包——采集 + 求解 + 发布 tf 全自动，内置退化检查（L2.3 的工程化）。
  • Halcon calibrate_hand_eye：机器视觉行业标准工具。
  • 与 08robot：UR5e + 末端相机的”视觉引导抓取”必须先做 eye-in-hand 标定——T_cam2gripper 就是这里的 X。

七、自检

  • 把位姿数 N 从 14 降到 3，看误差是否暴涨（体会”样本要多”）。
  • 把运动改成”只平移不旋转”，看求解是否退化（预告 L2.3 退化主题）。
  • 挑战：AX=XB 的解为什么”不唯一”？（X 的整体任意性来自相对运动方程——固定第一个姿态的坐标即可；这解释了为什么标定结果依赖参考系选择）
