双目标定（Stereo）· 深入：立体校正 + 极线对齐 + 视差→深度

上篇 L1 双目基础 求出了相对位姿 R,T。本篇走完双目的”最后一公里”：把极线拉平、做立体匹配的前置——立体校正，并用它把视差变成深度。

一、为什么要立体校正（Rectification）

标定只给了 R,T。但原始左右图像里，同一个空间点的对应像素并不在同一行，极线是斜的——立体匹配得在 2D 里搜，计算量大且易错。

立体校正用 stereoRectify 求出两路旋转 R1,R2，把两个图像平面扭到共面且行对齐：校正后 x_L 与 x_R 必落在同一行（水平极线）。匹配从”二维搜索”降成”沿同一行一维搜”，这才是 SGBM/BM 能实时跑的前提。

本 demo 的硬指标：校正后同一 3D 点的两图 y 坐标差（垂直视差）≈ 0（< 0.01 px）。

校正的几何（怎么把斜极线拉平）

核心洞察：校正不移动光心（保持三角几何），只”旋转像平面”——所以校正后的像素对应仍然有效，且极线变水平。这是”计算上便宜”的变换（一次重映射），却把匹配从 2D 搜索降为 1D。

二、视差 → 深度

校正后两相机光轴平行、焦距 f、基线 B。对深度为 Z 的点，左右图像上的视差：

  • 视差越大 → 越近；视差趋近 0 → 无穷远。
  • 深度误差来自视差测量误差 σ_d：σ_Z ≈ Z²·σ_d / (f·B)。

由此得到两条工程铁律（本 demo 用合成数据量化）：

退化 后果 直觉
基线 B 过小 同样 σ_d 下 σ_Z 剧增 双目”看得远”靠大基线换视差
标定 R,T 有误差 校正失败、垂直视差变大 极线不再行对齐 → 一维匹配失配

深度误差公式的推导（为什么 σ_Z ∝ Z²）

三条推论（背下来）：

  1. 距离越远误差平方级放大——10m 处深度误差是 1m 处的 100 倍（同样 σ_d）；
  2. 基线越大误差越小——B 翻倍 σ_Z 减半（但视野/体积代价）；
  3. σ_d 固定时 f 大误差小——高分辨率/长焦相机深度更准。

三、代码走读（cali_l2_stereo_rect.cpp）

  1. makeRig 造一个 rig 真值（K_L,K_R, R,T, 基线 B=0.12 m）。
  2. stereoRectify(KL,dL,KR,dR,img,R,T,...) → 校正旋转 R1,R2 与投影矩阵 P1,P2、视差→深度矩阵 Q。
  3. 在左相机坐标系下取 40 个 3D 点，用 P1,P2 投影：
    • 垂直视差 |v1−v2| 应 ≈ 0（极线对齐）；
    • 深度 Z_est = f·B/d 与真值 Z 比对，相对误差应 < 5%。
  4. 退化①：把基线缩到 3 cm 重校，深度相对误差显著变大——印证”小基线→深度误差大”。
  5. 退化②：给 T 注入 5% 误差再校，垂直视差立刻涨起来——印证”标定误差→校正失效→匹配崩”。
  6. 健康指标达标才 PASS。

深度反解（本 demo 用的公式路径）

工程细节：OpenCV 的 Q 矩阵把”视差→3D 齐次坐标”一步完成（含主点/基线的全部内化）——reprojectImageTo3D 就是用它。手算 Z=f·B/d 与 Q 等价，但 Q 更完整（处理主点偏移）。

四、与单目标定的闭环

整条双目链路是：

内参不准 → 双目发散；R,T 不准 → 校正失效；基线选错 → 深度误差爆炸。三者任何一环出问题，双目测距都会崩——所以单目、双目基础、校正三篇要连起来看。

五、工程落点（真实项目）

  • OpenCV stereoRectify / reprojectImageTo3D / StereoSGBM——本 demo 的校正+深度就是这些接口的数学。
  • **ROS stereo_image_proc**：stereo/rectify + stereo/disparity + stereo/point_cloud2——加载标定 yaml 实时产出校正图/视差/点云。
  • 深度相机（RealSense/ZED）：出厂即做双目标定+校正（ZED 还做”立体校准在线重标”）。
  • 视觉抓取/避障：双目测距的深度误差按 Z² 放大——远目标（>5m）双目精度不足，这是”为什么补激光雷达”的量化理由。

六、下一步
