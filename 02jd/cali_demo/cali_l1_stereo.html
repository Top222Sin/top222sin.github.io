双目标定（Stereo）· 基础：求两相机相对位姿

单目标定（cali_l1_monocular / L1.3）只标定”一个相机”。双目视觉要进一步知道 左→右相机的相对位姿 R,T，把两幅图对齐到同一坐标系，才能做立体匹配与测距。本篇是双目标定的第一站。

一、双目标定要算什么

给定两个已各自单目标定的相机（K_L、K_R、畸变已知），双目标定的目标是估计：

  • R：3×3 旋转，把左相机坐标系旋到右相机坐标系；
  • T：平移向量，‖T‖ 就是两光心间距——基线长度 B；
  • 对水平排列的双目，理想情况下 T 主要由 T_x 贡献（参见 guide 的”基线方向检查”）。

双目标定的自由度（为什么需要同步对）

关键：双目标定必须同一时刻左右各拍一张（同步对）——非同步 = 板移动了两帧之间，对应关系就废了（这也是为什么双目标定要用”硬件同步触发”）。

二、与单目标定的边界

维度 单目标定 双目标定
输入 单相机多姿态图 同一时刻左右相机各一张（同步对）
输出 K + 畸变（+各图外参） R, T（相对位姿）+ E/F（本征/基础矩阵）
关键约束 共面单应 + 旋转正交 极线约束 + 基线一致性
用途 去畸变、PnP 前置 立体匹配、视差→深度、三维重建

工程经验（见根目录 guide §9）：先各自单目标定、再用 CALIB_FIX_INTRINSIC 固定内参做双目标定。联合优化自由度太多，内参一不稳双目就发散。本 demo 正是这么做的。

为什么固定内参（自由度爆炸的教训）

工程铁律：先单目、后双目、双目时 CALIB_FIX_INTRINSIC——这是 OpenCV 官方推荐也是行业惯例（内参不稳时双目发散是经典翻车现场）。

基础矩阵 F 的推导（为什么是 x_RᵀFx_L=0）

核心洞察：极线约束是”两相机共享同一 3D 点”的几何必然——R,T 定了，F 就定了，任意对应点必须满足这个双线性约束（x_RᵀFx_L 对 x_L 线性、对 x_R 线性，不是二次曲线约束）。立体匹配（SGBM/BM）沿极线一维搜索正是靠它（L2.6 校正后极线变水平线）。注意：E=[t]^R 用归一化坐标、F=K_R⁻ᵀEK_L⁻¹ 用像素坐标——两者不能混用。

四、代码走读（cali_l1_stereo.cpp）

  1. 合成 rig：真值 K_L,K_R、真值相对位姿 Rgt,Tgt（基线 B=0.12 m，两相机间 ~15° 偏航让 R 非平凡）。
  2. 对第 i 张图随机取左相机外参 (rl,tl)；右相机外参由 Rr=Rgt·Rl、tr=Rgt·tl+Tgt 推出——保证左右看到同一块板。
  3. projectPoints 分别投到左右，加 0.5 px 噪声得 vL,vR。
  4. stereoCalibrate(..., CALIB_FIX_INTRINSIC, ...) 固定内参、反估 R,T，同时得 E,F。
  5. 对拍：
    • 旋转角差 ang = arccos((trace(R_est·R_gtᵀ)-1)/2) 应 < 2°；
    • 平移相对误差 ‖T_est−T_gt‖/‖T_gt‖ 应 < 5%；
    • 三角化一致性：用估计的 R,T 重建 P1,P2，三角化第 0 张图点云再投回左右，重投影 RMS 应 ≈ 噪声（极线几何闭环）。
  6. 全满足才 PASS。

旋转角差的公式来源（为何 arccos(trace/2−1)）

工程细节：旋转误差用”转角”度量（直观、单位 °），平移误差用”相对误差”（消除基线尺度影响）——这是标定验收的标准度量（L2.5 误差校验继续用）。

五、常见坑（来自 guide §9.2）

  • 双目重投影误差发散 → 多半是内参不稳，先固定内参（本 demo 已用 CALIB_FIX_INTRINSIC）。
  • T 方向与物理安装不符 → 标完检查 T 是否 T_x 主导（水平基线）。

六、工程落点（真实项目）

  • OpenCV cv::stereoCalibrate / cv::stereoRectify：双目标定+校正的标准实现（本 demo 全部用到）。
  • **ROS stereo_image_proc**：加载双目标定 yaml 后实时校正+视差——camera_info 里的 P1/P2/Q 就是 stereoRectify 产物。
  • 深度相机：Intel RealSense / ZED 出厂标定即双目 R,T——用户可重标（漂移后）。
  • 与 08robot：若机器人视觉用双目测距，T_left2right 是”视差→深度”（L2.6）的前置输入。

七、下一步
