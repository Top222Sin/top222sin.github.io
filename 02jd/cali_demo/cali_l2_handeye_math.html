L2.2 手眼数学：AX=XB 的求解

L1.5 直接用了”一个求解器”。L2.2 把它拆开：两种经典闭式解 + 非线性精化，看清每一步在算什么。

一、旋转部分：为什么可交换给了机会

A·X = X·B 中，旋转满足 R_A·R_X = R_X·R_B。因为 R_X 同时出现在左乘和右乘，可以”消”出一个仅关于 R_X 的线性方程——这是手眼标定能闭式求解的根本。

可交换性的代数结构（为什么 SVD 能解）

核心洞察：AX=XB 的旋转部分 = “两组相对旋转的轴-角配对“——每对运动提供一个”轴对齐”约束，多对堆叠后 R_X 被唯一确定。对偶四元数/四元数法把”共轭”线性化为矩阵乘法（S(qA)·qX = W(qB)·qX），SVD 一步求解——这是它能闭式解的数学本质。

二、两种闭式解

方法 旋转怎么解 平移怎么解 特点
Park–Martin（L1.5 用） 旋转轴/矩阵对数 + 单位四元数堆叠 (S(qA)-W(qB))·qX=0，SVD 取最小奇异向量（仅旋转部分；平移另解） (R_A-I)·t_X = R_X·t_B - t_A 线性解 数值稳，最常用
Tsai–Lenz 两步法 两步分离：先轴角闭式解旋转，再线性解平移（与 OpenCV TSAI 对应） 同上线性方程 经典、直观、两步清晰
Daniilidis 对偶四元数（实部+对偶部 8 维，含 Study 条件约束） 一步整体求解 完整但对偶约束实现复杂

术语修正：L1.5 早期称”Park–Martin 对偶四元数”有误——Park–Martin 是旋转轴/单位四元数分离求解，对偶四元数法（Daniilidis）是另一种方法。本 demo 两种都实现（solvePM/solveTsai），OpenCV 的 TSAI/PARK 是不同算法枚举。

本 demo 把两者都实现，并在同一带噪数据上对照，结果应高度一致（不一致说明实现有 bug）。

平移部分的推导（旋转解出后线性解）

关键：平移方程 (R_A−I) 的秩 = 旋转自由度——纯旋转绕单轴时秩亏（这正是 L2.3 的”仅绕单轴退化”）。旋转多样性不足 → 平移也解不出来——旋转与平移的退化是绑定的。

三、非线性精化（Gauss–Newton）

闭式解对噪声敏感。以 6 维位姿参数 (rvec, t) 描述 X，最小化

从闭式解出发做高斯–牛顿（数值雅可比即可），误差通常再降一截。本 demo 用数值雅可比实现，验证”精化后 ≤ 闭式”。

为什么精化有效（闭式 vs 优化的分工）

工程结论：生产流程 = 闭式解初值 + GN/LM 精化（OpenCV calibrateHandEye 内部同样推荐后续优化）。这是”两阶段估计”的经典模式（L2.5 的误差校验里会验证精化后的改善）。

四、眼外 / 眼手的数学差异（再次强调）

两者解的是**同一个 A·X=X·B**，唯一区别是相对运动 (A,B) 的配对方向：

  • 眼在手上：A = G_i⁻¹·G_{i+1}，B = T_i·T_{i+1}⁻¹
  • 眼在手外：A = G_{i+1}·G_i⁻¹，B = T_{i+1}·T_i⁻¹

数据按此生成，同一 solveHandEye 即可两用（见 L1.5）。

五、代码走读（cali_l2_handeye_math.cpp）

  • solvePM / solveTsai 两种闭式解；refineGN 数值雅可比高斯–牛顿。
  • 造带噪眼在手数据 → 四种结果（PM / Tsai / GN / OpenCV）→ 误差对照。
  • 断言：三种自实现方法旋转误差 <1°、平移 <2 cm，且精化不差于闭式。

六、工程落点（真实项目）

  • OpenCV cv::calibrateHandEye（TSAI/PARK/HORAUD/ANDREFF）+ cv::optimizeHandEye（GN 精化）——本 demo 自实现与之对照。
  • easy_handeye：ROS 手眼标定包内部就是”闭式 + 精化”两阶段。
  • Halcon calibrate_hand_eye：同样提供多方法 + 优化精化。
  • 视觉引导机器人产线：手眼 X 精度直接决定抓取/装配的定位精度——精化这一步在量产里是必做的。

七、自检

  • 把噪声从 0.5 mm 加到 5 mm，看闭式 vs 精化的差距如何拉大（噪声越大精化收益越明显）。
  • 把姿态数降到 6（刚好超定），看 PM 与 Tsai 是否开始分歧（数值差异暴露）。
  • 挑战：为什么 GN 精化要用 SE(3) 对数映射残差而不是直接减矩阵元素？（SE(3) 残差是”流形上的距离”——矩阵元素差不是几何距离，且破坏旋转约束）

八、下一步

进 L2.3 退化 ⭐：当运动不满足”多轴多样”时，上面这些求解器会悄悄失效。
