L4.5 RGB-D 深度标定与对齐（depth bias calibration + depth-color extrinsics）

这是 cali_demo 的 L4 扩展篇第四条，补齐 P2 cali 四主线之「RGB-D」（应用：深度-彩色对齐）。
RealSense/Kinect 等 RGB-D 相机同时给”彩色图 + 深度图”，但两块都需标定：① 深度含系统性偏置（随距离非线性漂移）；② 深度与彩色是两路相机，需外参对齐才能”像素级配准”。
本篇纯 C++17（不依赖 OpenCV），与已落地的六篇 L4 保持”纯标准库”一致。

〇、为什么 RGB-D 必须额外标定

现实 工业场景 不处理的后果
深度偏置 ToF/结构光深度随距离漂移（非线性） 测距 0.5m 准、3m 偏几厘米 → 体积/尺寸检测全错
深度-彩色未对齐 彩色与深度是两颗独立相机（不同视角/光心） 彩色图上的点对应不到正确深度 → 分割/抓取/AR 叠加全错位

重要约定：本篇刻意纯 C++17。深度偏置是标量二次式、外参对齐是刚体变换，从公式实现最直观；OpenCV 对深度偏置标定无现成 API（只有 registerDepth 这种经验对齐）。

一、深度偏置标定（depth bias calibration）

RGB-D 深度的系统性误差常近似为随距离增长的二次式：

  • 物理来源：ToF 飞行时间随距离非线性、IR 强度随距离平方衰减导致相位/相关峰偏移。
  • 标定：用一组已知真值距离 d_i（标定板/靶标置于不同距离）测出 d̃_i，对线性模型 d̃_i = d_i + c·d_i² 最小二乘拟合 c：
  • 校正：反解真深度（二次方程取正根）

二、深度-彩色外参对齐（depth-color extrinsics）

彩色相机相对深度相机有刚体外参 (R, t)。像素级配准要求：深度帧的 3D 点 P_d 经 P_c = R·P_d + t 变换后，投影到彩色图应与彩色相机实际观测一致。

一致性校验（回环重投影）：P_d → 投影深度图 → 反投回 3D → 变换到彩色帧 → 投影彩色图 → 反投 → 逆变换回深度帧，应精确回到 P_d（残差 ~0）。这等价于验证 (R,t) 与两路内参 K 构成的配准链自洽。

五、你会看到什么（已用受管 Python 3.13.12 数值核验 + C++ 控制流镜像复核）

检查 结果 结论
① 真值深度回投误差 0 反投影几何正确
② 未校正偏置明显 4.0e-2 ≥ 1e-2 深度确实含系统性误差
③ 校正后误差 4.0e-15 偏置被精确消除
④ 校正后 ≪ 校正前 4e-15 ≤ 4e-2 校正显著有效

六、自检（PASS/FAIL 含义）

  • 真值回投=0：证明 proj/unproj 互为逆，几何管线正确。
  • 未校正偏置≥1e-2：证明偏置模型确实引入了可观测误差（不是凭空造）。
  • 校正后~1e-15：证明二次反解 + 拟合的 c 完全消除偏置。
  • c≈0.01：证明标定拟合在无噪声下 bit 级精确（真实场景加 RANSAC 见 L3.2）。
  • 外参回环~2e-16：证明深度↔彩色变换链自洽，配准可用。

七、与现有知识库的互引

  • 接 L1.3（内参）：RGB-D 两路相机都需 K，本篇投影/反投影复用针孔模型。
  • 接 L1.5/L2.2（手眼标定）：深度-彩色外参 (R,t) 本质就是一路”手眼”标定问题。
  • 接 L2.6（双目深度）：双目也是”两路相机求深度”，但 RGB-D 用主动测距，且需额外偏置标定。
  • 接 L3.2（鲁棒估计）：真实深度有噪声/丢点，拟合 c 应接 RANSAC 剔除坏距离。
  • 接 L4.3（自标定）：RGB-D 系统同样可借自标定减少对标定板的依赖。

八、下一步建议

  1. 加噪声 + RANSAC（cali_l3_robust）做鲁棒 c 拟合，处理高反光/吸光表面的坏深度。
  2. 用 cali_l1_handeye 的真实流程标定深度-彩色外参 (R,t)，替换本篇合成值。
  3. 把校正后的深度接 cali_l4_structured_light 的点云，做融合 3D 重建。
