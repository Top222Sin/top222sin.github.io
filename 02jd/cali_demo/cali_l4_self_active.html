L4.3 自标定 / 主动标定（self-calibration & active calibration）

这是 cali_demo 的 L4 扩展篇第二条，补齐 P2 cali 四主线之「自标定/主动标定」。
它把 cali_l3_auto_system（L3.3 自动/在线标定系统）里「蜻蜓点水」的主动运动规划章，落到可运行的数学上：
① 自标定——相机绕固定内部结构旋转即可回收内参，无需标定板；② 主动标定——让机器人「主动选运动」，使标定信息量最大、避开 L2.3 退化。
本篇纯 C++17（不依赖 OpenCV），与已落地的 jac_l4_autodiff / ctrl_l4_mpc / ls_l4_lasso / cali_l4_fisheye_rs / cali_l4_lidar_imu 五篇 L4 保持”纯标准库”一致。

〇、为什么这两块是工业刚需

现实 工业场景 不处理的后果
自标定 机器人/无人机相机在作业过程中自转、或手持相机绕光心旋转；无标定板环境（户外/仓储/手术） 传统张正友法必须有标定板；很多现场根本没板、或不想每次摆板。自标定只用「旋转 + 图像对应点」就能估内参
主动标定 / 运动规划 机器人标定臂、自动质检站、SLAM 初始化——需要”采哪几个位姿最优” 沿用 L2.3 的教训：只绕单一轴转 → 某些自由度不可观测（退化）；瞎采浪费时间还标不准。主动规划让每次运动都”信息量最大”

重要约定：本篇刻意纯 C++17。自标定是线性代数（K·R = H∞·K 的线性系统）、主动规划是观测矩阵 AᵀA 的秩/奇异值分析——从公式实现最直观，OpenCV 对此也无现成 API，且本机无 OpenCV 也能验证。

一、自标定原理（旋转相机 → 无穷单应）

相机绕其光心旋转（内部结构固定，只有外参 R 变）：对场景中的无穷远点（或平面场景），单应矩阵退化为

  • 若机器人/云台能给出旋转 R（编码器/IMU/手眼链），且从图像对应点估出 H∞，则 H∞ 只含 K。
  • 关键等式 K·R = H∞·K 对 4 个内参 (fx, fy, cx, cy) 线性（固定 K[2][2]=1 表示投影尺度）：每取一个 (i,j) 元素就得到一条线性方程，3 组异轴旋转即可精确回收全部 4 参数。
  • 这正是”无需标定板”的本质：旋转提供了场景结构之外的独立约束，等价于标定板提供的约束。

为什么不走 IAC（绝对二次曲线像）？

经典文献用 Hᵀ·ω·H = ω（ω = K⁻ᵀK⁻¹）求 ω 再 Cholesky 回收 K。但 ω 病态（条件数 ~1e10，ω₁₁≈4e-6 vs ω₃₃≈1.64），齐次零空间解在双线性重建时数值灾难性抵消（验证中 inv(ω) 直接 ZeroDivisionError）。线性法 K·R=H∞·K 良态（回收残差 ~5.7e-14），本篇采用。

二、主动标定 / D-最优运动规划

把所有 (H, R) 线性方程的系数为行堆成观测矩阵 A，则 AᵀA（4×4，对应 4 个内参）的奇异值/行列式 = 信息量：

  • 同 z 轴旋转（两组都绕光轴）：AᵀA 秩亏（σ_min=0，亏秩=1）——所转的”自由度”在 K 里是耦合不可分的（接 L2.3 退化）。
  • 异轴旋转（z + x，或更充分的 z + x + y）：AᵀA 满秩（σ_min>0.1），4 自由度全部可观。
  • D-最优准则：选使 det(AᵀA) 最大的运动序列。异轴相对同 z 轴的行列式比 > 10×（差一个数量级信息量）；三组异轴比两组信息量更大（det 更大）→ 主动规划让标定更稳更准。

这正是 cali_l3_auto_system（L3.3）”可扩展方向”里”主动运动规划”章的落地数学：系统不该被动接受任意运动，而应主动指令机器人执行异轴旋转。

三、闭环验证思路

四、代码走读（cali_l4_self_active.cpp）

  • 矩阵库：matmul/transpose/matvec/inv3/inv(Gauss-Jordan 任意阶)/jacobi_eig(对称阵特征值)/solve4(4×4)。
  • Hinf(R) = matmul(matmul(K,R), inv3(K))：合成无穷单应。
  • build_lin(H,R)：每个 (i,j) 生成一条线性方程 K·R 与 H∞·K 对应元素之差 = 0，系数线性于 (fx,fy,cx,cy)。
  • recover_K(HRs)：堆叠所有方程 → 法方程 AᵀA·x = Aᵀb → solve4。
  • observ(HRs)：返回 (σ_min, det, 亏秩数)，用于 D-最优分析。
  • 两段 chk：Part A 回收 K + 闭环；Part B 退化/满秩/det 比/三组更优。

五、你会看到什么（已用受管 Python 3.13.12 数值核验 + C++ 控制流镜像复核）

检查 结果 结论
① 回收 fx ≈ 真值 误差 1.71e-13 线性法精确回收
② 回收 fy ≈ 真值 误差 2.27e-13 同上
③ 回收 cx ≈ 真值 误差 5.68e-14 同上
④ 回收 cy ≈ 真值 误差 1.14e-13 同上
⑤ Krec·R1 = H1·Krec 闭环残差 5.68e-14 回收自洽、编码正确

六、自检（PASS/FAIL 含义）

  • 回收误差 <1e-4（实际 ~1e-13）：证明 K·R=H∞·K 线性方程组正确、求解器精确。
  • 闭环残差 <1e-9：证明回收出的 K 与原始 H∞/R 自洽（不是”满足最小二乘但违背几何”）。
  • 同 z 轴亏秩：复现 L2.3 退化的数学根源——只绕单一轴转，K 中部分参数不可分离。
  • 异轴满秩 + det 比 >10× + 三组更优：证明”主动规划异轴旋转”确实让标定信息量更大，是 D-最优准则的可运行示范。

七、与现有知识库的互引

  • 接 L2.3（退化）：本篇 §二 的”同 z 轴亏秩”是 L2.3 退化理论的具体可运行实例（标定板共面 ⇄ 旋转同轴，本质都是观测矩阵秩亏）。
  • 接 L3.3（自动/在线标定系统）：本篇把 L3.3「可扩展方向」里的主动运动规划章落到数学——系统应主动指令机器人执行异轴旋转（反向链接见 cali_l3_auto_system.md）。
  • 接 L1.3（内参标定）：张正友法用标定板；自标定是”无板”路线的补充，二者估的是同一个 K。
  • 接 Jacobian_demo / Least_squares：recover_K 是标准线性最小二乘；可接 GN/LM 做成带噪声的鲁棒版。

八、下一步建议

  1. 把”已知旋转 R”换成真实来源：机器人正向运动学（cali_l1_frames）+ IMU/编码器，做真实自标定。
  2. 把 D-最优准则做成闭环：标定系统自动生成”下一组最优旋转”指令（接 L3.3 的 CalibSystem 框架）。
  3. 加噪声 + RANSAC（cali_l3_robust）把 H∞ 估计做得鲁棒，再喂给 recover_K。
