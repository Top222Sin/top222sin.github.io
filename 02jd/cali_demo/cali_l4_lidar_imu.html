L4 LiDAR-IMU 时空标定（空间外参 + 时间偏移）

这是 cali_demo 的 L4 扩展篇：补齐激光雷达(LiDAR)-IMU 融合最刚需的两块”标定”——空间外参与时间偏移。
现有 17 篇（L1–L3）把”相机-机器人”标定讲透了，但多传感器 LiDAR/IMU 融合的标定是空白（仅 L2.2 手眼 AX=XB 沾边，且只针对相机-机械臂）。
本篇纯 C++17 从公式实现（不依赖 OpenCV），与已落地的 jac_l4_autodiff / ctrl_l4_mpc / ls_l4_lasso / cali_l4_fisheye_rs 四篇 L4 保持”纯标准库”一致。

〇、为什么这是自动驾驶/机器人刚需

现实 工业场景 不标定的后果
空间外参 X = T_L^I LiDAR 与 IMU 刚性固连，二者坐标系差一个刚体变换（旋转 R + 平移 t）；所有融合（LO/SLAM/点云配准）都先要把两路数据统一到同一坐标系 外参差 1°，10 m 外点云就错位 ~17 cm；与相机/车体坐标对不齐，多传感器融合直接崩
时间偏移 Δt LiDAR 与 IMU 各有时钟，触发/曝光不同步（尤其滚动快门、多 LiDAR）；同一物理时刻两传感器”看到”的世界姿态不同 高速运动下（车 30 m/s），10 ms 偏移 → 0.3 m 位置错位；点云”拖影”、LO 残差发散

重要约定：cali_demo 其余 18 篇用 OpenCV。本篇刻意纯 C++17——刚体对齐(SVD)、时间搜索都是标准数值方法，从公式实现最直观，也与四篇 L4 兄弟保持一致、本机无 OpenCV 也能验证。

一、空间外参：Umeyama / Kabsch 刚体对齐

给定 N 对对应点（在 LiDAR 系 P_i、在 IMU 系 Q_i，满足 Q_i ≈ R·P_i + t），求最优 R,t：

关键洞察：直接用 U Vᵀ 可能得到 det = −1 的”反射”解（镜像），物理上不是刚体运动；Umeyama 的反射修正 S=diag(1,1,det(U Vᵀ)) 一行解决。3×3 SVD 用对称矩阵 G=H Hᵀ 的 Jacobi 特征分解即可（无需通用 SVD）。

二、时间偏移：1-D 网格搜索

LiDAR 注册相邻两帧得到相对位姿 A（物体真实相对运动，外参已定后 frame-无关）。IMU 在同一对 LiDAR 时间戳 t1,t2 处、假设时间偏移 Δt̂ 时预测的相对位姿为 B(Δt̂) = T_imu(t1+Δt̂, t2+Δt̂)。两者一致当且仅当 Δt̂ = Δt_true：

关键洞察：刚性螺旋运动 T(τ)=[Rz(ωτ)|(vτ,0,0)] 下，相对平移项含 Rz(ωΔt)·(v·t1,0,0)，对绝对时刻 t1+Δt 敏感 → Δt 偏一点残差就涨，1-D 搜索即可精确回收。

三、两者如何协同（联合）

空间外参 X 与时间偏移 Δt 必须一起标定：把 X 嵌入 A_lidar = X⁻¹·T_imu(t1+Δt,t2+Δt)·X，残差仍在正确的 Δt 处最小（相似变换不改变残差）。工程上先粗标空间（手眼/标定板），再精修时间偏移（或联合优化），本篇用 §二/§三 演示这条链路。

四、代码走读（cali_l4_lidar_imu.cpp）

  • jacobi_eigen：对称 3×3 Jacobi 特征分解（经典旋转扫掠），给 H Hᵀ 求 U 与特征值；套公式得 V，即 3×3 SVD。
  • umeyama：按 §一 五步求 R,t，含反射修正。
  • T_rel / pose_mul / pose_inv / rel_residual：SE(3) 螺旋运动模型与残差。
  • 三段 chk 逐步验证（A 空间 / B 时间 / C 联合），全部 PASS/FAIL 打印。
  • 全程用一个固定种子 LCG 生成真值与噪声，保证 C++ 与受管 Python 验证脚本逐位复现。

六、自检（PASS/FAIL 含义）

  • A1 零噪声恢复误差 <1e-9：证明 umeyama 的 SVD + 反射修正确实给出精确刚体变换（不是近似）。
  • SVD 重建残差 <1e-9 且 U/V 正交：证明自实现的 3×3 SVD（Jacobi）数值正确，是 A1 正确的根因。
  • A2 带噪重建误差 <3×noise：证明噪声下仍给出一致估计（误差只来自噪声，不发散）。
  • B/C 时间偏移回收误差 <0.002：证明 1-D 网格搜索能精确找回注入的 50 ms 偏移，且嵌入外参后结论不变。

七、与现有知识库的互引

  • 接 L2.2（手眼标定数学 / AX=XB）：手眼求的是相机-机械臂外参；本篇是”LiDAR-IMU 外参 + 时间”的兄弟篇，本质都是多传感器刚体标定，但本篇多了时间维与在线滚动搜索。
  • 接 Jacobian_demo L3.7（多动力学模型 / 灵敏度）：时间偏移本质是”运动模型对时间戳的灵敏度”，可用自动微分求 ∂残差/∂Δt。
  • 接 control_demo L4.1（MPC）：高速平台（车/无人机）的 LiDAR-IMU 融合是 MPC 状态估计的输入，时间未对齐会污染预测。
  • 接 KF_demo（EKF/ES-EKF）：LiDAR-IMU 时空标定是紧耦合 SLAM/LO 前端，其后才是 KF 状态估计。

八、下一步建议

  1. 把 umeyama 接到 L2.2 的 AX=XB：用真实的”LiDAR 里程计相对运动 vs IMU 预积分相对运动”做 hand-eye 求 X。
  2. 把时间偏移 Δt 作为待估参数，写进一个最小二乘/BA 求解器（参考 Least_squares_method_demo），做时空联合优化。
  3. 用 Jacobian_demo/jac_l4_autodiff 自动求 ∂残差/∂Δt，把 1-D 搜索升级为 GN/高斯牛顿精修。
