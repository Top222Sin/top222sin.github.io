L4.6 多相机 rig（环视 BEV 拼接 + 回环一致性）

这是 cali_demo 的 L4 扩展篇第五条（最后一条），补齐 P2 cali 四主线之「多相机 rig」（应用：环视 surround-view / BEV 拼接）。
自动驾驶/AGV 用 4~6 路相机环绕做 360° 环视拼接——这是标定在「多相机系统」上的工程落点。
本篇纯 C++17（不依赖 OpenCV），与已落地的七篇 L4 保持”纯标准库”一致。

〇、为什么多相机 rig 是工业刚需

现实 工业场景 不处理的后果
多相机外参需自洽 环视/全景需把多路相机统一到 rig 坐标系 外参标错 → 拼接画面错位、重影、尺度跳变
回环一致性 相机绕 rig 成环，相邻外参应闭合 回环不闭合 = 标定有误差累积，BEV 拼接边缘对不齐
逆透视 IPM 把每路图像地面像素投回统一地面 → 俯视 BEV 不做 IPM 就无法拼成”上帝视角”环视

重要约定：本篇刻意纯 C++17。刚体变换 SE3、透视投影、地面平面求交都是标准几何，从公式实现最直观；OpenCV 对多相机 rig 的回环一致性无现成 API。

一、多相机 rig 外参与回环闭合

4 相机环绕 rig，各有外参 T_i : rig→cam_i（旋转 R_i + 平移 t_i，几何一致 t_i = −R_i·cam_pos_i）。
相邻相机相对位姿 rel(i→i+1) = T_i⁻¹·T_{i+1}。沿环走一圈应回到单位变换：

若不闭合（R≠I 或 t≠0），说明某相机外参标错、误差沿环累积——BEV 拼接会在此处错位。回环闭合是标定质量的硬判据（接 L2.3 退化/一致性）。

二、逆透视映射 IPM 与 BEV 拼接

单路相机把地面点 G=(X,Y,0)（rig 系）投影到像素 (u,v)；反推——给定像素 (u,v)，其射线 K⁻¹(u,v,1) 与地面 z=0 的交点即该像素对应的地面位置：

各相机各自做 IPM，把地面像素投回统一 rig 地面，即得环视 BEV。跨相机一致性要求：同一 rig 地面点，被多相机看到时，各相机 IPM 还原出的坐标必须相同（否则拼接对不齐）。

四、代码走读（cali_l4_multicam_rig.cpp）

  • 矩阵/SE3 库：matmul/transpose/matvec + se3_mul/se3_inv/apply_se3（刚体变换）。
  • rot_z/rot_x：合成各相机朝向（朝外 + 向下俯仰 120°）。
  • proj：针孔投影；ipm_to_ground：像素射线与地面求交（先 se3_inv 把射线点变换回 rig 系）。
  • 四段 chk：回投 / 回环旋转 / 回环平移 / IPM 回环 / 跨相机共享点 / 跨相机偏差。

五、你会看到什么（已用受管 Python 3.13.12 数值核验 + C++ 控制流镜像复核）

检查 结果 结论
① 世界点回投自洽 2.8e-16 投影↔反投互为逆，外参正确
② 回环闭合 旋转=I 3.3e-16 4 相机外参沿环自洽
② 回环闭合 平移=0 4.4e-16 无误差累积
③ IPM 回环像素误差 1.1e-13（100 样本） 逆透视精确可逆
④ 跨相机共享地面点 37 个 多相机视野重叠（可拼接）
④ 跨相机 BEV 偏差 8.9e-16 同一地面点各相机还原一致

末尾打印 PASS=6 FAIL=0 → [PASS] 多相机 rig 全部验证通过。

六、自检（PASS/FAIL 含义）

  • 回投 ~1e-16：证明 SE3 变换与投影/反投影正确，外参几何一致。
  • 回环 ~1e-16：证明 4 相机外参沿环闭合，无累积误差（标定质量硬判据）。
  • IPM ~1e-13：证明逆透视精确，像素↔地面可互逆（BEV 拼接的基础）。
  • 跨相机 37 共享点、偏差 ~1e-16：证明重叠区地面点各相机还原一致，拼接无缝。

七、与现有知识库的互引

  • 接 L1.5/L2.2（手眼标定）：每个相机外参 T_i 本质就是一路”相机↔rig”的手眼标定。
  • 接 L2.3（退化）：回环不闭合常源于某相机标定退化/数据不足，是退化在多相机系统的表现。
  • 接 L4.3（自标定）：多相机 rig 可用自标定减少对标定板的依赖。
  • 接 L4.5（RGB-D 对齐）：RGB-D 是两路相机对齐，rig 是多路——同一”外参一致性”主题。
  • 接 L3.3（自动/在线系统）：环视系统需自动标定 + 在线再标定，回环一致性是自动质检指标。

八、下一步建议

  1. 加噪声 + 回环约束做 BA（Bundle Adjustment），把”回环闭合”作为优化残差（接 Least_squares_method_demo）。
  2. 接 cali_l3_robust（RANSAC）剔除坏对应点，做鲁棒多相机联合标定。
  3. 把 IPM 输出接成真实 BEV 鸟瞰图（图像逆变换 + 多路融合），做成可用环视 demo。
