cali_demo —— 机器人/视觉标定系统学习目录

本目录是「NEON（ARM 后端）→ CUDA（GPU 后端）→ 标定（机器人与视觉的几何地基）」三步学习法的第三站。
与 neon_demo/、cuda_demo/ 平级，沿用同一套 L1/L2/L3 三级递进 + 每个知识点落成「可运行 .cpp + 配套 .md（含内联 SVG）+ _diagrams.html 预览 + images/ 矢量图」 的约定。

当前阶段：全部已落成 ✅。 共 23 篇（L1×7 + L2×6 + L3×4 + L4×6），每篇均为自包含、可编译运行的 .cpp（合成数据 + 真值对拍 + PASS/FAIL）+ 配套 .md（含内联 SVG）+ _diagrams.html 预览 + images/*.svg。无需真机即可验证算法正确性。

〇、运行环境约定（重要，决定 demo 怎么写）

  • 语言/库：C++17 + OpenCV（与 NEON/CUDA 的 C++ 主线一致，且跨 Linux/Windows）。
  • 无真机也能跑：每个 demo 自带 合成数据生成器（用已知真值 X、K、TCP 反推观测位姿 + 加可控噪声），跑完把「恢复值 vs 真值」做误差对拍并打印 PASS/FAIL。这复刻了 cuda_demo 的「CPU 对拍」风格——标定不需要真机器人/真相机即可验证算法正确性。
  • OpenCV 依赖：calib3d（solvePnP / calibrateCamera / calibrateHandEye）、core、imgproc。无图形界面要求，CI 友好。
  • 构建：每个 .cpp 均可 g++（Linux）或 cl（MSVC）/ MinGW 直接编译；目录根提供 CMakeLists.txt 一键构建全部。
  • 与已有两份 guide 的关系：根目录 camera_calibration_guide.md（单/双目标定、张正友法、立体校正）与 hand_eye_calibration_guide.md（眼在手外/上、AX=XB、Tsai-Lenz、OpenCV 流程）是原理底稿，本目录在其之上补齐：① L1/L2/L3 分级 ② TCP 标定 / 标定板 / 退化 / 误差校验 / 验证 这些 guide 未系统覆盖的块 ③ 全部改成「可运行 demo + 合成数据对拍」。

L4.4 结构光 3D 扫描 看懂并复现 N 步相移轮廓术 N 步相移 Iₙ=A+B·cos(2π·p_cam/P+2πn/N)；包裹相位 φ_w=atan2(ΣIₙsin,ΣIₙcos)=−θ；参考平面解包裹 m=round((p_flat−p_w)/P)；高度 h=(p_est−p_flat)/k，凸起峰值≈2.0、平坦面≈0 cali_l4_structured_light.cpp + .md + _diagrams.html ✅ 已落成
L4.5 RGB-D 深度校正 + 彩色对齐 修深度偏置、对齐彩色图 深度二次偏置 d_meas=d_true+c·d_true²；标定 c=Σ(d̃−d)·d²/Σd⁴、校正 d_true=(−1+√(1+4c·d_meas))/2c（校正后误差 ~4e-15）；深度-彩色刚体外参 (R,t) 回环重投影自洽 cali_l4_rgbd.cpp + .md + _diagrams.html ✅ 已落成
L4.6 多相机 rig 环视（BEV） 4 相机环绕外参 + 逆透视拼接 4 相机环绕 SE3 外参 T_i(rig→cam_i)，几何一致 t_i=−R_i·cam_pos_i；回环闭合 cam0→1→2→3→0=I；IPM 逆透视（像素射线与地面 z=0 求交，先 se3_inv 回 rig 系）；跨相机共享地面点一致性 cali_l4_multicam_rig.cpp + .md + _diagrams.html ✅ 已落成
