单目标定（Monocular）· 端到端闭环与”标定的价值”

L1.3 让你跑通张正友法得到 K+畸变，L2.1 讲清误差从哪来。本篇把两者”收口”——不仅验证”标得准”，还量化”标定到底有啥用”。

一、单目标定到底产出什么

单目标定（monocular / single-camera calibration）就是求一个相机的内参 K 与畸变 D：

  • 张正友法（见 L1.3 内参标定）用它解出 K 与畸变；
  • 误差来源（姿态覆盖、角点精度、模型阶数）见 L2.1 内参深入。
  • 本篇是这条线的端到端验收：合成真值 → 反估 → 对拍真值 → 顺便证明”不标定会很糟”。

二、为什么还要单独写一个”端到端”demo

L1.3 已经能恢复 K、畸变、RMS。但有个问题没回答：标定为啥必须做？ 不标定直接用相机行不行？

直觉上，相机像素宽高差不多等于焦距量级——有人会想”拿图像尺寸当 K 凑合得了”。本 demo 用一组对照把这件事说死：

方案 内参 重投影 RMS
标定后 反估的 K、畸变 ≈ 角点噪声（~0.6 px）
不标定（naive） fx=fy=图像宽、主点=中心、零畸变 大得多（数 px 甚至十 px）

差距就是”标定的价值”。

naive 内参为什么错得离谱（量化）

工程结论：内参错误不报错、不显眼，但会系统性污染所有下游 3D 结果（PnP、手眼、双目）——这就是”标定必须做”的终极理由（L2.5 的”系统性 vs 随机残差”正是识别这类错误的工具）。

三、代码走读（cali_l1_monocular.cpp）

  1. 用真值 Kgt、dgt + 24 个随机姿态，projectPoints 合成 2D 角点并加 0.6 px 噪声。
  2. calibrateCamera 反估 Kc、Dc，记录各图 rvecs/tvecs（外参）。
  3. 真值对拍：K 相对误差<5%、畸变误差<0.05、RMS<2px → 标得准。
  4. 价值验证：用同一批外参，分别拿 Kc/Dc（标定后）和 naive 针孔 Kn/Dn（标定前）把 3D 点投影回像素，和观测点求距离：
    • 标定后 RMS（calRMS）应≈ 角点噪声量级（仅噪声）；
    • naive RMS（naiveRMS）应远大于它（K 错 + 没去畸变）；
    • 判定 naiveRMS > 3×calRMS → 标定确实显著降低误差（方向别写反！）。
  5. 全部满足才 PASS。

这正是下游算法（PnP、SLAM、手眼、双目）强依赖单目标定的原因：一个错的内参会系统性地把所有 3D 结果带偏。

四、与双目标定的关系

单目标定是双目标定的前置：双目要先各自单目标定得到稳定 K、再 stereoCalibrate(..., CALIB_FIX_INTRINSIC, ...) 固定内参去求两相机相对位姿。没有可靠的单目内参，双目必发散（见 L1 双目标定基础）。

误差传递链（为什么单目是地基）

一句话：单目标定是整条链的第一块多米诺——它稳，后面才可能稳；它偏，后面全偏（L2.5 误差校验会量化每一环）。

五、工程落点（真实项目）

  • OpenCV 标定示例：camera_calibration 的官方流程 = 本 demo 的”采集→标定→RMS”三步。
  • ROS 相机驱动：usb_cam/realsense 加载 calibration.yaml 后 undistort 图像——去畸变是下游所有视觉算法的前提。
  • PX4 视觉着陆/避障：机载相机 K/D 标定后，AprilTag/光流/深度估计才有正确几何。
  • Kalibr：视觉惯性标定（相机-IMU 外参）的第一步就是单目标定——它的 camchain.yaml 就是本 demo 的产物。

六、自检

  • 把噪声从 0.6 px 调到 3 px，看 naiveRMS/calRMS 比值是否仍 >> 1（标定价值对噪声鲁棒）。
  • 把 Kn 的焦距故意设成真值的 0.5 倍，看 naiveRMS 进一步爆炸——直观感受 K 偏差的破坏力。
  • 挑战：为什么”标定后 RMS≈噪声”而不是 0？（标定是拟合，残差下限 = 角点检测噪声——RMS 接近噪声说明模型对、没过拟合）

七、下一步

进 L1 双目标定基础：两个标定好的相机如何拼在一起、求相对位姿、对齐极线。
