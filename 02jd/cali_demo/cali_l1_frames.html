L1.1 坐标变换与刚体变换基础

标定要解决的核心问题只有一个：把”相机看到的”和”机械臂知道的”放进同一个坐标系。
这第一步不晕坐标，后面手眼标定、TCP 标定全是它的延伸。

一、标定涉及的四大坐标系

坐标系 符号约定 说明
世界 / 标定板系 target 标定板所在，作为参考真值
相机系 cam 原点在光心，Z 轴沿光轴
机器人基座系 base 机械臂控制器知道的”家”
工具 / 末端系 gripper 法兰盘或手爪，TCP 在其上

记号约定（全文统一）：T_A2B 表示把 A 系坐标变换到 B 系的矩阵（A 在 B 下的位姿）：

记号易混淆提醒：有的资料写 T_AB 表示”A 到 B 的变换”（方向同本文），有的写”B 在 A 下的位姿”（方向相反）——读任何手眼标定代码前，先确认它的记号约定，否则 AX=XB 的方向会差一个对称。本文的检验法：T_A2B 的”上标”是源系 A、”下标”是目标系 B；链式复合时，左侧矩阵的目标系 = 右侧矩阵的源系（B2C 的目标 C 接 A2B 的源 A 之间靠 B 衔接）。

二、齐次变换矩阵 T = [R t; 0 1]

刚体位姿用一个 4×4 矩阵表示：

三条铁律（务必记牢，按本文 T_A2B 记法）：

  • 点变换：p_B = T_A2B · p_A（A 系点 → B 系坐标）
  • 复合：T_A2C = T_B2C · T_A2B（先 A→B 再 B→C，左乘）
  • 求逆：T_A2B⁻¹ = T_B2A = [ Rᵀ -Rᵀ·t ; 0 1 ]（闭式最直观且严格保持刚体结构；cv::invert SVD 版是通用矩阵求逆，不保证 SO(3) 结构，逆变换优先用闭式）

本 demo 的测试 3 就验证了坐标链：
T_target2base = T_gripper2base · T_cam2gripper · T_target2cam

复合顺序的推导（为什么”从右往左乘”）

记忆口诀：链式变换从右往左读，左侧矩阵的目标系 = 右侧矩阵的源系（T_cam2gripper 的目标 gripper 接 T_gripper2base 的源 gripper）。写链时把”谁在谁的系里”标出来，错不了。

三、四种旋转表示（何时用哪个）

表示 参数 优点 典型用途
旋转矩阵 R 9 直接构造变换，无奇点 内部计算、组装 T
轴角 / 旋转向量 3（轴×角） 紧凑、连续、OpenCV 默认 Rodrigues 互转、优化变量
四元数 q 4（w,x,y,z） 无万向锁、球面插值稳 姿态插值、SLAM、滤波
欧拉角 3（yaw/pitch/roll） 人类可读 示教器显示、调试

关键认知：欧拉角有奇点（万向锁），优化和组合变换里永远用 R / 四元数 / 旋转向量，欧拉角只用于”给人看”。

旋转表示的选择决策表（面试高频）

工程结论：机器人/视觉代码内部清一色 R 和四元数，欧拉角只在 UI 层出现——你在 UR5e 仿真项目 的 URDF/控制器里看到的姿态几乎全是四元数或旋转矩阵。

四、代码走读（cali_l1_frames.cpp）

  • randPose()：小幅随机旋转（Rodrigues）+ 随机平移，造一个 T。
  • inv44() / applyPose()：求逆、点变换。
  • rvec2quat / quat2R / R2euler / euler2R：四种表示的互转（手写，看清数学）。
  • 三个测试：① T·T⁻¹=I（20 组）② 旋转表示互转闭环（20 组）③ 坐标链一致性。
  • 全部 norm(err) < 1e-6 才打印 [PASS]。

五、工程落点（真实项目）

  • OpenCV cv::Rodrigues（旋转向量↔矩阵）、cv::composeRT（链式组合）、cv::invert（SVD 求逆）——本 demo 的互转/求逆全部有 OpenCV 对应函数。
  • Eigen Isometry3d / AngleAxis / Quaterniond：机器人代码里的事实标准（URDF 解析、moveit 全是它）。
  • **ROS tf2**：transform 消息、lookupTransform、doTransform——坐标系图（frame graph）的运行时管理，标定结果最终发布为静态 tf。
  • UR/协作臂 SDK：get_actual_tcp_pose 返回的就是 T_tcp2base（工具在基座下的位姿）——与本文 T_A2B 记号一致。

六、自检

  • 改 randPose() 的旋转角到接近 π，看欧拉互转是否出现数值抖动（体会奇点）。
  • 把坐标链顺序写错成 T_cam2gripper · T_gripper2base · T_target2cam，测试 3 是否立刻 FAIL（验证你真的懂左乘顺序）。
  • 挑战：T_ab 的逆为什么是 [Rᵀ, −Rᵀt]？（因为逆变换 = 把 b 系坐标变回 a 系——R 的转置是旋转的逆，−Rᵀt 是”原点的位移”在新系下的坐标）
