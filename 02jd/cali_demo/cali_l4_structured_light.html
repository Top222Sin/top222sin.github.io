L4.4 结构光 3D 扫描（structured light / phase-shifting profilometry）

这是 cali_demo 的 L4 扩展篇第三条，补齐 P2 cali 四主线之「结构光」（应用：3D 扫描）。
单台相机 + 一台投影仪即可对物体做高精 3D 重建——工业检测、模具/人脸扫描、流水线体积测量都靠它。
本篇纯 C++17（不依赖 OpenCV），与已落地的五篇 L4（jac_l4_autodiff/ctrl_l4_mpc/ls_l4_lasso/cali_l4_fisheye_rs/cali_l4_lidar_imu/cali_l4_self_active）保持”纯标准库”一致。

〇、为什么结构光是工业 3D 刚需

现实 工业场景 不处理的后果
单目无深度 普通相机只有 2D，没有距离 无法做尺寸检测、体积计量、逆向建模
双目在弱纹理失效 白墙、均匀工件、反光面 → 立体匹配找不到对应点 双目（L1.7/L2.6）在这些表面直接”瞎”
结构光主动投影纹理 投影仪把已知条纹打到物体上，主动制造”纹理” 任意表面都能可靠求得对应点与深度

重要约定：本篇刻意纯 C++17。相移解码是标准三角函数（atan2 + 查表），从公式实现最直观；OpenCV 的 structured_light 模块 API 繁琐且本机无 OpenCV 也能验证。

一、相移轮廓术原理（phase-shifting profilometry）

投影仪投一组正弦条纹，每张图相位偏移固定步长：

  • p_cam(u,v) = 相机像素 (u,v) 看到的投影列；P = 条纹周期（投影列/周期）。
  • 对 N 步相移图做标准解码，得到包裹相位 φ_w = atan2(Σ Iₙ·sin(2πn/N), Σ Iₙ·cos(2πn/N))。
  • 本篇 N=4：解码结果 φ_w = −θ（mod 2π），θ = 2π·p_cam/P → 反解 p_cam 仅需解包裹。

解包裹（unwrapping）

包裹相位只在 (−π, π] 内，要恢复绝对相位需消掉整周期 2π。工业标准做法：先采一张参考平面（无物体），其投影列映射 p_flat(u) 已知；用 round((p_flat(u) − p_w)/P) 定整周期倍数 → 绝对投影列 p_est。

二、高度恢复（3D 重建）

物体表面高度 h(u,v) 使投影列相对参考平面偏移：p_cam(u,v) = p_flat(u) + k·h(u,v)（k = 高度→相位位移比例，由系统几何决定）。于是

p_est 直接给出每个相机像素对应的投影列 → 结合投影仪-相机三角测量即可反算 3D 点。本篇用合成高度场（高斯凸起峰值 2.0）验证恢复精度。

三、闭环验证思路

四、代码走读（cali_l4_structured_light.cpp）

  • p_flat / height / p_cam：合成参考平面映射、真值高度场（高斯凸起）、含物体的投影列。
  • captured_pcam(pc,n)：第 n 步相移强度（合成观测）。
  • raw_phase_pcam(pc)：atan2(ΣIₙsin, ΣIₙcos) 解码包裹相位。
  • unwrap_pcam(pc,u)：用 p_flat 解包裹得绝对投影列。
  • 五段 chk：高度恢复误差 / 平坦面≈0 / 凸起峰值 / 包裹相位精确 / 无整周期跳变。

五、你会看到什么（已用受管 Python 3.13.12 数值核验 + C++ 控制流镜像复核）

检查 结果 结论
① 高度恢复 最大误差 1.97e-14 bit 级精确（解码+解包裹正确）
② 平坦平面恢复高度 7.1e-15 ≈ 0 无物体时反算高度为 0，无伪凸起
③ 凸起峰值 2.0000（真值 2.0） 峰高恢复精确
④ 包裹相位解码 = wrapped(−θ) 1.22e-15 解码公式正确
⑤ 解包裹无整周期跳变 最大跳变 2.07 ≪ 周期 24 相邻像素连续，无相位断裂

末尾打印 PASS=5 FAIL=0 → [PASS] 结构光 全部验证通过。

六、自检（PASS/FAIL 含义）

  • 高度恢复误差 ~1e-14：证明相移解码 + 解包裹链路精确，无累积误差。
  • 平坦面 h≈0：证明参考平面解包裹正确，不会”凭空造出”高度。
  • 峰值 2.0 精确：证明局部高度对比（3D 形貌）可还原。
  • 包裹相位 = wrapped(−θ)：证明 4 步解码公式实现无误。
  • 无整周期跳变：证明解包裹在空间上连续（真实系统靠空间连续性+参考平面消歧，本篇用参考平面法）。

七、与现有知识库的互引

  • 接 L2.6（双目校正/深度）：双目在弱纹理失效；结构光用主动投影”造纹理”，是其互补方案。
  • 接 L1.3（内参）：解码得到的是投影列/相机像素，最终三角测量仍需 K（投影仪与相机内参）。
  • 接 L4.3（自标定）：结构光系统同样需要先标定投影仪+相机内参/外参，自标定可提供无板约束。
  • 接 Least_squares_method_demo：多频/多周期外差解包裹本质是分阶段最小二乘。

八、下一步建议

  1. 加噪声 + 多周期外差（multifrequency heterodyne）做大动态范围绝对相位解算。
  2. 把 p_est 经投影仪-相机三角测量转成真实 3D 点云（需投影仪内参/外参，接 L1.3）。
  3. 接 cali_l3_robust（RANSAC）处理高光/遮挡导致的坏相位点。
