跨仓同构对照：MIMO 解耦 =「把耦合提前减掉」

跨仓同构对照：MIMO 解耦 =「把耦合提前减掉」

两仓共享同一范式：用 DC 增益逆预补偿器 D = K(0)⁻¹ 把多变量对象在直流严格对角化，使 D·K = I——等于在控制量送入对象之前，把交叉耦合预先减掉；之后每条回路退化为独立 SISO，可单独整定。这条主线在 control_demo 与 pid_demo 各落了一版，本文把二者钉在同构框架下对照。

  • 控制仓：control_demo L4.5 MIMO 静态解耦（开环、稳态对角化验证）
  • PID 仓：pid_demo L4.7 MIMO PID（闭环、加 PID、瞬态抑制验证）

一、同构对照表

维度 control_demo L4.5 pid_demo L4.7 同构点
解耦器 D = K⁻¹，K=(I−A)⁻¹B D = Kss⁻¹，Kss=(I−A)⁻¹B 完全相同：D = K(0)⁻¹
对角化目标 D·K = I（残差 1.57e-16） D·Kss = I 严格对角化
对象维度 2×2，K=[[1,0.5],[0.3,1/3]] 2×2，K=[[1,0.3],[0.5,1]] 同结构、不同数值
预补偿位置 u = D·r（开环，无控制器） u = D·u_loop，u_loop=各路 PID 都先乘 D 再进对象
验证焦点 稳态交叉响应 y₂：0.300 → 0 瞬态交叉耦合峰值 y₂：0.1479 → 0.0000 都证明交叉耦合被压到≈0
关键洞察 直流对角化可行 对角化后各路可独立整定；解耦价值在抑瞬态（稳态已被积分器消掉） 互补成完整方法论
耦合比 下降 >100× 峰值降 >100× 量级一致

二、为什么是「把耦合提前减掉」

解耦器的数学本质就是逆增益预补偿。设对象直流增益 K，希望「参考 r 经补偿后直接映射到输出 y」：

D=K⁻¹ 就是那块「提前减掉耦合」的前置模块：它把原本非对角的 K 在直流拧成对角的 I，于是 u₁ 只影响 y₁、u₂ 只影响 y₂，调一路再不会「带跑」另一路。

三、差异与互补：开环验证 vs 闭环验证

两仓不是重复，而是同一范式的两个层次：

  • control_demo L4.5 = 证明「对角化本身可行」（开环、无控制器）。只验证 u=D·r 时稳态 y₂ 从 0.300 掉到 0，交叉耦合比降 >100×。它回答的是「解耦器数学对不对」。
  • pid_demo L4.7 = 证明「对角化后能干活」（闭环、各对角回路套 PID）。它进一步发现：有积分器时，稳态交叉耦合本来就已被本回路积分器消除（r₂=0 强迫 y₂→0），所以解耦器的真正价值在抑制瞬态交叉耦合——峰值 0.1479 → 0.0000。它回答的是「解耦 + 闭环动态到底好在哪」。

拼起来就是完整方法论：① 先 D=K⁻¹ 对角化（control 仓证其成立）→ ② 再在对角回路上独立整定 PID（pid 仓证其实用价值在抑瞬态）。

四、可复用范式（两仓一致）

  • 显式构造严格对角化闭环：D = inv((I−A)⁻¹B)，断言 matnormF(D·K − I) < 1e-12。
  • 手写小矩阵库：eyeM / matmul / matsub / matvec / inv(Gauss-Jordan) 在 control 与 pid 两仓逐字同构，纯 C++17 不依赖第三方。
  • 稳态 vs 瞬态要分清：断言交叉耦合时，稳态耦合（有积分器）已被消除，必须测瞬态峰值才有区分度——这是 pid L4.7 的关键修正点。

五、应用映射

  • 控制仓侧重多变量产线 / 半导体多区温控 / 精馏塔 / 双轴平台（强耦合 MIMO，对角化后各轴独立）。
  • PID 仓侧重多回路暖通 / 家电 / 高精度伺服（每路一个 PID，解耦后互不干扰）。
  • 本质同一套「先对角化、后分回路整定」，只是对象与控制器形态不同。
