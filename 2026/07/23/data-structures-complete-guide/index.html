十一、STL 容器对比总表

11.1 容器特性对比

容器 底层结构 元素有序 迭代器失效规则 内存连续性
array 定长数组 插入顺序 — ✅ 连续
vector 动态数组 插入顺序 realloc 时全失效，中间插入/删除后移 ✅ 连续
deque 分段连续块 插入顺序 前端/后端插入时不失效，中间插入全失效 ❌ 分段连续
list 双向链表 插入顺序 只影响被操作的节点 ❌ 离散
forward_list 单向链表 插入顺序 只影响被操作的节点 ❌ 离散
set/map 红黑树 按 key 排序 插入不失效，删除只影响被删节点 ❌ 离散
multiset/multimap 红黑树 按 key 排序 同上 ❌ 离散
unordered_set/map 哈希表 无顺序 rehash 时全失效 ❌ 桶内链表
stack deque 适配 LIFO — —
queue deque 适配 FIFO — —
priority_queue vector 适配堆 按优先级 — —

11.2 时间复杂度对比

操作 vector deque list set/map unordered_set/map
前端插入/删除 O(n) O(1) O(1) — —
后端插入/删除 O(1) amortized O(1) O(1) — —
中间插入/删除 O(n) O(n) O(1) O(log n) O(1) avg
按值查找 O(n) O(n) O(n) O(log n) O(1) avg
按索引访问 O(1) O(1) O(n) — —
排序 O(n log n) O(n log n) O(n log n) 自动有序 不排序
迭代 O(n) O(n) O(n) O(n) O(n)

11.4 容器选用内存占用（近似，因实现而异）

容器 每个元素额外开销 说明
vector 0（连续，额外 capacity 空间） 内存效率最高
deque ~8 字节 block 管理 分段连续
list ~16 字节（prev + next 指针） 每个节点额外 16B
forward_list ~8 字节（next 指针） 最省内存的链表
set/map ~24 字节（parent + left + right + color） 红黑树节点
unordered_set/map ~8 字节 + 桶数组 链表 + 桶
