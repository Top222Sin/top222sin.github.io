1.2 核心概念（第一周）

概念 类比（CPU 转 GPU） 关键理解
Host vs Device CPU = 总经理, GPU = 千人工厂 host 调度，device 执行
Kernel 工厂的生产流程单 用 __global__ 声明，<<<grid,block>>> 调用
Grid 工厂的订单批次 所有线程的集合
Block 一个班组 可共享内存、可同步（__syncthreads()）
Thread 一名工人 threadIdx, blockIdx, blockDim, gridDim
Warp 流水线上的 32 人小组 硬件执行单位，32 个线程同时执行同一条指令

4.2 cuDNN

cuDNN 是 NVIDIA 专门为深度学习优化的库，提供了高度优化的卷积实现。

cuDNN 的算法选择：

算法 适用场景 特点
IMPLICIT_GEMM 通用 im2col + Sgemm，内存占用大
IMPLICIT_PRECOMP_GEMM 通用 预计算 im2col 索引，省内存
GEMM 通用 显式 im2col，速度最快但最耗内存
DIRECT 小卷积核 直接卷积，不需 workspace
FFT 大卷积核（≥7×7） FFT 变换，O(N log N)
WINOGRAD 3×3, 5×5 Winograd 变换，乘法量最少
WINOGRAD_NONFUSED 3×3 非融合版 Winograd

你的 manual_cuda.cu 手写卷积 ≈ DIRECT 算法，是最简单但性能最低的。

常见瓶颈解读：

Stall 原因 含义 解决方向
stall_long_scoreboard 访存延迟，等待数据从全局内存到达 用共享内存、改善合并访问
stall_short_scoreboard 短延迟，通常是 L1/L2命中后的延迟 增加指令级并行度

stall_math_pipe 计算 pipe 吃满 计算密集型，已优化到位
